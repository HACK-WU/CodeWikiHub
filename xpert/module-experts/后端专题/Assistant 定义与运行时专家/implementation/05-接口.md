## 1 全局前缀与路由装配

- 全局前缀：`app.setGlobalPrefix('api', { exclude: [...] })`（排除 `a`、`a/(.*)`、`.well-known/oauth-protected-resource/(.*)`）。下列所有路径均为完整路径。
- 每个模块通过 `RouterModule.register([{ path, module }])` 追加模块前缀；`XpertMarketplaceModule` 与 `EnterpriseChatkitModule` 不注册 RouterModule，前缀由 controller 自带路径段承担。

```mermaid
graph LR
  C[Client] --> API[/api]
  API --> XP["/api/xpert — XpertModule"]
  API --> EK["/api/xpert/:identifier/enterprise-h5 — EnterpriseChatkitModule"]
  API --> AI["/api/ai — AIModule"]
  API --> WS["/api/xpert-workspace"]
  API --> AB["/api/assistant-binding"]
  API --> TP["/api/xpert-template"]
  API --> MK["/api/xpert-marketplace + /api/xpert-access-requests"]
  API --> EV["/api/environment"]
```

## 9 鉴权与凭证受众约定

- `@Public()`：关闭全局 JWT 守卫，**不等于**匿名可用；是否放行由该路由的附加守卫与装饰器决定。
- `@Public()` + `ApiKeyOrClientSecretAuthGuard` + `@AllowClientSecretBindings(SecretTokenBindingType.ENTERPRISE_XPERT)`：企业 ChatKit 受众面（`/api/ai/assistants`、`threads`、`conversations`、`contexts`、`workspace-files`、`connectors` 等）。`AssistantsController` 在类上同时具备三者，因此该类全部端点都靠守卫兜底。
- `@Public()` + `ApiKeyOrClientSecretAuthGuard`（无绑定装饰器）：`/api/ai/store`、`/api/ai/knowledges`、`/api/ai/v1/*`、`/api/ai/mcp-apps`、`/api/ai/sandbox/*`、`threads/:threadId/voice`、`assistants/:assistantId/workspace`；群工作台额外声明 `USER_CONVERSATION`。
- `XpertGuard`：创作侧助手准入。命中规则为 `xpert.createdById === user.id` 或 `workspaceService.canAccess(xpert.workspaceId, user.id)`，否则 `ForbiddenException('Access denied')`；结果按 `userXperts:<tenantId>:<userId>_<xpertId>` 缓存 5 分钟。
- `WorkspaceAuthoringGuard`（`request.params.workspaceId` → `assertCanAuthor` = `assertCanWrite`）与 `WorkspaceOwnerGuard`（→ `assertCanManage`）：工作区创作/管理面；前者先做 UUID 校验（`WorkspaceIdInvalid`）。
- `AssistantFileAccessGuard` + `@AssistantFileAccess(policy)`：文件专用面。`workspace` 策略只接受 `USER_XPERT`；会话策略接受 `USER_XPERT`/`ENTERPRISE_XPERT`；并强制 `principalType==='client_secret'`、`resourceScope.kind==='assistant'`、apiKey/请求组织与当前组织一致、`host.hostId === resourceScope.xpertId`，任一不符抛 `WorkspaceFileAccessDenied`；登录用户（无 `principalType`）直接放行，由领域服务再校验。
- `GroupScopeGuard` / `GroupWorkbenchGuard`：`/api/ai/groups/*` 的群成员与工作台准入，二者由 `AIModule` 提供。
- `AnonymousXpertAuthGuard`：公共 App 专用，Passport 策略顺序 `['xpert', 'jwt']`，保证请求 scope 与 `createdBy` 钉在已发布助手上。
- 权限点（`PermissionGuard` + `@Permissions`）：`AIPermissionsEnum.XPERT_EDIT`（助手列表/选择项/统计）、`PermissionsEnum.ALL_ORG_VIEW|ALL_ORG_EDIT`（按 principal user 反查）、`ORG_USERS_VIEW|ORG_USERS_EDIT`（用户组授权矩阵）、`INTEGRATION_EDIT`（触发连接扫码）。
