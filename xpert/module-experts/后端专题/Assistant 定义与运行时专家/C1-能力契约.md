## §2 服务能力契约（10 个最常被外部调用的方法）

| 契约方法（签名） | 用途 | 参数与行为语义要点 | 返回 | 异常 |
|---|---|---|---|---|
| `XpertService.saveDraft(id: string, draft: TXpertTeamDraft)`、`updateDraft(id: string, draft: Partial<TXpertTeamDraft>)` | 草稿写入 | 全量为覆盖、增量为补丁；仅当 body 命中 `nodes` / `connections` 键才覆盖图字段；`savedAt` 由控制器写入 | 更新后的 `Xpert` | 404（助手不存在） |
| `XpertService.publish(id: string, newVersion: boolean, environmentId: string \| null \| undefined, notes: string, marketplace?: TXpertPublishMarketplaceInput, businessAreaId?: string \| null)` | 发布为版本行 | 多步无事务（版本备份 → 图落库 → 草稿清空 → 助手外部账号补齐 → 触发发布），中途失败不回滚；`newVersion` 决定是否新增版本行 | 发布结果（版本行 + 更新后的助手） | 404 `No draft found`；400 `Published xperts must be assigned to at least one user group.` / `xpert.Error.AgentOutdated` / `XpertBusinessAreaScopeMismatch`；500 游离节点或重名 |
| `XpertService.assertCanAuthorById(id: string, resolvedWorkspaceId?: string \| null): Promise<void>` | 创作准入闸门 | 优先用持久化的 `workspaceId`，未持久化时以入参兜底；只通过或抛错，无返回 | `void` | 403（无权创作该助手） |
| `PublishedXpertAccessService.getAccessiblePublishedXpert(id, options?: Omit<FindOneOptions<Xpert>, 'where'>)`、`getAccessiblePublishedXpertForCurrentUser(id)` | 运行时准入读一条已发布助手 | 先按凭证受众强制校验目标再加载；只命中 `publishAt` 非空且 `latest`；后者在存在用户助手受众时二次复查（私有复查方法 `assertCurrentUserAccess` 非对外契约） | `IXpert` | 403 `You do not have access to this assistant.` |
| `XpertWorkspaceAccessService.getAccess(workspaceId, options?)`、`getCapabilities(workspace, { includePublishedRunAccess })`、`assertCanRead \| assertCanRun \| assertCanWrite \| assertCanAuthor \| assertCanManage(workspaceId, options?)` | 工作区四动作能力面 | 同租户 + 非归档短路，不满足即四项全 false；`assertCanAuthor` ≡ `assertCanWrite`（无独立能力位）；批量场景传 `includePublishedRunAccess: false`；用户组只桥接 `canRun`（私有动作映射 `can` 非对外契约） | `{ workspace, capabilities, isTenantShared }` / `TXpertWorkspaceCapabilities` | 403 `Access denied to workspace`；404（工作区不存在） |
| `AssistantFilesService.forRuntime(assistantId)`、`forAuthoring(assistantId)` | 助手文件入口选择器 | 入口由服务端硬编码；返回的客户端每次操作都重新授权；`authoring` 分支遇委派凭证直接拒绝；`runtime` 分支要求「可跑的已发布助手」 | 卷客户端（`capabilities` / `list` / `read` / `save` / `upload` / `download` / `delete` / `saveBinary`） | 403 `WorkspaceFileAccessDenied` / `Delegated credentials cannot select the Studio authority`；400 越界路径 |
| `XpertTemplateService.getCatalog(language: LanguagesEnum, query?: TXpertTemplateCatalogQuery)` | 模板目录 | 目录源为外部模板目录（`XPERT_TEMPLATE_DIR`）+ 插件贡献；分页参数 `search` / `category` / `pluginName` / `offset` / `limit` | 分页目录项 | 无（只读路径） |
| `XpertMarketplaceService.requestAccess(id: string, input?: TXpertAccessRequestCreateInput)` | 市场访问申请 | 唯一键 `(tenantId, organizationId, xpertId, requesterId)` 单行 upsert，重申原地复用；已拥有 / 已可访问直接拒绝 | `IXpertAccessRequest` | 400 `XpertMarketplaceAlreadyAccessible`；403 `XpertMarketplaceTenantRequired` / `OrganizationRequired` / `UserRequired` |
| `XpertMarketplaceService.approveRequest(id: string, input?: TXpertAccessRequestDecisionInput)` | 审批通过（授权落地） | 三步无事务副作用：建 / 复用 `UserGroup` → 申请人入组 → 组入 `xpert.userGroups`，再回写状态与 `accessGroupId`；自审与无权审均拒绝 | `IXpertAccessRequest`（含 `accessGroupId`） | 403 `XpertMarketplaceSelfReviewForbidden` / `XpertMarketplaceReviewForbidden`；404 `XpertMarketplaceRequestNotFound` / `XpertMarketplaceRequesterNotFound` |
| `AssistantBindingService.getEffectiveBinding(code: AssistantCode): Promise<IResolvedAssistantBinding>` | 系统槽位生效绑定 | 回落顺序 organization → tenant → `sourceScope: NONE`；非系统管理 code 直接拒绝 | `IResolvedAssistantBinding` | 越权拒绝（`ensureSystemManagedCode` 判定） |

## §3 代码示例（真实调用方代码，签名已核实）

### 例 1 · 草稿 → 发布（`XpertController`）
```ts
// packages/server-ai/src/xpert/xpert.controller.ts（节选）
@UseGuards(XpertGuard)
@Post(':id/draft')
async saveDraft(@Param('id') id: string, @Body() draft: TXpertTeamDraft) {
    draft.savedAt = new Date()
    return await this.service.saveDraft(id, draft)
}

@UseGuards(XpertGuard)
@Post(':id/publish')
async publish(
    @Param('id') id: string,
    @Query('newVersion') newVersion: string,
    @Body()
    body: { environmentId?: string | null; releaseNotes: string; businessAreaId?: unknown; marketplace?: unknown }
) {
    const marketplace = parseXpertPublishMarketplaceInput(body.marketplace)
    const businessAreaId = parseXpertPublishBusinessAreaId(body.businessAreaId)
    return this.service.publish(
        id,
        newVersion === 'true',
        body.environmentId,
        body.releaseNotes,
        marketplace,
        businessAreaId
    )
}
```
- 只有 `newVersion === 'true'` 才新增版本行；`marketplace` 与 `businessAreaId` 先经解析器归一，非法值抛 400。
- 发布是多步无事务写路径：中途抛错不回滚已写入的备份行与 agent —— 调用方不要假定可重试幂等。

### 例 2 · 运行时准入读一个已发布 Assistant（`AssistantsController`）
```ts
// packages/server-ai/src/ai/assistant.controller.ts（节选）
async getOne(@Param('id') id: string) {
    const item = await this.publishedXpertAccessService.getAccessiblePublishedXpert(id, {
        relations: ASSISTANT_RELATIONS
    })
    return transformAssistant(item)
}
```
- 该类在类级声明 `@Public()` + `ApiKeyOrClientSecretAuthGuard` + `@AllowClientSecretBindings(SecretTokenBindingType.ENTERPRISE_XPERT)`：路由「匿名可达」由守卫兜底，放行结论由受众与目标的匹配关系决定。
- 出参一律经 `transformAssistant` 白名单投影，不序列化实体本身；受众不匹配回 403。

### 例 3 · 运行时读文件（`AssistantWorkspaceFilesController`）
```ts
// packages/server-ai/src/ai/assistant-workspace-files.controller.ts（节选）
@Get('file')
async readWorkspaceFile(
    @Param('assistantId', UUIDValidationPipe) id: string,
    @Query(new ZodValidationPipe(workspaceFileQuerySchema, invalidWorkspaceFileRequest)) query: WorkspaceFileQuery
) {
    const workspace = this.workspaceFilesService.forRuntime(id)
    const file = await workspace.read(query.path)
    return { ...file, capabilities: await workspace.capabilities() }
}
```
- 类级装饰：`@Public()` + `@UseGuards(ApiKeyOrClientSecretAuthGuard, AssistantFileAccessGuard)` + `@AssistantFileAccess('workspace')` + `@Controller('assistants/:assistantId/workspace')`。
- 8 个端点每个都重新 `forRuntime(id)`；运行时被拒**不得**回退 `forAuthoring`，也不得由请求数据选择入口。

### 例 4 · 市场申请与审批（`XpertMarketplaceController`）
```ts
// packages/server-ai/src/xpert-marketplace/xpert-marketplace.controller.ts（节选）
@Post('xpert-marketplace/:id/access-requests')
async requestAccess(@Param('id') id: string, @Body() body: TXpertAccessRequestCreateInput) {
    return this.service.requestAccess(id, body)
}

@Put('xpert-access-requests/:id/approve')
async approveRequest(@Param('id') id: string, @Body() body: TXpertAccessRequestDecisionInput) {
    return this.service.approveRequest(id, body)
}
```
- 该控制器用空 `@Controller()` + 方法级自带首段，因此同一控制器产出 `/api/xpert-marketplace/*` 与 `/api/xpert-access-requests/*` 两个前缀。
- 批准即把授权落地为 `UserGroup` 成员关系，运行权立即生效；撤销无反向同步（见 `C0` §7 第 10 条）。
