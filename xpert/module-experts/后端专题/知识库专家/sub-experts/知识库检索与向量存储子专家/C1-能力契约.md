### 1.3 路由要点

- **`tag-usage` 不是单段端点**：合法形态 `/api/knowledgebase/tag-usage/:tagId`；同层单段请求被 `@Get(':id')` 兜住并按 UUID 校验拒绝。
- **单段路由的注册顺序即契约**：`keyword-analyzers`（EDIT 守卫）、`vector-stores`（EDIT 守卫）声明在 `:id` 之前所以安全；`KnowledgeTagUsageController` 因注册序列靠后被 `:id` 抢先。
- **`rag-vstore` 无 HTTP 面**：`RagVStoreModule.controllers = []`，能力只通过 `RagCreateVStoreCommand` → `RagCreateVStoreHandler` 暴露。

### 2.4 向量存储抽象（`rag-vstore/`）

| 组件 | 语义 |
| --- | --- |
| `RagCreateVStoreHandler.execute` | `command.config.vectorStore ?? environment.vectorStore` → `switch`：`PGVECTOR` 走本地实现，其余走 `VectorStoreRegistry.get(strategy)`；都没命中则 500 `Error.UnsupportedVectorStore` |
| `RagCreateVStoreHandler.createPgVectorStore` | 建 `KnowledgePGVectorStore`，表名 `knowledge_document_vector` / `knowledge_document_collection`，列映射 `id` / `vector` / `content` / `metadata`，随后 `ensureTableInDatabase()` + `ensureCollectionTableInDatabase()` |
| `KnowledgePGVectorStore` | `getByIds(ids)`、结构化相似检索；写入用 `ON CONFLICT (...) DO UPDATE` 原子 upsert |
| `VectorStoreSettingsService.options()` | 返回 `{ default: environment.vectorStore, stores }`；`MILVUS` 仅在被 `VectorStoreRegistry` 注册时列出 |
| `VectorStoreSettingsService.forCreate(value)` | `value == null` 或属 `{PGVECTOR, MILVUS}` 才可选；否则 400 `Error.KnowledgeVectorStoreUnavailable` |
| `VectorStoreSettingsService.assertUnchanged(current, requested)` | 请求值与现值（或环境默认）不同即 400 `Error.KnowledgeVectorStoreImmutable` |

## §3 代码示例

### ① 建库 → 取向量句柄 → 三路召回 + 重排

```ts
// 真实调用方：packages/server-ai/src/xpert-agent/workflow/handlers/create-wn-knowledge-retrieval.handler.ts
const retriever = createKnowledgeRetriever(queryBus, knowledgebaseId, {
    recall: {
        mode: 'hybrid',
        topK: 10,
        score: null,               // null 关闭向量相似度阈值
        rerankThreshold: 0.2,
        contentScope: 'all',       // 'wiki' 会让 graph 权重归零
        fusion: { mode: 'weighted_rrf', rankConstant: 60, weights: { vector: 0.65, keyword: 0.3, graph: 0.35 } }
    },
    retrieval: { filtering: { fixed: { kind: 'group', operator: 'and', children: [] }, agent: { enabled: true } } }
})
const { documents, diagnostics } = await retriever.retrieveDetailed('季度报告口径', undefined, undefined, { xpertId, threadId })

// 手握句柄直连向量层（图谱实体向量是另一条 collection）
const store = await knowledgebaseService.getActiveVectorStore(knowledgebaseId, true, undefined, { rerankEnabled: true })
const hits = await store.similaritySearchWithScore('季度报告口径', 10)
```

### ② 切 embedding 并推进重建

```ts
// 方式一（HTTP）：POST /api/knowledgebase/:id/rebuild-embedding
// 方式二（服务）：切到「需重建」的模型绑定，更新入口自动转入重建启动
await knowledgebaseService.updateKnowledgebase(kbId, { copilotModelId: nextEmbeddingModelId })
await knowledgebaseService.startEmbeddingRebuild(kbId)              // 需已有 pending 模型与指纹
await knowledgebaseService.processEmbeddingRebuildJob(jobData)      // 队列 rebuild-knowledgebase-embedding
await knowledgebaseService.markEmbeddingRebuildFailed(jobData, msg) // 失败落 rebuild_failed + 错误列
await knowledgebaseService.cancelPendingEmbeddingModel(kbId)        // 反悔：清 pending 与错误回 ready
// 显式门禁：await knowledgebaseService.assertNotRebuilding(kbId)   // 仅 REBUILDING 抛 400
```

### ③ 校验向量存储可选性与不可变性

```ts
const options = vectorStoreSettings.options()            // → GET /api/knowledgebase/vector-stores
const type = vectorStoreSettings.forCreate(input.vectorStore)  // 未注册的 MILVUS → 400 Unavailable
vectorStoreSettings.assertUnchanged(kb.vectorStore, input.vectorStore) // 改类型 → 400 Immutable
```
