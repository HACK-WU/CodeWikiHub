### 1.3 路由要点

- **`requireKnowledgebaseId` 是列表族的硬门**：`where.knowledgebaseId` 缺失、为数组、或展开出多个不同值，一律按 `Error.KnowledgebaseAccessDenied` 拒绝，避免「不带 KB 条件扫全表」。
- **两处 `version` 的解析规则一致**：`parseExpectedVersion` 接受正整数或可解析为整数的字符串，否则 400「version is required」。
- **`process` 参数是 `ParseBoolPipe`**：`?process=true` 才自动启动；不带则只落库。

### 2.3 读过滤与删除协议

| 组件 | 语义 |
| --- | --- |
| `readableDocumentWhere(...)`（私有） | 读路径统一追加的可见性条件（含 `hardDeletePendingAt IS NULL`） |
| `userDocumentListWhere(where)` / `visibleDocumentSql(metadata)` | 普通 HTTP 列表叠加系统托管过滤：`systemManaged IS DISTINCT FROM 'true'` **或** `systemManagedType = 'agent-writer'` |
| `deleteResolvedDocument(document, expectedVersion)` / `deleteDocumentArtifacts(document)` | 硬删顺序路径：先 `assertNotRebuilding`，再清外部产物（Wiki 撤回 / 向量删 / 图谱清理），最后删行 |

## §3 代码示例

### ① 幂等 + 增量登记一批文档

```ts
// 单篇幂等（服务面）：恰好 1 篇 + key ≤160 才走该路径
const one = await documentService.createBulkIdempotently(
    [{ knowledgebaseId, name: 'handbook.pdf', filePath, type: 'pdf' }],
    'import-20261016-1'
)
// one.createdIds / skippedIds 指示复用或新建

// 批量增量（HTTP：POST /api/knowledge-document/bulk?process=true）
const sync = await documentService.createBulkWithIncrementalSync(documents)
// sync.processableIds 会被投到 embedding-document；?process=true 时代码在控制器里显式调用 startProcessing
await documentService.startProcessing(sync.processableIds)   // mode 默认 'full'
```

### ② 用 `mode` 复用快照重切

```ts
// 先探测：GET /api/knowledge-document/:id/reprocess-capabilities → { rechunk: { available, reason } }
try {
    await documentService.startProcessing([docId], undefined, 'rechunk')   // 复用不可变转换快照
} catch (error) {
    if (error instanceof TransformSnapshotUnavailableError) {
        await documentService.startProcessing([docId], undefined, 'full')  // 只有快照不可用时才降级
    } else throw error
}
```

### ③ 停止任务与按版本硬删

```ts
// DELETE /api/knowledge-document/:id/job 的等价行为
const job = await docQueue.getJob(document.jobId)
if (job) { await job.discard(); await job.moveToFailed({ message: 'Job stopped by user' }, true) }
document.jobId = null; document.status = KBDocumentStatusEnum.CANCEL; document.progress = 0

// DELETE /api/knowledge-document/:id?version=3
await documentService.deleteWithVersion(docId, parseExpectedVersion(version))   // 版本不符 → 409
```
