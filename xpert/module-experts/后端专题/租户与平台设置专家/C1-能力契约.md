> 契约层文档（父专家）｜资产基线：**2026-10-16 · commit `80f5676fd`**（原基线 `c07bb83d`）
> 阅读约定：路径均含全局前缀 `api`；「鉴权」列写 `@Public` 表示免鉴权，否则为需登录（并可能叠加 guard）；标注「未确认」的条目为源码未明确者。

## 2. 服务能力契约（同进程跨模块调用）

以下为父专家契约主体。每条格式：用途｜参数行为语义｜返回｜异常。签名均回源码核实。

### 2.1 `TenantService`（[tenant.service.ts](file://packages/server/src/tenant/tenant.service.ts)）

- `onboardTenant(entity: ITenantCreateInput, user: IUser, options?: { skipSubdomainPreparation?: boolean }): Promise<Tenant>`｜用途：租户创建全链路编排（建租户 → 角色权限 → 开关 → 默认设置 → 绑定 SUPER_ADMIN → 可选默认组织 → 发 `tenant.created`）｜参数：`options.skipSubdomainPreparation` 为真时跳过子域规范化/查重（自举路径已预处理）｜返回：创建的租户｜异常：`InternalServerErrorException`（租户内找不到 SUPER_ADMIN 角色）；子域非法/重复由准备阶段抛 400｜约束：**整链无事务**，中途失败会留下半初始化租户。
- `prepareTenantCreateInput(entity)` / `prepareTenantUpdateInput(tenantId, entity)`｜用途：子域规范化 + 唯一性校验｜返回：可落库的输入｜异常：400（`Tenant subdomain is invalid` / `Tenant subdomain already exists`）。
- `getDefaultTenant()`｜用途：按 `DEFAULT_TENANT` 名读默认租户｜返回：`Tenant`｜约束：另有一条 24 小时缓存读取路径，改名后长期不刷新（未确认失效开关）。

### 2.2 `TenantSettingService`（[tenant-setting.service.ts](file://packages/server/src/tenant/tenant-setting/tenant-setting.service.ts)）

- `getSettings(request?: FindManyOptions<TenantSetting>): Promise<Record<string, any>>`｜用途：把行式设置折成 `{name: value}` 字典｜参数：调用方自备 `where`（中间件传 `{ tenantId }`）｜返回：键值映射｜异常：未显式声明（DB 异常向上抛）｜约束：无租户过滤，跨租户取数由调用方负责。
- `saveSettngs(input: ITenantSetting, tenantId: string): Promise<ITenantSetting>`｜用途：按 key upsert 租户设置（存在改 value，否则新建）｜参数：`input` 为任意 name→value 映射；`tenantId` 必填｜返回：保存后的映射｜异常：未显式声明｜约束：**原文拼写为 `saveSettngs`**；表上无 `(tenantId, name)` 唯一约束，且**不清理请求级设置缓存**。

### 2.3 功能开关（[feature-organization.service.ts](file://packages/server/src/feature/feature-organization.service.ts)、[feature.service.ts](file://packages/server/src/feature/feature.service.ts)）

- `FeatureOrganizationService.updateFeatureOrganization(entity: IFeatureOrganizationUpdateInput): Promise<IFeatureOrganization[]>`｜用途：写「单个 feature × 单个作用域」开关｜参数：租户取自 `RequestContext`；`organizationId` 非空=组织级，空/未传=租户级；组织级写购买类开关会被拒｜返回：作用域内开关行｜异常：`BadRequestException`（`server-ai:Error.MembershipPurchaseFeatureTenantScopeRequired`）｜约束：写后必然 bump 租户级 feature 缓存版本号；仅状态真正翻转时 emit `feature.organization.updated`。
- `FeatureOrganizationService.updateTenantFeatureOrganizations(tenants: ITenant[]): Promise<IFeatureOrganization[]>`｜用途：新租户全量初始化开关｜参数：租户数组（空数组直接返回）｜返回：写入的开关行｜约束：**只为叶子 feature 建 toggle**（有 children 的分组跳过），默认值取自内置定义；每个租户 bump 一次版本号。
- `FeatureService.getParentFeatures(relations: string[] = []): Promise<IPagination<IFeature>>`｜用途：读顶层 feature 列表（按创建时间升序）｜返回：分页结果｜约束：读侧已过滤退役 code。
- `FeatureService.seedDB()`｜用途：同步内置 feature 定义（并先做退役清理）｜返回：未显式声明｜约束：启动引导（`onApplicationBootstrap`）会执行同一清理路径。

### 2.4 返利（[referral.service.ts](file://packages/server/src/referral/referral.service.ts)、[referral-validation-rate-limit.service.ts](file://packages/server/src/referral/referral-validation-rate-limit.service.ts)）

- `isFeatureEnabled(tenantId: string, manager?: EntityManager): Promise<boolean>`｜用途：判定租户级 `FEATURE_REFERRAL` 是否开启｜参数：可传调用方事务的 `EntityManager` 以读到未提交状态｜返回：布尔｜约束：DB 直查，**不读用户 feature 上下文缓存**。
- `validateCode(tenantId, code?, manager?): Promise<boolean>` / `validatePublicCode(tenantId, code?)`｜用途：校验码是否属于该租户下未被软删的用户｜参数：`code` 会去空白并大写｜返回：布尔（开关关闭或无码恒 `false`）｜异常：无。
- `bindRegistration(manager: EntityManager, input: { tenantId: string; referredUserId: string; referralCode?: string }): Promise<void>`｜用途：注册时建立返利关系｜参数：必须在调用方事务的 `manager` 上执行｜返回：`void`（幂等，已在则不覆盖；开关关闭或无码静默返回）｜异常：`BadRequestException`（`server-ai:Error.ReferralInvalidCode`：码不存在、无归属用户或自邀）。
- `getMyCode(): Promise<IReferralCodeView>` / `regenerateMyCode(): Promise<IReferralCodeView>`｜用途：读/换我的邀请码｜返回：`{ code }`｜异常：`BadRequestException`（`ReferralTenantContextRequired`）、`UnauthorizedException`（`ReferralAuthenticatedUserRequired`）、`NotFoundException`（通信型用户或开关关闭）。
- `getRelations(query: IReferralRelationQuery): Promise<IPagination<IReferralRelationView>>`｜用途：租户内返利关系分页｜参数：`take` 夹在 1..100（默认 20）、`skip` 非负、`search` 模糊匹配码与双方账号｜返回：分页视图（已删账号带 `deleted: true` 占位）｜异常：`BadRequestException`（`ReferralTenantScopeRequired`，非租户 scope）、`NotFoundException`（开关关闭）。
- `ReferralValidationRateLimitService.assertAllowed(tenantId: string, identifier: string): Promise<void>`｜用途：公开校验限流（60 秒 30 次）｜参数：`identifier` 由调用方传客户端 IP，内部只存哈希｜返回：`void`｜异常：429（`ReferralValidationRateLimited`）、500（`ReferralValidationRateLimitUnavailable`，客户端不可用或计数不可解析 → **fail-closed**）。

### 2.5 SMTP 与发信（[custom-smtp.service.ts](file://packages/server/src/custom-smtp/custom-smtp.service.ts)、[email.service.ts](file://packages/server/src/email/email.service.ts)）

- `CustomSmtpService.getSmtpSetting(query: ICustomSmtpFindInput): Promise<ICustomSmtp | ISMTPConfig>`｜用途：取组织/租户级 SMTP 配置｜参数：`organizationId` 空则取租户级，同作用域多条取最新｜返回：配置实体或默认 SMTP 配置｜约束：**查询异常被吞掉并回退「默认且不含认证」的配置**，不得据此判断「未配置」。
- `CustomSmtpService.verifyTransporter(transport: IVerifySMTPTransport): Promise<boolean>`｜用途：实测连通性（`POST /api/smtp/validate`）｜返回：布尔（异常吞掉 → `false`）。
- `EmailService.getEmailInstance({ organizationId, tenantId }): Promise<Email>`｜用途：装配发信实例｜参数：`tenantId` 缺省取当前上下文｜返回：`email-templates` 实例（已绑定 hbs 视图与模板渲染器）｜异常：`InternalServerErrorException`（组织级 / 租户级 / 环境默认三级 SMTP 校验全部失败）｜约束：每级都会真实握手验证且无缓存。
- `EmailService.welcomeUser(user, languageCode, organizationId?, originUrl?)` / `sendVerifyEmailMail(user, languageCode, url, organizationId?, originUrl?)` / `requestPassword(user, url, languageCode, organizationId, originUrl?)` / `inviteUser(inviteUserModel: IInviteUserModel)` / `sendAcceptInvitationEmail(joinEmployeeModel: IJoinEmployeeModel, originUrl?)`｜用途：业务发信族（欢迎 / 邮箱验证 / 重置密码 / 邀请 / 邀约通知）｜返回：未显式声明｜异常：**不抛出**（失败静默，仍尝试落发送记录）｜约束：收件人命中 `DISALLOW_EMAIL_SERVER_DOMAIN` 时跳过真实发信但保留记录。

### 2.6 模板与匿名解析（[email-template.service.ts](file://packages/server/src/email-template/email-template.service.ts)、[anonymous-tenant-resolver.service.ts](file://packages/server/src/tenant/anonymous-tenant-resolver.service.ts)）

- `EmailTemplateService.findAll(params: BaseQueryDTO<EmailTemplate>): Promise<IPagination<IEmailTemplate>>`｜用途：列模板（租户专属 + 全局默认行同时返回）｜参数：`where` 支持 `tenantId`/`organizationId`/`languageCode`｜返回：分页结果｜约束：传入的 `tenantId` 会被当前上下文覆盖。
- `EmailTemplateService.handleTenantCreatedEvent(event: TenantCreatedEvent)`｜用途：租户创建后播种默认模板｜返回：未显式声明｜约束：模板目录缺失时只告警跳过，不阻断租户创建。
- `AnonymousTenantResolverService.resolve(request: Request): Promise<AnonymousTenantResolution>`｜用途：匿名请求的租户解析｜参数：读中间件写入的请求子域标识｜返回：解析结果（含租户与「是否发生回退」标识）｜约束：子域命中优先，未命中回退 `DEFAULT_TENANT`。

### 2.7 内部成员（**非跨模块契约**，仅作语义索引）

- `EmailService` 的渲染与记录写入、`FeatureService` 的退役清理与定义同步、`ReferralService` 的上下文校验与码规范化、`FeatureOrganizationService` 的默认状态收集、`TenantSettingService.get`（遗留路径）均为内部实现细节；外部模块**不得**依赖，其行为只通过上文公开契约间接体现。

**① 读/写租户设置（并注意 5 分钟缓存窗口）**

```ts
// 1a. 读：消费方只读请求上下文上的快照 —— file-storage.ts#setProvider
const request = RequestContext.currentRequest()
if (request && isNotEmpty(request['tenantSettings'])) {
  const provider = request['tenantSettings']['fileStorageProvider'] as string
  this.config.provider = this.normalizeConfiguredProvider(provider)
} else {
  this.config.provider = this.normalizeConfiguredProvider(environment.fileSystem.name)
}

// 1b. 写：CQRS handler 内按当前租户 upsert —— tenant-setting.save.handler.ts#execute
const { input, tenantId } = command
await this._tenantSettingService.saveSettngs(input, RequestContext.currentTenantId() || tenantId)
// 说明：写后不会清理 tenantSettings_<tenantId>，最长 5 分钟内 request['tenantSettings'] 仍是旧值
```

**② 改一个（批量）开关，并触发缓存版本号失效**

```ts
// 2a. 控制器：一次请求拆成多个命令并并行执行 —— feature-toggle.controller.ts
@UseGuards(TenantPermissionGuard, PermissionGuard)
@Permissions(PermissionsEnum.ALL_ORG_EDIT)
@Post('/')
async enabledDisabledFeature(@Body() input: CreateFeatureToggleDTO[]): Promise<boolean[]> {
  return await Promise.all(
    input.map(item => this._commandBus.execute(new FeatureToggleUpdateCommand(item)))
  )
}

// 2b. 命令处理器只转调服务 —— feature-toggle.update.handler.ts#execute
const { input } = command
return this._featureOrganizationService.updateFeatureOrganization(input)
// 说明：服务内部必然 bump 租户级 feature 缓存版本号（用户 feature 上下文立即失效），
//       且仅当开关由关→开 / 开→关翻转时才广播 feature.organization.updated
```

**③ 发一封业务邮件（模板解析与回退）**

```ts
// 3a. 注册后发验证邮件 —— auth.service.ts#signup
const emailVerificationToken = nanoid()
const user = await this.createRegisteredUser(input, languageCode, {
  emailVerified: false,

// 3b. 邀请批量创建后发邀请邮件 —— invite.service.ts#createBulk（节选，真实代码未 await）
const registerUrl = `${originUrl}/auth/accept-invite?email=${item.email}&token=${item.token}`
if (emailInvites.inviteType === InvitationTypeEnum.USER) {

    originUrl,

// 回退顺序：SMTP 组织级 → 租户级 → 环境默认（每级真实握手）
```
