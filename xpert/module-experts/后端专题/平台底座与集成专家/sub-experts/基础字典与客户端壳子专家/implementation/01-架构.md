## 1. 职责与边界

**本子域四组职责**：

1. **字典 = 平台基础枚举与种子**。三类全局字典只有读端点：`LanguageController.findAll` / `findByName`（`/api/languages` 2 条）、`CountryController.findAll`（`/api/country` 1 条）、`CurrencyController.findAll`（`/api/currency` 1 条）；写路径只有种子函数 `createLanguages` / `createCountries` / `createCurrencies` 与租户侧命令 `LanguageInitCommand → LanguageService.initialize()`。`language` 收 `all-languages.ts` 的 182 条语言（以 `nativeName` 计数），`is_system` 由 `LanguagesEnum` 判定；`country` / `currency` 的键都是两位 / 三位 ISO 码，正文只存名称。
2. **`contact` = 组织联系人目录**（语义上是业务实体，物理上与字典族同放 `packages/server/src`）。它只有 1 条自写端点（`getAllContact`），其余 CRUD 由 `CrudController` 基类提供，实体列全部可空且 `country` 存 isoCode 字符串而非外键；**当前 `/api/contact` 未挂载**（见不变量 ③）。
3. **客户端壳 = 桌面 / 移动的服务端面**。`desktop-shell` 持有「设备注册 + 会话授权 + 执行台账」三张表与一条 WebSocket 通道，**执行本体在用户机器上**；`mobile` 是纯只读投影（`/api/mobile/bootstrap`、`/api/mobile/xperts`，0 表）；`initialization` 是入组/建组织/建租户的引导队列（`bootstrap.service.ts` + `bootstrap.processor.ts`）与 2 条 ClawXpert 恢复端点。
4. **`ai-model` = 模型 Provider 目录**。只答三个问题：provider 存在吗（`AIProvidersService.getProvider`）、凭证 schema 合法吗（`providerCredentialsValidate`）、图标二进制是什么（`GET /api/ai-model/provider/:name/:iconType/:lang`）。模块**不装配 `TypeOrmModule`，0 表**。
5. **相邻并挂**：`tags`（`/api/tags` 8 条显式端点 + 1 表 + 2 张显式 `@JoinTable`）是本子域唯一**可写**字典；`export-import`（2 表）保留模块但**无 HTTP 面**。

**不做什么**：不执行桌面命令（只登记与派发，执行在客户端 `Xpert Desktop`）；不拥有沙箱与 Agent 运行时；不安装插件（`plugin` / `plugin-resource` / `skill-repository` 归平台插件域）；不解析身份权限（只复用 `RequestContext`、`TenantPermissionGuard`、`PermissionsEnum.ORG_TAGS_EDIT`）；不存模型定义与密钥；不做跨域导出/导入真实逻辑（`ImportAllService` 与 `unzipAndParse` 在源码内被注释）。

## 2. 与「模型访问与计费」的分工

| 维度 | 本子域 `ai-model` | 模型访问与计费域（`model-access` / `model-gateway` / `copilot*`） |
|---|---|---|
| 回答的问题 | provider 是否存在、凭证 schema 是否合法、图标是什么 | 该用户/组织能否用这个模型、配额多少、用了要记多少账 |
| 数据面 | **0 表**（`AIModelModule` 只有 `RouterModule` + `DiscoveryModule` + `CqrsModule`） | `model_access_request` / `model_access_event` / `user_model_grant` 等实体 |
| 目录来源 | 进程内插件注册表 `AIModelProviderRegistry`（`getProvider(name, throwError?, organizationId?)`） | 注入同一个 `AIProvidersService`，把它当**只读目录门面** |
| 凭证处理 | 取 `provider_credential_schema` → `ProviderCredentialSchemaValidator.validateAndFilter` → 策略 `validateProviderCredentials`，**只把过滤后的字段**交回调用方 | 落库与加密归属消费方；`provider-credentials-validate.handler` 内留有 `// Todo: encrypt secret variables in credentials` |
| 对外 HTTP | 仅 `@Public` 图标端点 1 条 | 授权解析、模型列表、运行与记账端点 |

**边界的实际形态**：凭证校验命令 `AiProviderCredentialsValidateCommand` 由**邻域 `copilot-provider`** 的 upsert 流程消费，不暴露在 HTTP 上；本域不落任何模型/密钥/授权行，也不判断「是否已授权」。因此「凭证校验通过」**不等于**「已授权使用」——前者证明 provider 认得这组字段，后者由访问域解析。`getProvider` 默认**不抛**（插件卸载后返回 `undefined`），只有 `throwError = true` 才抛 `AIModelProviderNotFoundException`，这条默认值使目录调用方必须显式处理「provider 已下线」的情形。

章节来源：[ai-model.service.ts](file://packages/server-ai/src/ai-model/ai-model.service.ts)（关键符号：AIProvidersService.getProvider / providerCredentialsValidate）、[ai-model.module.ts](file://packages/server-ai/src/ai-model/ai-model.module.ts)（关键符号：AIModelModule imports / AIModelProviderRegistry）、[provider-credentials-validate.handler.ts](file://packages/server-ai/src/ai-model/commands/handlers/provider-credentials-validate.handler.ts)（关键符号：AiProviderCredentialsValidateHandler.execute / encrypt TODO）、[provider_credential_schema_validator.ts](file://packages/server-ai/src/ai-model/schema_validators/provider_credential_schema_validator.ts)（关键符号：ProviderCredentialSchemaValidator.validateAndFilter）

## 5. 关键不变量

1. **字典是「只读端点 + 种子」，不是运行时可写字典**：`language` / `country` / `currency` 三模块的控制器只有 `@Get()`（language 另加 `getByName/:name`）且 `@Public()`；`country` / `currency` 的 `isoCode` 只有**非唯一** `@Index()`，唯一性仅由种子内容保证；`Language` 有 `@Unique(['code'])`，重跑种子靠 `try/catch + console.log({error})` 吞掉冲突（**不幂等**）。`createLanguages` 每次重跑都会用 `faker.internet.color()` 改写 `color` 并把 `description` 置空——**改种子内容等同于改初始化语义**，必须回到种子/迁移侧，不允许加写端点。
2. **多语言 fallback 规则是「en 兜底 + zh_Hans 可选」**：`I18nObject` 以 `en_US` 为必填、`zh_Hans` 为可选；服务端选语言的唯一依据是 `RequestContext.getLanguageCode()`，i18next 初始化以 `fallbackLng: 'en'` / `fallbackNS: 'common'` 兜底，并把 `t()` monkey-patch 成「总是注入当前语言」。字面实现可见 `getDefaultOrganizationWorkspaceName()`（`LanguagesEnum.Chinese | SimplifiedChinese → zh_Hans ?? en_US`）与 `AIModelGetIconHandler`（`lang === 'zh_hans' && icon.zh_Hans || icon.en_US`）；`tags` 的 `label` 也用同一形状（zod 要求 `en_US` 必填、`zh_Hans` 可选）。
3. **`contact` 的继承面 = 基类 CRUD 全量暴露 + 1 个自写读端点**：`ContactController extends CrudController<Contact>`，自写 `GET /`（`getAllContact`，用 `ParseJsonPipe` 解析 `data` 取 `relations` / `findInput`），其余端点来自基类（`GET count` / `GET pagination` / `GET /` / `GET my` / `GET :id` / `POST` / `PUT :id` / `DELETE :id` / `DELETE :id/soft` / `PUT :id/recover`），类级只有 `@UseGuards(TenantPermissionGuard)`；实体为 `TenantOrganizationBaseEntity`、**无唯一索引、无外键**，三处 `@OneToMany` 被整段注释。**当前该控制器不可达**：`ContactModule` 既未注册进 `server.module.ts`，也没有 `RouterModule.register([{ path: '/contact' }])`，因此 `/api/contact` 在运行期不存在（Swagger 亦不出现）。
4. **`desktop_shell_device.credentialHash` 是 sha256 摘要，凭证本体只在客户端**：`register` 生成 `randomBytes(32).toString('base64url')` 明文密钥，只返回一次 `token = ${deviceId}.${secret}`，库内仅存 `createHash('sha256').update(secret).digest('hex')`（varchar 64）；认证时用 `timingSafeEqual` 比较摘要，并同时校验 `enabled` 与 `credentialExpiresAt`。`refresh` 是唯一轮换路径（旧 token 立即失效）；`credentialExpiresAt = now + LIMITS.grant` 与授权 `expiresAt` 取 `min(设备到期, now + LIMITS.grant)`。
5. **`desktop-shell` 三表 + 两个显式迁移 + 一条 WS 通道**：`desktop_shell_device`（`UNIQUE(tenantId,organizationId,userId,installationId)`）、`desktop_shell_grant`（`@Index(deviceId,enabled)` + `operation jsonb`）、`desktop_shell_operation`（`UNIQUE(tenantId,runId,toolCallId)` + `@Index(deviceId,state)`）；`20260924-desktop-shell.sql` 是 `BEGIN…COMMIT` + `CREATE TABLE IF NOT EXISTS`（additive），`20260928-desktop-shell-approval.sql` 只有一句 `ALTER TABLE desktop_shell_grant ADD COLUMN IF NOT EXISTS operation jsonb NULL`。通道为 Socket.IO `namespace = /desktop-shell`、`transports: ['websocket']`、`VERSION = 1`，握手校验 `version + token` 并签发新的 `connectionEpoch`；**DB 是唯一真相，Redis `xpert:desktop-shell:dispatch` 只是唤醒提示**。
6. **`mobile` bootstrap 的版本兼容靠能力位而非版本号**：`XpertMobileBootstrap` 无 `apiVersion` 字段，`getDeploymentConfig()` 固定返回 `apiBasePath: '/api'`、`aiApiPath: '/api/ai'`、`viewHostsPath: '/api/view-hosts'` 与 6 个 `capabilities` 布尔位（chatkit / extensionViews / scheduledTasks / fileMemory / sandboxTerminal / publicChatkitSessions），可由环境变量覆盖 `apiBaseUrl`（`MOBILE_API_BASE_URL` → `PUBLIC_API_BASE_URL` → `API_BASE_URL`）与 `chatkitFrameUrl`。即**旧客户端靠能力位自行降级，服务端不做版本协商**；服务端只保证「不增加会破坏序列化的敏感字段」（有用例专门断言部署配置不含 `OPENAI_API_KEY` / JWT secret）。
7. **`initialization` 的幂等 = 稳定 jobId + 出队重查**：4 个 `@OnEvent` 只做入队并给稳定 jobId（`org-bootstrap:{orgId}`、`tenant-skill-repository-bootstrap:{tenantId}`、`user-org-bootstrap:{orgId}:{userId}`、`user-org-cleanup:{orgId}:{userId}`，链式 `user-default-skills:{workspaceId}`），统一 `attempts: 3, backoff: 10_000, removeOnComplete: true`（链式 `attempts: 8, backoff: 30_000`）；6 个 `@Process` 在动手前重查前置条件（`bootstrapUserInOrganization` 首步判 `isActiveOrganizationMember`）。`ClawXpertRecoveryService.recover()` 对 failed 作业用 `existing.retry()`（原子，不重复入队），否则用同一 jobId `add`；`canRecover` 对 `SUPER_ADMIN` 恒为 `false`（个人工作区不可用）。
8. **`ai-model` 的凭证校验 ≠ 访问授权**：本域只做 provider 目录与 `provider_credential_schema` 校验（0 表、`AIModelModule` 无 `TypeOrmModule`），授权解析 / 配额 / 记账在 `model-access` / `model-gateway` / `copilot*`。`getProvider` 默认返回 `undefined` 而不抛；校验命令由 `copilot-provider` 侧消费，不暴露 HTTP。
9. **`export-import` 的 `/api/import` 未挂载**：`ImportAllModule` 自身声明 `RouterModule.register([{ path: '/import' }])`，但全仓没有任何模块 import 它、`server.module.ts` 也未注册 → `GET/POST /api/import` 均不可达；控制器内 `ImportAllService` 与 `unzipAndParse` 相关调用**全部被注释**，`POST` 只做「`FileInterceptor('file')` 落盘 + 写一条 `import-history`（成功/失败都按 `ImportHistoryStatusEnum` 各写一行）」，`GET` 只按 `tenantId + importDate DESC` 分页读历史。附带事实：`ImportRecord` 出现在 `core/entities/index.ts` 导出的 `coreEntities` 中，而 `ImportHistory` **只**出现在 `ImportHistoryModule` 的 `forFeature` 里——模块不装配时该表缺少注册来源。

## 7. 结论

1. **本子域的内核是「平台基础枚举的只读 + 种子」与「服务端只做壳」**：字典四模块共用一套基类 CRUD 与一条种子通道，唯一可写字典是 `tags`；桌面 Shell 的真相在 `desktop_shell_*` 三张表与一条 WS 通道，执行本体在客户端；移动端与模型目录都是 0 表门面；初始化是队列副作用而非 HTTP 能力。
2. **安全语义集中在四处**：`credentialHash`（sha256 摘要 + `timingSafeEqual` + 90 秒级租约由 `LIMITS.lease` 决定）、`grant.operation`（`argsHash = sha256([command,cwd,timeoutSec])` 双端一致 + `decision` 三态）、`operation` 三元组唯一键（`tenantId + runId + toolCallId`，重试幂等）、`currentShellScope()` 三键同入 where（跨租户/组织不探测）。
3. **两处「代码在但不可达」必须如实标注**：`/api/contact`（`ContactModule` 未装配）与 `/api/import`（`ImportAllModule` 无人 import，核心逻辑注释）。它们不产生运行期行为，但会污染表计数与 Swagger 预期，任何「补挂载」动作都要同时补守卫与幂等。
4. **风险最高的单点是 `TagManagementService.usage` 的隐性契约**：它遍历全库 `entityMetadatas`，未在 `usageTargets` 登记的新 M2M junction 会让 `/api/tags/directory` 直接 400——跨域新增联接表时必须同步改这里。
