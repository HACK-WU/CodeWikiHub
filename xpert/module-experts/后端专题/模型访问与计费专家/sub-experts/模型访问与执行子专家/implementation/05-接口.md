## 鉴权约定

- **平台登录态 + 权限点**：`ModelAccessController` 的 `admin/*` 需要 `MODEL_ACCESS_REQUEST_VIEW` 或 `MODEL_ACCESS_REQUEST_EDIT`（读）与 `MODEL_ACCESS_REQUEST_EDIT`（写）；`ModelGatewayController` 的 `admin/*` 与 `ModelExecutionAdminController` 全类需要 `MODEL_GATEWAY_MANAGE`。
- **登录态但无 `@Permissions`**：`ModelAccessController` 的 `catalog` / `requests/my` / `requests` / `requests/:id/withdraw` / `grants/my`，`ModelGatewayController` 的 `catalog` / `requests*` / `grants/my` / `keys*` / `calls/my`，`ModelExecutionQueryController` 全类与 `ModelExecutionSessionController` 均无权限装饰器，只依赖 `RequestContext` 的租户/组织/用户。
- **显式拒绝 API principal**：`call-options`、`calls`、`revoke-mine`、`admin/*`（`reviewerTenant`）与 `ModelExecutionReconciliationService.reconcile` 在 `RequestContext.currentApiPrincipal()` 命中时抛 `Denied`；查询端点还要求 tenant/organization/user 三者齐备且相等。
- **网关 API Key**：`Authorization: Bearer sk-xpert-<10 位前缀>-<随机串>`；`ModelGatewayService.authenticate` 用 sha256 查 `tokenHash`，校验状态、有效期与属主存在性；scope 取自 Key 自身（tenant/organization/user），**不接受客户端 scope 头**。`ModelGatewayController` 与 `RequireTenantScope` 均要求租户上下文。
- **执行凭据**：`Authorization: Bearer xpert-exec-<43 位 base64url>`；`ModelExecutionGrantService.authenticate` 只比对 `credentialHash`，明文仅在 `issue` 响应出现一次。native 端点额外接受 `x-api-key`（内部包成 Bearer）；`/api/model-execution/openai/v1` 只读 `authorization` 头，不支持 `x-api-key`。
- **不接受的凭据**：管理端点不接受 CLI 执行凭据或 ChatKit client secret；个人查询端点不接受任何 API principal。

## OpenAI 兼容与 native 契约

- **两套入口分工**：`/api/openai/v1` 绑定 API Key 与 publication，调用经网关 `startCall` / `finishCall` 结算；`/api/model-execution/openai/v1` 绑定 grant 与其可访问模型集，调用经执行准入与 `metering.finish`。二者共用 `parseOpenAIChatRequest` 与 `executeGatewayChat`。
- **请求白名单**：`model`、`messages`、`stream`、`stream_options`、`tools`、`tool_choice`、`parallel_tool_calls`、`temperature`、`top_p`、`max_tokens`、`max_completion_tokens`、`stop`、`presence_penalty`、`frequency_penalty`、`prompt_cache_key`、`seed`、`n`；出现白名单外字段 → 400 `ModelGatewayOpenAIUnsupportedParameters`。`n` 仅支持 1；`stream_options` 仅支持 `include_usage`；工具仅 `function` 类型；`tool` 消息必须带 `tool_call_id`；内容类型仅 `text` 与 `image_url`（执行侧出现 `image_url` → 400 `BridgeUnsupported`）。
- **能力校验**：`assertRequestCapabilities` 按 publication/grant 快照的 `ModelFeature`（`VISION`/`TOOL_CALL`/`MULTI_TOOL_CALL`/`STREAM_TOOL_CALL`）校验，不支持时 400。
- **非流式响应**：`object:'chat.completion'`，`id: chatcmpl-<requestId>`，`choices[0].message.content`（空内容为 `null`）与可选 `tool_calls`，附 `usage{prompt_tokens,completion_tokens,total_tokens}`。
- **流式响应（SSE）**：`data: <json>\n\n` 分帧；首帧 `delta.role='assistant'`，后续 `chat.completion.chunk` 携带 `delta.content` / `delta.tool_calls`，末帧带 `finish_reason`；`stream_options.include_usage` 为真时附一帧空 `choices` + `usage`；以 `data: [DONE]\n\n` 结束。响应头为 `text/event-stream; charset=utf-8` + `no-cache, no-transform`。流中途失败时在已发送头部的情况下写一帧 `{error:{type:'upstream_error',message,code:'stream_failed'}}` 再收尾。
- **中断与超时**：`request.once('aborted')` 与 `response.once('close')` 触发 `AbortController.abort()`；执行侧另有 `grants.watch` 每 5 秒 `revalidate`（撤销/过期/收紧迫使中断）与 `requestIdleSeconds`（默认 600 秒静默）+ `absoluteExpiresAt` 双截止；网关侧 `MODEL_GATEWAY_UPSTREAM_TIMEOUT_MS`（29 分钟）超时中断并报 `ModelGatewayRequestTimedOut`。
- **429 契约**：限流抛 `ModelGatewayRequestLimitException`（HTTP 429），响应头带 `Retry-After: <retryAfterSeconds>`（速率限制为 60，并发限制为 1），错误体 `code` 为 `rate_limit_exceeded`；其它 429（如额度耗尽）`code` 固定 `insufficient_quota`。
- **native 请求**：`POST /api/model-execution/openai/v1/responses` 与 `/api/model-execution/anthropic/v1/messages` 必须提交含非空 `model` 的对象；`openai_responses` 拒绝 `store:true`、`background:true`、`previous_response_id`、`conversation` 并强制 `store:false`，要求 `input` 为字符串或数组；`anthropic_messages` 要求 `messages` 数组；两者都要求内联输入（`item_reference`/`file`/`input_file`/`image`/`input_image`/`input_audio`/`document`/`file_id` 一律 `Invalid`），递归深度上限 64。
- **native 参数与体积**：`max_output_tokens`（responses）/ `max_tokens`（messages）若非 undefined 必须是正的安全整数；非流式上游响应体累计超过 16 MB → `Invalid`；仅转发 `anthropic-` 前缀且长度 ≤ 4096 的请求头；流式要求上游 `content-type` 含 `text/event-stream` 且帧必须完整结束，否则 `Unavailable`；仅 404 之外的非 2xx 统一按 `Unavailable`。
- **native 错误体**：`{"type":"error","error":{"type":"rate_limit_error"|"invalid_request_error","message":…}}`；仅当状态码 < 500 时透出真实文案，否则替换为 `Unavailable` 文案。
- **协议降级**：模型不支持目标 native 协议但支持其桥接协议且租户 `chatBridgeProtocols` 允许时，走 `ChatBridgeWriter` 输出 native 形态帧；否则要求 `policy.nativeProtocols` 与模型 `protocols` 同时包含该协议，否则 `Unavailable`。native 失败不会回退到 Chat，也不会扩大授权。

## 错误码

- **执行族**（`executionError`）：`Budget`、`RateLimit` → 429；`Invalid`、`BridgeUnsupported`、`ConversationRequired` → 400；`Unavailable`、`Denied`、`Model`、`Unknown` → 403。每次构造都调用 `applicationMetrics.recordModelExecution(code)`，i18n 键形如 `server-ai:Error.ModelExecution<Code>`。
- **执行侧 OpenAI 兼容错误体**：`{"error":{"message","type","code":"model_execution_failed"}}`，`type` 在 429 为 `rate_limit_error`、其余 `invalid_request_error`；仅状态码 < 500 时 `message` 为真实文案。
- **网关族**（`modelGatewayMessage`，键 `server-ai:Error.<Key>`）：`ModelGatewayBearerRequired`、`ModelGatewayApiKeyInvalid`、`ModelGatewayApiKeyNotFound`、`ModelGatewayApiKeyOwnerMissing`、`ModelGatewayApiKeyNameRequired`、`ModelGatewayTenantScopeRequired`、`ModelGatewayAuthenticatedUserRequired`、`ModelGatewayFeatureDisabled`、`ModelGatewayPermissionRequired`、`ModelGatewayChatOnly`、`ModelGatewayModelNotFound`、`ModelGatewayModelNotCallable`、`ModelGatewayNoRemainingPoints`、`ModelGatewayRateLimitExceeded`、`ModelGatewayConcurrencyLimitExceeded`、`ModelGatewayCallNotFound`、`ModelGatewayCallInterrupted`、`ModelGatewayClientDisconnected`、`ModelGatewayRequestTimedOut`、`ModelGatewayUpstreamAssistantExpected`、`ModelGatewayStreamFailed`。
- **网关 OpenAI 兼容错误体**：`{"error":{"message","type","param":null,"code"}}`，`type` ∈ `authentication_error` / `permission_error` / `rate_limit_error` / `invalid_request_error` / `upstream_error`；请求解析错误码见 `openai-adapter.ts`（如 `ModelGatewayOpenAIUnsupportedParameters`、`ModelGatewayOpenAIMessagesRequired`、`ModelGatewayOpenAINOnlyOne`、`ModelGatewayOpenAIStreamOptionsUnsupported`、`ModelGatewayOpenAIStopShape` 等）。
- **模型访问族**：`ModelAccessRequestReasonRequired`、`ModelAccessRequestNotFound`、`ModelAccessWithdrawForbidden`、`ModelAccessAlreadyGranted`、`ModelAccessPlanIncluded`、`ModelAccessModelNotFound`、`ModelAccessModelDisabled`、`ModelAccessModelDeleted`、`ModelAccessManagerCannotRequest`、`ModelAccessGrantNotFound`、`ModelAccessGrantNotActive`、`ModelAccessGrantCannotShorten`、`ModelAccessGrantAlreadyPermanent`、`ModelAccessInvalidRequestStatus`、`ModelAccessRevocationReasonRequired`、`ModelAccessRejectionReasonRequired`、`ModelAccessFeatureDisabled`、`ModelAccessTenantContextRequired`、`ModelAccessAuthenticatedUserRequired`。
- **native 侧**：`ModelExecutionInvalid`（请求形状）、`ModelExecutionUnavailable`（上游/协议不可用）、`ModelExecutionModel`（模型不在可访问集，403）。

## 结论

三个前缀分工清晰：`/api/model-access` 是授权台账面（登录态 + 审批权限），`/api/model-gateway` + `/api/openai/v1` 是 API Key 面（Key 自证 + publication 语义），`/api/model-execution` 是执行面（短时凭据 + 三重身份判定 + 管理员对账）。两处需要强区分才能避免误用：两套 OpenAI 兼容入口的错误体与虚拟模型不同；`admin/*` 的 `:id` 必须用 `items[].id`（数据库 UUID），且 `applied` 不等于账本已投递，正用量仍需检查 `delivered`。
