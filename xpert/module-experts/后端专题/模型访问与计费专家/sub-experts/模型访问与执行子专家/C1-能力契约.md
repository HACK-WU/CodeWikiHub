## §1 HTTP 接口契约

**鉴权基线**：`ModelAccessController` 的 `admin/*` 需 `MODEL_ACCESS_REQUEST_VIEW` 或 `MODEL_ACCESS_REQUEST_EDIT`（读）/ `MODEL_ACCESS_REQUEST_EDIT`（写）；`ModelGatewayController` 的 `admin/*` 与 `ModelExecutionAdminController` 全类需 `MODEL_GATEWAY_MANAGE`；`/api/model-execution/openai/v1`、`/api/model-execution/openai/v1/{responses}`、`/api/model-execution/anthropic/v1/messages`、`/api/openai/v1/*` 均为 `@Public()` 自证鉴权。管理端点不接受 CLI 执行凭据或 ChatKit client secret。

## §2 服务能力契约

### 2.1 `ModelAccessService`（[model-access.service.ts](file://packages/server-ai/src/model-access/model-access.service.ts)）

| 方法 | 用途 | 参数与行为语义 | 异常 / 约束 |
| --- | --- | --- | --- |
| `getCatalog()` | 内部通道目录 | 无参数，scope 取当前请求上下文；读前处理到期授权 | 需租户与用户上下文 |
| `getExternalCatalog()` | 外部通道目录 | 无参数；通道固定 `external_api` | 特性未启用时可见集为空 |
| `resolveModelAccess(input)` | 单模型路径解析 | `tenantId`、`organizationId?`（缺省 `null` = 租户范围）、`userId`、`xpertId?`、`copilotId`、`copilotModelId`、`modelType`；返回 `allowed` / `accessSource`(`direct`/`plan`/`grant`) / `scope` / `multiplier` / `unavailableReason` | 付款人经 `resolveBillableUserId` 归一 |
| `canUseCatalogModel(input)` | 判权（布尔） | 入参同 `resolveModelAccess`；`direct` 亦为 `true` | 不抛权限异常 |
| `canUseCatalogModels(input)` | 批量判权 | `tenantId`/`organizationId?`/`userId`/`xpertId?` + `models[]`（同序返回 `boolean[]`，空数组返回 `[]`，付款人只解析一次） | 无 |
| `assertCanUseModel(input)` | 判权（抛错版） | 不可用抛 `ExceedingLimitException`；随后继续做会员配额与限流校验 | 不可用即抛 |
| `createRequest(input)` | 提交申请 | `reason` 必填 1–1000；顺序校验租户/用户/可见启用目标/特性开关/非管理者；先去重（已授权、已有 pending） | `ModelAccessManagerCannotRequest`、`ModelAccessRequestReasonRequired`、`ModelAccessPlanIncluded`、`ModelAccessAlreadyGranted` |
| `withdrawRequest(id, input?)` | 撤回 | 仅本人、仅 `requested` | `ModelAccessWithdrawForbidden`、`ModelAccessInvalidRequestStatus` |
| `approveRequest(id, input)` / `rejectRequest(id, input)` | 审批 / 驳回 | 审批 `validUntil?`(`YYYY-MM-DD`)、`note?`；驳回 `reason` 必填；审批幂等短路 | `ModelAccessRejectionReasonRequired`、`ModelAccessGrantNotFound` |
| `extendGrant(id, input)` / `revokeGrant(id, input)` | 延期 / 撤销 | 执行前先 `processDueGrants`；延期只允许延长；撤销写 `revokedAt/ById/Name/revokeReason` | `ModelAccessGrantNotActive`、`ModelAccessGrantCannotShorten`、`ModelAccessGrantAlreadyPermanent`、`ModelAccessRevocationReasonRequired` |
| `processDueGrants(filter)` / `processAllDueGrants()` | 到期处理 | `tenantId` 必填，可带 `organizationId`/`userId`/`copilotId`/`copilotModelId`/`modelType`；事务内悲观锁 `take(500)` 逐条转 `expired`，事件键 `grant:{id}:expired` | 由定时任务与读接口共同触发 |
| `closeOrganizationAccessForRemovedUser(input)` / `handleCopilotStateChanged(copilot)` / `handleConfiguredModelDeleted(input)` | 配置与生命周期联动 | 关单 + 撤销；模型删除时撤销对应授权；事件键如 `grant:{id}:user-left-organization` | 无 |

### 2.2 `ModelExecutionGrantService`（[execution-grant.service.ts](file://packages/server-ai/src/model-execution/execution-grant.service.ts)）

| 方法 | 用途 | 参数与行为语义 | 异常 / 约束 |
| --- | --- | --- | --- |
| `issue(actor, input)` | 签发执行凭据 | `actor{tenantId,organizationId,userId}`；`input{conversationId, source, environment, tool{id,version}, prepare?, deadline?, tokenBudget?}`；工具与精确版本必须命中租户策略（否则 `Invalid`）；`shell_execution` 必须 `prepare=true`，非 shell 不允许 `prepare`；返回 `{grant, secret, gatewayBaseUrl}`，secret 形如 `xpert-exec-<43 位 base64url>`，**库中只写 sha256**；`expiresAt = min(deadline, now+leaseSeconds)`，`absoluteExpiresAt = deadline`（受 `maxDurationSeconds` 封顶） | `Invalid`、`Denied`、`Model` |
| `authenticate(authorization?)` | 凭据认证 | 只接受 `/^Bearer (xpert-exec-[A-Za-z0-9_-]{43})$/`，按 `credentialHash` 反查后转 `validate` | 格式不符或查不到即 `Denied` |
| `validate(grant)` | 请求期校验（内部） | 逐项比对 tenant/org/actor/billable 四项上下文、`assertActive`、工具仍在策略中、`tightenExecutionLimits` 只收紧、来源与环境能力校验；把已存 `models` 与当前可见模型按 `id`/`copilotId`/`model`/`modelType`/`provider`/`providerScopeId`/`providerOrganizationId` 求交并裁剪能力与协议 | 默认模型被移除抛 `Model` |
| `revalidate(grant)` | 跨节点重读 | 事务内悲观锁重读授权并重跑校验；失败即抛错，调用方据此中断在途请求 | `Denied` |
| `activate(id, actor)` | 两阶段激活 | 只接受 `pending` + `shell_execution`；UPDATE 谓词带 `clock_timestamp()`；`affected !== 1` 即拒绝；**不重置准备租约、不复活已过期凭据** | `Denied` |
| `renew(id, actor)` | 续租 | 事务内先悲观锁行（注释说明 UPDATE 谓词可能先于行锁等待执行），再以 `expiresAt` / `absoluteExpiresAt` / `createdAt + maxDurationSeconds` 三重谓词续租 | 任一不满足即拒 |
| `revoke(id, actor)` | 撤销 | 仅限本人/本组织范围；置 `status='revoked'`；幂等 | `Denied` |
| `watch(grant, abort)` | 在途监护 | 每 5 秒 `revalidate`，失败即 `abort.abort()` | 无 |

### 2.3 准入与计量

| 方法 | 用途 | 参数与行为语义 | 异常 / 约束 |
| --- | --- | --- | --- |
| `ModelExecutionAdmissionService.begin(grant, model, outputLimit, estimatedInputTokens)` | 准入与预占 | 四参必填；单事务内先 `pg_advisory_xact_lock(hashtextextended('model-execution:{tenantId}:{ownerId}'))` 再悲观锁 `status='active'` 行并 `tightenExecutionLimits`；`reservation = estimatedInputTokens + outputLimit`（输出未指定取 `model.outputTokenLimit ?? 0`）；按 grant 级与付款人级各跑一次聚合，再对 shell 的父执行取最小已签发预算；非负安全整数不满足即 `Invalid`；插入 `source='execution_grant'`、`status='started'` 的尝试并记 `admitted` | `Budget`、`RateLimit`、`Denied`、`Invalid` |
| `ModelExecutionAdmissionService.dispatch(call, grant)` | 一次性派发 | 同序取锁后悲观锁读回 `status='started'` 的尝试，`!attempt \|\| attempt.dispatchedAt` 即 `Denied`；重新校验 grant 级/付款人级/父执行级预算后写 `dispatchedAt`（崩溃后预占保留） | `Denied`、`Budget`、`RateLimit` |
| `ModelExecutionMeteringService.finish(input)` | 落用量事实与结算态 | `input{call, grant, model, resolution, usage, providerUsage, error?, priceAuthority?('catalog'\|'provider'), providerRequestId?}`；仅 `usage.source === provider && totalTokens > 0` 构造 `ExecutionUsageFact`；事务内 `addSelect(['call.usageFact','call.settlementContext'])` + 悲观锁读回，已有事实与新事实 `isDeepStrictEqual` 不符即 `Invalid`；`errorCode='reconciled_no_usage'` 拒写；状态转 `settlement_pending`，有事实即同步 `deliver(call.id)` | `Invalid` |
| `ModelExecutionMeteringService.deliver(id)` | 幂等投递 | 缺 grant/model/settlementContext 抛 `Invalid`；派发 `CopilotTokenRecordCommand`，幂等键 `attemptId` = `call.requestId`；捕获 `ExceedingLimitException` 时必须查到 `ModelUsageDeliveryReceipt.status='completed'` 才算已投递 | `Invalid` |

### 2.4 `ModelGatewayService`（[model-gateway.service.ts](file://packages/server-ai/src/model-gateway/model-gateway.service.ts)）

| 方法 | 用途 | 参数与行为语义 | 异常 / 约束 |
| --- | --- | --- | --- |
| `createKey(name, lifetime?)` | 创建 API key | `name` 去空格后不可为空；`lifetime` 缺省 `90_days`；生成 `sk-xpert-<10 位前缀>-<随机串>`，存 `tokenHash` 与 `encryptedSecret`；返回含明文 `secret`（仅此一次） | `BadRequestException`（`ModelGatewayApiKeyNameRequired`）；需当前用户有效 |
| `listMyKeys()` / `revokeMyKey(id, reason?)` | 列出 / 撤销我的 Key | 列出前先 `expireDueApiKeys(tenantId)` 并 `addSelect('apiKey.encryptedSecret')`；撤销按 tenant+user+organization 三重过滤 | `ModelGatewayApiKeyNotFound` |
| `authenticate(authorization?)` | API key 认证 | `addSelect('apiKey.tokenHash')` 后按 sha256 查；过期就地把 Key 置 `Expired`；命中后刷新 `lastUsedAt`；**scope 取自 Key 自身** | `ModelGatewayBearerRequired`、`ModelGatewayApiKeyInvalid`、`ModelGatewayApiKeyOwnerMissing` |
| `listAccessiblePublications(identity)` | 可调用模型清单 | 按 Key 的 tenant/organization 过滤 publication 后逐个 `resolveExternalModelAccess`，只保留 `grantId` 且（allowed 或 `QuotaExhausted`）的项 | 无 |
| `requireCallablePublication(identity, externalModelId)` | publication 校验 | 找不到 model → 404；`QuotaExhausted`/`MembershipRequired` → 429；其余不可用 → 403 | `ModelGatewayModelNotFound`、`ModelGatewayNoRemainingPoints`、`ModelGatewayModelNotCallable` |
| `startCall(input)` | 网关准入 | `input{identity, publication, resolution, requestBody}`；先 `getOrCreateSettings` + `getAdmissionLimits(tenantId)`；事务内对 Key 属主 `User` 行悲观锁后再统计 60 秒窗口内 `source='external_api'` 计数与 `started` 并发数；插入 `model_gateway_call`（必带 `apiKeyId` + `publicationId`），仅 `storeBodies` 为真才写 `encryptedRequest` 与 `bodyExpiresAt` | `ModelGatewayRequestLimitException`（429，`openAICode='rate_limit_exceeded'`，`retryAfterSeconds` 速率 60 / 并发 1） |
| `finishCall(input)` | 结算 | `input{call, resolution, usage, responseBody?, error?}`；只接受 `started` 或 `settlement_pending`；先按 `settleChargeToCny` 折算（`unpriced → null`、`free → 0`），再调 `MembershipService.recordGatewayUsage`（`sourceReference = model-gateway:<requestId>`、按 `gatewayRequestId` 去重），回写 `chargedPoints`/`excessPoints`/token 三元组、清空 `settlementContext` | 其它状态直接返回当前行（不结算） |
| `recordSettlementFailure(call, usage, settlementError, outcome?)` | 结算失败降级 | 只在行仍为 `started` 时置 `settlement_pending` 并保留 token 与价格快照；写库异常返回 `null` | 无 |
| `retryPendingSettlements()` | 结算重试 | `@Interval(5 分钟)`；每次 `addSelect('call.settlementContext')` 取最旧 100 条 `external_api` + `settlement_pending`；缺 context 时重新 `resolveExternalModelAccess` 再重放 `finishCall` | 单条失败保持待结算 |
| `getSettings()` / `updateSettings(input)` | 网关设置与限流 | `getSettings` 内部 `getOrCreateSettings` 会建行（GET 有写副作用）；`updateSettings` 写 `storeBodies`/`bodyRetentionDays`/`requestsPerMinute`/`maxConcurrentRequests` | 越界值回退默认 |

### 2.5 `GatewayAdmissionPolicy`（[gateway-admission-policy.ts](file://packages/server-ai/src/model-gateway/gateway-admission-policy.ts)）

| 方法 | 用途 | 参数与行为语义 | 异常 / 约束 |
| --- | --- | --- | --- |
| `getAdmissionLimits(tenantId)` | 读取网关限流键 | 按 `tenantId` + `name IN (MODEL_GATEWAY_REQUESTS_PER_MINUTE_SETTING, MODEL_GATEWAY_MAX_CONCURRENT_REQUESTS_SETTING)` 查 `TenantSetting`，逐项 `parseBoundedInteger(值, 默认值, 最小值, 最大值)` | 越界或缺失回退默认值，不抛错 |
| `ModelGatewayRequestLimitException(message, retryAfterSeconds)` | 限流异常契约 | HTTP 429；字段 `openAICode = 'rate_limit_exceeded'`、`retryAfterSeconds`；控制器据此设置 `Retry-After` 响应头与错误体 `code` | 由 `startCall` 抛出 |

### ② 创建网关 API key 并调用 `/api/openai/v1`（含 429 处理）

```ts
// 服务端：明文密钥只在创建响应出现一次
const created = await modelGatewayService.createKey('my-service', ModelGatewayApiKeyLifetimeEnum.Days90)
console.log(created.secret) // sk-xpert-<prefix>-<random>

// 客户端：模型名必须是 publication 的 externalModelId，不能写 assistant-default
const response = await fetch('https://<host>/api/openai/v1/chat/completions', {
    method: 'POST',
    headers: { authorization: `Bearer ${created.secret}`, 'content-type': 'application/json' },
    body: JSON.stringify({ model: 'glm-5.3', messages: [{ role: 'user', content: 'Hello' }] })
})
if (response.status === 429) {
    const body = await response.json()
    // 限流：code='rate_limit_exceeded' 且带 Retry-After（速率=60s，并发=1s）；额度耗尽：code='insufficient_quota' 且无 Retry-After
    const retryAfter = Number(response.headers.get('retry-after') ?? 1)
    if (body?.error?.code === 'rate_limit_exceeded') await new Promise((r) => setTimeout(r, retryAfter * 1000))
}
```
