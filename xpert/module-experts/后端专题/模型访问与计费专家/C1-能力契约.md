### 1.3 OpenAI 兼容与 native 入口（两套入口差异）

| 维度 | `/api/openai/v1`（网关） | `/api/model-execution/openai/v1`（执行） |
| --- | --- | --- |
| 凭据 | `Authorization: Bearer sk-xpert-…`（API key） | `Authorization: Bearer xpert-exec-…`（执行凭据）；native 亦接受 `x-api-key` |
| 绑定范围 | API key 自身 scope + publication（外部模型名） | 单次执行授权及其可访问模型集 |
| 模型名 | publication 的 `externalModelId` | 授权内模型 id，额外支持虚拟模型 `assistant-default` |
| 计费路径 | 网关调用结算（按外部调用记账） | 执行准入预占 + 权威用量事实结算 |
| `GET models` | `{object:'list',data:[{id,object:'model',created,owned_by:'xpert'}]}` | 同结构但无 `created`，可能含 `assistant-default` |
| 请求白名单 | 仅接受受支持的 Chat Completions 字段；`n` 仅 1、`stream_options` 仅 `include_usage`、工具仅 `function`、内容仅 `text`/`image_url` | 同白名单；出现 `image_url` 直接拒绝（`BridgeUnsupported`） |
| 能力校验 | 按 publication 的 `vision`/`tool_call`/`multi_tool_call`/`stream_tool_call` 校验 | 按授权的 `capabilities` 与 `protocols` 校验 |
| 响应 | 非流式 `object:'chat.completion'`；流式 `chat.completion.chunk`，`data: <json>\n\n` 分帧，末尾 `data: [DONE]` | 与网关一致；native 入口输出 Responses / Messages 形态 |
| 错误体 | `{"error":{"message","type","param":null,"code"}}`，`type` 取 `authentication_error`/`permission_error`/`rate_limit_error`/`invalid_request_error`/`upstream_error` | `{"error":{"message","type","code":"model_execution_failed"}}`；native 为 `{"type":"error","error":{…}}` |
| 429 | 限流带 `Retry-After`，`code` 固定为 `insufficient_quota` | `Budget` / `RateLimit` 映射 429，`type`=`rate_limit_error` |
| 文案透出 | 状态码 < 500 时透出真实文案，否则 `Unavailable` 文案 | 同上 |

## §2 服务能力契约

### 2.1 `ModelAccessService`（`packages/server-ai/src/model-access/model-access.service.ts`）

| 方法 | 用途 | 参数与行为语义 | 返回 | 异常 / 约束 |
| --- | --- | --- | --- | --- |
| `getCatalog()` | 内部通道模型目录 | 无参数；scope 取当前请求上下文 | `IModelAccessCatalog` | 需登录态与租户；会先处理到期授权 |
| `getExternalCatalog()` | 外部通道目录 | 无参数；通道固定 `external_api` | `IModelGatewayCatalog` | 通道特性未启用时可见集为空 |
| `resolveModelAccess(input)` | 单模型授权解析 | `tenantId`、`organizationId?`（缺省为 `null` = 租户范围）、`userId`、`xpertId?`、`copilotId`、`copilotModelId`、`modelType` | `IModelAccessResolution`（`allowed`、`accessSource`、`scope`、`multiplier`、`unavailableReason`） | `accessSource` 取值差异：`direct`（自有 provider 凭据，不产生记账）/ `plan`（会员套餐）/ `grant`（显式授权）；`scope` 取 `tenant` 或 `organization` |
| `canUseCatalogModel(input)` | 判权（布尔） | 同上 | `boolean` | 不抛权限异常；`direct` 亦为 `true` |
| `canUseCatalogModels(input)` | 批量判权 | `tenantId`、`organizationId?`、`userId`、`xpertId?` + `models[]`（每项 `copilotId`/`copilotModelId`/`modelType`） | `boolean[]`（与入参同序） | 空数组返回 `[]`；付款人只解析一次 |
| `assertCanUseModel(input)` | 判权（抛错版） | 同 `resolveModelAccess` | `IModelAccessResolution` | 不可用抛 `ExceedingLimitException`；随后继续做会员配额与限流校验 |
| `createRequest(input)` | 提交申请 | `copilotId`、`copilotModelId`、`modelType`、`reason`（必填 ≤1000） | `IModelAccessRequest` | 管理者自审被阻断（`ForbiddenException`）；已有申请回读既有记录；已授权则抛「已授权」 |
| `approveRequest(id, input)` | 审批通过 | `validUntil?`（`YYYY-MM-DD`）、`note?` | 授权对象或 `null` | 目标模型已删除时关闭申请并返回 `null`；重复审批幂等 |
| `rejectRequest(id, input)` | 驳回 | `reason` 必填 | `IModelAccessRequest` | 缺理由即拒 |
| `extendGrant(id, input)` | 延期 | `validUntil?`、`note?` | 授权对象 | 只允许延长；已是永久不可再改 |
| `revokeGrant(id, input)` | 撤销 | `reason` 必填 | 授权对象 | 撤销前先处理到期授权 |
| `processDueGrants(filter)` | 到期处理 | `tenantId` 必填，可带 `organizationId`/`userId`/`copilotId`/`copilotModelId`/`modelType` | 失效条数 | 由定时任务与读接口共同触发，可用范围参数收窄 |

### 2.2 `ModelExecutionGrantService`（`packages/server-ai/src/model-execution/execution-grant.service.ts`）

| 方法 | 用途 | 参数与行为语义 | 返回 | 异常 / 约束 |
| --- | --- | --- | --- | --- |
| `issue(actor, input)` | 签发执行凭据 | `actor`：`tenantId`/`organizationId`/`userId`；`input`：`conversationId`、`source`（`agent_invocation` / `cli_session` / `shell_execution`）、`environment`、`tool{id,version}`、`prepare?`（仅 shell，否则拒绝）、`deadline?`、`tokenBudget?`（只可收紧） | `{ grant, secret, gatewayBaseUrl }` | 工具与精确版本必须命中租户策略；明文 secret 仅在此响应出现一次 |
| `authenticate(authorization)` | 凭据认证 | `Authorization: Bearer xpert-exec-<43 位>` | 授权解析结果（含授权与可访问模型） | 格式不符、查不到或失效均拒绝 |
| `validate(grant)` | 请求期校验（内部） | 已有授权对象 | 校验后的授权 | 上下文与授权必须一致；只能收紧，不得放宽模型/协议/预算 |
| `revalidate(grant)` | 跨节点重读授权 | 已有授权对象 | 刷新后的授权 | 授权被撤销/过期时抛错；调用方据此中断在途请求 |
| `activate(id, actor)` | 两阶段激活 | `id` + `actor` | 激活结果 | 仅 `pending` + shell 可用；不重置准备租约、不复活已过期凭据 |
| `renew(id, actor)` | 续租 | `id` + `actor` | 更新结果 | 受绝对截止与策略时长封顶；失败即拒绝 |
| `revoke(id, actor)` | 撤销 | `id` + `actor` | 无 | 幂等；仅限本人/本组织范围内授权 |

### 2.3 准入与计量

| 方法 | 用途 | 参数与行为语义 | 返回 | 异常 / 约束 |
| --- | --- | --- | --- | --- |
| `ModelExecutionAdmissionService.begin(grant, model, outputLimit, estimatedInputTokens)` | 执行准入与预占 | 四参必填；`outputLimit` 与 `estimatedInputTokens` 必须为非负安全整数 | 新建的调用尝试（`started`，含预占量） | 预算未配置即不参与准入（无隐式默认）；预算超限 `Budget`、并发/速率超限 `RateLimit`、授权无效 `Denied` |
| `ModelExecutionAdmissionService.dispatch(call, grant)` | 一次性派发 | 调用尝试 + 授权 | 派发时间标记 | 二次派发被拒；派发后失败不释放预占 |
| `ModelExecutionMeteringService.finish(input)` | 落用量事实与结算态 | `call`/`grant`/`model`/`resolution`/`usage`/`providerUsage`/`error?`/`priceAuthority?`（`catalog`/`provider`）/`providerRequestId?` | 结算态调用尝试 | 仅 `usage.source = provider` 且 `totalTokens > 0` 视为权威事实；同一尝试重复提交不一致事实即判非法；估算绝不进入事实 |

### 2.4 `ModelGatewayService`（`packages/server-ai/src/model-gateway/model-gateway.service.ts`）

| 方法 | 用途 | 参数与行为语义 | 返回 | 异常 / 约束 |
| --- | --- | --- | --- | --- |
| `createKey(name, lifetime?)` | 创建 API key | `name` 必填非空；`lifetime` 缺省 `90_days`，可选 `30_days`/`90_days`/`180_days`/`permanent`（`permanent` 无到期时间） | 创建结果（含明文密钥，仅此一次） | 名称为空、有效期不支持即 400；需当前用户有效 |
| `authenticate(authorization)` | API key 认证 | Bearer 令牌 | 身份对象（租户/组织/用户 + key） | 令牌无效、已撤销或属主缺失即 401；过期 key 会被就地置为过期 |
| `listAccessiblePublications(identity)` | 可见模型清单 | 身份对象 | 可调用条目（publication + 授权解析） | 只保留当前仍可调用（或仅剩配额原因）的条目 |
| `startCall(input)` | 网关准入 | `identity`、`publication`、`resolution`、`requestBody` | 新建调用记录（`started`） | 超 RPM 或并发上限抛限流异常（429，含 `Retry-After`） |
| `finishCall(input)` | 结算 | `call`、`resolution`、`usage`、`responseBody?`、`error?` | 结算后的调用记录 | 仅 `started`/`settlement_pending` 可结算；价格未知按未定价处理、免费记 0 |
| `retryPendingSettlements()` | 结算重试 | 无参数；每次取最旧 100 条待结算的外部调用 | 成功条数 | 缺结算上下文时重新解析访问；单条失败保持待结算 |
| `getSettings()` | 读网关切关与限流 | 无参数（取当前租户） | 设置与限流参数 | **读会初始化设置行**（写副作用） |
| `updateSettings(input)` | 写网关设置 | `storeBodies`、`bodyRetentionDays`、`requestsPerMinute`、`maxConcurrentRequests` | 更新后的设置 | 越界值回退默认；需 `MODEL_GATEWAY_MANAGE` |

### 2.5 `MembershipService`（`packages/server-ai/src/membership/membership.service.ts`）

| 方法 | 用途 | 参数与行为语义 | 返回 | 异常 / 约束 |
| --- | --- | --- | --- | --- |
| `recordUsage(input)` | 记账（调用与会话路径） | 必含 `tenantId`、`userId`、`settlementAmount` 与 `sourceReference`（幂等键：调用侧为 `model-usage-charge:<事实ID>`，个人积分行为同键加 `:personal` 后缀）；`modelAccess?` 为解析结果 | 账本行或 `null` | 金额为 0、`accessSource = direct`、或该范围未启用会员计划时静默返回 `null`（不记账） |
| `recordGatewayUsage(input)` | 记账（网关路径） | 幂等键由服务自造 `model-gateway:<gatewayRequestId>`；无需调用方提供 | `{ chargedPoints, excessPoints, ledger }` | 无会员访问时返回零扣费但带超额证据的结果 |
| `adjustUserPoints(userId, input)` | 调整会员额度 | `pointDelta` 必须非零；仅当前租户/组织范围 | 会员对象 | 无限额度会员不可调整；需 `MEMBERSHIP_EDIT` |
| `adjustPersonalPoints(userId, input)` | 调整个人积分 | `pointDelta` 必须非零 | 调整结果 | 组织范围调用即 403；用户须符合资格 |
| `isMembershipPlanEnabled(input?, manager?)` | 判断范围是否启用会员计划 | 缺省取当前范围；`organizationId` 有值时按组织判定 | `boolean` | 组织与租户开关口径不同，勿混用 |
| `findModelAccess(input?, manager?, forUpdate?)` | 解析会员与模型访问 | `forUpdate` 缺省 `false`；`organizationId` 缺省为 `null`（租户范围） | 会员访问对象或 `null` | **解析路径可能产生自愈写入**（范围未初始化时） |
| `assertCanUse(input, modelAccess?)` | 调用前配额校验 | 至少 `tenantId`/`userId`/`copilotId`/`provider`/`model`；`organizationId`、`copilotOrganizationId`、`xpertId` 可选 | 无（通过即返回） | `direct` 与开关关闭直接放行；无访问抛「需会员计划」；额度耗尽且无个人积分抛「积分超限」；末尾执行限流校验 |
| `hasConsumableBalance(access)` | 是否仍有可用余额 | 会员访问对象 | `boolean` | 无限额度视为可用；额度为 0 时看个人积分 |
| `assertRateLimits(...)`（内部，经 `assertCanUse` 生效） | 套餐限流 | 规则按 `provider`/`model` 匹配，`model` 支持 `*`；窗口取 `hour`/`day`/`week`/`cycle` | 无（通过即返回） | 统计口径只含会员与个人积分两类扣减行 |
| `processDueMembershipPeriods(limit?)` | 周期结算 | `limit` 缺省 100（内部收敛上限 500） | 含扫描/结算/跳过/失败计数的结果 | 每分钟由定时任务触发；单条失败只累加失败计数 |
