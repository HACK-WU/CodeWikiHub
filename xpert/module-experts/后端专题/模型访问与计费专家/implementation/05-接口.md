## 鉴权约定

- **登录态 + 权限点**：`MODEL_GATEWAY_MANAGE`（网关管理、执行管理）、`MODEL_USAGE_MONITOR`（用量台账）、`MODEL_ACCESS_REQUEST_VIEW`/`MODEL_ACCESS_REQUEST_EDIT`（模型访问审批）、`MEMBERSHIP_USE`/`MEMBERSHIP_EDIT`（会员与计费）、`COPILOT_EDIT`（模型/提供商配置）。权限点枚举见 `AIPermissionsEnum`。
- **API Key（网关）**：`Authorization: Bearer sk-xpert-<prefix>-<random>`，`ModelGatewayService.authenticate` 以 sha256 哈希查 `model_gateway_api_key`，校验状态、有效期与用户有效性；scope 取自 Key 自身（tenant/organization/user），不接受客户端 scope 头。
- **执行凭据（execution credential）**：`Authorization: Bearer xpert-exec-<43 位 base64url>`，`ModelExecutionGrantService.authenticate` 只比对 `credentialHash`（明文仅在签发时返回一次）；native 端点亦接受 `x-api-key` 头（内部包成 Bearer）。
- **登录态但无 `@Permissions`**：`ModelAccessController` 的 `catalog`/`requests*`/`grants/my`、`ModelGatewayController` 的个人 `keys`/`calls/my`/`requests*`、`CopilotController.findAllCopilots/getOne/availables/providers/models`、`CopilotCheckpointController` 三个端点均无权限装饰器，只依赖登录态与上下文租户/组织/用户判定。
- **显式拒绝 API principal**：`/api/model-execution` 的 `call-options`、`calls`、`revoke-mine` 与全部 `admin/*` 在 `RequestContext.currentApiPrincipal()` 命中时抛 `Denied`，并要求 tenant/organization/user 三重相等。

## 模型访问接口

- `GET /api/model-access/catalog` — 当前用户可用的内部通道模型目录（`ModelAccessService.getCatalog`）。
- `GET /api/model-access/requests/my`、`POST /api/model-access/requests`（`ModelAccessRequestCreateDto`）、`POST /api/model-access/requests/:id/withdraw`（`ModelAccessRequestWithdrawDto`）— 申请与撤回。
- `GET /api/model-access/grants/my` — 我持有的授权。
- `GET /api/model-access/admin/requests|grants|events` — 分页列表，支持 `$take`/`$skip` 与 `ModelAccessAdminQueryDto` 过滤；需 `MODEL_ACCESS_REQUEST_VIEW` 或 `MODEL_ACCESS_REQUEST_EDIT`。

- 状态流转由生命周期协调任务补偿（见运维文档），接口本身不提供批量改库入口。

## OpenAI 兼容与 native 协议契约

- **两套 OpenAI 入口**：`/api/openai/v1`（`ModelGatewayOpenAIController`，API Key，绑定 publication scope，调用经网关结算）与 `/api/model-execution/openai/v1`（`ModelExecutionOpenAIController`，执行凭据，绑定 grant 及其可访问模型集，调用经执行准入与计量）。二者共用 `parseOpenAIChatRequest` 与 `executeGatewayChat` 执行体。
- **`GET models`**：网关侧返回 `{object:'list',data:[{id,object:'model',created,owned_by:'xpert'}]}`；执行侧返回同结构但无 `created`，且在 `grant.defaultModelId` 属于可访问模型时追加虚拟模型 `assistant-default`。
- **`POST chat/completions` 请求白名单**：`model`、`messages`、`stream`、`stream_options`、tools 相关字段、`seed`、`n` 等（`SUPPORTED_KEYS`）；出现白名单外字段 → 400 `ModelGatewayOpenAIUnsupportedParameters`。`n` 仅支持 1；`stream_options` 仅支持 `include_usage`；工具仅支持 `function` 类型，`tool` 消息必须带 `tool_call_id`；内容类型仅 `text` 与 `image_url`，其余 → `ModelGatewayOpenAIContentTypeUnsupported`。
- **网关侧能力校验**：`image_url`、工具、并行工具、流式工具分别按 publication 的 `ModelFeature`（`VISION`、`TOOL_CALL`、`MULTI_TOOL_CALL`、`STREAM_TOOL_CALL`）校验，不支持时返回 400。
- **执行侧限制**：出现 `image_url` 内容直接抛 `BridgeUnsupported`（400）；只接受 `protocols` 含 `openai_chat` 的模型；`assistant-default` 解析为 `grant.defaultModelId`，模型不在可访问集时抛 `Model`（403）。
- **响应结构**：非流式为 `object: 'chat.completion'` + `choices[0].message`；流式为 `object: 'chat.completion.chunk'`，首帧 `delta.role = 'assistant'`，每帧 `choices[0].delta`/`finish_reason`，`stream_options.include_usage` 为真时末尾附 `usage`，最后以 `data: [DONE]` 结束（`data: <json>\n\n` 分帧）。
- **SSE 与中断**：`request.once('aborted')` 与 `response.once('close')` 触发 `AbortController.abort()`；执行侧另有 `grants.watch` 每 5 秒 `revalidate`，撤销或过期即中断在途请求；网关侧还有 `MODEL_GATEWAY_UPSTREAM_TIMEOUT_MS` 超时中断。
- **native 端点**：`POST /api/model-execution/openai/v1/responses` 与 `POST /api/model-execution/anthropic/v1/messages`。请求体必须是含非空 `model` 的对象，否则 `Invalid`；`openai_responses` 拒绝 `store:true`、`background:true`、`previous_response_id`、`conversation`，并强制 `store:false`；`anthropic_messages` 要求 `messages` 数组；两者都要求内联输入。
- **native 参数与体积**：`max_output_tokens`（responses）/ `max_tokens`（messages）若给出必须是正的安全整数，否则 `Invalid`；非流式响应体累计超过 16 MB 抛 `Invalid`；仅转发 `anthropic-*` 前缀且长度 ≤ 4096 的请求头；上游 404 之外的非 2xx 统一按 `Unavailable` 处理。
- **协议降级（Chat bridge）**：模型不具备目标 native 协议但具备其桥接协议且租户策略 `chatBridgeProtocols` 允许时，走 `ChatBridgeWriter` 输出 native 形态帧；否则要求 `policy.nativeProtocols` 与模型 `protocols` 同时包含该协议，否则 `Unavailable`。

## 模型执行接口

- `GET /api/model-execution/call-options` — 返回当前用户维度的 `assistants`（去重 `context->>'xpertId'`）、`models`、`tools` 候选；要求 tenant/organization/user 齐备且非 API principal。
- `GET /api/model-execution/calls` — 本人执行调用分页，过滤项含 `model`、`usageSource`、`environment`、`pricingStatus`、`startedAfter/Before`、`status`、`entry`（`cli`/`agent_runtime`/`shell`）、`assistantId`、`conversationId`、`executionId`、`tool`、`take`/`skip`；返回 `points`、`pricingStatus`、`delivered` 等结算视图字段。
- `POST /api/model-execution/revoke-mine` — 将本人 `pending`/`active` 的执行授权批量置为 `revoked`，返回 `{revoked:true}`。
- `POST /api/model-execution/openai/v1/chat/completions`、`GET /api/model-execution/openai/v1/models`、`POST /api/model-execution/openai/v1/responses`、`POST /api/model-execution/anthropic/v1/messages` — 见上一节契约。
- `GET /api/model-execution/admin/pending` — 待核对积压分页（`take` 1–100、`skip` 0–100000），返回 `id`（数据库 UUID）、`attemptId`、`callId`、模型与预占量。
- `POST /api/model-execution/admin/calls/:id/reconcile` — 提交外部证据核对（`operationId`、`evidenceReference`、`evidenceSha256`、`reason`、`providerRequestId`、`outcome` 及 Token/金额），`:id` 必须使用 `pending` 列表的 `items[].id`。
- `POST /api/model-execution/admin/calls/:id/retry-delivery` — 重放用量事实投递，返回 `delivered`。
- `GET|PUT /api/model-execution/admin/policy` — 读取/写入租户执行策略：`nativeProtocols`、`chatBridgeProtocols`、`gatewayBaseUrl`、`limits`、`cliPermissions`、`tools`；写入用 `pg_advisory_xact_lock('model-execution-policy:<tenantId>')` 串行化。

## Copilot 系接口

## 错误码

- **模型执行族**（`executionError`）：
  - `Budget`、`RateLimit` → 429（`HttpStatus.TOO_MANY_REQUESTS`）；
  - `Invalid`、`BridgeUnsupported`、`ConversationRequired` → 400（`BadRequestException`）；
  - `Unavailable`、`Denied`、`Model`、`Unknown` → 403（`ForbiddenException`）。
  - i18n key 形如 `server-ai:Error.ModelExecution<Code>`，如 `ModelExecutionUnavailable`、`ModelExecutionBridgeUnsupported`、`ModelExecutionDenied`、`ModelExecutionRateLimit`、`ModelExecutionModel`、`ModelExecutionUnknown`（中英文文案见 `zh-Hans.json`/`en-US.json`）。
  - 每次构造错误都会调用 `applicationMetrics.recordModelExecution(code)`，事件名即 code。
- **执行侧 OpenAI 兼容错误体**：`{"error":{"message","type","code":"model_execution_failed"}}`；`type` 在 429 时为 `rate_limit_error`，其余为 `invalid_request_error`；仅当状态码 < 500 时 `message` 为真实文案，否则替换为 `Unavailable` 文案。
- **网关族**（`modelGatewayMessage`，key 为 `server-ai:Error.<Key>`）：`ModelGatewayBearerRequired`、`ModelGatewayApiKeyInvalid`、`ModelGatewayApiKeyNotFound`、`ModelGatewayApiKeyNameRequired`、`ModelGatewayKeyLifetimeUnsupported`、`ModelGatewayTenantScopeRequired`、`ModelGatewayAuthenticatedUserRequired`、`ModelGatewayFeatureDisabled`、`ModelGatewayPermissionRequired`、`ModelGatewayChatOnly`、`ModelGatewaySourceNotChat`、`ModelGatewayModelNotFound`、`ModelGatewayModelNotCallable`、`ModelGatewayNoRemainingPoints`、`ModelGatewayRateLimitExceeded`、`ModelGatewayConcurrencyLimitExceeded`、`ModelGatewayCallNotFound`、`ModelGatewayCallInterrupted`、`ModelGatewayClientDisconnected`、`ModelGatewayRequestTimedOut`、`ModelGatewayUpstreamAssistantExpected`。
- **网关 OpenAI 兼容错误体**：`{"error":{"message","type","param":null,"code"}}`；`type` 取值 `authentication_error` / `permission_error` / `rate_limit_error` / `invalid_request_error` / `upstream_error`；限流时额外带 `Retry-After`，且 429 的 `code` 固定为 `insufficient_quota`（限流异常本身用其 `openAICode`）。请求解析类 400 文案：`ModelGatewayOpenAIUnsupportedParameters`、`ModelGatewayOpenAIMessagesRequired`、`ModelGatewayOpenAINOnlyOne`、`ModelGatewayOpenAIStreamOptionsUnsupported`、`ModelGatewayOpenAIToolCallsUnsupported`、`ModelGatewayOpenAIParallelToolsUnsupported`、`ModelGatewayOpenAIStreamToolsUnsupported`、`ModelGatewayOpenAIImageUnsupported`、`ModelGatewayOpenAIToolMessageIdRequired`、`ModelGatewayOpenAIRoleUnsupported`、`ModelGatewayOpenAIContentRequired`、`ModelGatewayOpenAIFunctionToolsOnly`、`ModelGatewayOpenAIToolArgumentsJson`、`ModelGatewayOpenAIContentShape`、`ModelGatewayOpenAIContentTypeUnsupported`、`ModelGatewayOpenAIStopShape` 及 `ModelGatewayOpenAI{ObjectRequired,FieldNonEmptyString,FieldString,FieldNumber,FieldBoolean,FieldArray}`。
- **native 错误体**：`{"type":"error","error":{"type","message"}}`，429 时 `type` 为 `rate_limit_error`，其余 `invalid_request_error`，同样只在状态码 < 500 时透出真实文案。
- **其他**：检查点线程缺失 → 400（`server-ai:Error.CheckpointThreadRequired`）；provider 模型不匹配 → 403；图标缺失 → 404 `Icon not found`。
