## 上传与下载契约

- **插件归档上传**：`POST /api/plugin/archive`，`multipart/form-data` 字段名 `file`，服务端硬上限 100MB（`100 * 1024 * 1024`）；`config` 支持 JSON 字符串或对象，解析失败 → 400 `config must be valid JSON` / `config must be a JSON object`。
- **技能包上传三处**：`POST /api/skill-package/workspace/:workspaceId/upload`（整包 zip）、`POST /api/skill-package/workspace/:workspaceId/:id/file/upload`（字段 `path` + `file`，单文件）、`POST /api/skill-repository/:id/upload`（zip，仅 workspace-public 仓库）。三者均使用 `FileInterceptor('file')`，源码未声明显式体积上限，实际受全局 body/multer 配置约束。
- **技能包下载两处**：`GET .../:id/download` 与 `GET .../:id/file/download?path=`；目录走 `archiver('zip', { zlib: { level: 9 } })` 流式打包，单文件走 `createReadStream(...).pipe(res)`；两者统一写 `Content-Type` 与 `Content-Disposition: attachment; filename="<encodeURIComponent(name)>"; filename*=UTF-8''<同值>`，归档出错时 `res.destroy(error)`。
- **文件级读写路径**：目录 → `GET .../:id/files`；读 → `GET .../:id/file?path=`；写 → `PUT .../:id/file`（body `{ path, content }`）；上传 → `POST .../:id/file/upload`（表单 `path`）；删 → `DELETE .../:id/file?path=`；路径越界在 service 层以 `validateSkillRelativePath`/`resolve` 校验，越界或非法 → 400（如 `Invalid skill file path`）。
- **市场图标**：`GET /api/plugin/marketplace/assets/icon` 以 `StreamableFile` 返回二进制并带私有缓存头。

## 鉴权约定

- **全局两层守卫**：API 启动时执行 `app.useGlobalGuards(new AuthGuard(reflector), new PluginScopeGuard(reflector))`——除显式 `@Public()` 外所有路由要求已认证；`PluginScopeGuard` 按路由 handler/class 上的 `ORGANIZATION_METADATA_KEY` 元数据（插件安装时写入的 scope）与请求上下文比对，未标注或标注为 `SYSTEM_GLOBAL_SCOPE` 直接放行，否则不匹配即抛 `ForbiddenException('Plugin endpoint is not available in the current tenant or organization scope')`。因此**调整插件 controller 的 scope 声明等价于调整全局鉴权面**。
- **`@Public()` 例外**：本范围内仅 `/api/plugin/marketplace/public` 一处公开；其余市场路由（含 `assets/icon`）保持需登录，`icon` 额外用 `Vary: Authorization, tenant-id, organization-id, x-scope-level` 防止跨租户缓存串味。
- **角色要求**：`installOrganization` 与 4 个 `mcp/:componentKey/*` 端点 → `RoleGuard` + `SUPER_ADMIN`；`/api/plugin-applications` 的 `initialize`/`prepare`/`bind-toolset`/`discard-configuration` → `RoleGuard` + `SUPER_ADMIN`/`ADMIN`/`TRIAL`；`/api/system/setup/plugins` → `TenantPermissionGuard` + `RoleGuard` + `SUPER_ADMIN`。
- **`WorkspaceAuthoringGuard` 语义**：取 `request.params.workspaceId`，非 UUID → 400 `server-ai:Error.WorkspaceIdInvalid`（默认文案 `A valid Workspace ID is required.`）；随后 `workspaceAccessService.assertCanAuthor(workspaceId)`，其实现直接委托 `assertCanWrite` → `assertCan(workspaceId, 'write')`，即判定依据是当前用户对目标工作区的**写权限**（而非成员身份或管理权）。
- **注意**：`POST /api/skill-package/install` 与 `DELETE /api/skill-package/uninstall` 未挂 `WorkspaceAuthoringGuard`，其授权依赖全局 `AuthGuard` 与 service 内部校验，调用方不应假定存在工作区级写权限检查。

- **400 `BadRequestException`**
  - 文案类：`pluginName is required`、`file is required`、`plugin name is required`、`config must be valid JSON`、`config must be a JSON object`、`target must be organization, workspace or xpert`、`workspaceId is required`、`xpertId is required`、`Query is required`、`Request body is required`、`Repository name and provider are required.`、`A valid zip file is required`、`Skill file not found`、`File path is required`、`This file type cannot be edited`、`Invalid skill file path`。
  - i18n key：插件侧 `server:Error.PluginNamesRequired`、`server:Error.PluginPackageNameRequired`、`server:Error.PluginSystemLevelInstallForbidden`、`server:Error.PluginTenantLevelInstallForbidden`、`server:Error.PluginProcessLevelConflict`、`server:Error.PluginTenantLevelAlreadyOwned`、`server:Error.PluginRuntimePolicyChanged`、`server:Error.PluginInstallFailed`、`server:Error.PluginSystemLevelDefaultTenantRequired`、`server:Error.PluginSystemUninstallForbidden`、`server:Error.SetupPluginCatalogQuery`、`server:Error.SetupPluginSelection`；技能侧 `server-ai:Error.WorkspaceIdInvalid`、`server-ai:Error.ApplicationInitializeRequestInvalid`、`server-ai:Error.ApplicationToolsetSelectionInvalid`、`server-ai:Error.ApplicationToolsetDependencyInvalid`、`server-ai:Error.ApplicationSetupScopeRequired`、`server-ai:Error.ApplicationSetupConflict`。
- **403 `ForbiddenException`**：`PluginScopeGuard` 的 scope 拒绝；`RoleGuard` 角色不符；应用初始化 `role_required`。
- **404 `NotFoundException`**：`plugin was not found`；市场图标 hash 不匹配（空体）；插件资源 `{ errorCode: 'PLUGIN_RESOURCE_NO_MATCHING_COMPONENTS', message: server-ai:Error.NoMatchingPluginComponents }`（`PLUGIN_RESOURCE_ERROR_CODE` 定义于 contracts）；`Loaded plugin App configuration was not found`。
- **409 `ConflictException`**：`application_installation_conflict`、`application_assistant_name_conflict`。
- **500 `InternalServerErrorException`**：索引同步失败，消息为 `getErrorMessage(error)`；同步前另可能抛 400、运行时错误 `SyntaxError`/`TypeError` 抛 `Error`。
- **业务字符串码（400/403）**：`scope_not_supported`、`organization_scope_required`、`application_preflight_failed`、`application_suite_runtime_unavailable`、`invalid_vision_model`、`invalid_embedding_model`。
