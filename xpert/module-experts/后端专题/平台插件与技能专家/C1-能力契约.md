## 上传与下载契约

- **插件归档上传**：`POST /api/plugin/archive`，字段名 `file`，**服务端硬上限 100MB**；`config` 支持 JSON 字符串或对象，解析失败 400 `config must be valid JSON` / `config must be a JSON object`。
- **技能包上传三处**：整包 zip（`POST /api/skill-package/workspace/:workspaceId/upload`）、单文件（`POST …/:id/file/upload`，表单 `path` + `file`）、公开仓库 zip 直传（`POST /api/skill-repository/:id/upload`）。三者均使用 `FileInterceptor('file')` 且**未声明显式体积上限**，实际受全局配置约束。
- **技能包下载两处**：整包 `GET …/:id/download` 与单文件 `GET …/:id/file/download?path=`；目录以 zip 流式打包（压缩级别 9），单文件以读流管道输出；两者统一写 `Content-Type` 与 `Content-Disposition: attachment; filename="…"; filename*=UTF-8''…`，失败时直接销毁响应。
- **文件级读写路径**：目录 `GET …/:id/files`；读 `GET …/:id/file?path=`；写 `PUT …/:id/file`（body `{path, content}`）；上传 `POST …/:id/file/upload`；删 `DELETE …/:id/file?path=`；路径越界在服务层校验，非法即 400（如 `Invalid skill file path`）。
- **市场图标**：`GET /api/plugin/marketplace/assets/icon` 以 `StreamableFile` 返回二进制，带私有缓存头与 `Vary`。

## 鉴权约定

- **全局两层守卫**：API 启动时同时注册 `AuthGuard` 与 `PluginScopeGuard`。除显式 `@Public()` 外所有路由要求已认证；`PluginScopeGuard` 按路由上的插件作用域元数据与请求上下文比对，未标注或标注为系统全局即放行，否则 403 `Plugin endpoint is not available in the current tenant or organization scope`。因此**调整插件控制器的作用域声明等价于调整全局鉴权面**。
- **`@Public()` 例外**：本范围仅 `/api/plugin/marketplace/public` 一处公开；其余市场路由（含 `assets/icon`）需登录。
- **角色要求**：`install-organization` 与 4 个 `mcp/:componentKey/*` 端点 → `SUPER_ADMIN`；`/api/plugin-applications` 的 4 个写端点 → `SUPER_ADMIN` / `ADMIN` / `TRIAL`；`/api/system/setup/plugins` → `TenantPermissionGuard` + `SUPER_ADMIN`；市场来源与注册表写操作在服务层再校验 SuperAdmin。
- **`WorkspaceAuthoringGuard` 语义**：取路径参数 `workspaceId`，非 UUID → 400 `server-ai:Error.WorkspaceIdInvalid`；随后断言当前用户对目标工作区具备**写权限**（而非成员身份或管理权）。
- **注意**：`POST /api/skill-package/install` 与 `DELETE /api/skill-package/uninstall` 未挂该守卫，其授权依赖全局认证与服务层内部校验，调用方不应假定存在工作区级写权限前置检查。
