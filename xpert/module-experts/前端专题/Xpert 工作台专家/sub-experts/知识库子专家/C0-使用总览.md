## 1. 定位与何时找

本子域是「**一个详情壳 + 一族页面 + 一组注入式轮询**」：`KnowledgebaseComponent` 以 `getDetail` 为唯一数据源并向子页面开放 `refresh()`；页面族各自经 `@core` 知识库服务族读写；派生态进度（标签 / Wiki / GraphRAG）封装为 `inject*` 函数返回 `computed<Map>`，只是**新鲜度补偿**，不构成一致性保证。

```mermaid

  R["入口 /xpert/knowledges/*<br/>knowledge/routing.ts"] --> L["列表层 KnowledgebaseHomeComponent<br/>getAllByWorkspaceOnly + 卡片统计"]
  R --> X["connect · create-from-pipeline"]
  R --> S["详情壳 KnowledgebaseComponent<br/>myRxResource getDetail + refresh()"]
  S --> PAGES["页面族 documents · test · faq · tags · graph · wiki"]
  S --> P["pipeline/ KnowledgebasePipelineComponent"]
  P --> ST["Studio：XpertStudioComponent（跨域复用）"]
  ST -. published$.next .-> P
  PAGES --> CORE["@core：Knowledgebase · KnowledgeDocument · KnowledgeFAQ · KnowledgeTags · KnowledgeWiki"]
  CORE --> BE["后端知识库专家（知识模型 / 摄取 / 检索 / 图谱 / Wiki）"]
```

## 4. 边界

1. **知识模型归后端「知识库专家」**：可见性推导、可访问过滤、重名翻译与实体语义不在本子域；前端只消费 DTO（`IKnowledgebase` / `IKnowledgeDocument` / `KnowledgeTagCatalog` / `KnowledgeWikiStatusResponse`）。
2. **摄取归后端「文档摄取与流水线子专家」**：文档创建/幂等/增量/解析/切片/向量化/删除回收（`knowledge-document/`、`rag-web/`）——前端只发起 `createBulk` / `startParsing` / `stopParsing` 并展示进度。
3. **检索归后端「知识库·检索·向量存储子专家」**：三路召回 + 融合 + 重排 + 引用投影的语义；前端只组装 `POST /:id/test` 的入参并渲染 `{ documents, diagnostics }`。
4. **图谱归后端「GraphRAG 与知识身份子专家」**：图谱索引、实体归一、语义裁判；前端只做画布与动作入口。
5. **Wiki 归后端「知识 Wiki 与知识组织子专家」**：生成 / 归并 / 目录 / 分类对账；前端只做阅读、目录、分类动作与门控。
6. **画布本体归同专题「Agent 编排 Studio 专家」**：节点渲染、连线、面板、保存发布（`features/xpert/studio/**`）；本子域只**复用**，不实现。
7. **权限点与守卫归 `@core` 与路由声明**：`AIPermissionsEnum.KNOWLEDGEBASE_EDIT` + `NgxPermissionsGuard`（`redirectTo: '/settings'`）+ `knowledgebaseWikiGuard`；本子域不放宽守卫。
8. **工作区归工作区子专家**：工作区选择、列表、成员、可见性不在本子域；两侧仅共享 `XpertWorkspaceService.getAllMy(purpose: 'authoring')`。
9. **通用 UI 与契约归共享层**：`@shared/knowledge`（`XpertPipelinesComponent` / `KnowledgeChunkComponent` / 检索设置面板）、`@xpert-ai/headless-ui`、`@xpert-ai/contracts`。
10. **前端不维护权威副本**：一切写操作「调接口 → `reload()`」收尾；`apiEnabled` 属直写式 `linkedModel`（写入即发请求），轮询只是新鲜度补偿。

## 5. 已知问题与常见坑

1. **① pipeline 复用 `XpertStudioComponent` 的接入契约是「三件事」且冻结**：只允许 `imports: [RouterModule, XpertStudioComponent]`、`providers: [XpertService]`、`inject(KnowledgebaseComponent)`；画布**无 `@Input`/`@Output`**，靠 `injectParams('id')` 工作，因此该页 `paramId` 语义是 **xpertId**（路由 `/xpert/knowledges/:kbId/xpert/:xpertId`），改路由层级或参数名会**静默不加载**；该页出现 Studio 工具栏属设计预期。
2. **② 可见性（Private / Organization / Public）只影响列表分组，不决定可访问**：`permission` 缺失或 `Private` → personal，`Organization` / `Public` → team；`scope='all'` 不过滤；管理图标门槛是 `canManage(item) = canWriteWorkspace() && item.workspaceId === 当前 workspaceId`；真正的授权边界在后端 service 断言。
3. **③ 摄取进度是「状态驱动轮询 + 去抖」，不是推送**：表格面由 `effect` 侦测在途态（`WAITING/RUNNING/TRANSFORMED/SPLITTED/UNDERSTOOD/EMBEDDING`）触发 `documentDelayRefresh$ → debounceTime → refresh()`；知识库级只对 `graphStatus === INDEXING` / `REBUILDING` 轮询；只有标签轮询带 `document.visibilityState === 'visible'` 门。
4. **④ 切片预估与真实切片是两条路**：`POST /by-workspace/:id/preview-chunks`（`KnowledgeChunkPreviewComponent`，**只算不落库**）与详情页的真实切片列表（`getChunks`）字段与语义不同；`estimate` / `estimate-table` 又属文档服务，不要混用。
5. **⑤ 检索测试的参数语义**：`k = topK() ?? 10`、`score` 缺省 `null`、`rerankModel` 三段回退（显式模型 → `undefined` 沿用已保存 → `null` 本次不重排）、过滤为 `filters: { request }`、`contentScope` **仅文档库且 `wikiConfig.enabled`** 时下发；试跑不落库，`complete` 后只 `reload()` 检索日志；`testSettings` 用 `linkedSignal` 刻意不跟随父级刷新——**页面参数 ≠ 已保存配置**。
6. **⑥ FAQ 导入是「预检 + 提交」两步，体积上限不在前端**：契约是 `previewImportFile` → `importFile(FormData, mode)`（另有 `export` / `import-template`）；本子域**未发现体积/行数上限的显式前端校验**，超限失败只能表现为服务端错误经 `getErrorMessage` toast——[推测] 前端提示层属待补缺口。
7. **⑦ `/settings/knowledgebase/*` 与 `/xpert/knowledges/*` 双挂载同一批组件**：设置域的 `:id` 子树 `loadChildren` 指向本子域 `knowledgebase/routing.ts`（设置域列表根另有自己的 `KnowledgebaseHomeComponent`）；改这份 routing 或其中的组件契约会**同时影响两个宿主**。
8. **⑧ `knowledgebaseWikiGuard` 的门控语义**：用 `pathFromRoot` 第一个 `id` 取详情，非文档库或 Wiki 未启用 → `createUrlTree(getKnowledgebaseDefaultRoute(...), { queryParams })`（**保留查询参数**）；异常 → `toastr.danger` + `/xpert/w`；`knowledgebase-wiki-routing.spec.ts` 断言「未启用时不挂载 Wiki 组件」。
9. **⑨ 重建锁（`REBUILDING` → `vectorMutationLocked`）阻断写操作**：上传入口、文档行内动作、FAQ 操作、配置页 `save()` 均早退；`KnowledgeDocumentDialogService` 在**打开对话框之前**再 `getDetail` 复核一次，FAQ 页在锁定期以 `timer(0, 3000)` 刷详情等待解锁。
10. **⑩ 轮询叠加与覆盖缺口**：单页最多可并存 6 组定时器（表格去抖、标签 5s、Wiki 5s、Graph 2.5s/5–30s、FAQ 3s、配置 2s）；`KnowledgebasePipelineComponent` 的 `publishedSub` **未退订**；62 个 spec 集中在导入/重处理、进度轮询、切片、Wiki、FAQ，而**列表、详情壳、文档表格主体、画布复用宿主均 0 覆盖**——改轮询常量、检索请求体或复用契约前先读 `implementation/06-测试.md`。
