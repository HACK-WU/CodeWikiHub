## 1. HTTP 调用面（按分组）

## 2. 前端服务与组件契约

### 2.1 `KnowledgebaseComponent`：详情壳 = 唯一真源

- 资源：`myRxResource({ request: () => ({ id: paramId() }), loader: getDetail })`；失败 → `toastr.danger` + `router.navigate(['/xpert/w'])` + `EMPTY`。
- 对外：`refresh()`（= `#knowledgebase.reload()`）、`type / faq / wikiEnabled / external / pipelineId / pipeline / documentNum / xpertCount / xperts` 等 computed；子页面**一律 `inject(KnowledgebaseComponent)`** 读，不各自取详情。
- 页头动作：`back()`（尊重 `?returnTo=/xpert/*`）、`deleteKnowledgebase()`、`downloadPipeline(id)`、`openXpert()`（`window.open('/xpert/x/:id/agents')`）、`openApiKey()`、`openConfiguration(initialSection)`；`apiEnabled` 是直写式 `linkedModel`（写入即发 `update`）。

章节来源：[knowledgebase.component.ts](file://apps/cloud/src/app/features/xpert/knowledge/knowledgebase/knowledgebase.component.ts)（关键符号：`KnowledgebaseComponent.#knowledgebase`、`refresh`、`openConfiguration`、`apiEnabled`）· [knowledgebase.service.ts](file://apps/cloud/src/app/@core/services/knowledgebase.service.ts)（关键符号：`KnowledgebaseService.getDetail`）

### 2.2 轮询注入族与视图状态基类

- `DocumentViewState`：`documentDelayRefresh$ → debounceTime(REFRESH_DEBOUNCE_TIME) → refresh()`（在途态驱动）；`knowledgebaseDelayRefresh$ → knowledgebaseComponent.refresh()`（**仅** `graphStatus === INDEXING` / `vectorMutationLocked`）；`vectorMutationLocked` 是写操作门。
- `injectDocumentTags(kb, documents)`：只在 `automaticTagging.enabled && isDocumentKnowledgebaseType(type)` 生效；按当前页文档 id 排序、**100 个一批**、`timer(0, 5000)` + `document.visibilityState === 'visible'` 门 + `exhaustMap` + 失败保留上一快照。
- `injectDocumentWikiProgress` / `injectDocumentGraphProgress`：`timer` 5s（Wiki）/ 活跃 5s·落定 30s（Graph，`ACTIVE_POLL_MS`/`SETTLED_POLL_MS`），按 `KNOWLEDGE_*_DOCUMENT_STATUS_BATCH_SIZE` 分批，缓存 key 含 `version/updatedAt/status/disabled`。

章节来源：[document-view-state.ts](file://apps/cloud/src/app/features/xpert/knowledge/knowledgebase/documents/document-view-state.ts)（关键符号：`DocumentViewState.documentDelayRefresh$`、`knowledgebaseDelayRefresh$`、`vectorMutationLocked`、`REFRESH_DEBOUNCE_TIME`）· [document-tags-refresh.ts](file://apps/cloud/src/app/features/xpert/knowledge/tags/document-tags-refresh.ts)（关键符号：`injectDocumentTags`、`document.visibilityState`）

### 2.3 `KnowledgeTestComponent`：检索测试输入输出

- 输入面：`testSettings = linkedSignal(source: knowledgebase, …)`（**保留本地未保存改动**）、`recall`（FAQ 走 `normalizeKnowledgebaseFAQRecall`）、`score / topK / retrievalMode / retrievalSettings`、`requestFilter`；`showDocumentTestControls = isDocumentKnowledgebaseType(type)`、`showContentScope = 文档库 && wikiConfig.enabled`。
- 请求体：`{ query, k: topK() ?? 10, score: score() ?? null, rerankThreshold: recall()?.rerankThreshold ?? null, rerankModel（三段回退）, filters: requestFilter() ? { request } : undefined, retrieval, contentScope? }`。
- 输出面：`results`（`DocumentInterface<DocumentMetadata>[]`）与 `diagnostics`；`complete` → `#logs.reload()`；`selectLog(log)` 只回填 `query` 并清空结果（**不自动重跑**）。

章节来源：[test.component.ts](file://apps/cloud/src/app/features/xpert/knowledge/knowledgebase/test/test.component.ts)（关键符号：`KnowledgeTestComponent.test`、`testSettings`、`showContentScope`、`SYSTEM_KNOWLEDGE_FILTER_FIELDS`）· [knowledgebase.service.ts](file://apps/cloud/src/app/@core/services/knowledgebase.service.ts)（关键符号：`KnowledgebaseService.test`）

### 2.4 `KnowledgeTagsComponent` / `KnowledgeFAQComponent`

- 标签是「目录 + 打标」双模：`documentId` 有值 → 文档态（`source === 'automatic'` 额外给「确认手工」动作），无值 → 知识库选标；`canEdit` **完全取后端 `catalog.canEdit`**；每次 `mutate()` 后 `refresh()` 并用 `revision` 做竞态守卫。
- FAQ：`PAGE_SIZE = 20`、`statusFilter`（all/enabled/disabled）、`#loadRequestId` 竞态守卫；`busy` 聚合 loading 与 `vectorMutationLocked`，锁定期 `timer(0, 3000)` 刷详情；删除带 `version`，支持批量启停/重处理与导入导出。

章节来源：[knowledge-tags.component.ts](file://apps/cloud/src/app/features/xpert/knowledge/tags/knowledge-tags.component.ts)（关键符号：`KnowledgeTagsComponent.options`、`mutate`、`catalog.canEdit`）· [faq.component.ts](file://apps/cloud/src/app/features/xpert/knowledge/knowledgebase/faq/faq.component.ts)（关键符号：`PAGE_SIZE`、`busy`、`vectorMutationLocked`、`setStatusFilter`）

### 2.5 `KnowledgebasePipelineComponent`：复用画布接入契约（冻结）

- 装饰器只有三段：`imports: [RouterModule, XpertStudioComponent]`、`animations: [routeAnimations]`、`providers: [XpertService]`；类体只做两件事——`inject(KnowledgebaseComponent)` 与构造期 `xpertService.published$.subscribe({ next: () => knowledgebaseComponent.refresh() })`。
- **画布无 `@Input`/`@Output`**：数据由 `XpertStudioComponent` 自己 `injectParams('id')` 读 xpertId 并注入本页提供的 `XpertService`（`getTeam` 9 relations）获取；宿主不传输入。
- 两个 id 不可混：路由 `xpert/:id` 的 `:id` 是 **xpertId**，知识库 id 来自父段 `:kbId`；知识库侧 `pipeline / pipelineId / documentNum` 来自详情壳 `getDetail`。
- 事件回流：Studio 发布成功 `published$.next(result)` → 本页订阅 → 详情壳 `reload()`；广播是**内存态**、不跨标签页、无重放，作用域由 `providers` 决定。

章节来源：[pipeline.component.ts](file://apps/cloud/src/app/features/xpert/knowledge/knowledgebase/pipeline/pipeline.component.ts)（关键符号：`KnowledgebasePipelineComponent.imports`、`providers`、`publishedSub`、`knowledgebaseComponent`）· [routing.ts（详情子树）](file://apps/cloud/src/app/features/xpert/knowledge/knowledgebase/routing.ts)（关键符号：`path: 'xpert/:id'`）

## 3. 示例（真实调用方）

① **上传文档并跟踪进度**（结构示意：符号与调用形态已回源码核实，逐行实现见对应文件）：

```ts
// documents/import/import-dialog.component.ts：就绪门控 → 建档 + 启动摄取
readonly ready = computed(() => this.documents().length > 0 && !this.busy() /* 且上传全部 done、无配置错误 */)
this.#documentAPI.createBulk(this.documents(), false, this.selectedTagIds())
  .pipe(switchMap((created) => this.#documentAPI.startParsing(created.map((d) => d.id), 'full')))
  .subscribe({ next: () => this.dialogRef.close(true), error: (err) => this.#toastr.error(getErrorMessage(err)) })

// documents/document-view-state.ts：在途态 → 去抖重取（不推送，靠轮询）
this.documentDelayRefresh$.pipe(debounceTime(REFRESH_DEBOUNCE_TIME)).subscribe(() => this.refresh())
```

② **跑一次检索测试**（请求体形状与三段回退即契约）：

```ts
// test/test.component.ts → knowledgebase.service.ts 的 test(id, options)
this.#knowledgebaseAPI.test(id, {
  query: this.query(), k: this.topK() ?? 10, score: this.score() ?? null,
  rerankThreshold: this.recall()?.rerankThreshold ?? null,
  rerankModel: this.rerankModel(),               // 显式模型 | undefined（沿用已保存）| null（本次不重排）
  filters: this.requestFilter() ? { request: this.requestFilter() } : undefined,
  retrieval: this.retrievalSettings(),           // mode/entityTopK/neighborHops/graphWeight/communityTopK/fusion
  contentScope: this.showContentScope() ? this.contentScope() : undefined   // 仅文档库且 wiki 启用
}).subscribe({
  next: ({ documents, diagnostics }) => { this.results.set(documents); this.diagnostics.set(diagnostics) },
  error: (err) => this.error.set(getErrorMessage(err)),
  complete: () => this.#logs.reload()            // 试跑不落库，只刷检索日志
})
```

③ **用 pipeline 装配画布**（**原样摘录**，接入契约只有三行）：

```ts
// knowledge/knowledgebase/pipeline/pipeline.component.ts
@Component({
  selector: 'xp-knowledgebase-pipeline',
  imports: [RouterModule, XpertStudioComponent],
  animations: [routeAnimations],
  providers: [XpertService]
})
export class KnowledgebasePipelineComponent {
  readonly knowledgebaseComponent = inject(KnowledgebaseComponent)
  readonly xpertService = inject(XpertService)
  private publishedSub = this.xpertService.published$.subscribe({
    next: (pipeline) => { this.knowledgebaseComponent.refresh() }
  })
}
```
