## 1. 建模边界总览：哪些只在前端、哪些是后端投影

- **后端投影（唯一真源在服务端）**：`IXpert` / `TXpertTeamDraft` / `TXpertGraph` / `IXpertToolset` / `IXpertTool` / `IXpertWorkspace` / `IKnowledgebase` 全部定义在 `packages/contracts/src/ai/**`，由 `@core` 再导出；本域不复制、不扩展这些接口。
- **只在前端**：`XpertService` 的投影信号（`latestXpert` / `xpert` / `paramId`）、`published$` 事件、`XpertAssistantFacade` 的上下文对象、组件内表单与脏标记（`toolsDirty` / `isDirty()` / `testResult`）、`XpertConfigureToolComponent` 抽象基类、`ChatKit*Effect` 解析工具类型。
- **本域不新增 HTTP DTO**：接口层直接复用 `XpertAPIService` / `XpertToolsetService` / `XpertToolService`，本域自有类型只有「本地草稿工具类型」（如 `TImportedXpertDsl`、`BlankWizardSelections` 系列）。
- **前后端共享的解析口径**：`omitXpertRelations`、`figureOutXpert`、`resolveRuntimeXpert`（`xpert.utils.ts`）把「草稿覆盖已发布」的合并规则固化在契约层，前端与后端执行侧共用同一套回落顺序。
- **知识库模型不在本域**：`IKnowledgebase` 仅被流水线/详情页消费，建模细节归知识库子专家。

章节来源：[xpert.model.ts](file://packages/contracts/src/ai/xpert.model.ts)（关键符号：`IXpert`、`TXpertTeamDraft`）、[XpertService](file://apps/cloud/src/app/features/xpert/xpert/xpert.service.ts)（关键符号：`XpertService.latestXpert`、`XpertService.published$`）、[xpert.utils.ts](file://packages/contracts/src/ai/xpert.utils.ts)（关键符号：`omitXpertRelations`、`figureOutXpert`、`resolveRuntimeXpert`）

## 2. `IXpert` 与前端视图模型的投影关系

**类型名**：`IXpert`（含基底 `TXpert`、枚举 `XpertTypeEnum`）
**定义位置**：[xpert.model.ts](file://packages/contracts/src/ai/xpert.model.ts)

- **字段与语义（节选）**：身份面 `slug/name/type/title/description/active/avatar/starters`；配置面 `options`（含 `workbench`、`knowledge/toolset/agent/xpert` 位置字典）、`agentConfig`、`features`、`summarize`、`commandProfile`、`marketplace`、`businessAreaId`；版本面 `version/latest/releaseNotes/publishAt`；编排面 `draft?: TXpertTeamDraft`、`graph?: TXpertGraph`；关系面 `agent/agents/executors/leaders/copilotModel/copilotModelId/knowledgebase/knowledgebases/toolsets/userGroups/integrations/tags`；集成面 `api/app/environmentId/environment`；隔离面 `workspaceDataScope: 'shared' | 'user'`（`DEFAULT_XPERT_WORKSPACE_DATA_SCOPE = 'shared'`）。
- **生产方**：`GET /api/xpert/:id/team`（`XpertAPIService.getTeam`，9 relations）；列表接口 `getAllByWorkspace` / `getMyAll` / `getBySlug`；`publish` / `importDSL` / `create` / `duplicate` 的返回值。

- **约束**：`IBasePerWorkspaceEntityModel` 提供 `workspaceId?`、`workspace?`、`publishAt?`、`deletedAt?`；`type === 'knowledge'` 时必须绑定 `knowledgebase`（注释即契约）。

## 3. `latestXpert` / `xpert`：草稿优先投影信号

**类型名**：`latestXpert: Signal<IXpert>`、`xpert: Signal<Partial<IXpert>>`
**定义位置**：[xpert.service.ts](file://apps/cloud/src/app/features/xpert/xpert/xpert.service.ts)

| 成员 | 类型 | 写入点 | 语义 |
| --- | --- | --- | --- |
| `latestXpert` | `signal<IXpert>` | `xpertSub` 订阅回调 | 服务端响应原文，含 `draft`/`graph`/`version` |
| `xpert` | `signal<Partial<IXpert>>` | `value.draft?.team ?? value` | 展示用投影，草稿优先 |
| `#draft` | `signal<TXpertTeamDraft>` | 无写入点 | 声明后未使用的前端草稿槽位 |

- **生产方**：`paramId$ → distinctUntilChanged → filter(nonBlank) → switchMap(#refresh$ → getXpertTeam(id))`，唯一订阅者即 `xpertSub`。
- **消费方**：`XpertComponent`（`xpert`/`latestXpert` 均暴露）、`XpertBasicComponent`（`xpert`）、`XpertBasicManageComponent`/`XpertAPIComponent`/`XpertAppComponent`/`XpertMonitorComponent`/统计与日志（`latestXpert`）、`memory/files`（`xpert() ?? latestXpert()`）。
- **约束**：投影只做一层回落，不做深合并；写操作后必须显式 `refresh()` 才更新（无自动失效订阅）。

章节来源：[XpertService](file://apps/cloud/src/app/features/xpert/xpert/xpert.service.ts)（关键符号：`XpertService.latestXpert`、`XpertService.xpert`、`XpertService.#draft`、`XpertService.xpertSub`）

## 4. `TXpertTeamDraft`：草稿装配面与图模型

**类型名**：`TXpertTeamDraft`、`TXpertGraph`、`TXpertTeamNode`、`TXpertTeamNodeSpec`、`TXpertTeamConnection`
**定义位置**：[xpert.model.ts](file://packages/contracts/src/ai/xpert.model.ts)

- **字段与语义**：`team: Partial<IXpert>`（草稿上的助手本体，主 agent 在 `team.agent`）、`nodes: TXpertTeamNode[]`、`connections: TXpertTeamConnection[]`、`template?`（模板元数据）、`savedAt?: Date`（服务端落盘时间）、`checklist?: ChecklistItem[]`（发布前检查项）。
- **节点类型（`TXpertTeamNodeSpec`）**：`agent → IXpertAgent`、`knowledge → IKnowledgebase`、`toolset → IXpertToolset`、`xpert → IXpert`（含嵌套 `nodes/connections/expanded`）、`workflow → IWorkflowNode`；节点基底含 `key/position/size?/hash?/parentId?/readonly?`。
- **连接**：`{ key: 'from/to', from, to, type: 'edge' | TXpertTeamNodeType, required?, readonly? }` —— `edge` 表示水平流程，其余表示纵向（agent）流程。
- **生产方（本域）**：`buildEditableXpertDraft`（Studio 草稿源头，本域导出）、`applyChatTriggerInputParametersToDraft`、`upsertTriggerEditorItemsIntoDraft`、`buildBlankXpertDraft` / `buildBlankKnowledgeDraft` / `buildBlankWorkflowDraft`（`blank-draft.util.ts`）、`BlankProjectManagement.apply`（capability 预览草稿）、`XpertAPIService.saveDraft` 的回包。
- **消费方**：Studio 的 `XpertStudioApiService`（画布真源）、知识库流水线页（`providers: [XpertService]` + 复用画布组件）、`XpertNewBlankComponent` 的 checklist 判定（`hasBlockingChecklist`）、`XpertBasicManageComponent.importDsl` 的覆盖写入。
- **约束**：`team.id` 缺省回落 `xpert.id`；`nodes` 三级回落、`connections` 二级回落；`upsertTriggerEditorItemsIntoDraft` 在缺主 agent 节点时抛 `XPERT_DRAFT_PRIMARY_AGENT_NODE_MISSING`。

章节来源：[xpert.model.ts](file://packages/contracts/src/ai/xpert.model.ts)（关键符号：`TXpertTeamDraft`、`TXpertTeamNodeSpec`、`TXpertTeamConnection`）、[editable-draft.util.ts](file://apps/cloud/src/app/features/xpert/draft/editable-draft.util.ts)（关键符号：`buildEditableXpertDraft`）、[xpert-draft-trigger.util.ts](file://apps/cloud/src/app/features/xpert/draft/xpert-draft-trigger.util.ts)（关键符号：`upsertTriggerEditorItemsIntoDraft`、`XPERT_DRAFT_PRIMARY_AGENT_NODE_MISSING`）

- `ChatKitEffectEvent` / `ChatKitPromptWorkflowEffect` / `ChatKitWorkspaceSkillEffect` 及解析函数 `getChatKitEffectData`、`getChatKitEffectXpertId`、`getChatKitPromptWorkflowEffect`、`getChatKitWorkspaceSkillEffect` —— 助手门面的事件输入类型与白名单式解析。

## 8. 校验规则、必填与默认值、未知字段

- **类型守卫 / 归一化**：`isXpertNodeType(type)`（节点收窄）、`isToolEnabled(tool, disableToolDefault)`（`disabled → enabled → disableToolDefault` 三级默认，`isEnableTool` 已废弃）、`getEnabledTools(toolset)`（再按 `options.toolPositions` 排序）、`getToolLabel(tool)`（`label → schema.identity.label → name`）、`getXpertAgentRecursionLimit` / `normalizeXpertAgentConfig`（缺省 `DEFAULT_XPERT_AGENT_RECURSION_LIMIT = 1000`）。
- **必填**：`IXpert.name`、`IXpert.type`、`IXpertToolset.name`、`IXpertTool.name`、`IXpertWorkspace.name` / `ownerId` / `status`、`TToolParameter.name`、`TXpertTeamConnection.key`；`XpertBasicComponent` 对 `copilotModel` 施加 `Validators.required`。
- **默认值**：`DEFAULT_XPERT_WORKSPACE_DATA_SCOPE = 'shared'`（`workspaceDataScope` 缺省）；`createBlankXpert` 显式写 `workspaceDataScope: isolateWorkspaceData() ? 'user' : 'shared'`；工具集 `aiProviderRole` 默认 `AiProviderRole.Secondary`；`TXpertWorkspaceCapabilities` 判定默认全 `true`（`canRead/canRun/canWrite/canManage` 的 `?? true`）；工作区可见性缺省归一为 `'private'`。
- **未知字段**：`TXpertToolsetOptions` 用索引签名接收未知键（宽松）；`TXpertOptions` 显式列出 `workbench/knowledge/toolset/agent/xpert/…` 并使用 `IPoint`/`ISize` 位置字典，未知键不保证保留；`TToolCredentials` 为 `Record<string, string|number|boolean|any>`（等于不做字段校验）。
- **未知/宽松字段的读取姿势**：本域一律走 computed 读取（`xpert()?.x`、`toolset()?.options?.x`），不做运行时逐字段校验；跨端契约收窄由 `contracts` 的工具函数承担。
