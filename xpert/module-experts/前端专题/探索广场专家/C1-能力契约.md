## 1. 前端契约

### 1.1 `ExploreScopeService` 成员与语义

定义处 `features/explore/explore-scope.service.ts`（`providedIn: 'root'`）。它是本域**唯一**的作用域入口，只读派生 + 一个切换方法：

| 成员 | 类型 | 语义与约束 |
| --- | --- | --- |
| `activeScope` | `Signal<IRequestScope>`（直通 `ScopeService.activeScope`） | 当前请求作用域实体；不缓存、不复制 |
| `isTenant` | `Signal<boolean>` | `activeScope().level === RequestScopeLevel.TENANT`；租户态＝无组织上下文 |
| `organizationName` | `Signal<string>` | 显式依赖 `activeScope()` 后读 `Store.selectedOrganization?.name ?? ''`；**因此切换后一定重算** |
| `key` | `Signal<string>` | `${userId}:${tenantId}:${level}:${organizationId（仅 ORGANIZATION 级）}`；跨页面唯一比对键（广场再拼 `language()`） |
| `choose(organizationOnly = false)` | `Promise<boolean>` | 打开 `ExploreScopeDialogComponent`，`data: { allowTenant: !organizationOnly && canUseTenantScope() }`；用户取消/关闭 → `false`；否则调 `ScopeService.switchToTenant()` 或 `switchToOrganization(org)` 并返回其结果 |

对话框契约：`ExploreScopeSelection = { kind: 'tenant' } | { kind: 'organization'; organization: IOrganization }`；`selectTenant()` / `selectOrganization(org)` 即 `dialogRef.close(payload)`。`ExploreScopeComponent`（选择器 `xp-explore-scope`）是纯展示触发器，只 inject 服务并 `(click)="scope.choose()"`，**不下发任何状态**。

章节来源：[explore-scope.service.ts](file://apps/cloud/src/app/features/explore/explore-scope.service.ts)（关键符号：`ExploreScopeService.activeScope`、`isTenant`、`organizationName`、`key`、`choose`）· [explore-scope-dialog.component.ts](file://apps/cloud/src/app/features/explore/explore-scope-dialog.component.ts)（关键符号：`ExploreScopeSelection`、`load`、`selectOrganization`、`selectTenant`）· [explore-scope.component.ts](file://apps/cloud/src/app/features/explore/explore-scope.component.ts)（关键符号：`ExploreScopeComponent.scope`）

### 1.2 `explore-route-state` 解析规则与 URL 契约

- `ExploreTab = 'skills' | 'agent-square' | 'connectors'`；`DEFAULT_EXPLORE_TAB = 'agent-square'`。
- `normalizeExploreTab(value, agentMarketplaceEnabled)`：`agent-square` / `agents` 且市场开关开 → `agent-square`；`connectors` → `connectors`；`skills` → `skills`；其余 → 市场开关开时 `agent-square`，否则 `skills`。
- 壳侧 URL 契约：`tab` / `mode`（`square` | `mine`，默认 `square`）/ `search` 三个 query；`linkedModel.update` 在写默认值时置 `null`（即不写进 URL），navigation 使用 `queryParamsHandling: 'merge'` + `replaceUrl: true`。广场侧额外用 `catalog`（默认 `experts`）。`tab=connectors` 不渲染页签，壳在构造时 `queueMicrotask` 触发 `openConnectorManagement()`。

章节来源：[explore-route-state.ts](file://apps/cloud/src/app/features/explore/explore-route-state.ts)（关键符号：`ExploreTab`、`DEFAULT_EXPLORE_TAB`、`normalizeExploreTab`）· [explore.component.ts](file://apps/cloud/src/app/features/explore/explore.component.ts)（关键符号：`mode`、`tab`、`search`、`navigate`、`openConnectorManagement`）

| --- | --- | --- |

## 3. 示例

① **切换作用域并刷新列表**（选择器 → 服务 → 页面 effect）：

```ts
// explore-scope.service.ts（剪裁）：单点切换
async choose(organizationOnly = false) {
  const selection = await firstValueFrom(
    this.#dialog.open<ExploreScopeSelection>(ExploreScopeDialogComponent, {
      data: { allowTenant: !organizationOnly && this.#scope.canUseTenantScope() },
      panelClass: 'xp-overlay-pane-dialog'
    }).closed
  )
  if (!selection) return false
  return selection.kind === 'tenant'
    ? this.#scope.switchToTenant()
    : this.#scope.switchToOrganization(selection.organization)
}

// agent-square.component.ts（剪裁）：key 变化 → 重置并重取
effect(() => {
  const scopeKey = `${this.scope.key()}:${this.language()}`
  const catalog = this.catalog()
  untracked(() => {
    if (scopeKey !== this.#loadedScopeKey) {
      this.#loadedScopeKey = scopeKey
      this.resetScope()
      void this.loadFeaturedExperts()
      if (catalog !== 'applications') void this.loadApplications(true)
    }
    if (catalog === 'experts') void this.loadExperts(this.currentExpertQuery())
  })
})
```

② **申请访问一个广场条目**（按钮分支 → 对话框 → 提交 → 重取）：

```ts
// agent-square.component.ts（剪裁）
async handleExpertAction(item: IXpertMarketplaceItem, event?: Event) {
  event?.stopPropagation()
  if (this.canUseExpert(item)) { void this.#router.navigate(['/chat/x', item.xpert.slug, 'c']); return }
  if (item.accessStatus === 'requested') return           // 已申请：固定为「待审批」
  const reason = await firstValueFrom(
    this.#dialog.open<string | null>(AgentSquareAccessRequestDialogComponent, { data: { item } }).closed
  )
  if (reason == null) return                              // null = 用户取消
  await firstValueFrom(this.#marketplaceService.requestAccess(item.xpert.id, { reason }))
  await Promise.all([this.loadExperts(), this.loadFeaturedExperts(true)])
}

// access-request-dialog.component.ts（剪裁）：reason 上限 500，提交回传 trim 后的字符串
submit() { this.#dialogRef.close(this.reason().trim()) }
```

③ **从模板向导创建助手**（装配参数 → 模态 → 回跳）：

```ts
// template-detail.component.ts（剪裁）
async install() {
  let detail = this.detail()
  if (!detail) return
  if (this.scope.isTenant()) { if (!(await this.scope.choose(true))) return; await this.load(); detail = this.detail()! }
  if (detail.application) {
    await this.router.navigate(['/explore/apps', detail.application.appName],
      { queryParams: { plugin: detail.application.pluginName, setup: 1 } })
    return
  }
  this.dialog.open<BlankXpertWizardResult>(XpertNewBlankComponent, {
    width: '1360px', disableClose: true, data: createAgentTemplateWizardData(detail.id, null)
  }).closed.subscribe((result) => { if (result?.xpert?.id) void this.router.navigate(['/xpert/x', result.xpert.id]) })
}

// agent-template-wizard.ts：锁定 Agent 类型与模板起点，跳过模板选择步骤
export function createAgentTemplateWizardData(templateId: string, workspace: IXpertWorkspace | null): BlankXpertDialogData {
  return { workspace, type: XpertTypeEnum.Agent, allowedModes: [XpertTypeEnum.Agent], allowWorkspaceSelection: true,
    completionMode: 'create', initialStartMode: 'template', initialTemplateId: templateId,
    lockStartMode: true, lockType: true, skipTemplateSelectionStep: true }
}
```
