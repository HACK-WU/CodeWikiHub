## 1. 组件与服务契约

**1.1 `ClawXpertFacade`（工作台总门面，`implements WorkbenchChatFacade`）**

| 分组 | 公开成员 | 语义与约束 |
|---|---|---|
| 绑定与视图态 | `definition`、`organizationId`、`userId`、`preference`、`availableXperts`、`hasLoadedXperts`、`loading`、`errorMessage`、`showWizard`、`resolvedPreference`、`orphanedPreference`、`viewState`、`viewErrorMessage()`、`sidebarStatus` | `definition` 取自 `getAssistantRegistryItem(AssistantCode.CLAWXPERT)`；`viewState` 四态闭合联合；`orphanedPreference` 为真即「原绑定已不可用」 |
| 写绑定 | `savePreference`、`bindPublishedXpert`、`clearPreference`、`cancelWizard`、`openWizard`、`mergeAvailableXpert` | 乐观写 + 失败 rollback + toastr；`mergeAvailableXpert` 把新建 xpert 并入可绑列表 |
| 身份与会话 | `identity`、`threadId`、`activeConversation`、`suppressAutoResume`、`pendingConversationStartId`、`assistantId`、`xpertId`、`currentXpert`、`currentWorkspaceId` | `identity` 是 `runtimeKey` 组成项；`currentWorkspaceId` 为**契约外**成员，骨架用 `getOptionalSignalValue` 读取 |
| 偏好与触发器 | `userPreference`、`toolPreferences`、`conversationPreferences`、`defaultThreadId`、`defaultFollowUpBehavior`、`setToolEnabled`、`setSkillEnabled`、`isToolEnabled`、`isSkillEnabled`、`saveUserPreference`、`persistConversationPreferences`、`setDefaultFollowUpBehavior`、`triggerProviders`、`triggerDraft`、`triggerDraftSource`、`triggerEditorItems`、`loadTriggerDraft`、`saveTriggerDraft` | 偏好乐观写 + 失败回滚；`saveTriggerDraft` 只写 draft（`upsertTriggerEditorItemsIntoDraft` → `saveDraft`） |
| 任务与概览 | `taskSummary`、`scheduledTaskSummary`、`taskCount`、`scheduledTaskCount`、`recentTasks`、`taskRefreshTick`、`refreshTaskSummaries()`、`conversationCount`、`boundDays`、`dailyMessageSeries` | `refreshTaskSummaries()` 只自增 `taskRefreshTick` 触发重取，不直接发请求 |
| 宿主回调与导航 | `onChatThreadChange`、`beginPendingConversation`、`ensureConversationEntry`、`setActiveConversation`、`patchActiveConversationStatus`、`handleThreadChange`、`navigateToOverview`、`navigateToChat`、`navigateToThread`、`armNullThreadChangeGuard`、`shouldIgnoreNullThreadChange` | 前五个与 `WorkbenchChatFacade` 同签名，是本子域对骨架暴露的**唯一写入面** |

**1.2 `ClawXpertScopedConversationFacade`（per-scope 适配器，`implements WorkbenchChatFacade, OnDestroy`）**

- 注入面：`shared: ClawXpertFacade`、`router: Router`、`entries: ClawXpertConversationEntryStore`、`scope: Signal<ClawXpertConversationScope>`（由 `CLAWXPERT_CONVERSATION_SCOPE` 的 `useFactory` 取自面板 `input.required`）。
- 委托面（直接取共享门面）：`definition` / `assistantId` / `xpertId` / `currentXpert` / `assistantTitle` / `assistantAvatar` / `initialLayout` / `defaultViewKey` / `chatkitFrameUrl` / `loading` / `loadingUserPreference` / `viewState` / `viewErrorMessage()`。
- 自有面：`identity` = `` `${shared.identity()}:${scope()}` ``、`active`（URL 作用域 === 本 scope）、`threadId`、`activeConversation`、`suppressAutoResume`（默认 `true`）、`initialized`、`entryInitialized`、`resetInProgress`、`nullGuardUntil`、`ownerKey`、`owner`、`destroyed`、`isCurrentRoute`、`ownsCurrentBinding`。
- 回调约束：`beginPendingConversation` 仅 `scope === 'task'` 委托且成功后清空 composer；`ensureConversationEntry` 一次性且要求 `viewState() === 'ready'`；`onChatThreadChange` 在 `resetInProgress` / `nullGuardUntil` 内不写状态、非当前路由只记不跳；`setActiveConversation` / `patchActiveConversationStatus` 先过 `ownsCurrentBinding()`；`ngOnDestroy` 置 `destroyed` 阻断迟到回写。

**1.3 `ClawXpertBindingState`（绑定子状态）**

- 对外只读信号（6 个）：`preference`、`availableXperts`、`loading`、`hasLoadedXperts`、`errorMessage`、`showWizard`。
- 方法：`refresh(scope)`（并行 `get` + `getAvailableXperts`）、`commit(preference, xperts)`（用户完成选择，主动 `#requestId++`）、`persistCurrent()`（写缓存）、`isCurrentScope(scope)`（`requestId` + scope 双判）、`restore(scope)`（冷启动读缓存）、`apply(...)`。
- 纯函数：`normalizeClawXpertXperts(items)`（滤「无 id / `latest === false` / 重复 id」）、`sameScope`、`isAccessRejected(error)`（401/403/404 → 删缓存 + 清信号 + **必写** `errorMessage`）、`BindingContext`。

**1.4 `ClawXpertBootstrapService`（创建 / 发布 / 绑定 / 跳转）**

- 跨路由通道：`pendingCreatedClawXpert`（signal）、`readPendingCreatedClawXpert()`、`clearPendingCreatedClawXpert()`、`consumePendingCreatedConversationXpertId()`。
- 主链：`resolveFirstAvailableLlmModel()` → `createClawXpert()` → `createAndOpenClawXpert()` → `bindAndOpenCreatedClawXpert(xpert)`；模板路径 `createTemplateXpert(template, model)`。
- 链内步骤（排障对照）：`prepareTemplatePlugins` → `ensureDefaultWorkspace` → `ensureTemplatePlugins` → `refreshDraftSnapshotBeforePublish` → `publishCreatedXpert` / `publishCreatedXpertOrFallback`；安装名由 `createClawXpertInstallName` / `createTemplateInstallName` / `normalizePluginInstallName` 生成。
- 契约：`bindAndOpenCreatedClawXpert` = `AssistantBindingService.upsert` → `pendingCreatedClawXpert.set` → `router.navigate(['/chat/clawxpert','c'])`，失败回滚 `#pendingCreatedConversationXpertId`（不抛给调用方）。

**1.5 作用域解析契约（`clawxpert-conversation-scope` + `group-workbench-scope`）**

- `clawXpertConversationScope(url)` → `'task'`（`/chat/clawxpert/c[/:threadId]`）｜`'assistant'`（`/chat/clawxpert/assistant[/:threadId]`、`/chat/clawxpert/settings`）｜`null`；`clawXpertConversationPath(scope, threadId?)` 反向拼路径；`clawXpertScopedThreadId(url, scope)` 取本 scope 的线程段；`CLAWXPERT_CONVERSATION_SCOPE` 为 `InjectionToken<Signal<ClawXpertConversationScope>>`。
- `createGroupWorkbenchScope(input)`：输入 `{ groupId, identity, assistantId, ready, api.getContext, onError }`，返回 `{ key, resolved }`；`key = JSON.stringify([identity, groupId, assistantId])`，key 变化立即 `null`；`getContext` 返回 `{ groupId, projectId, conversationId }`，必须校验 `assistantId` 一致且 `conversationId` 存在，否则 `onError` 且**不回退**个人视图。

## 3. 代码示例（真实调用方）

① **打开一个作用域会话**（面板装配 + 作用域门面按 URL 恢复线程）：

```ts
// clawxpert-conversation-pane.component.ts（剪裁：装配块，同块还提供 CLAWXPERT_CONVERSATION_SCOPE / ScopedSkillTrialIntent / ClawXpertWorkbenchViewUrlState）
providers: [
  { provide: WORKBENCH_CHAT_FACADE, useExisting: ClawXpertScopedConversationFacade },
  { provide: ViewClientCommandRegistry, useExisting: ScopedConversationCommands }
]
// clawxpert-scoped-conversation.facade.ts（剪裁：身份带作用域，active 由 URL 判定）
readonly identity = computed(() => `${this.shared.identity()}:${this.scope()}`)
readonly active = computed(() => clawXpertConversationScope(this.shared.currentUrl()) === this.scope())
```

② **走一次绑定**（向导只选择与保存；创建/发布/绑定全在 bootstrap）：

```ts
// clawxpert-binding-wizard.component.ts（剪裁）
async savePreference() {
  const assistantId = this.selectedXpertId()
  if (assistantId) await this.facade.savePreference(assistantId)
}
// clawxpert-bootstrap.service.ts（剪裁：新建并发布后绑定并跳转；payload 形状以 AssistantBindingService.upsert 为准）
await this.#assistantBindingService.upsert({ code, scope, assistantId: created.id })
this.#pendingCreatedClawXpert.set(created)
await this.#router.navigate(['/chat/clawxpert', 'c'])
```

③ **读取工具偏好**（两类数据源 `forkJoin` 扇出，单个失败不炸整页）：

```ts
// clawxpert-tool-preferences.component.ts（剪裁）
toggleTool(sourceType, nodeKey, metadata, toolName, enabled) {
  this.facade.setToolEnabled(sourceType, nodeKey, metadata, toolName, enabled)   // 乐观 + 失败回滚
}
toggleSkill(packageId, enabled) { return this.enqueueSkillPreferenceUpdate(packageId, enabled) } // 串行队列
// 单源异常 → buildSourceErrorState(...) 收集进 errors[]，不阻断其它节点
```
