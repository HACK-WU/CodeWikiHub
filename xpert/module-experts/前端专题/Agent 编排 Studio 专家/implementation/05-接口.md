## 1. 接口口径与总览

- 前端所有请求走同源 `/api` 前缀：`API_PREFIX = '/api'`；`XpertAPIService` 在构造时 `super(API_XPERT_ROLE)`，即 `apiBaseUrl = '/api/xpert'`；SSE 场景额外拼接 `baseUrl = injectApiBaseUrl()`（同源部署时为空串）。
- 服务端侧对照（`.fe-index`）：`XpertModule` 控制器 `XpertController` 提供 85 个接口（`.fe-index/xpert-server/modules/xpert.md:20`）；`XpertAgentModule` 挂载 `chat / xpert / middlewares`（`.fe-index/xpert-server/modules/xpert-agent.md:7,14`）；`XpertAgentExecutionModule` 挂载 `:id / xpert`（`.fe-index/xpert-server/modules/xpert-agent-execution.md:5,12`）。
- Studio 的接口面按用途分四组：**编排（team/draft/version/publish）**、**编排辅助（variables/diagram/export/commands/triggers/sandbox）**、**执行调试（`/api/xpert/:id/chat`、`/api/xpert-agent/chat`、`/api/xpert-agent-execution/*`）**、**资源位（workspace/knowledgebase/toolset/environment/business-area/chat-conversation/feedback）**。

章节来源：[xpert.service.ts](file://apps/cloud/src/app/@core/services/xpert.service.ts)（关键符号：`API_XPERT_ROLE`、`injectApiBaseUrl`）、[app.constants.ts](file://apps/cloud/src/app/@core/state/constants/app.constants.ts)（关键符号：`API_PREFIX`）

## 7. 前端组件对外契约

### 7.1 `XpertStudioComponent`（`xp-xpert-studio`）

- **无 `@Input`/`@Output`**。入场契约由三部分组成（`studio.component.ts:97-147,306-357`）：
  1. **注入依赖**：宿主必须提供 `XpertService`（`studio.component.ts:173`）；画布自身在 `providers` 中提供 `XpertStudioApiService`、`SelectionService`、`XpertExecutionService`、`JsonSchemaWidgetStrategyRegistry`、`provideJsonSchemaWidgets()`，并将 `CopilotServerService` 覆盖为 `XpertStudioCopilotServerService`（`studio.component.ts:135-145`；`xpert-studio-copilot-server.service.ts:9-18`）。
  2. **xpertId 来源**：可直接来自路由参数 `id`（`injectParams('id')`，`studio.component.ts:172`），组件把它写入 `XpertService.paramId`（`:312-316`）；因此在"非 `:id/agents` 路由"复用时可只提供 `XpertService` 并设置 `paramId`。
  3. **可选协作**：`XpertAssistantFacade`（`@optional`）用于助手上下文同步与 `studioRefresh`（`studio.component.ts:171,318-352`）。
- **复用样例**：知识库管线（`apps/cloud/src/app/features/xpert/knowledge/knowledgebase/pipeline/pipeline.component.ts:14-28`）直接 `imports: [XpertStudioComponent]` 且 `providers: [XpertService]`，并订阅 `xpertService.published$` 刷新知识库。
- **对外暴露成员**（被 header/toolbar/panel/节点组件通过 `inject(XpertStudioComponent)` 使用）：`sidePanel`（`model<'preview'|'variables'|'environments'|'commands'>`，与 header/panel 双向绑定：`studio.component.html:464-475`）、`xpert`/`viewModel`/`team`/`id`/`rootAgent`（`:191-193,269-271`）、`nodes`/`connections`/`groups`/`xperts`/`startNodes`（`:195-265`）、`executions`/`toolMessages`/`runningToolsets`/`selectAgentStatus`（`:279-304,523-526`）、`centerGroupOrNode`（`:576-578`）、`deleteNode`/`copyNode`/`duplicateNode`/`removeNode`/`expandXpertTeam`（`:462-574`）、选中相关 `selectionChanged`/`onSelectNode`/`onFocusNode`（`:469-497`）、`onDropToGroup`（`:713-732`）、键盘快捷键（`:583-643`）。

## 8. 错误处理与提示

- **统一错误取文**：`getErrorMessage(err)`（`@core/types`），在 studio 各服务/组件中广泛使用。
- **保存失败**：`saveDraft()` 链路 `catchError → toastr.error(getErrorMessage(err))`（`domain/xpert-api.service.ts:324-327`），并把错误写入 `draftSaveError`（`:390-392`）。
- **协作者拉取失败**：`createCollaborator` 错误 → `toastr.error(getErrorMessage(error))`（`domain/xpert-api.service.ts:587-597`）。
- **复制成功提示**：`copyNode` → `toastr.success('XP.Messages.CopiedToClipboard')`（`studio.component.ts:532-535`）。
- **发布/版本操作**：`publish` / `setAsLatest` / `deleteVer` 均 `loading` 包裹并 `toastr.error(getErrorMessage(error))`；成功提示 `XP.Xpert.PublishedSuccessfully` / `XP.Xpert.DeletedSuccessfully`（`header/publish/publish.component.ts:183-264`）。
- **执行错误**：`onChatError(message)` → `toastr.error(message)` + `executionService.markError(message)`（`panel/agent-execution/execution.component.ts:425-429`）；预览面板同法（`panel/preview/preview.component.ts:135-138`）。
- **参数校验**：调试面板在提交前校验参数 `maximum`（超限 → `toastr.error(...)` 并中断）（`panel/agent-execution/execution.component.ts:302-307,382-423`）。
- **失败重试（checkpoint 回放）**：`state-inspector.rerunFromCheckpoint()` 校验 `messageId/checkpointId`，缺失时 `toastr.error('XP.Xpert.ExecutionRetrySourceMissing')`（`state-inspector.component.ts:467-478`）；随后 `executionService.requestPreviewRetry(messageId, checkpointId)`（`services/execution.service.ts:189-197`）→ 预览面板 effect 消费 nonce 并调用 `preview.retryMessage(messageId, checkpointId)`（`panel/preview/preview.component.ts:100-110`）→ `chat({retry:true, messageId, checkpointId})`（`@shared/chat/preview/preview.component.ts:615-621`）；流内 `ON_AGENT_END`/`ON_CONVERSATION_END` 到来时 `completePreviewRetrySelection(executionId)` 并自动选中该执行（`panel/preview/preview.component.ts:113-133`）。
- **检查点加载失败**：`state-inspector` 内 `catchError → toastr.error(getErrorMessage(error))`（`state-inspector.component.ts:249-257`）。
- **流式中断**：`fetch-event-source` 对 `RUNTIME_STREAM_INTERRUPTED_EVENT` 直接 `error`，避免把未完成回复当成功（`fetch-event-source.ts:95-117`）。

章节来源：[xpert-api.service.ts](file://apps/cloud/src/app/features/xpert/studio/domain/xpert-api.service.ts)（关键符号：`draftSaveError`、`catchError`、`getErrorMessage`）、[state-inspector.component.ts](file://apps/cloud/src/app/features/xpert/studio/components/state-inspector/state-inspector.component.ts)（关键符号：`rerunFromCheckpoint`、`requestPreviewRetry`）

## 9. 版本策略：versions 与草稿的关系

- **草稿（draft）**：画布编辑的持久化暂存，类型 `TXpertTeamDraft`，存放在 `Xpert.draft`（`GET /api/xpert/:id/team` 返回）；前端用 `buildEditableXpertDraft(team)` 构建可编辑草稿（`domain/xpert-api.service.ts:344-363`），以 1s 去抖自动保存（`POST /api/xpert/:id/draft`）。`pristineDraft` 记录"最近一次成功保存"，`unsaved` 用哈希比较得出（`:314-316,375-398`）。服务端在 `saveDraft` 时写入 `savedAt`（`packages/server-ai/src/xpert/xpert.controller.ts:420-426`）。
- **版本（versions）**：`GET /api/xpert/:id/version` 返回 `{id, version, latest, publishAt, releaseNotes}[]`；`latest` 标记最新版本。每个版本是**同一 family 下的独立 Xpert 记录**——header 切换版本是路由跳转（`header.component.ts:159-161`），删除版本是 `DELETE /api/xpert/:id`（`publish.component.ts:205-230`）。
- **发布**：`POST /api/xpert/:id/publish?newVersion=true|false`；`newVersion=true` 产生新版本记录，`false` 覆盖当前版本（`publish.component.ts:232-264`；后端 `@Post(':id/publish')`，`xpert.controller.ts:480-484`）。发布前若 `unsaved()` 为真会先保存草稿（`publish.component.ts:235`）。
- **草稿与版本的关系**：草稿 = 版本之上的可编辑增量；发布把草稿"固化"为版本（成功回调 `studioService.refresh()`，`versions` 信号随 `#refresh$` 重取）；`resume()` 则丢弃草稿（`PUT /api/xpert/:id {draft: null}`）。

章节来源：[xpert-api.service.ts](file://apps/cloud/src/app/features/xpert/studio/domain/xpert-api.service.ts)（关键符号：`versions`、`pristineDraft`、`saveDraft`、`resume`）、[xpert.controller.ts](file://packages/server-ai/src/xpert/xpert.controller.ts)（关键符号：`allVersions`、`saveDraft`、`publish`）
