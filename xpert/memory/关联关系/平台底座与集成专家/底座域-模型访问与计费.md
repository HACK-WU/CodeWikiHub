[强关联] 平台底座与集成专家 与 模型访问与计费专家（ai-model 目录/凭证校验 ↔ 授权解析与记账）
- 强度：必改（**单向契约面**：B 端注入 A 端服务）——改 A 端 `getProvider`/`providerCredentialsValidate` 的签名或返回值形状 → B 端全部取模型与凭证落库路径必改；改 B 端的授权/配额口径 → A 端不用管（A 端不判授权）
- 原因：`ai-model` 只做 **Provider 目录门面 + 凭证 schema 校验**（`AIModelModule` 仅 `DiscoveryModule + CqrsModule + RouterModule`，**无 `TypeOrmModule`、0 表**），授权解析、配额与记账全在 `model-access`/`model-gateway`/`copilot`——二者是「目录/校验」与「授权/记账」的分工，不是同一层的两个实现
- A 端（本域）：`AIProvidersService.getProvider(name, throwError?, organizationId?)` 直查 plugin-sdk 的 `AIModelProviderRegistry`，**默认吞异常回 `undefined`**，`throwError=true` 才抛 `AIModelProviderNotFoundException` @ file://packages/server-ai/src/ai-model/ai-model.service.ts
- A 端（本域）：`providerCredentialsValidate` = 取 `provider_credential_schema` → `ProviderCredentialSchemaValidator.validateAndFilter` → 策略 `validateProviderCredentials` → **只把过滤后的凭据**交回调用方落库（handler 内留 `// Todo: encrypt secret variables in credentials`）@ file://packages/server-ai/src/ai-model/commands/handlers/provider-credentials-validate.handler.ts
- A 端（本域）：HTTP 面只有 `@Public()` 的 `GET /api/ai-model/provider/:name/:iconType/:lang`（图标二进制，缺文件 404 `Icon not found`）；`ListProviders`/`ListBuiltinModels`/`GetModelIcon` 均为进程内 Query/Command
- B 端（模型访问与计费专家）：`ModelAccessService` 注入 `AIProvidersService`，`createModelTarget` 的**形参类型即 `ReturnType<AIProvidersService['getProvider']>`** @ file://packages/server-ai/src/model-access/model-access.service.ts
- B 端（模型访问与计费专家）：`copilot-provider` 的 upsert handler 消费 `AiProviderCredentialsValidateCommand`；`entity.providerName` 存在时显式 `getProvider(name, true)`（**必须 throwError**）@ file://packages/server-ai/src/copilot-provider/commands/handlers/upsert.handler.ts
- B 端（跨域装配）：`initialization.module.ts` imports 含 `model-access`/`model-gateway`（共 14 个域模块）——本域 bootstrap job 会间接触发计费域落库 @ file://packages/server-ai/src/initialization/initialization.module.ts
- 改哪一侧会连带改另一侧：① `getProvider` 默认吞异常 → B 端若忘了 `throwError=true`，「插件已卸载」会被当成「无 provider」静默降级，排障表现是**模型不可用但无报错**；② 凭证校验**不加密、不落库、不判授权** → 加密落点在消费域 `[推测]`，A 端改签名时必须复核 B 端的落库与加密顺序；③ 把「凭据可用性」做成对外 HTTP 能力或把计费前移到目录层 → 触发 C5 §D8 重评条件，**不得**在 `ai-model` 内落表
- 边界面：模型可见性/授权台账/执行 grant/账本（27 张，见邻域 C4）归 B 端；`ai-model` 不存模型、不存密钥、不判授权与配额——排障「模型不可用」不能只看本域（C0 已知问题 8）
