[强关联] 平台底座与集成专家 与 平台插件与技能专家 + 前端（Angular apps/cloud 与 desktop 客户端）
- 强度：必改（**契约面**）——改视图协议（7 路由返回形状、manifest 公共键与 `view.type` 枚举、`dataSource.mode`）→ 前端 renderer 与全部插件视图必改；改宿主契约（`hostType`/`slots`/`resolve`/`canRead`/`prepareFileAction`）或插件注册表接口 → 本域解析链与插件实现必改；改 `mobile.deployment.viewHostsPath`/`apiBasePath` 属**破坏性变更**
- 原因：本域的扩展点全是「**消费插件注册表 + 面向前端协议入口**」——宿主事实在服务端对象、清单与数据事实在插件、渲染事实在前端；本域**不安装插件、不渲染视图**，只做解析、权限过滤与缓存
- A 端（本域·视图）：`ViewExtensionService.resolveHostContext/listSlotViews/getViewData/getViewManifest/executeAction/executeFileAction`；`ViewExtensionRoutes` 类级 `@Public()` + `ApiKeyOrClientSecretAuthGuard` + `@AllowClientSecretBindings(ENTERPRISE_XPERT)`（每入口自担鉴权边界）@ file://packages/server/src/view-extension/view-extension.controller.ts
- A 端（本域·宿主）：`ViewHostDefinitionRegistry.onModuleInit`（`DiscoveryService` 扫 `@ViewHostDefinition`，**进程内内存、新增宿主需重启**）与唯一在用宿主 `IntegrationViewHostDefinition`（`slots=[{key:'detail.main_tabs',mode:'tabs',order:0}]`，`hostSnapshot` 含 `options.botToken`）@ file://packages/server/src/view-extension/host-definition.registry.ts
- A 端（本域·缓存与过滤）：`ViewExtensionCacheService`（清单 60s、view data `min(ttlMs,30s)`，键含 `sha1(features + hostState)`）与 `ViewExtensionPermissionService`（宿主 → manifest → action 三层裁决；Project 角色不符时文案 `The current Project role does not allow this extension action`）
- A 端（本域·插件运行时面）：`DataSourceRuntimeService`（`@RuntimeCapabilityProvider(DataSourceRuntimeCapability)`，capability `platform.datasource.workbench`，`list/open` 是插件唯一出口、返回逐方法 `check()` 的代理）@ file://packages/server/src/data-source/data-source-runtime.service.ts
- A 端（本域·跨端契约）：`MobileService.getDeploymentConfig()` 输出 `apiBasePath='/api'`、`aiApiPath='/api/ai'`、`viewHostsPath='/api/view-hosts'` 与 6 个 `capabilities`（**编译期静态开关**，不落库、不随租户变化）@ file://packages/server-ai/src/mobile/mobile.service.ts
- B 端（平台插件与技能专家·注册表）：plugin-sdk 侧 `ViewExtensionProviderRegistry`、`IntegrationStrategyRegistry`、`DataSourceStrategyRegistry`/`DBQueryRunner`、`AIModelProviderRegistry` 由插件提供实现；插件安装与准入（`plugin_instance` / `plugin-resource` / `skill-*`）归 B 端，本域只消费注册表
- B 端（前端·Angular）：`apps/cloud` 的 `view-extension-api.service.ts` 与 `@shared/view-extension/renderers/*`（清单/数据/动作消费方）、`@core/services/languages.service.ts`（`GET /api/languages`、`getByName`）；前缀口径见 memory/项目架构/前端 API 前缀口径（Angular 应用）.md（`API_PREFIX='/api'`，各服务 base 不同）
- B 端（前端·desktop 与移动端）：`apps/desktop/electron/shell/controller.cjs` 调 `/api/desktop-shell/devices` 与 `/devices/:id/grants`（token 只回一次，随后 WS 握手、协议 `VERSION=1`）；移动端按 `deployment.capabilities` + `viewHostsPath` 加载扩展视图
- 改哪一侧会连带改另一侧：① 改 `normalizeManifest` 形状校验（公共键 `providerKey__manifestKey`、`title` 必须有非空 `en_US`、`view.type ∈ stats|table|list|detail|raw_json|remote_component`、`dataSource.mode` 强制 `platform`、`runtime.featureProviders` 由宿主重算）→ 插件与前端 renderer 同时必改；② 改 remote component 约束（`protocolVersion === 1` + `isolation === 'iframe'` + `Cache-Control: no-store` + 入口 key 路径穿越校验）→ 前端 iframe 隔离与安全边界一起失效；③ 新增第二个宿主或要求插件热更新 → 注册表须改为可刷新并复核两条失效链（C5 §D5 重评条件）
- 边界面：`view-extension` **只消费注册表、不安装插件**；`packages/plugin-sdk` 与 `packages/plugins/*` 不在本域；另两个视图入口是 `/api/ai/groups/:groupId/workbench` 与移动端 `deployment.viewHostsPath`
