[强关联] 租户生命周期 与 下游身份域（用户/角色/组织）
强度：必改——改 onboarding 的步骤顺序或各命令的入参结构 → 下游域（user/role/role-permission/feature/organization）必改；改下游各实体内部实现 → 租户域不用管

- TenantModule @ packages/server/src/tenant/tenant.module.ts
