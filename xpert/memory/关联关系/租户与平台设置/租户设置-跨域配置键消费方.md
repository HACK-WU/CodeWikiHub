[强关联] 租户设置（tenant_setting）与 跨域配置键消费方
强度：必改——改 tenant_setting 的 name 键名或值的语义/取值 → 所有按名读取该键的消费方必改；改消费方内部实现 → 租户域不用管
原因：设置是「按字符串键读取」的隐式契约，无枚举约束，键名漂移不会编译报错、只会静默失效

设置端：
- TenantSettingService.getSettings / saveSettngs @ packages/server/src/tenant/tenant-setting/tenant-setting.service.ts
- TenantSettingsMiddleware（请求级缓存 tenantSettings_<tenantId>，TTL 5 分钟，写后不失效）@ packages/server/src/tenant/tenant-setting/tenant-settings.middleware.ts

消费方（按当前已知键）：
- MODEL_GATEWAY_REQUESTS_PER_MINUTE_SETTING / MODEL_GATEWAY_MAX_CONCURRENT_REQUESTS_SETTING @ packages/server-ai/src/model-gateway/
- 会员/模型执行相关设置 @ packages/server-ai/src/{membership,model-execution}/
- 插件 setup 进度键 name='setupPluginInstallation' @ packages/server/src/plugin/setup/
- fileStorageProvider（onboarding 写 LOCAL）@ packages/server/src/file-storage/
