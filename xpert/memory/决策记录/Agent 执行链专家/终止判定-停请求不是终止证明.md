【决策记录｜停请求不是终止证明】\n- 分类：终止判定 / 可观测性\n- 动机（避坑）：现象——发出取消或观察者断开即认为运行结束；后果——`unknown` 被隐藏、投影出错误终态、上层基于假终态做决策\n- 决策：终止**只由 `exited` 确认**；**`unknown` 必须保持可见**；断开观察者不取消运行，取消需 provider 确认\n- 背景约束：执行授权生命周期跟随 CLI 会话/托管调用，独立于浏览器/Desktop 登录与查看/控制连接；终态、取消、过期或权限失效仍需 host 对账\n- 被否决方案：把 stop 请求或连接断开当作终止证明（明确否决）\n- 重新评估触发条件：无此项\n- 关联代码：agent-invocation/README.md（Host execution runner 节）；handoff/runtime-messaging/README.md（「ambiguous launch … must remain visible」同类原则）\n- 证据来源：agent-invocation/README.md 逐字——「A stop request is not proof of termination: only `exited` confirms the process stopped, and `unknown` must remain visible.」
