【决策记录｜角色是租户级且一人一角色】
- 分类：架构设计
- 动机：无
- 决策：角色在租户维度维护；一个用户只挂一个 roleId，**不随组织切换而改变**；授权结果以「角色 + 权限点 + enabled」的记录形式存储
- 背景约束：user 表只有一个角色列；组织切换改变的是工作上下文与数据范围，不改变角色；组织级权限只保留了少量旧列场景
- 被否决方案：组织级角色（文档明确当前不支持，仅列为未来可能）
- 重新评估触发条件：出现「同一用户在不同组织需拥有不同能力」的明确需求（成员关系携带角色字段，或出现按组织授予权限的接口需求）
- 关联代码：User.role @ packages/server/src/user/user.entity.ts；RoleService.create @ packages/server/src/role/role.service.ts；RolePermissionService.checkRolePermission @ packages/server/src/role-permission/role-permission.service.ts
- 证据来源：docs/zh-Hans/guides/permission.mdx（明写：租户级角色、一人一角色、组织切换不换角色）
