【决策记录｜发信通道与模板多级回退】
- 分类：兼容处理
- 动机：优化
- 决策：[推测] 发信通道按「组织级 → 租户级 → 环境默认」回退，每级都做真实 SMTP 握手校验，全失败才抛 500；模板按「组织+目标语言 → 组织+英文 → 租户+目标语言 → 租户+英文」回退，全未命中渲染空内容且不报错
- 背景约束：大量租户不配置自定义 SMTP；模板语言覆盖不全
- 被否决方案：无
- 重新评估触发条件：出现「必须严格使用租户自有通道、禁止回退」的合规要求（新增禁止回退的配置项）
- 关联代码：EmailService.getEmailInstance / render @ packages/server/src/email/email.service.ts；CustomSmtpService.getSmtpSetting @ packages/server/src/custom-smtp/custom-smtp.service.ts
- 证据来源：无直接证据，基于 email.service.ts 中三级通道回退与四级模板回退的代码结构推断
