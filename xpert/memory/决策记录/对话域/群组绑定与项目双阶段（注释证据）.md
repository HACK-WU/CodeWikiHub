**决策：群组按会话 id 绑定；项目作用域双阶段（有代码注释证据）**

- 分类：数据一致性
- 决策 1：群组会话按会话 id 绑定，不加载私有 Assistant thread（门面契约字段注释明示：Group sessions are bound by conversation ID; they do not load a private Assistant thread.）
- 决策 2：项目作用域分两阶段——chatkitMountProjectId / chatkitProjectSelection 为初始绑定与草稿意图；syncConversationProject(threadId) 在运行开始/结束后刷新持久项目（不新开会话）；ChatKit 运行时从已保存会话解析项目作用域
- 背景约束：群组与私有会话的存储/权限模型不同；项目作用域错位会导致会话切换错乱
- 重新评估触发条件：出现群组内个人视角历史、或会话中途换项目的产品需求时
- 证据来源：features/chat/workbench-chat/workbench-chat.facade.ts 的 group / chatkitMountProjectId / chatkitProjectSelection / syncConversationProject 字段注释
