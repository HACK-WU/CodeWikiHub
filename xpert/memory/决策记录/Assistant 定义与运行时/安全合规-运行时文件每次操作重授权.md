【决策记录｜运行时文件必须经 ResolveAssistantFileAccessCommand 且每次操作重授权】
- 分类：安全合规
- 动机：避坑——授权撤销（移出 UserGroup、凭证受众变更、助手撤回发布）必须在**下一次操作**就生效，而不是等会话或缓存过期
- 决策：把「授权」建模为一个 Command；文件入口的每个操作都重新派发 ResolveAssistantFileAccessCommand，由 AssistantFileAccessService.execute() 单点判定并返回 { scope, capabilities }
- 背景约束：AssistantFilesService.bind() 注释「Reauthorize each operation, including after a previously successful list or capability lookup.」；AssistantWorkspaceFilesController 的 8 个端点每个都重新 forRuntime(id)。代价：文件列表页 N 次调用 = N 次准入查询 + N 次 resolveXpertDataVolumeScope（**有意取舍**）
- 被否决方案：无
- 重新评估触发条件：准入查询耗时占比显著高于卷 I/O，或列表页出现超时/告警
- 关联代码：assistant-files.service.ts（bind）、assistant-file-access.service.ts（execute/denied）、ai/assistant-workspace-files.controller.ts
- 证据来源：AGENTS.md + assistant-files.service.ts:29 注释（明写）
