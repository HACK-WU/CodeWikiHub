【决策记录｜对外出参一律用白名单投影，不序列化实体】
- 分类：安全合规
- 动机：避坑——实体携带着加载关系（members/environments/desktopBootstrap/agent）与服务端恢复态，直接序列化会把内部字段与恢复现场泄漏给匿名或低权客户端
- 决策：所有对外响应手工构造白名单字段——XpertProfileController.getProfile 逐项裁剪；XpertAccessController 只回 { id, avatar }；WorkspacePublicDTO 用 @Exclude() 排除 members/environments；EnvironmentPublicDTO 抹掉 variables[].value；AssistantBinding.desktopBootstrap 用 @Exclude({toPlainOnly:true})；BosiBootstrapService.publicProgress() 只回四字段
- 背景约束：getProfile 注释原文 Construct a whitelist instead of serializing the entity and its loaded relations；@Exclude 只作用于 instanceToPlain 方向，绕过 class-transformer 的序列化路径仍可能泄漏
- 被否决方案：无
- 重新评估触发条件：无（安全出口约束）
- 关联代码：xpert-profile.controller.ts、xpert-access.controller.ts、assistant-binding.entity.ts、bosi/bosi-bootstrap.service.ts
- 证据来源：上述源码注释（明写）
