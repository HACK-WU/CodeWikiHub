【数据流｜项目任务图与执行账本】
- 实体类型：表（任务图节点 / 步骤 / 执行尝试 / 会话链接；`XpertProjectTask` 是全批**唯一带 `@VersionColumn`** 的表）
- 结构 `xpert_project_task`：唯一 `(projectId,providerKey,sourceKey)`；`@VersionColumn revision default 1`（CAS 基准）/`predecessorIds json default '[]'`/`parentTaskId`/`kind default 'task'`（task/summary/milestone）/`progress`（`@Min(0)@Max(100)`）/`decisions jsonb default '[]'`/`status`（10 值）/`priority`（4 值）/`requirements jsonb`
- 结构 `xpert_project_task_step`：`taskId`（可空 FK CASCADE）/`stepIndex`/`description`/`notes default ''`/`status ∈ pending|running|done|failed`
- 结构 `xpert_project_task_execution`：**三唯一索引** `IDX_project_task_execution_invocation(invocationId)`、`IDX_project_task_execution_dispatch(projectId,createdById,dispatchRequestId)`、`(taskId,sourceKey)`；`dispatchState ∈ pending|submitted`/`dispatchRequestId`/`dispatchIntent jsonb select:false`/`specificationSnapshot jsonb`/`purpose jsonb`/`projectedTaskRevision`/`projectedInvocationRevision default -1`/`attempt default 1`/`status ∈ queued|running|succeeded|failed|cancelled`；FK `taskId CASCADE`、`conversationId → ChatConversation SET NULL`
- 结构 `xpert_project_task_conversation`：`@Unique UQ_project_task_conversation_relation(projectId,taskId,conversationId,relationType)`；`relationType ∈ origin|discussion|execution|review default 'discussion'`/`isPrimary default false`/`sourceMessageId`/`sourceExecutionId`
- 未接线：`xpert_project_task_log`（`stepId` FK CASCADE、`logType ∈ input|output|error`）实体与注册齐备但**未找到写入/读取点**，排障不要依赖
- 生产方：`XpertProjectTaskService.saveAll/createTask/updateTask/updateTaskSteps`（骨架 `assertOrdinaryTaskInput → lockProject(pessimistic_write) → assertOrdinaryTask → assertBusinessStatus`）、`ProjectTaskGraphService.graph/change`（provider `snapshot` 回写、id 由 `projectTaskIdentity` sha256 派生稳定 UUID）、`ProjectTaskDispatchService.dispatch/submit`、`ProjectRuntimeObservationHandler`（投影位）、`linkConversation`
- 主要消费方：任务图读模型与 `platform.project-tasks` 视图、`ProjectTaskRuntimeReadService`、任务卡片与 8 个插件工具、`PUT /:id/task-graph` 图变更入口
- 状态语义：`runtimeTaskStatus` 只有三种自动映射 `succeeded→review`、`failed→blocked`、`running && progress.startedAt→in_progress`；业务完成只能由 `ProjectTaskDecisionService.decide` 显式给出（accept → CAS `done` 并 append `decisions`，否则回 `todo`）
- 业务用途：项目内协作任务图 + 一次执行尝试的唯一账本（`invocationId = agentInvocationId(scope,'project-task:<requestId>')`，重放绝不新造）；`invocationStatus`/`runtimeStartedAt`/`runtimeCompletedAt` 是**非持久化读投影**；步骤隐式完成仅在「无带 `invocationId` 的执行且全部步骤 done」时成立
- 详细流向：见 .module-experts/后端专题/项目与任务协作专家/implementation/{03-数据流转.md,04-模型.md}
