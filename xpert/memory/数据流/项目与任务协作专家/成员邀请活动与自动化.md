【数据流｜成员邀请活动与自动化】
- 实体类型：表（4 张 + 1 张弃用 M2M 关系）
- 结构 `xpert_project_membership`：唯一 `IDX_xpert_project_membership_unique(projectId,userId)`；`role varchar(20) default 'member'`/`joinedAt`/`removedAt`/`deletedAt`；FK project/user CASCADE、invitedBy SET NULL——**owner 不入此表**
- 结构 `xpert_project_invitation`：部分唯一 `IDX_xpert_project_invitation_pending(projectId,normalizedEmail) WHERE status='pending' AND "deletedAt" IS NULL`；唯一 `IDX_xpert_project_invitation_token(tokenHash)` 且 `tokenHash select:false` + `@Exclude`；`email(255)`/`targetUserId SET NULL`/`role`/`status default 'pending'`/`expiresAt`（缺省 14 天）/`invitedById RESTRICT`/`acceptedById SET NULL`/`lastSentAt`/`legacyMembershipSync*` 4 列
- 结构 `xpert_project_activity`：`type`/`entityType`/`entityId`/`summary text`/`payload json`（写前按 `token/secret/password/prompt/authorization/apiKey` 键名递归脱敏）+ 继承软删 `deletedAt`
- 结构 `xpert_project_automation` / `xpert_project_automation_run`：`name`/`enabled default false`/`trigger json ∈ schedule|task.status_changed|asset.created|conversation.completed`/`actions json`/`lastRunAt`/`nextRunAt`；run 表 `automationId`（FK CASCADE）/`status ∈ queued|running|succeeded|failed|cancelled`/`occurrenceKey`/`jobId`/`error`/`output json`
- 生产方：`XpertProjectMembershipService.add/remove/list/replaceMembers/transferOwnership/interveneAsOrganizationAdministrator`、`XpertProjectInvitationService.invite/accept/decline/revoke/list`、`XpertProjectActivityService.record`（项目与计划两控制器共 12 处写点）、`XpertProjectAutomationProcessor.handle`（run 表**唯一**写入方，一律写 `failed`）
- 主要消费方：`resolveAccess`（成员即角色来源）与 `list` 合并为 `TXpertProjectMemberSummary`、邀请控制器、`GET /:id/activities` 与 `/overview`、`GET /:id/automations[/runs]`（只读遗留）、legacy 同步器
- 关键约束：邀请明文 token 只回一次（`randomBytes(32).toString('base64url')`），库内只有 `tokenHash`；同项目同邮箱至多一条 pending（复用同一行并轮换 hash），`accept` 幂等返回既有成员行；过期时**先落 `status='expired'` 再抛错**；`add` 命中软删行先 `restore` 复用（`joinedAt` 重置）；`remove` 拒移除 owner，先批量 `pause` 该用户 `XpertTask` 再 `emitAsync('xpert-project.member-removed')`
- 已知遗留：`xpert_project_member` 标 `@deprecated`（注释逐字「Legacy relation. Use memberships and the Project membership API; no startup backfill is performed.」）但仍在双写，长期存在两套成员事实；`revoked` 状态未见写入点 `[推测]`；历史成员同步由 60s `@Interval` 重试、退避上限 1h
- 「自动化」现状：写路径（`createAutomation`/`updateAutomation`/`removeAutomation`/`run`）全部抛 `GoneException`（410），`triggerEvent()` 恒返回 `[]`，`@Cron('*/30 * * * * *')` 扫描器直接 `return`——两张表仍可读、仍装配，调用会**静默空转**
- 业务用途：项目「人相关事实」（成员/角色/邀请/活动流）+ 已下线的旧版自动化历史
