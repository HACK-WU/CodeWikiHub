【数据流｜计划族-计划里程碑冲刺泳道】
- 实体类型：表（4 张，层级靠显式 FK，**无 `@Tree`/闭包表**）
- 结构 `xpert_project_plan`：`name`/`description`/`status ∈ draft|active|completed|archived default 'active'`/`view ∈ board|table|gantt|calendar|list default 'board'`/`startDate`/`dueDate`/`order default 0`；OneToMany `milestones`/`sprints`（均 cascade）
- 结构 `xpert_project_milestone`：`planId`（FK CASCADE）/`name`/`status ∈ planned|in_progress|completed|blocked default 'planned'`/`dueDate`/`order default 0`
- 结构 `xpert_project_sprint`：`planId`（可空 FK CASCADE）/`goal text`/`status ∈ planned|running|review|done default 'planned'`/`strategyType varchar default 'software_delivery'`（**不可变更**）/`startAt`/`endAt`/`retrospective`；OneToMany `swimlanes`（cascade）
- 结构 `xpert_project_swimlane`：`sprintId`（FK CASCADE）/`key`/`name`/`kind ∈ backlog|execution default 'execution'`/`priority default 0`/`weight default 1`/`concurrencyLimit default 0`/`wipLimit default 0`/`agentRole default 'planner'`/`environmentType default 'browser'`/`sortOrder`/`sourceStrategyType`
- 结构口径：4 表均**无重复唯一索引**，层级与从属由 `planId`/`sprintId` FK 表达；`xpert_project_sprint.planId` 可空而 `milestone.planId` 必填
- 生产方：`XpertProjectPlanService.ensureDefaults/list/createPlan/createMilestone/createSprint/createSwimlane/updateSwimlane/updateSprint`、`duplicate`/`importProject`（计划族随项目复制）
- 主要消费方：计划列表与计划树、`GET /overview` 聚合、导出 DSL、泳道执行位分配（`concurrencyLimit`/`wipLimit`/`agentRole`/`environmentType`）、`sortOrder` 排序
- 关键约束：`ensureDefaults` 保证「Default plan + Uncategorized」存在；simple 模式只允许这两个默认对象（加对象 400 `Sprints require advanced project mode`）；`createSprint` 强制 advanced 且**同一次调用内**生成 `defaultSwimlanes`（保留 `backlog` + 按 `strategyType` 生成执行泳道，并固化 `sourceStrategyType`）；`createSwimlane` 拒 `key==='backlog'`，`updateSwimlane` 拒把 backlog 升为 `execution`，`updateSprint` 禁改 `strategyType`
- 枚举口径：`software_delivery → planning/coding/review/release`；`data_analysis → research/analysis/visualization`；`backlog` 为保留泳道（`kind:'backlog'`、`concurrencyLimit:0`、`wipLimit:0`）
- 业务用途：项目交付排期骨架（plan → milestone / plan → sprint → swimlane），泳道列承载「能不能并发跑、跑什么角色、跑在什么环境」；四个状态字段**无代码内自动迁移**，靠 API 直接赋值
