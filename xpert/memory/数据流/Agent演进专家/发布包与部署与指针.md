【数据流｜发布包与部署与指针】
- 实体类型：表（`agent_evolution_release_package` / `_release_deployment` / `_canary_test_override` ＋ 被它们前推的 `_active_pointer`）
- 结构 `release_package`：`releasePackageId`（staged 路径 `PUB-<changeId>`、夹具 `RP-<simulationId>`）、`candidateId`、`targetId`、`status`、`scopeType`/`scopeKey`、`value`(json，**内含冻结的 `gatePolicy` 与 `canaryPercent`**)；**UQ `(…, releasePackageId)`**
- 结构 `release_deployment`：`deploymentId`、`releasePackageId`、`channel`、`status`、`scopeType`/`scopeKey`、`value`(json，含 `sampleCount`/`candidateAccuracy`/`severeErrors`/`p95LatencyMs`/`averageCost`/`observations[]`/`completedAt`)；**UQ `(…, deploymentId)`**
- 结构 `canary_test_override`：`overrideId`、`releasePackageId`、`candidateId`、`deploymentId`、`targetId`、`subjectKey`、**`activeKey`(nullable)**、`status`、**`expiresAt`(timestamptz)**、`value`(json)；UQ `(…, overrideId)` **与单列 UQ `(activeKey)`（不带租户维度）**；idx `(…, releasePackageId, status)`
- 生产方：`EvolutionPublicationExecutor.package`（调用方事务内写包 + 冻结策略）、`EvolutionRuntimeStore.saveDeployment/completeDeployment/saveRuntimeObservation`（锁内累加统计 + append `observations[]`）、`createCanaryTestOverride`（写 `activeKey = sha256(tenant:org:deploymentId:subjectKey)`）、`consumeCanaryTestOverride`（清 `activeKey` + 翻 `consumed` + 审计）
- 主要消费方：四道闸门（`sampleCount`/`severeErrors`/`startedAt`/时长）、`activateProduction`/`rollbackProduction`（指针 CAS 的前置比对）、`AgentEvolutionRuntimeService.resolveExecutionPlan`（canary > shadow > production 选路 ＋ 唯一消费覆盖）、`createExperience`（生产门槛）、GET `/releases|/deployments|/releases/:id/canary-test-overrides`
- 用途：承载「策略冻结 + 阶梯位置 + 样本账 + 一次性试放行」四件事；**发布完成 ≠ 生效**——真正切换由消费方 `resolve` 触发指针 CAS
- 边界：`gatePolicy` 只在建包时冻结一次（`forRelease` 缺失即 400 `Release gate policy was not frozen`）；`rolled_back` 是终态、指针 `revision` 只 +1 不回退（误回滚只能重走 `install → shadow → canary`）
- 读路径写库：`getDashboard` 与 `GET /releases/:id/canary-test-overrides` 会把「pending 且已过期」的覆盖行**就地翻 `expired` 且不写审计** —— 高并发下有写竞争与审计缺口
