【数据流｜产物版本与访问日志】
- 实体类型：表（artifacts 自建 4 张：容器 / 不可变版本 / 分享链接 / 访问审计；外键只有单向的「指向 Artifact」）
- 结构 `artifact`（产物容器）：**4 条部分唯一索引** —— 按 `organizationId`/`userId` 是否为 NULL 分列组合 `tenantId+[organizationId]+[userId]+pluginName+resourceType+resourceId`（同一来源在同一作用域内只能有一个容器）＋ 1 条同名普通索引；`kind`(默认 `'file'`)/`status`(默认 `'active'`)/`title`/`description`(text)/`checksum`/`currentVersionId`(uuid)；作用域列 `workspaceId`/`projectId`/`xpertId`/`userId`；json `metadata`
- 结构 `artifact_version`（不可变内容版本）：唯一 `['tenantId','organizationId','artifactId','versionNumber']`（抗版本号并发）、`['artifactId','idempotencyKey']`（抗重放）；索引 `['sha256']`；FK `artifactId → Artifact` **CASCADE**；**`workspaceFileRef` json 非空（字节不进表）**、`versionNumber`(int)/`status`(默认 `'active'`)/`mimeType`/`fileName`/`size`(bigint ＋ number transformer)/`sha256`/`sourceVersionId`；json `metadata`
- 结构 `artifact_link`（分享/打开入口）：唯一 `['slug']`；部分唯一 `['artifactId','shareKey'] WHERE shareKey IS NOT NULL AND status='active'`；FK CASCADE；`versionMode`(默认 `'latest'`)/`accessMode`/`status`(默认 `'active'`)/`publicUrl`(text)/`tokenHash`；`expiresAt`/`revokedAt`；`accessCount`/`downloadCount`(int 默认 0)；`disposition`(默认 `'inline'`)/`allowDownload`(默认 true)/`safeHtmlProfile`；json `customPrincipals`/`metadata`
- 结构 `artifact_access_log`（访问与生命周期审计）：索引 `['tenantId','organizationId','linkId']`、`['slug']`；FK `linkId → ArtifactLink`（可空）**onDelete: SET NULL**；`artifactId`(uuid，**无 FK**)/`slug`/`event ∈ access|download|denied|revoked|expired|archived|deleted`/`accessMode`/`principalUserId`/`ipHash`/`userAgent`(text)/`statusCode`(int)/`error`(text)；只写摘要，**禁止**落预览 token/平台凭据/文件内容
- 生产方：`ArtifactsService.createArtifact/ensureArtifactVersionWithDefaults/createArtifactLink/createSignedPreviewLink/updateArtifactLinkAccess/revokeArtifactLink/recordAccessLog`；插件侧经 `createScopedApi()`（沙箱中间件 `FileActivityStorage.archive` 先 `WorkspaceFiles.uploadBuffer(artifact-snapshots/uuid)` 再登记）
- 主要消费方：`resolveForPublicAccess`/`resolveForManagementAccess`（读 `workspaceFileRef` 后经 VolumeClient 取字节，下发 `X-Xpert-Artifact-Version`/`X-Xpert-Artifact-SHA256`）、`GET /api/artifacts/share/:slug[/download|/descriptor]`、`/artifacts/shared-links/:slug/content`、`createArtifactShareSession`（cookie TTL 15 分钟、服务端把上限钉在 365 天）、管理端审计查询与运营报表
- 用途：把「元数据容器 ＋ 不可变内容版本 ＋ 访问策略 ＋ 访问证据」四表分离，使同一产物可反复分享而内容不可变、链接被删/被撤销后审计仍可追溯
- 状态机：artifact `active|archived|deleted`；version `active|deleted`；link `active|revoked|expired`（`expired` 由 `expiresAt` 在读取时判定并写审计）；lifecycle 由 archive/delete/revokeLink 端点驱动
- 边界：`artifact_version` **无更新语义**（改内容只能新增版本，展示策略改在 `artifact_link`）；`artifact_access_log` 是只追加台账，**未找到 TTL/清理任务**；四表无 `select:false` 列（`tokenHash`/`ipHash` 靠服务层不出参）；「descriptor 预览是否也写审计」「`denied` 是否每次 401 都写」**未逐一核实**
