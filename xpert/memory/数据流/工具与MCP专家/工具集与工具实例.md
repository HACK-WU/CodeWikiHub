【数据流｜工具集与工具实例】
- 实体类型：表（`XpertToolset` 聚合根，唯一可软删）+ `XpertTool` 子实体 + M2M 联接表 + stdio 运行时审计表
- 结构 `xpert_toolset`：`name`、`type`(varchar 50)、`category`(varchar 10)、`options`(json)、**`credentials`(json，`@Exclude({toPlainOnly:true})` 但库内明文)**、`schema`(text)、`schemaType`、`privacyPolicy`；继承 `workspaceId`/`publishAt`/`deletedAt`（软删）；**无 name 唯一索引、无 status 列**
- 结构 `xpert_tool` / M2M：`xpert_tool` 有 `name`、`label`(json)、**`enabled`(`@deprecated use disabled`) 与 `disabled` 双列**、`schema`(json)、`parameters`(json)、`toolset = ManyToOne(onDelete:'CASCADE')` + 冗余 `toolsetId`，**无唯一索引**；M2M 由 `@ManyToMany + @JoinTable({name:'tag_xpert_toolset'})`（`cascade:true`、`eager:true`，无实体类）声明
- 结构 `mcp_runtime_instance`：`status ∈ starting|running|closing|closed|failed`、`origin`、`startedAt`/`closedAt`/`closeReason`、`runnerPid`/`childPid`、`stderrTail`(text 16KB 截断)、`commandLabel`（token|secret|password|key= 替换 `[redacted]`）、`commandHash`(sha256)、`policySnapshot`(jsonb 白名单五字段)；裸列 `workspaceId`/`toolsetId`/`xpertId`/`executionId`/`appInstanceId`；5 个复合索引
- 生产方：`XpertToolsetService.create/createBuiltinToolset/updateToolset`、`XpertToolset.tools` 级联写入（insert/update/remove/soft-remove/recover）、`PluginResourceInstallerService`（平台插件域跨域投影：`ensureMcpToolset` **先 `toolRepo.delete({toolsetId})` 再 `updateToolset`**）
- 生产方（运行时审计）：`McpRuntimeAuditService.recordStarting/recordRunning/recordClosed/recordAppInstance`（由 `mcpStdioRuntimeManager.setAuditSink` 驱动；只增改、从不 delete）
- 主要消费方：`ToolRuntimeService.loadToolsets/executeTool/describeCapabilities`、`XpertToolService.getTool/testTool/getParamsFaker`、`McpCapabilityCatalogService.discover*`、助手侧只读 `ToolsetCatalogItem`（`getAllByWorkspace` + `afterLoad`）、运维面 `operations/mcp-runtimes`（原生 join `xpert_workspace` 取展示名）
- 用途：助手可挂载的工具集实例 = provider 身份 + 凭据 + schema 载体；`mcp_runtime_instance` 是 stdio 生命周期唯一持久事实（默认查询窗口 180 天）
- 边界：软删只覆盖 `xpert_toolset`（`xpert_tool`、MCP 发布八表、Agent 插件两表无 `deletedAt`/`workspaceId`）；凭据库内明文，本层只保护**回显**
- 详细流向：见 .module-experts/后端专题/工具与 MCP 专家/implementation/{03-数据流转.md,04-模型.md}
