【数据流｜桌面壳设备与命令】
- 实体类型：表 × 3（`desktop_shell_device` / `desktop_shell_grant` / `desktop_shell_operation`，tenant+organization 级）+ 2 个显式 SQL 迁移；三表真相在 DB，Redis 只做唤醒（`SHELL_DISPATCH_CHANNEL`）
- 结构 `desktop_shell_device`：**UNIQUE(tenantId,organizationId,userId,installationId)**；`installationId`(uuid)、`platform(20)`、`shell(256)`、`cwd`(text)、`enabled`(默认 false)、**`credentialHash` varchar(64)（sha256 摘要，非明文秘密）**、`credentialExpiresAt`、`connectionEpoch`(uuid 可空)、`leaseExpiresAt`（可空）
- 结构 `desktop_shell_grant`：`@Index(deviceId,enabled)`；`userId/deviceId/assistantId`(uuid)、`threadId`(可空)、`enabled`(默认 true)、`expiresAt`、**`operation`(jsonb = `ShellOperationAuthorization`：`{runId,toolCallId,argsHash,decision}`)**；`deviceId → device CASCADE`、`grantId → grant` **未声明 ON DELETE（NO ACTION）**
- 结构 `desktop_shell_operation`：**UNIQUE(tenantId,runId,toolCallId)** + `@Index(deviceId,state)`；`grantId/threadId/runId`(非空)、`toolCallId(255)`、`argsHash(64)`、`command/cwd`(text)、`timeoutSec/deadline`、`state`(varchar(24) default `pending`，9 态)、`output`(jsonb default `'[]'`，`ShellChunk[]`)、`outputBytes/seq`、`exitCode/signal/truncated/errorCode(80)`
- 是否加密/脱敏：**无加密列**；唯一「摘要而非明文」的是 `credentialHash`（sha256，凭证本体只在客户端）；设备 token 明文**只在 `register` 响应返回一次**；`assistantId/threadId/runId` 均为**跨域弱引用（无外键）**
- 生产方：`DesktopShellAuthService.register/refresh/disable/authenticate`（`timingSafeEqual` 比对）、`issueGrant/bindForRun/revokeGrant`、`prepareOperation`（写 `decision:'pending'` 并把 grant 压到 ≤10 分钟，**只路由不执行**）、`decideOperation`（事务 + `pessimistic_write`，只允许 `pending→approved|rejected` 或同值重放）、`DesktopShellOperationService.execute/receive/cancel`、`DesktopShellGateway` 的 **1s 巡检**（也直接 UPDATE）
- 消费方：`DesktopShellGateway`（握手 `version=1`+`token` → 轮换 `connectionEpoch`、租约 90s、旧 socket 踢出）、`DesktopShellMiddleware`（`desktop_shell` 工具 + `requestShellApproval` 两段式 HITL）、`wait/result`、`DesktopShellController` 的 `operations` 列表
- 状态机（实证）：`operation.state` `pending → running`（首个 output 片）→ 终态（6 值 `isFinal`，含 `succeeded/failed/cancelled/timed_out/rejected/unknown`）；`rejected` 仅可由 `pending` 进入；`revoke`/device `disable` → grant `enabled=false`（不可逆，需重签）
- 迁移与协议：`20260924-desktop-shell.sql`（`BEGIN…COMMIT` + `IF NOT EXISTS` 建三表 + 2 UNIQUE + 2 索引，additive）→ `20260928-desktop-shell-approval.sql`（`ADD COLUMN IF NOT EXISTS operation jsonb`）；**先跑前者再跑后者，回滚按外键逆序**；`packages/desktop-protocol` 的 `LIMITS`（command/chunk 16KiB、output 1MiB、result 64KiB、timeout 60/600s、lease 90s、grant 8h）双端校验
- 边界/风险：超租约活跃行置 `unknown/EXECUTION_UNKNOWN`（**明确不重放**，需人工对账后重新发起）；`output` 每 chunk 全量写回，容量随连接数与输出量增长；三表**无 TTL 清理作业**；撤销有最长秒级窗口（dispatch 每轮复查 + 1s 巡检兜底）
