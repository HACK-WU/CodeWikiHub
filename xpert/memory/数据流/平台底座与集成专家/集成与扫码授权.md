【数据流｜集成与扫码授权】
- 实体类型：表（`Integration` 单表，tenant+organization 级）+ **Redis-only 会话**（扫码授权，**不落库、无审计表**）
- 结构 `integration`：`name`（`@Index` 普通）、`description`、`avatar`（json）、**`slug`（`@Index` unique，列可空）**、`provider`（非空）、**`options`（json，含 `botToken` 等凭据）**、`features`（jsonb，`IntegrationFeatureEnum[]`，**无 CHECK**）、`userId`（ManyToOne `User` 可空、**未声明 onDelete**，作稳定技术主体）、`tags` M2M → `Tag`（**未声明 `@JoinTable`**，隐式联接表名 `[推测：integration_tags_tag]`）
- 是否加密/脱敏：**无加密列**；脱敏只在列表出口（`IntegrationPublicDTO` 把 `options` `@Exclude()`），服务层与宿主快照仍直读 `options`——`hostSnapshot` 会带出 `options.botToken`（读权限仅 `INTEGRATION_VIEW|EDIT` 兜底）
- 生产方：`IntegrationUpsertCommand` handler（controller POST/PUT，次序 = 策略 `validateConfig` 六字段白名单 → `onUpdate` 钩子 → 落库）、`IntegrationQrService.complete`（**id = 会话 id** 换崩溃重试幂等，命中既有行只**浅合并** `options` 并跑 `onUpdate`，`outcome=reused`）、`ConnectorAppIntegrationService.create`（slug `connector-{bindingId}-{requestId}` + `orIgnore()` + 回查幂等）
- 会话键与状态：`integration:qr:session:<uuid>`（zod `sessionSchema`）、`integration:qr:active:<tenant>:<org>:<user>:<provider>:<purpose>`、`integration:qr:account:<…>:<sha256(identity)>`；状态 `waiting → authorized|expired|denied|failed`，`expiresAt = now + clamp(30..600)s`、`intervalSeconds ≥ 2`、`complete` 后清空 `deviceCode/options`（终态不可逆）
- 消费方：`IntegrationViewHostDefinition.resolve`（宿主快照，`hostType='integration'`，slot `detail.main_tabs`）、connector-app 的 resolve handler、`view-extension` 宿主缓存订阅者（insert/update/remove → `invalidateHostIdentity`）、`xpert-project`（`IntegrationAuthorizedEvent`，消费方在批次外）
- 用途：第三方集成实例 = provider 策略 + options 凭据 + 特性清单，同时是 view-extension 的**唯一在用宿主**
- 边界：QR 会话仅存 Redis——Redis 清空即全失效，过期/越权/不存在**统一 404**（防会话枚举）；账号去重依赖策略提供 `getQrAuthorizationIdentity`，缺省时**可能重复建 integration 行**；写入门槛 = `slug` 唯一索引 + 策略 `validateConfig` + `INTEGRATION_EDIT`
- 风险：轮询期间第三方令牌明文驻留 Redis 直到 `complete`；provider 的 `intervalIncrementSeconds` 会把轮询间隔拉长（上限 600s）且过期后选项不可恢复
