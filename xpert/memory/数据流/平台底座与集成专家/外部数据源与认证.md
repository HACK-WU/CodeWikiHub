【数据流｜外部数据源与认证】
- 实体类型：表（`DataSource` tenant+organization 级 + `DataSourceAuthentication` tenant+userId 级）；模块 `data-source`（`packages/server/src/data-source`）
- 结构 `data_source`：`name`（`@Index` 普通）、`typeId`（`@Index`，**列非空**）+ `type` ManyToOne → `DataSourceType`（`onDelete: 'CASCADE'`）、`authType`（varchar 可空，`AuthenticationEnum`）、`options`（json：**列上方 `// @Exclude()` 处于注释态 → 默认出网**）、OneToMany `authentications`（`cascade: true`）；**无唯一索引**
- 结构 `data_source_authentication`：`dataSourceId`（`@RelationId` 真列）+ `dataSource` ManyToOne（`onDelete: 'CASCADE'`，仅**关系**上有 `@Exclude()`）、`userId`（非空、**无外键**）、`username`、**`password`（普通 text：无加密、无 `select:false`、无 `@Exclude`）**、`validUntil`（可空）；**无唯一索引**（`{tenantId,dataSourceId,userId}` 唯一是服务层 read-then-write 约定）
- 是否加密/脱敏：本批 14 表**无任何加密列**；`password` 是**明文落库 + 明文回显**；脱敏只发生在 `GET /api/data-source` 列表（`DataSourcePublicDTO` 白名单 `id/name/type/typeId/authType/createdAt/updatedAt/createdBy`），`GET /:id`（可 `$relations=["authentications"]`）与 `GET /:id/authentication` 直出明文
- 生产方：`CrudController` + `DataSourceService.create/update`、`PUT /:id` 直连（**绕过命令总线**，留 `@todo`）、`createAuthentication`（按三元组 upsert，`validUntil = now + 30d` 写死，**无续期/失效路径**且读取侧从不校验）、`deleteAuthentication`
- 消费方：`prepareDataSource`（`authType=BASIC` 时把当前用户 `username/password` **写回 `options`** 后交给 runner）、`getCatalogs/getSchema/query/olap/queryCapability/import/dropTable`、`DataSourceRuntimeService`（插件运行时唯一出口，只读 + 引擎白名单 `mysql|doris|postgres` + `updatedAt` revision 复核）、`xpert-table` 的 `XpertDatabasesQuery`、`findSqlDataSources`
- 用途与流程：连接配置（**不是数据副本**）→ 代理链 `prepareDataSource → DataSourceStrategyQuery(type, options) → runner → finally teardown()`（每次新建连接，**无 schema 缓存、无超时定义**）；OLAP 另有会话级 runner 复用（10 分钟）
- 取值范围与状态：本表**无 status 列**；`authType` 由 `AuthenticationEnum` 表达；认证行无状态机（删除即删行），过期只靠 `validUntil` 值、无运行时拦截
- 边界：`typeId` 列非空意味着每源必挂类型，类型被删 `CASCADE` 连带删源；认证是**个人粒度**（非共享）；`data_source_type`、`organization_language` 都不在本批 14 表内
- 风险：新增任何 `options`/`password` 读取面（导出、事件、日志字段、`$relations` 展开）都会带出明文凭据——唯一兜底是库级权限（C5 §D2）；`DataSourceUpdatedEvent` 目前**域内无消费者**（`events/handlers/index.ts` 空导出）
