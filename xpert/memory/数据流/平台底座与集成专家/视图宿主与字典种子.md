【数据流｜视图宿主与字典种子】
- 实体类型：**视图宿主 0 表**（进程内注册表 + 缓存，只在 `Integration` 行上做宿主解析）+ **字典 3 表**（`language`/`country`/`currency`，全局 `BaseEntity`，无隔离键）
- 结构 `language`：**`@Unique(['code'])`**、`name`（非空）、`code`（可空但唯一）、`is_system`（默认 true，由 `LanguagesEnum` 判定）、`description`、`color`（非空，`faker.internet.color()`）；OneToMany `organizationLanguages`（`cascade: true`）
- 结构 `country` / `currency`：`isoCode`（`@Index` **非唯一**、非空）+ `country` / `currency`（非空）；**无唯一索引**——唯一性只由种子内容保证
- 是否加密/脱敏：**无加密列、无敏感列**；字典读端点 `@Public` 且无 DTO 白名单；`contact.country` 存 `isoCode` 字符串而非外键
- 视图宿主生产方：`@ViewHostDefinition('integration')` → `ViewHostDefinitionRegistry.onModuleInit` 用 `DiscoveryService` + `Reflector` 建 `Map<hostType, contract>`（**进程内内存，新增宿主需重启**；同键静默覆盖、无冲突检测与卸载钩子）；清单事实由插件 `ViewExtensionProviderRegistry` 提供
- 视图缓存与失效：`ViewExtensionCacheService`（`VIEW_EXTENSION_CACHE_SERVICE_TOKEN`）清单 60s、view data `min(ttlMs, 30s)`，键含 `tenant/org/userId` 与 `sha1(features + hostState)` 激活态摘要；**两条失效链**——实体级 `IntegrationViewHostCacheSubscriber`（`invalidateHostIdentity`）与全局 `StrategyBus.events$` → `clearAll()`
- 字典生产方：`SeedDataService.seedBasicDefaultData`（顺序 `Countries → Currencies → Languages → Features`，每步 `tryExecute`；默认阶段再 `createDefaultTags/createTags`）、`LanguageInitCommand → LanguageService.initialize()`（运行期重灌）；`contact.seed.ts` 全仓无调用方
- 字典幂等性：`createLanguages` 整批 `save()`（**upsert 语义**，唯一冲突被 `try/catch + console.log` 吞掉）、`createCountries`/`createCurrencies` **直插无去重**（重复执行重复插行）、faker 颜色使种子**不可复现**且 `description` 每次被重置
- 消费方（字典）：`LanguageController`（`@Public` getAll/getByName，未命中回 `null`）、`CountryController`/`CurrencyController`（只读）、`organization_language`（server-core，本域只声明关系、跨域写）、多语言 fallback（`zh_Hans ?? en_US`，按 `RequestContext.getLanguageCode()`——字典缺行时下游文案**静默**走默认分支）
- 消费方（视图）：前端 `view-extension-api.service.ts` 与 `@shared/view-extension/renderers/*`；移动端 `deployment.viewHostsPath` 固定 `/api/view-hosts`（**直接指向本链路端点簇**）
- 边界：一致性的权威是「常量 + 种子」，改字典 = 改常量 + 改初始化，**不允许加写端点**（C5 §D1）；视图宿主契约（`hostType/slots/resolve/canRead/可选 prepareFileAction`）变更会连带改插件与前端
