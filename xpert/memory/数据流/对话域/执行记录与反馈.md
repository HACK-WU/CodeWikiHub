**数据实体 · 执行记录与反馈**（对话域，与 Studio 共享）

- 是什么：会话执行中每个 Agent/节点的执行记录（IXpertAgentExecution，状态 RUNNING/SUCCESS/ERROR/PENDING/TIMEOUT/INTERRUPTED）+ 上下文用量（TThreadContextUsageEvent）+ 消息反馈（IChatMessageFeedback）
- 来源：实时事件（socket/流）+ 回查 /api/xpert-agent-execution/:id/log、/checkpoints、/state；反馈 /api/chat-message-feedback
- 去向：agentExecutions / contextUsageByAgentKey 投影 → 消息渲染执行树（agent-run-tree）与共享执行组件
- 消费方：对话页、Studio（状态检查器/预览调试，同一批数据实体与共享组件 @shared/xpert/execution-log、execution-status）
- 业务用途：对话可观察性与质量信号
- 关键约束：前端零新增数据（纯投影），避免与后端双源漂移
