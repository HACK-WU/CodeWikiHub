【数据流｜记忆体与信号】
- 实体类型：**卷上文件（无表）** —— 记忆体是 `.xpert/memory` 下的 markdown/JSON；`file-memory` 自身 **0 张自有表**，只读 3 张外部表（`chat_conversation`/`chat_message`/`xpert`，**本域零写入**）
- 结构（目录布局）：`.xpert/memory` ＋ 索引 `MEMORY.md` ＋ 四类目录 `user|feedback|project|reference` ＋ `.dream/**`（Dream 运行证据）＋ `scorecards/index.json`（记分卡）；项目卷下按助手隔离为 `.xpert/memory/xperts/<xpertId>`，否则直接用助手卷 `.xpert/memory`
- 结构（路径护栏）：`normalizeFileMemoryRelativePath` 拒绝 `..`、绝对路径与空路径；单段（xpertId/文件名）拒绝含 `/`；子域根读取需显式 `{ allowRootWorkspace: true }`
- 结构（条目 frontmatter）：`id`（`mem_<uuid>`）/`scope`/`type ∈ user|feedback|project|reference`/`status ∈ active|archived|conflict`/`usage`/`confidence`/`source ∈ explicit|writeback`/时间戳；正文为 body；**状态写在 frontmatter，无 DB 状态机**
- 结构（信号 6 类）：`recall_hit`（`recordRecallHits` 写并重写 `scorecards/index.json`）、`detail_read`（`getMemory` 追加并 `updateTopicUsage`）、`explicit_write`、`writeback_candidate`、`user_correction`、`index_issue`
- 生产方（写入三入口）：① `memory_write` 工具 → `FileMemoryService.writeMemory`（`source:'explicit'`，无 `memoryId` 时生成 `mem_<uuid>`）；② `afterAgent` → `FileMemoryWritebackRunner.enqueue(snapshot)` → `processSnapshot` 先 `recordWritebackCandidate`（`sourceRef = conversation:<id>`）再 `searchMemory(limit 6)` → `decideFileMemoryWriteback` 决策 `upsert|archive`（`source:'writeback'`；**模型缺失时只留候选并 warn，不落半成品记忆**）；③ Dream 离线整理（`FileMemoryDreamService.triggerDream` → `XpertAgentChatCommand` 调 dreamer 助手，直接编辑卷上 markdown 与 `MEMORY.md`，运行前备份、`finally` 清理，证据落 `.dream/runs/<runId>/**`）
- 主要消费方（消费二入口）：`XpertFileMemoryMiddleware.wrapModelCall` 前置注入 `[...buildMemoryContextMessages(recall), ...request.messages]`（`recall` 来自 `beforeAgent` 起的后台召回）＋ `memory_search`/`memory_get` 工具；`XpertFileMemoryScopeResolver`/`XpertConversationHistoryReader` 只读三张外部表做取证与作用域解析（`select id/threadId/title/xpertId/tenantId` ＋ 作用域过滤）
- 用途：让长期记忆**可人读、可 diff、可被 Agent 工具直接读写**（实现层原文口径），且与解析链零代码耦合 —— 一次解析失败或向量库不可用不会连带记忆不可用
- 边界（并发与去重）：写入按 `createFileMemoryScopeKey`（tenant/project/user）**串行**（后到覆盖 `pending`，`softDrain` 超时返回 false 表示未等待完成）；同轮已显式写则 `afterAgent` 直接 `skipped reason=explicit_write`；`upsert` 复用候选 `memoryId` 是**软去重，无 DB 唯一约束兜底**；归档只改 `status:'archived'`（文件仍留卷上，无物理删除入口）
- 边界（Dream 闸门）：默认 `{enabled:true, minIntervalMinutes:30, minNewOrUpdatedMemories:1, minConversationCount:1}`，env 键 `FILE_MEMORY_DREAM_GATE_ENABLED`/`FILE_MEMORY_DREAM_MIN_INTERVAL_MINUTES`/`FILE_MEMORY_DREAM_MIN_NEW_MEMORIES`/`FILE_MEMORY_DREAM_MIN_CONVERSATIONS`；未过落 `status='skipped'`（**不是错误**）；运行状态 `queued→running→succeeded|partial|failed|cancelled|skipped`
- 边界（未确认）：**未见 `@Cron/@Interval/@Processor`** ⇒ Dream 自动触发时机与并发加锁**未确认**；条目数/总字节/保留期无强制实现（`index-validator.ts` 只做索引格式校验），是否有外部配额**未确认**
- 详细流向：见 .module-experts/后端专题/文件理解与记忆专家/implementation/{03-数据流转.md 链路六,02-实现.md 文件记忆链,04-模型.md 记忆侧只读外部表}；决策见 C5-关键决策.md §D7/§D11
