**数据实体 · 令牌与准入上下文**（认证域）

- 令牌（XpAuthToken）：来源 /api/auth/custom/{login,register,refresh-token}；去向 @core/auth 存储 → http-context 注入全站请求；消费方：全站 HTTP、ChatWebsocketServer（连接与刷新重连）、各域守卫
- 用户与组织上下文：认证响应 + organization-status（经 @xpert-ai/store）→ onboard.guard 判定 → onboarding 向导
- 邀请/返利上下文：邀请链接 → referral-registration-session（注册期保持）→ 注册载荷 → 后端结算
- OIDC/SSO：后端 identity 授权码流 → consent/bind/confirm 页 → 统一令牌链
- 关键约束：令牌强校验（非法即抛 NbAuthIllegalTokenError）；改令牌结构/刷新语义 = 全站级影响；公共页免登录是显式白名单
