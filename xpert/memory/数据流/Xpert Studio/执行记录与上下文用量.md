**数据实体 · 执行记录与上下文用量**（Xpert Studio）

- 是什么：一次运行中每个 Agent/节点的执行记录（状态/起止/输入输出摘要/所属会话）+ 各 Agent 线程上下文用量事件
- 来源：实时 SSE（POST /api/xpert/:id/chat、POST /api/xpert-agent/chat）；回查 GET /api/xpert-agent-execution/:id/log / checkpoints / state
- 去向：前端仅投影（不落本地存储）——映射为画布节点状态徽标、执行面板列表、状态检查器视图
- 消费方：Studio 画布（节点状态/悬浮卡片）、状态检查器（日志/检查点/重跑）、共享执行日志组件（@shared/xpert/execution-log、execution-status，对话域亦使用）
- 业务用途：让编排可观察——看清每个节点在跑什么、卡在哪、从哪个检查点重跑
- 关键约束：执行真相在后端，前端零新增数据（纯投影），避免双源漂移
