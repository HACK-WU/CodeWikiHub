**数据实体 · 版本记录（versions）**（Xpert Studio）

- 是什么：发布版本元信息 {id, version, latest, publishAt, releaseNotes}[]；每个版本是同一 family 下的独立 Xpert 记录
- 来源：GET /api/xpert/:id/version；变更：POST publish?newVersion= / POST latest / DELETE /api/xpert/:id
- 去向：版本切换 = 路由跳到目标版本记录；模板导出 GET export / POST export/template
- 消费方：Studio header（版本选择/发布/删除）、发布市场与模板、对话运行时（按版本运行）
- 业务用途：编排的发布历史——回切旧版本、标注最新、对外分发
