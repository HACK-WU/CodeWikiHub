- 一句话职责：回答「请求是谁」（5 种凭据 → principal）与「这个人能做什么」（角色 + 权限位 + Guard 判定），并维护「人—租户—组织」归属关系（用户、成员、用户组、员工、邀请）
- 核心能力：AuthService.register/issueTokensForUser/refreshTokens、UserService.findCurrentUser/deleteWithGuards、UserOrganizationService.ensureMembership、InviteService.createBulk、RolePermissionService.checkRolePermission、AccountBindingService.bindUser
