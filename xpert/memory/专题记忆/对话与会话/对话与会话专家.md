【专题记忆｜对话与会话】
- 资产路径：.module-experts/后端专题/对话与会话专家/（用 expert-lookup 加载；含 3 个子专家）
- 一句话职责：平台**对话账本与投递账本**的持有者——会话/线程/目标/读状态与消息的持久化与授权、分支（写模型）与脉络地图（只读视图）、群聊协作（成员/发布幂等/收据/HITL）、handoff 投递队列（4 队列/4 消费者/路由/取消/死信）与运行时消息闭环（delivery → inbox → 续跑）
- 模块范围：packages/server-ai/src 下 chat-conversation/（含子目录 conversation-branch/・conversation-map/・goal/）· **handoff/**（真实目录名，索引 slug 是 handoff-queue）· chat-group/ · chat/ · chat-message/ · chat-message-feedback/；不含 shared/stream（共享 SSE 设施）

- 高频坑（≤3）：① **取消是协作式**（AbortSignal）+ 扫描式，`dead(canceled:…)` **不进死信不重试**；`consumer_outcome_unknown` 不得自动重放（需人工 redrive），**不是 exactly-once** ② **outbox 与 Invocation CAS 必须同事务**；`Redrive never changes an Invocation or clears a user stop` ③ `messageEnvelope` 唯一是 provenance/presentation 契约（**不是授权**、不要放 prompt/凭据）；地图**无 entity**（view-extension provider）
