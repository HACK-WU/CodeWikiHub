- 核心能力（沙箱）：`NsjailSandboxProvider.create`、`SandboxConversationContextService.authorizeConversation/resolveConversationSandbox`、`SandboxJobRuntimeCapabilityService.run/cancel/cleanupOrphans`、`SandboxManagedServiceService.startBy*/proxyByConversationId`、`SandboxTerminalGateway.open`
- 核心能力（运维面）：`RuntimeControlService.requestRestart/assertAuthorizedActor`、`RuntimeLifecycleService.beginDrain/readiness/trackRequest`、`RuntimeDrainMiddleware`、`HealthController.check/readiness`
- 核心能力（产物面）：`ArtifactsService.createArtifact/ensureArtifactVersion/resolveForPublicAccess`、`WorkspaceFileAccessService.createSession/createGrant/resolveAuthorizedFile`
- 高频坑①：`@Public()` 只等于「跳过全局 JWT」——**3 条 proxy**（有 `SandboxPreviewAuthGuard` 票面与路径参数比对）＋ **`GET volume/*path` 通配（无身份、无审计、无速率限制，仅路径黑名单）**；`@Public()` ≠ 放行
- 高频坑②：Runner 的真实实现在 **`/.deploy/nsjail-runner/`**（`runner.py`/`network.py`/`seccomp.policy`/Dockerfile），`packages/nsjail-runner` 只有发布元数据（`private: true`）——改 runner 行为必须去 `.deploy` 侧改
- 高频坑③：配额是 Redis Lua **三桶租约**（global 20 / tenant 4 / user 2），任一满即 `SandboxJobRuntimeError('SANDBOX_CAPACITY_UNAVAILABLE', retryable=true)` 且在拿到 lease 前长时间挂住；注册表强制 `timeoutMs ≤ hardDeadlineMs`；`RUNTIME_IDLE_TTL_SECONDS=7200` 只回收运行时、**不回收卷内文件**
- 关键代码位置：`sandbox/{sandbox.controller.ts,sandbox-conversation-context.service.ts,sandbox-terminal.gateway.ts,sandbox-managed-service.service.ts,nsjail/*,sandbox-job/*}`、`packages/server/src/runtime-control/*`、`packages/server/src/health/health.controller.ts`、`artifacts/{artifacts.controller.ts,artifacts.service.ts}`、`workspace-file-access/*`
- 数据落地：`sandbox_managed_service`（唯一 `['conversationId','name']`、FK CASCADE）· `sandbox_job`（唯一 `['tenantId','idempotencyKey']`、`containerRef` 已 `@deprecated`）· `artifact`（4 条部分唯一索引）· `artifact_version`（`workspaceFileRef` json 非空，**字节不进表**）· `artifact_link`（`slug` 唯一）· `artifact_access_log`（`linkId` SET NULL，链接删除后仍留证据）
- 数据落地口径：5 模块**无 `migrations/*.sql`**（DDL 依赖外部 schema-sync）；6 表**无 `select:false` 列**、枚举列全为 varchar 无 DB 级 CHECK；敏感字段（`tokenHash`/`ipHash`）靠服务层不出参
