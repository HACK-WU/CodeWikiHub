【专题记忆｜平台插件与技能】
- 资产路径：.module-experts/后端专题/平台插件与技能专家/（用 expert-lookup 加载；含 3 个子专家）
- 一句话职责：插件与技能的「准入 → 落地 → 运行」闭环——插件从市场/本地代码/归档进入平台（SDK 校验 → staging → schema preflight → 动态加载 → 路由/策略注册），导出的 portable 资源按固定矩阵安装到工作区/智能体/组织，技能包与技能仓库索引的安装、创作、分享与同步
- 核心能力：PluginManagementService.installPlugin/installArchivePlugin/refreshCodePlugin/uninstallByNamesWithGuard、PluginInstanceService.upsert/findVisibleInOrganization、PluginMarketplaceService.listMarketplace/createSource/refreshSources、PluginResourceInstallerService.installToWorkspace/installToXpert、SkillPackageService.installSkillPackage/shareSkillPackage/syncPluginSkillBundle、SkillRepositoryIndexService.sync
- 高频坑（≤3）：① **动态装配顺序不可颠倒**（先合并插件 ORM metadata → 再 lazyLoad → 最后注册路由/策略），否则 `EntityMetadataNotFoundError` 或「装成功但全 404」；② 插件启动 hook 超时/失败**即致命**（关闭 readiness）且启动日志**不记录插件配置与异常文本**；③ **技能仓库索引前缀是 `/api/skill-repository-indexes`**（AGENTS.md 写作 `/skill-repository/indexes` 是错的）
- 关键代码位置：PluginManagementService @ packages/server/src/plugin/plugin-management.service.ts；PluginInstanceService @ packages/server/src/plugin/plugin-instance.service.ts；plugin-orm-metadata.ts / plugin-http-routes.ts / plugin-runtime-policy.ts @ packages/server/src/plugin/；PluginResourceInstallerService @ packages/server-ai/src/plugin-resource/plugin-resource-installer.service.ts；SkillPackageService @ packages/server-ai/src/skill-package/skill-package.service.ts
- 数据落地：plugin_instance、plugin_marketplace_source、plugin_marketplace_registry_item、plugin_application_installation、plugin_resource_installation、skill_package、skill_repository、skill_repository_index（8 张；另复用 tenant_setting 存 setup 进度）
