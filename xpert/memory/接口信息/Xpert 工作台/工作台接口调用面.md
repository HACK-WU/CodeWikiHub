【接口信息｜Xpert 工作台接口调用面】
- 子功能：助手读取与草稿/发布写入、记忆/会话日志/统计/授权、工具集与工具配置、工作区入口、知识库挂载
- 所属模块：Xpert 工作台专家（前端专题）
- 接口列表：
  - 助手管理面：GET /api/xpert/:id/team?data={"relations":[9 项]} / 团队聚合读取（injectGetXpertTeam）；GET /by-workspace/:workspaceId、/my、/slug/:slug、/validate / 列表与重名校验
  - 写侧：PUT /api/xpert/:id（{draft:null} 丢弃草稿）、PUT·POST /:id/draft、POST /import、GET /:id/export、POST /:id/{sync-template,duplicate,publish}、DELETE /:id / 草稿保存、DSL 导入导出、发布与删除
  - 记忆/日志/统计/授权/账号：/api/xpert/:id/memory（+bulk/search/files）、/:id/conversations、/:id/statistics/*、/:id/user-groups[/authorizations]、/:id/api|app、/:id/principal-user
  - 工具集面：GET /api/xpert-toolset/:id?relations=tools、PUT/DELETE /:id、/providers、/provider/:name、/tags、/builtin-provider/:provider/{tools,credentials-schema,instance}、/by-workspace/:id、/provider/{openapi/schema,openapi/remote,odata/remote}、/:id/credentials
  - 工具面：POST /api/xpert-tool/test（responseType:'text'）、GET /api/xpert-tool/:id/faker、GET /api/xpert-tool/:id
  - 工作区面：GET /api/xpert-workspace/my?purpose=、/my/default、POST /:workspaceId/default、/:workspaceId（+/members、/visibility、soft/recover/archive）
  - 知识库面：GET /api/knowledgebase/my、/public、/by-workspace/:id、/detail/:id、元数据（keyword-analyzers/vector-stores/text-splitter/transformer/understanding 策略、preview-chunks）、PUT /:id/wiki/config
  - 前端组件与服务调用面：XpertService（路由级 provider：xpert()/latestXpert()/published$/refresh）、injectGetXpertTeam、injectGetXpertsByWorkspace、buildEditableXpertDraft、XpertAssistantFacade（optional 注入）、XpertAPIService/XpertToolsetService/XpertToolService/XpertWorkspaceService/KnowledgebaseService/FileMemoryAPIService
- 关键约束：查询串统一 ?data={...}；服务端契约归属——/api/xpert/* 归 Assistant 定义与运行时专家、工作区面归工作区子专家、知识库归知识库专家；管理页=读侧+动作触发侧，完整写侧归 Studio
