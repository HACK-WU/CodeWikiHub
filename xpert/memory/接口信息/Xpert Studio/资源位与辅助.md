**Xpert Studio 接口 · 资源位与辅助**（前端调用视角，真实路径）

- GET /api/knowledgebase/by-workspace/:id / GET /api/knowledgebase/detail/:id
  - 用途：知识库候选与详情（节点挂载选择）
- GET /api/xpert-toolset/by-workspace/:id / GET /api/xpert-toolset/:id?relations=tools / GET /api/xpert-toolset/providers
  - 用途：工具集候选/详情/provider 元数据
- GET /api/environment?data=… / PUT /api/environment/:id
  - 用途：环境列表 / 环境变量保存
- GET /api/business-area?data=…
  - 用途：业务域（发布绑定）
- GET /api/xpert/:id/variables / /api/xpert/:id/agent/:agentKey/variables / /api/xpert/:id/workflow/:nodeKey/variables
  - 用途：变量候选（配置面板补全）
- GET /api/xpert/triggers/providers / GET /api/xpert/sandbox/providers
  - 用途：触发器/沙箱 provider 元数据
- 前缀口径：API_PREFIX=/api；XpertAPIService apiBaseUrl=/api/xpert（API_XPERT_ROLE）
