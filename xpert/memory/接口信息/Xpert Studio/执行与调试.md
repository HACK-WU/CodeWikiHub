**Xpert Studio 接口 · 执行与调试**（前端调用视角，真实路径）

- POST /api/xpert/:id/chat（SSE）
  - 用途：画布预览整图调试（isDraft:true 跑当前草稿）
- POST /api/xpert-agent/chat（SSE）
  - 用途：单 Agent 调试 / 中断恢复（run | resume）
- POST /api/xpert-agent/xpert/:xpertId/test/:nodeKey
  - 用途：工作流单节点测试
- GET /api/xpert-agent-execution/:id/log
  - 用途：执行日志
- GET /api/xpert-agent-execution/:id/checkpoints
  - 用途：检查点列表（配合状态检查器重跑）
- GET /api/xpert-agent-execution/:id/state?checkpointId=
  - 用途：状态快照
- GET /api/chat-conversation/:id?relations=messages / GET /api/chat-conversation/xpert/:xpertId / POST /api/chat-conversation/:id/cancel
  - 用途：调试会话读取 / 取消
- 前缀证据：API_XPERT_AGENT_EXECUTION=/api/xpert-agent-execution（@core/constants/app.constants.ts）
