**Xpert Studio 接口 · 编排与草稿**（前端调用视角，真实路径）

- GET /api/xpert/:id/team?data={"relations":[…]}
  - 用途：读取编排本体 + 草稿（relations 含 agent/agents/executors/copilotModel/knowledgebase）
  - 前端：injectGetXpertTeam（features/xpert/utils.ts）← XpertStudioApiService 初始化链
- POST /api/xpert/:id/draft
  - 用途：草稿保存（自动保存 1s 去抖；服务端写 savedAt）
  - 前端：XpertStudioApiService.saveDraft（domain/xpert-api.service.ts）
- PUT /api/xpert/:id/draft
  - 用途：草稿局部更新（前端为 XpertAPIService.upadteDraft，studio 未直接调用）
- PUT /api/xpert/:id（body {draft:null}）
  - 用途：丢弃草稿、回到已发布版本（resume）
- GET /api/xpert/by-workspace/:workspaceId?published=true&where={"latest":true}
  - 用途：外部专家（协作者）候选列表
- 后端定义：packages/server-ai/src/xpert/xpert.controller.ts（@Get(':id/team') / @Post(':id/draft') / @Put(':id/draft')）
