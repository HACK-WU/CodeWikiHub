**Xpert Studio 接口 · 版本与发布**（前端调用视角，真实路径）

- GET /api/xpert/:id/version
  - 用途：版本列表（{id, version, latest, publishAt, releaseNotes}[]）
  - 前端：XpertStudioApiService.versions → header/publish
- POST /api/xpert/:id/publish?newVersion=true|false
  - 用途：发布（newVersion=false 表示覆盖当前版本）；body 含 environmentId / releaseNotes / businessAreaId / marketplace?
  - 前端：XpertPublishVersionComponent.publish（发布前 unsaved 为真则先保存草稿）
- POST /api/xpert/:id/latest
  - 用途：设为最新版本
- DELETE /api/xpert/:id
  - 用途：删除版本记录（每个版本是同一 family 下的独立 Xpert 记录）
- GET /api/xpert/:id/diagram?isDraft=true
  - 用途：生成编排图（blob）
- GET /api/xpert/:id/export?isDraft=… / POST /api/xpert/:id/export/template
  - 用途：导出 DSL / 导出为模板
- GET/PUT /api/xpert/:id/commands
  - 用途：命令配置读写
