【接口信息｜技能仓库与索引】
- 子功能：技能仓库登记与来源策略、仓库索引同步与市场检索、公开仓库保障
- 所属模块：平台插件与技能
- 接口列表：
  - GET|POST /api/skill-repository、PUT|DELETE /api/skill-repository/:id（覆写 CrudController）；GET /api/skill-repository/source-strategies；GET findAvailables、getSelectOptions；POST workspace-public/ensure（ensureWorkspacePublicRepository）；POST :id/upload（uploadSkillPackage，公开仓库整体 zip 直传）
  - GET /api/skill-repository-indexes（findAll：市场分页/搜索）；POST /api/skill-repository-indexes/sync/:repositoryId（body.mode='full'|'incremental'，**soft 参数已废弃被忽略**）
  - 服务入口：SkillRepositoryService.register / updateRepository / deleteRepository / findAllInOrganizationOrTenant / getSourceStrategies / ensureWorkspacePublicRepository / updateLastSyncAt / withWorkspacePublicRepositoryLock；SkillRepositoryIndexService.findMarketplace(query, search) / sync(repositoryId, {mode})
- 来源策略（4 种）：clawhub / github / workspace-public / zip（注册表来自 @xpert-ai/plugin-sdk 的 SkillSourceProviderRegistry）
- 关键约束：**每租户唯一一个系统托管公开仓库**（partial unique `(tenantId) WHERE provider='workspace-public' AND organizationId IS NULL AND deletedAt IS NULL` + pg_advisory_xact_lock 序列化）；workspace-public 与 zip provider **拒绝人工注册/修改**；增量按 skillId 对齐（compareSkillRepositoryIndexFreshness）
- 注意：真实前缀是 `skill-repository-indexes`（AGENTS.md 写的 `/skill-repository/indexes` 是错的）
