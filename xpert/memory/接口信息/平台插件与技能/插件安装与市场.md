【接口信息｜插件安装与市场】
- 子功能：插件安装（code/npm/archive）、卸载/升级/刷新、实例可见性、市场来源与平台注册表
- 所属模块：平台插件与技能
- 接口列表：
  - GET /api/plugin → 列出当前作用域可见插件（IPluginDescriptor[]：level、canUninstall、canUpdate、loadStatus、effectiveInCurrentScope、scopeRelation、componentSummary）
  - POST /api/plugin → 安装（body IPluginInstallInput{pluginName, version?, source?, config?, sourceConfig?}，source 缺省 marketplace）
  - GET /api/plugin/:name/components → **只读**组件清单（写操作的 componentKey 来源）
  - POST /api/plugin/archive（multipart file，**硬上限 100MB**）、POST /api/plugin/refresh（code 源重新 stage/加载）、POST /api/plugin/update、DELETE /api/plugin/uninstall（body {names[], organizationId?, scopeKey?}）
  - GET|POST|PUT|DELETE /api/plugin/marketplace/*（列表、public、sources CRUD、sources/refresh、registry CRUD、detail、:name、assets/icon；**仅 /public 为 @Public**；来源写需 SuperAdmin）
  - GET|POST /api/system/setup/plugins（TenantPermissionGuard + RoleGuard SUPER_ADMIN；含 /catalog；启动返回 202 Accepted）
  - 服务入口：PluginManagementService.installPlugin(body, options{allowPackageDir?, deferActivation?, requiredLevel?}) / installArchivePlugin / refreshCodePlugin / uninstallByNamesWithGuard / findLoadedPlugin / readLoadedPluginBundleComponents；PluginInstanceService.upsert/deactivate/uninstall/removePlugins/findVisibleInOrganization/findSystemLevelRegistration/findTenantLevelOwner；PluginMarketplaceService.listMarketplace/getMarketplacePluginDetail/listSources/createSource/refreshSource(s)；requiresPluginRestart(policy, level, op)
- 关键错误码：server:Error.PluginNamesRequired / PluginPackageNameRequired / PluginSystemLevelInstallForbidden / PluginTenantLevelInstallForbidden / PluginProcessLevelConflict / PluginTenantLevelAlreadyOwned / PluginRuntimePolicyChanged / SetupPlugin*
