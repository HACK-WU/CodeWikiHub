【接口信息｜技能包】
- 子功能：技能包安装（仓库/GitHub/直连）、工作区创作与文件读写、上传下载、分享与公开仓库
- 所属模块：平台插件与技能
- 接口列表：
  - GET /api/skill-package → getAllByWorkspace；POST installSkillPackage / installSkillPackageInWorkspace / uninstallSkillPackage / uninstallSkillPackageInWorkspace / uploadSkillPackage / installRepositorySkillPackages / installGithubSkillPackages / shareSkillPackage
  - 文件级：GET files / read、POST upload / save、DELETE delete、GET download（zip 流式）
  - 服务入口：SkillPackageService.installSkillPackage(workspaceId,indexId) / installRepositorySkillPackages / installGithubSkillPackages / installDirectGithubSkillPackage / uninstallSkillPackage(InWorkspace) / uploadSkillPackagesFromFile(workspaceId, file) / createWorkspaceSkillPackage / saveWorkspaceSkillMarkdown / save|read|delete|uploadSkillPackageFile / getSkillPackageFiles / getSkillPackageRootDownload|FileDownload / shareSkillPackage(workspaceId, id, input{displayName, description, tags?, license?, version?}) / syncTemplateSkillBundle(workspaceId, input, options?) / syncPluginSkillBundle(workspaceId, input{pluginName, componentKey, bundleRootPath, metadata?}, options?)
- 关键约束：写操作统一过 `WorkspaceAuthoringGuard`；**share 仅允许 skillIndexId 为空的工作区自建技能**（否则 400 Only workspace uploaded skills can be shared）；uploadSkillPackagesFromFile 缺文件 400 A valid zip file is required，**无显式体积上限**；**插件侧 bundle 的 sharedSkillId 由服务内部拼装**为 `plugin:<pluginName>:skill:<componentKey>`，调用方不要传
