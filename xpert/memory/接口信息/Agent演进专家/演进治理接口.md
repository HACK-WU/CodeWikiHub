【接口信息｜演进治理接口】
- 子功能：仪表盘与目标同步、能力版本 / 版本束 / 指针只读面、学习事件 / 诊断 / 聚类、提案 / 候选 / 数据集、评估与审批、部署阶梯与指针切换、一次性金丝雀覆盖、作业账本、观测 / 审计 / 经验、能力执行解析与一致性夹具
- 所属模块：Agent 演进专家（主控制器 `AgentEvolutionController`，空前缀，**39 条**；真实前缀 `/api/agent-evolution`）
- 接口列表（分组；读 = `EVOLUTION_VIEW｜XPERT_EDIT` 或语义，写 = `EVOLUTION_MANAGE`）：
  - 仪表盘与目标：GET `/dashboard`（store 直通、实测 **14 键**）、GET `/targets`、POST `/targets/synchronize`（写）
  - 版本与指针（只读）：GET `/capability-versions`、`/capability-bundles`、`/active-pointers`
  - 学习信号：GET `/learning-events`、PATCH `/learning-events/:eventId/review`（写）、GET `/diagnoses`、GET `/clusters`、POST `/diagnoses`（写，**只诊断不写提案**）
  - 提案与候选：GET/POST `/proposals`（POST 需 `requestId` 幂等）、GET/POST `/candidates`、POST `/candidates/:candidateId/approvals`
  - 数据集与评估：GET/POST `/datasets`、GET/POST `/evaluations`（POST **返回 `EvolutionJob` 不是评估结果**）
  - 发布与部署：GET `/releases`、`/deployments`；POST `/release-packages`；POST `/releases/:id/{install,shadow,canary,rollback}`（**入队**）、`{pause,activate}`（**同步**）；GET/POST `/releases/:releasePackageId/canary-test-overrides`
  - 账本与回流：GET `/jobs/:jobId`（未命中回 `null`/200）、GET `/runtime-observations`、`/audit-events`、`/experiences`、POST `/experiences`
  - 运行时与夹具：POST `/capability-executions/resolve`、POST `/simulations/conformance`、POST `/examples/conformance-field-mapping/run`（后两条生产 **404 门禁**）
- 关键约束：分页统一 `normalizeQuery`（`page` 1 / `pageSize` 20、上限 200；`search` 截断 200；`sort ∈ createdAt|updatedAt|status`；`order` 仅 `ASC` 否则 `DESC`）；上下文 `requestScope()`（租户＋组织）与 `commandContext()`（追加 `actorId/actorRole/actorRoleName/approvalAuthority/actorType:'human'`）
- 主要错误码：400（`change_not_found`/`agent_proposal_risk_forbidden`/`candidate_snapshot_mismatch`/`invalid_strategy_submission`…，统一经 `changeError`）；404 production pointer 缺失与夹具门禁；503 `Managed Queue is unavailable`
