【接口信息｜文档与摄取】\n- 子功能：文档 CRUD 与批量、上传与预览、切片读写、摄取控制与预估、网页抓取、原文件下载、问题生成\n- 所属模块：知识库专家\n- 接口列表（前缀 `/api/knowledge-document`，**无声明式守卫**，靠 service 断言）：\n  - `GET /`（**强制 `knowledgebaseId`**，过滤系统托管文档）・`GET /status?ids=`（只回 id/status/progress/processMsg）・`GET /:id`・`GET /getCount`・`GET /pagination`・`GET /my`\n  - `POST /`（校验原文件归属）・`POST /bulk`（`?process=true` 自动启动处理）・`PUT /bulk`・`DELETE /bulk`（后两者需版本号，冲突 409）\n  - 摄取：`POST /process`（`ids[]` + `mode ∈ {full, rechunk}`）・`DELETE /:id/job`（停止任务 → 置 cancel）・`GET /:id/reprocess-capabilities`（`rechunk.available/reason`）・`POST /estimate`、`POST /estimate-table`（预估不落库）\n  - 网页：`GET|POST /web/:type/options` 与 `/web/:type/load`（集成必须属本组织或本人创建）\n  - 文件：`GET /:id/original-file/download|preview`（Range 越界 416）・`POST /original-files/download`（zip，无文件 400）・`GET /:id/original-file/head`・分析预览族（`/:id/analysis-preview` + `/pages/:page` + `/pages/:page/raw` + `/assets/:assetId`）\n  - 切片：`GET|POST|PUT|DELETE /chunks` 族 + `DELETE /:id/pages/:page`\n  - `DELETE /:id/soft`（当前语义受限）・`PUT /:id/recover`・`POST /:id/move`・`GET /folder-child-counts`\n  - 问题生成：`GET /:documentId/chunk/:chunkId/questions`・`POST …/regenerate`・`DELETE …/:questionId`（`KnowledgeQuestionGenerationController`）\n- 关键约束：列表必须带 `knowledgebaseId`；切片与文件族共享知识库卷；`rechunk` 依赖 transform 快照（不可用时报 `TransformSnapshotUnavailableError`，**不静默转 full**）
