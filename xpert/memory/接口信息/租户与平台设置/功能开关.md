【接口信息｜功能开关】
- 子功能：功能开关定义与切换
- 所属模块：租户与平台设置
- 接口列表：
  - POST /api/feature/upgrade → FeatureController.upgrade @ packages/server/src/feature/feature.controller.ts：同步开关定义（seed，破坏性去重）
  - GET /api/feature/toggle/definition → FeatureToggleController.definitions @ packages/server/src/feature/feature-toggle.controller.ts：开关定义（代码侧字面量，不含数据库 id）
  - GET /api/feature/toggle/parent → FeatureToggleController.parentFeatures @ 同上：顶级开关（已过滤退役 code）
  - GET /api/feature/toggle → FeatureToggleController.findAll @ 同上：开关数据库行（含 id，写开关的 featureId 来源）
  - GET /api/feature/toggle/organizations → FeatureToggleController.findOrganizations @ 同上：组织维度开关状态（需 ALL_ORG_VIEW）
  - POST /api/feature/toggle → FeatureToggleController.enabledDisabledFeature @ 同上：批量启停（body 数组 {featureId,isEnabled,organizationId?}；organizationId 缺省=租户级；组织级切换 FEATURE_MEMBERSHIP_PURCHASE 返回 400）
