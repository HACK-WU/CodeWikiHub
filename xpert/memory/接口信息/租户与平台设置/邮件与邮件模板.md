【接口信息｜邮件与邮件模板】
- 子功能：邮件发送记录与邮件模板管理
- 所属模块：租户与平台设置
- 接口列表：
  - GET /api/email → EmailController.findAll @ packages/server/src/email/email.controller.ts：已发邮件查询（分页/关系）
  - PUT /api/email/:id → 同上：更新/归档发送记录
  - GET /api/email-template → EmailTemplateController.findAll @ packages/server/src/email-template/email-template.controller.ts：模板列表（含全局默认行 tenantId+organizationId 均为空）
  - GET /api/email-template/count、/pagination → 同上：统计与分页
  - GET /api/email-template/template → 同上：单模板查询（FindEmailTemplateQuery）
  - POST /api/email-template/template/preview → 同上：预览（body {data} 为 MJML 或 Handlebars 文本）
  - POST /api/email-template/template/save → 同上：保存模板（body {data} 为 IEmailTemplateSaveInput）
  - PUT /api/email-template/:id、DELETE /api/email-template/:id → 同上：更新/删除（全局默认模板先命中 404；跨租户非空 tenantId 返回 403）
