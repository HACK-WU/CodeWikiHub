【接口信息｜租户生命周期】
- 子功能：租户生命周期
- 所属模块：租户与平台设置
- 接口列表：
  - GET /api/tenant → TenantController.findAll @ packages/server/src/tenant/tenant.controller.ts：查当前上下文租户（SUPER_ADMIN）
  - POST /api/tenant → TenantController.create @ 同上：创建租户并执行 onboarding 全链路（调用者需尚无 tenant/role，否则 400）
  - POST /api/tenant/onboard → TenantController.onboardDefault @ 同上：首租户自举（Public，仅全库无租户时可用）
  - GET /api/tenant/onboard → TenantController.getOnboardEntity @ 同上：匿名解析租户（子域命中，否则回退默认租户）
  - GET /api/tenant/:id、PUT /api/tenant/:id、DELETE /api/tenant/:id → 同上：详情/改名（subdomain 空串跳过赋值）/删除（级联），id 非当前租户返回 403
  - GET /api/tenant/count、GET /api/tenant/pagination → 同上：显式返回 405
