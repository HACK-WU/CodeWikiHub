【接口信息｜会员与积分】
- 子功能：积分账本、会员计划与周期、积分调整、资格与配额判定
- 所属模块：模型访问与计费
- 接口列表：
  - GET /api/membership/me、me/overview、me/periods、me/usage、me/usage-summary、POST me/details（MEMBERSHIP_USE）
  - GET|POST /api/membership/plans、PATCH plans/:id、POST plans/:id/reassign|archive、DELETE plans/:id（MEMBERSHIP_EDIT）
  - POST /api/membership/admin/users/:userId/{assign,adjust-points,adjust-personal-points,renew,pause,resume,revoke}（MEMBERSHIP_EDIT）；GET /api/membership/admin/users 与 admin/users/:userId/{scope-memberships,personal-points,audit,periods}（管理端读）
  - 服务入口：MembershipService.recordUsage / recordGatewayUsage（事务 + sourceReference/gatewayRequestId 幂等）/ adjustUserPoints / adjustPersonalPoints / isMembershipPlanEnabled / findModelAccess / assertCanUse / hasConsumableBalance / assertRateLimits / processDueMembershipPeriods / settleDueMembershipPeriods / renewMembership / 退款 reserve+finalizeFutureMembershipPeriods
  - 后台：@Cron('0 * * * * *') 周期结算（Redis 锁 scheduler:membership-period-settlement）+ Bull 队列 MEMBERSHIP_MAINTENANCE_QUEUE（回填）；并发控制为 **9 处 PG advisory 事务锁** + 调度侧 1 个 Redis 锁
- 幂等底线：IDX_membership_ledger_source_reference(tenantId, sourceReference) 与 UQ_membership_ledger_model_usage_request_metric_revision —— **禁止绕过 Service 直写账本**
