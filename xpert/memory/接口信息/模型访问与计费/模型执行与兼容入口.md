【接口信息｜模型执行与兼容入口】
- 子功能：execution grant 签发与校验、执行准入预占、OpenAI 兼容与 native 协议、本人查询与撤销
- 所属模块：模型访问与计费
- 接口列表：
  - POST /api/model-execution/openai/v1/models、/chat/completions（@Public，execution credential）：models 含虚拟模型 assistant-default；chat/completions 仅 text + client tools，image_url → BridgeUnsupported；支持 SSE 与中断
  - POST /api/model-execution/openai/v1/responses、/api/model-execution/anthropic/v1/messages（@Public，native；默认关闭需 catalog 与策略双声明 protocols）：store:false、拒 background/服务端会话、响应上限 16MB
  - POST /api/model-execution/revoke-mine：批量撤销本人 pending/active 授权
  - GET /api/model-execution/call-options、/calls：本人可选模型与调用分页（无 @Permissions，靠拒绝 API principal + 租户/组织/用户三重相等）
  - /api/model-execution/admin/*（MODEL_GATEWAY_MANAGE）：pending、calls/:id/reconcile、calls/:id/retry-delivery、policy（GET/PUT）
  - 服务入口：ModelExecutionGrantService.issue（返回明文 secret、库内只存 hash）/ authenticate / validate / revalidate / activate / renew / revoke；ModelExecutionAdmissionService.begin（租户+付款人串行化+预占）/ dispatch；ModelExecutionMeteringService.finish（先落 usageFact 再投递，按 attemptId 幂等）
- 关键约束：错误体 {"error":{"message","type","code":"model_execution_failed"}}；429 → type=rate_limit_error
