【接口信息｜模型网关】
- 子功能：对外模型发布（publication）、网关 API key、限流、调用留存与结算重试
- 所属模块：模型访问与计费
- 接口列表：
  - /api/openai/v1/models、/chat/completions（@Public + API key）：网关侧 OpenAI 兼容入口（publication 语义）
  - /api/model-gateway/*：catalog（外部版本目录）、requests*/grants/my（转发 ModelAccess，channel=ExternalApi）、keys（创建/吊销/查询）、calls/my；admin：settings（GET/PUT）、admin/keys、admin/calls、admin/calls/:id/body（MODEL_GATEWAY_MANAGE；body 为唯一解密出口）
  - 服务入口：ModelGatewayService.authenticate / createKey / revokeMyKey / startCall（窗口并发+速率检查 + lockedUser 悲观锁）/ finishCall / recordSettlementFailure / retryPendingSettlements / getSettings / updateSettings
  - 限流：GatewayAdmissionPolicy.getAdmissionLimits(tenantId) 读 TenantSetting 的 MODEL_GATEWAY_REQUESTS_PER_MINUTE_SETTING / MODEL_GATEWAY_MAX_CONCURRENT_REQUESTS_SETTING；超限抛 ModelGatewayRequestLimitException（openAICode='rate_limit_exceeded'、retryAfterSeconds）
  - 5 个 @Interval：结算重试、body 清理、调用留存清理、key 过期、stale call 失败化
- 关键不变量（源码首行注释）：**client scope headers do not select the gateway's tenant or organization** —— 先用 API key scope 解析访问，再在 publication scope 执行
