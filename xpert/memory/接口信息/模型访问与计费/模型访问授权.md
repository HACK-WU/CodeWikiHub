【接口信息｜模型访问授权】
- 子功能：模型可见性、访问申请与审批、授权台账生命周期
- 所属模块：模型访问与计费
- 接口列表：
  - /api/model-access：catalog（可见模型目录）、requests*（申请/撤回/审批/驳回）、grants/my（我的授权）
  - 服务入口：ModelAccessService.getCatalog / resolveModelAccess / canUseCatalogModel(s) / assertCanUseModel / createRequest / approveRequest / rejectRequest / extendGrant / revokeGrant / processDueGrants / reconcileLifecycleBatch / writeEvent
  - 自动/后台：@Cron('0 * * * * *') 生命周期协调（Redis 锁 scheduler:model-access-lifecycle + cursor model-access:lifecycle-cursor:v1）；ensureAutomaticPublications（ExternalApi 渠道审批时自动建 publication）
- 关键约束：**self-audit 阻断**——createRequest 先调 assertRequesterIsNotManager，管理者（COPILOT_EDIT/MEMBERSHIP_EDIT/MODEL_ACCESS_REQUEST_EDIT）申请个人模型访问直接 403；审批迁移全部记入 model_access_event（idempotencyKey 唯一）
