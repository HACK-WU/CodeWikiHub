- 子功能：项目内任务（CRUD/步骤/批量/重排）、任务图与执行目标解析、计划族（plan→milestone / plan→sprint→swimlane）、派发与验收决策的命令/工具面、独立任务 CRUD 与生命周期、调度视图/便签/自动任务/模板、run-as 提案确认流
- 所属模块：项目与任务协作专家
- 接口列表（前缀 `/api/xpert-project`，任务与计划面；规划控制器 23 条经 `XpertProjectController extends XpertProjectPlanningController` 生效，任务图 3 条）：`GET|POST /:id/tasks`・`GET /:id/tasks/:taskId`、`/:id/tasks/:taskId/relations`・`PUT /:id/tasks/order`、`/:id/tasks/batch`、`/:id/tasks/:taskId`・`POST /:id/tasks/:taskId/conversations`・`POST|PUT /:id/tasks/:taskId/executions[/:executionId]`・`GET|POST /:id/plans`、`PUT|DELETE /:id/plans/:planId`・`POST|PUT|DELETE /:id/plans/:planId/milestones[/:milestoneId]`・`GET|POST /:id/plans/:planId/sprints`、`PUT /:id/sprints/:sprintId`・`GET|POST /:id/sprints/:sprintId/swimlanes`、`PUT /:id/sprints/:sprintId/swimlanes/:swimlaneId`・`GET|PUT /:id/task-graph`（图变更**必须带 `expectedRevision`**）・`GET /:id/task-executions/:executionId/target`

- 接口列表（前缀 `/api/business-area`，相邻字典域 5 条）：`GET ''`、`GET /:id`（读无守卫）・`POST ''`、`PUT /:id`、`DELETE /:id`（202；`RoleGuard` + `@Roles(SUPER_ADMIN, ADMIN)`）
- 守卫口径（四层）：项目域走类级 `@Public()`（只跳过全局 JWT 守卫，**≠放行**）+ `XpertProjectAuthGuard → XpertProjectFeatureGuard → XpertProjectPermissionGuard` + `@ProjectPermission(VIEW|EDIT)`；`ProjectTaskGraphController` 为**类级** `XpertProjectGuard`，规划继承方法自带方法级 `@UseGuards(XpertProjectGuard)`；`/api/xpert-task/*` 与 business-area 读端点无守卫，服务层断言是唯一边界（`assertHttpMutationAccess`/`findHttpAccessible`），**绕 service 直查仓库即越权**
- 关键约束：任务写路径统一骨架 `assertOrdinaryTaskInput → lockProject(pessimistic_write) → assertOrdinaryTask → assertBusinessStatus`；`PUT /:id/task-graph` 的 `projectTaskPlanSchema` 为 `.strict()`（多余字段 400）；`unarchive` 落 `PAUSED` 且不排程、`recover` 不重建 job（须再显式 `PUT /:id/schedule`）；派发/决策无独立 HTTP 端点，走命令与工具面（`DispatchProjectTaskCommand`/`DecideProjectTaskCommand`、`project_dispatch_task`/`project_decide_task`）
- 错误语义：`projectTaskRuntimeError` 规则 `Scope→403`、`NotFound→404`、`Invalid→400`，**其余一律 409**（`Conflict`/`Busy`/`Dependencies`/`State`/`Owned`/`Evidence`/`DecisionRequired`）；404 `Project task not found`；400 `ProjectTaskRunAsProposalMissing|Changed`、403 `ProjectTaskRunAsProposalTargetOnly`
