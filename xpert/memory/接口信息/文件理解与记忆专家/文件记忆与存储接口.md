【接口信息｜文件记忆与存储接口】
- 子功能：记忆卷的 Dream 触发/配置/运行台账/取消、对象存储登记与 URL 抓取与删除、记忆文件 CRUD（xpert 域复用）、非 HTTP 的工具与运行时能力面
- 所属模块：文件理解与记忆专家（子专家：文件记忆与存储）
- 接口列表（一）`FileMemoryController` 真实前缀 `/api/xpert/:id/memory`（`@Controller('xpert/:id/memory')`，`:id` 走 `UUIDValidationPipe`，类级 `@UseGuards(XpertGuard)`），共 **6 条**：
  - POST `/dream`（`triggerDream(xpert,{reason})`，`reason ∈ manual|scheduled|signal_threshold`；同 scope 已有 pending 运行直接返回 `{...pending, coalesced:true}`；gate 未过**不报错**，落 `status='skipped'` 并写 `output/gate.json`）
  - GET `/dream/config`（磁盘 `config.json` ＋ env 派生 `defaults`）、PUT `/dream/config`（归一化 `dreamerXpertId`/`dreamerAgentKey`/`gate{enabled,minIntervalMinutes,minNewOrUpdatedMemories,minConversationCount}` 后写回并回读）
  - GET `/dream/runs`（扫 `.dream/runs/*`，按 `requestedAt` 倒序；目录缺失返回 `[]`）、GET `/dream/runs/:runId`（summary ＋ preflight ＋ report ＋ validation ＋ artifacts）、POST `/dream/runs/:runId/cancel`（仅 `queued` 可取消，其他状态原样返回）
- 接口列表（二）`StorageFileController` 真实前缀 `/api/storage-file`（`RouterModule{path:'/storage-file'}`，**无控制器守卫、无 `@Public()`**，只受全局 `AuthGuard` ＋ service 断言），共 **3 条**：
  - POST `/api/storage-file`（`FileInterceptor('file')` → `UploadFileCommand`，target `{kind:'storage',directory:'files',prefix:'files'}`）、POST `/api/storage-file/url`（axios `responseType:'arraybuffer'` 拉取后 `provider.putFile`，`originalname` 按 latin1→utf8 纠正）、DELETE `/api/storage-file/:id`（`UUIDValidationPipe`）
- 接口列表（三）邻域同源入口（记忆文件 CRUD 在 `XpertController`，`/api/xpert`）：GET `:id/memory/files`、GET/PUT `:id/memory/file`、POST `:id/memory/file/upload`、DELETE `:id/memory/file`（均 `XpertGuard`）—— **校验与路径语义在本域 `FileMemoryFacade`/`paths.ts`**
- 接口列表（四）非 HTTP 面（本域主要消费面）：`XpertFileMemoryMiddleware` 挂 `memory_search`/`memory_get`/`memory_write`；`FileRuntimeService`（`@RuntimeCapabilityProvider(FileRuntimeCapability)`）实现 `AgentMiddlewareFileApi.resolveFile` 与 `createScopedApi({conversationId})`；`workspace-files-runtime-capability` 的状态/重试/检索/引用校验五条查询
- 关键约束：`XpertGuard` 判定 owner（`xpert.createdById === user.id`）或 workspace 可访问，失败 `ForbiddenException('Access denied')`，命中后缓存 5 分钟（`userXperts:<tenantId>:<userId>_<xpertId>`）；`deleteStorageFile` 是 **catch-all 403**（任何异常含找不到行都转 `ForbiddenException`，403 与 404 语义不可分）；跨域删除必须走 `deleteAuthorizedStorageFile` 比对 `tenantId`/`organizationId`；`createStorageFile` 无鉴权，仅归一化 provider（大写，缺省回落 `LOCAL`）
- 关键约束（重试门禁差异）：`workspace-files-runtime-capability.retryFileUnderstanding` 是**唯一带状态门禁**的重试入口（非 `failed` 且 `vectorIndexStatus` 非 `failed/unavailable` → 400），与 HTTP `parse/retry` 的无门禁行为不同
- 主要错误码：403（记忆全套 / 存储删除）；400 `Failed to upload storage file` / `Failed to download and store file from URL: <msg>` / `Only failed or unavailable file understanding can be retried`；PUT config 缺项文案 `FileMemory Dreamer config requires dreamerXpertId and dreamerAgentKey.`
