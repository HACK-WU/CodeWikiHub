【接口信息｜探索广场接口】
- 子功能：广场目录与访问申请、技能市场（索引/仓库/官方位/安装/分享）、应用详情与受控初始化、模板目录与详情、作用域切换
- 所属模块：探索广场专家（前端专题）
- 接口列表：
  - 广场目录：`GET /api/xpert-marketplace`（findMarketplace，返回 items + businessAreas + total + reviewableCount；支持 search/businessAreaIds/businessCategories/capabilityTags/status/sort/skip/take）、`GET /api/xpert-marketplace/:id`（getMarketplaceItem）；基址 `API_XPERT_MARKETPLACE`
  - 访问申请：`POST /api/xpert-marketplace/:id/access-requests`（requestAccess，{reason}）；`GET /api/xpert-access-requests/my`、`GET /api/xpert-access-requests/reviewable`、`PUT /api/xpert-access-requests/:id/approve|reject`（`{response}`；基址 `API_XPERT_ACCESS_REQUESTS`）——**服务端归属后端「Assistant 定义与运行时专家」**（xpert_access_request 面）
  - 技能市场：`GET /api/skill-repository-indexes`（getMarketplace，$where/$take/$skip/search）、`GET /api/skill-repository/availables|/source-strategies|/select-options`、`GET /api/xpert-template/skills-market`（getSkillsMarket → ISkillMarketConfig）、`POST /api/skill-package/install`、`GET /api/skill-package/by-workspace/:workspaceId`、`POST /api/skill-package/workspace/:workspaceId/:id/share`——**服务端归属后端「平台插件与技能专家」**
  - 应用（插件 App）：`GET /api/plugin-applications/status|/catalog|/detail?pluginName=&appName=`、`POST /api/plugin-applications/initialize|/prepare|/bind-toolset|/discard-configuration`（归属「平台插件与技能专家」）；运行时 MCP 组件 `GET /api/plugin/:name/components`
  - 模板：`GET /api/xpert-template`、`/catalog`、`/:id/overview`、`/:id/setup`（readiness，仅组织态）——归属「Assistant 定义与运行时专家」模板面
  - 模板向导与作用域切换：**无独立 HTTP**——`createAgentTemplateWizardData` 装配 → `XpertNewBlankComponent` 模态 → 结果回跳 `/xpert/x/:id`（向导本体归 Xpert 工作台专家）；作用域切换经 `ExploreScopeService.choose()` → `ScopeService.switchToTenant/switchToOrganization`
- 前端门面契约：本域无统一门面——页面组件经 6 个 @core 服务调用（XpertMarketplaceService / PluginApplicationService / XpertTemplateService / SkillPackageService / SkillRepositoryService / SkillRepositoryIndexService）；作用域单点为 `ExploreScopeService`（activeScope / isTenant / organizationName / key / choose）
- 关键约束：`accessStatus` / `canReview` / `reviewableCount` / `initializationAccess` / `preflight` 全由服务端裁决，前端只分级展示、不做权限推断；分享仅限工作区自建技能（`isLocalSkill = !item.skillIndex`，快照语义）；`choose(true)` 只允许组织，取消返回 false
- 逐端点明细：见 .module-experts/前端专题/探索广场专家/implementation/01-架构.md 与 C1-能力契约.md
