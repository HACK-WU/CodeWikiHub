【接口信息｜投递队列与运行时消息】
- 子功能：异步投递（4 队列/4 消费者/路由）、取消与死信、运行时消息 outbox→transport→inbox→续跑、回执读取与 redrive
- 所属模块：对话与会话
- 接口列表：
  - 队列（Bull）：`handoff`、`handoff:realtime`、`handoff:batch`、`handoff:integration`；job 名 `dispatch`；默认 maxAttempts=3；并发 env `XPERT_HANDOFF_DISPATCHER_CONCURRENCY`（基座 20）与 `XPERT_HANDOFF_CONCURRENCY_{REALTIME,BATCH,INTEGRATION}`；等待上限 `XPERT_HANDOFF_PENDING_TIMEOUT_MS`（默认 120000）
  - 服务入口：HandoffQueueService.enqueue / enqueueMany / enqueueAndWait（`@RequirePermissionOperation('handoff','enqueue'|'wait')`；**enqueueAndWait 仅本进程回调**）；HandoffRouteResolver.resolve（header `handoffQueue` > typePolicy > 匹配规则 > defaultQueue）；StopHandoffMessageCommand（messageIds/executionIds → 扫描 → 移除 job / Redis pub/sub `ai:handoff:cancel` → `dead(canceled:…)`）；HandoffDeadService
  - 运行时消息：appendRuntimeDelivery（**与 Invocation CAS 同事务**）→ `agent_runtime_delivery`（lease，unique(messageId)）→ transport enqueue → RuntimeMessageProcessor → RuntimeMessageInboxService.receive/lockInbox/claimWait（`agent_runtime_inbox` unique(tenant,org,ownerId,consumptionKey)；phase = reserved|started）→ runtime-message-continuation 续跑
  - HTTP（**物理注册在 agent-invocation.module.ts**）：`GET /api/agent-invocations/:id/delivery`（回执 owner 作用域）、`POST /api/agent-invocations/:id/delivery/redrive`（body 必须 `{}`；**不改 Invocation、不清 user stop**）
- 关键约束：**不是 exactly-once**（可重试投递 + 幂等消费）；`consumer_outcome_unknown` 不得自动重放；滚动升级**先部署消费者再部署生产者**
