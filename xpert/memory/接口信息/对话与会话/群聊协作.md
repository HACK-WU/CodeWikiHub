【接口信息｜群聊协作】
- 子功能：群成员、发送/提交/发布、成员可见投影、偏好、HITL 交互、群工作台与项目绑定
- 所属模块：对话与会话
- 接口列表（HTTP 适配器全部在 `ai/groups/**`，注册在 AIModule）：
  - `/api/ai/groups/*`：群列表/创建/成员（`GroupsController`）、`:groupId/members/:participantId/composer`（`GroupComposerController`）、`:groupId/project`（`GroupProjectController`）、`:groupId/workbench`（`GroupWorkbenchContextController`/`GroupViewsController`）、`:groupId/workbench/workspace-files/view-sessions`（`GroupViewFilesController`）；守卫 `GroupScopeGuard`/`GroupWorkbenchGuard`
  - 服务入口：GroupMessagesService.send/submit/publish/snapshot/preferences；GroupOutboxService.reconcile/flush/route/deliver；GroupAccessService.authorize；GroupMembersService；GroupInteractionsService（HITL claim）；GroupRuntimeService（PrepareGroupChatHandler/FinishGroupChatHandler）；GroupStreamService（SSE）
  - 成员模型：`chat_group_participant` 每人持 runtimeConversationId/runtimeThreadId（群内 Agent 成员各持运行时会话/线程）
- 关键约束：`publish` 在事务内锁 `purpose='group'` 会话 + `groupPublicationId` 幂等 + `chat_message_recipient` 收据 fan-out；**`GroupScopeGuard` 对 JWT 用户直接放行（已知缺口）**；群组**按会话 id 绑定、不加载私有 Assistant thread**
