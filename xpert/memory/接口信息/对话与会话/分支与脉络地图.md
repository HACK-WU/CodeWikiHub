【接口信息｜分支与脉络地图】
- 子功能：从历史点分叉会话（写模型）、对话脉络导航（只读视图）
- 所属模块：对话与会话
- 接口列表：
  - 分支：`ConversationBranchService.branch({sourceThreadId, afterMessageId, requestId})`（事务 + 线程行锁 + 复制消息谱系/fileAssets/CopilotCheckpoint + 写 branchSource/forkGraphRevision；**requestId 幂等**）；HTTP 适配器 `ConversationBranchController`（`/api/ai/conversations`）；调用约定：**用 `ConversationBranchCommand`，不要 import 模块**
  - 地图（无 entity、不落表）：`ConversationMapService.read / projectOptions / act`；注册为 `@ViewExtensionProvider('platform.conversation-map')`，slot `AGENT_WORKBENCH_SLOT`，key `topics`（对话脉络）；投影由 `presentation.ts` 的 turnNodes/humanMessageSummary 提供；`scope()` 做 host context 与 RequestContext 三重比对
- 关键约束：分支=写模型（事务/行锁/检查点，写放大换可独立续跑）；地图=只读视图（免迁移、依赖宿主 view-extension 与特性开关）
