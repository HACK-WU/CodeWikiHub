【接口信息｜会话与消息】
- 子功能：会话生命周期、消息写入与授权读取、读状态与未读、消息反馈、主聊天流
- 所属模块：对话与会话
- 接口列表：
  - `/api/chat-conversation/*`：`findMyAllPublic`、`getUnreadByXperts`、`findOneByThreadId`、`findEntryByThreadId`、`findOneById`、`resolveWorkbenchNavigation`、`updateConversation`、`deleteConversation`、`cancelConversation`、`markRead`、`get|set|update|clearGoal`、`getThreadState`、`findByXpert`、文件族（`getAttachments|getFiles|getFile|downloadFile|saveFile|uploadFile|deleteFile`）+ 侧边栏控制器
  - `POST /api/chat`（主聊天流）・`@Sse` 流・`GET synthesize`（SSE 语音合成）・`POST speech-to-text`
  - `GET /api/chat-message/:id/suggested-questions`（先断言会话访问再跑建议问题命令）・`/api/chat-message-feedback/*`（反馈授权 CRUD，走会话 assertAccess）
  - 跨域适配器（**注册在 ai/**，领域归属本域）：`/api/ai/conversations/*`（含 messages/messages search/goal/task-summary/artifacts/workspace files）、`/api/ai/threads/*`（含 run 控制 runStream/joinRunStream/runWait/cancelThreadRun/pauseRun/resumeRun/releaseDisplayPause/getThreadHistory/getThreadUsage）
  - 服务入口：ChatConversationService.create/update/assertAccess(id, 'read'|'contribute'|'manage')/findOneByThreadId/findOneDetail/markRead/getThreadState；ChatMessageService.findOneAuthorized/deleteByIds；ChatMessageFeedbackService.*
- 关键约束：消息 `sequence` 由**会话行锁**分配；`messageEnvelope` 是唯一 provenance/presentation 契约（**不是**授权授予）；`pause` 无 body（受理 ≠ 检查点完成）；`resume` 必带 `{pauseId}`
