【接口信息｜角色与权限】
- 子功能：角色 CRUD、权限点同步、判权注解入口
- 所属模块：身份与权限
- 接口列表：
  - GET|POST|PUT|DELETE /api/roles*（含 /find、/:id/soft、/:id/recover）→ 角色 CRUD（租户级角色，切换组织不改变角色；系统角色不可改名/不可被改写 isSystem）
  - /api/role-permissions/*（含 /count、/pagination、/my、/:id、/:id/soft、/:id/recover）→ 权限点读写（SUPER_ADMIN 角色的权限行拒绝改删）+ `sync-defaults` 增量对齐默认矩阵
  - 判权入口（非 HTTP）：`@Permissions` + PermissionGuard、`@Roles` + RoleGuard、TenantPermissionGuard / OrganizationPermissionGuard
  - 服务入口：RolePermissionService.checkRolePermission(tenantId, roleId, permissions, includeRole?)——**includeRole=true 限定该角色；默认 false 表示租户内任意角色命中即 true**；多权限点为**或**语义；enabled=false 的行等于不存在
- 已知坑：PermissionGuard 结果缓存 key userPermissions:{tenantId}_{roleId}_{permissions}，TTL **5 分钟**（撤权有窗口）；`@Public()` 只跳过认证不跳过判权；OrganizationPermissionGuard 唯一引用处已被注释
