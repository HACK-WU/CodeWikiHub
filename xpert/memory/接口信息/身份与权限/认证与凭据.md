【接口信息｜认证与凭据】
- 子功能：登录/注册/令牌/密码/邮箱验证/SSO/社交登录/外部身份绑定
- 所属模块：身份与权限
- 接口列表：
  - POST /api/auth/login → AuthController（@Public）：密码登录并签发 access/refresh
  - POST /api/auth/signup（@Public）、POST /api/auth/register（需登录）→ 自助注册 / 代客或受邀注册
  - GET /api/auth/refresh → 刷新令牌（轮换，旧 refresh 立即失效）
  - GET /api/auth/authenticated（@Public）、GET /api/auth/role → 令牌有效性 / 角色断言
  - POST /api/auth/request-password、POST /api/auth/reset-password（均 @Public）→ 申请重置 / 用 token 改密（重置成功顺带标记邮箱已验证）
  - GET /api/auth/verify（@Public）、POST /api/auth/resend-verification → 邮箱验证（2 天有效）/ 重发
  - GET /api/auth/sso/providers（@Public）、POST|GET /api/auth/sso/bind/{challenge,complete,register}（@Public）、/api/auth/sso/bind/current-user/{challenge,complete}（需登录）→ SSO 发现与绑定编排（以 ticket 串起）
  - GET|DELETE /api/account-binding/me/:provider → 读/解绑当前用户在某 provider 的绑定
  - 无 HTTP 入口：API key / secret token 通过请求头 x-api-key / x-client-secret（或 Bearer cs-x-…）校验；actor token 为服务内部铸造（无表、无端点）
- 备注：/api/auth/custom/* 不存在（前端单测自定义 baseEndpoint 的误记，已裁决）
