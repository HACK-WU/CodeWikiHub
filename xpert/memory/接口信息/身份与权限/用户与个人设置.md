【接口信息｜用户与个人设置】
- 子功能：当前用户读取、资料与偏好、按邮箱查用户、密码修改、删除
- 所属模块：身份与权限
- 接口列表：
  - GET /api/user/me → 读当前用户视图（@Public + ApiKeyOrClientSecretAuthGuard；data.relations 控制装配；默认排除通信账号）
  - PUT /api/user/me → 改自己资料（非本人需 ALL_ORG_EDIT / SUPER_ADMIN_EDIT）
  - GET /api/user/email/:email → 按邮箱查用户（TenantPermissionGuard + ALL_ORG_VIEW/EDIT；大小写不敏感，未命中返回空）
  - POST /api/user/:id/password → 改密（本人校验旧密码；管理路径需 ALL_ORG_EDIT 或 SUPER_ADMIN_EDIT）
  - DELETE /api/user/:id → 软删（走 deleteWithGuards：禁止删自己、技术用户、最后一个租户管理员）
  - 服务入口（跨模块）：UserService.findCurrentUser / findCurrentUserBootstrapOrganizations / findCurrentUserFeatureContext / getUserByEmail / createOne / updateProfile / changePassword / isActiveMemberOfOrganization / deleteWithGuards / ensureCommunicationUser
