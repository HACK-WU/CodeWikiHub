【接口信息｜组织与成员】
- 子功能：组织 CRUD、成员关系（user_organization）、默认组织与默认工作区、组织语言
- 所属模块：身份与权限
- 接口列表：
  - GET|POST|PUT|DELETE /api/organization* → 组织主数据与公开资料链接（删除前拒绝「存在待处理邀请或用户组」）
  - POST /api/user-organization → 建成员关系（必填 userId+organizationId；缺任一 400；自动维护默认/活跃不变量）
  - PUT /api/user-organization/:id → 改成员关系（置默认会降级其它默认；停用最后一条活跃成员被拒）
  - DELETE /api/user-organization/:id → 删成员关系（最后一条活跃成员须显式放行）
  - PUT /api/user-organization/me/preferences/entry-guides/:guide/auto-shown → 记录新手引导已展示
  - /api/organization-languages* → 组织语言配置
  - 服务入口（跨模块）：UserOrganizationService.ensureMembership / ensureMembershipInTransaction / addUserToOrganization / findCurrentUserMembership / ensureUniqueDefault / ensureActiveMembershipRemains / pickNextDefaultMembership / setCurrentUserDefaultWorkspaceId / markCurrentUserEntryGuideAutoShown
