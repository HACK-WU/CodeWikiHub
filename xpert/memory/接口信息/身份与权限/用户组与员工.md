【接口信息｜用户组与员工】
- 子功能：组织内用户组（含平台托管组）与员工档案
- 所属模块：身份与权限
- 接口列表：
  - GET|POST|PUT|DELETE /api/user-groups*（含 /:id/members）→ 用户组 CRUD 与成员维护；限同租户活跃成员；托管元数据（managedBy/managedEntityType/managedEntityId）只由平台侧写入，HTTP 入口会剥离
  - GET /api/employee/user/:userId → 按 userId 找员工（未命中也**不抛 404**；id 非 UUID 400）；继承的 /api/employee 标准 CRUD 仅全局 AuthGuard
  - 服务入口（跨模块）：UserGroupService.findAllByOrganizationId / create / update / updateMembers / validateMemberIds / assertAccessibleOrganizationId / stripManagedMetadata
- 边界（重要）：UserGroup **只给已发布 Xpert 的 canRun，不提升 workspace 的 canRead/canWrite/canManage**；未发布不产生 canRun
