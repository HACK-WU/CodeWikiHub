【接口信息｜邀请】
- 子功能：邀请创建/重发/公开校验/三条接受路径
- 所属模块：身份与权限
- 接口列表：
  - POST /api/invite/emails → InviteController.createBulk（TenantPermissionGuard + PermissionGuard + ORG_INVITE_EDIT）：body emailIds + roleId/organizationId/invitedById/inviteType；越权授予 SUPER_ADMIN → 401；返回 total/ignored
  - GET /api/invite/validate（@Public）：?data={"findInput":{"email","token"}}；验签 + email 匹配 + status=INVITED + 未过期，任一失败 400
  - POST /api/invite/user（@Public）：**body IInviteAcceptInput{inviteId, organization}**（originalUrl 由服务端取 Origin 头）→ 注册（内部建成员关系）→ 邀请置 ACCEPTED
  - POST /api/invite/employee（@Public）：同 IInviteAcceptInput；注册 → ACCEPTED；**不再产出 employee**（文档与实现不一致）
  - POST /api/invite/contact（@Public）：**body IOrganizationContactAcceptInviteInput** → 新租户 → 角色 → 建组织 → 注册 → 联系人/邀请置 ACCEPTED
  - POST /api/invite/resend（ORG_INVITE_EDIT）：重发（失败时错误对象被当作返回值返回）
  - PUT /api/invite/organization-contact/:id、GET /api/invite、DELETE /api/invite/:id
- 已知坑：invite.email 是**全局唯一索引**（跨租户冲突风险）；invite_organization_contact 为 M2M 且有 TODO 建议改 1:1
