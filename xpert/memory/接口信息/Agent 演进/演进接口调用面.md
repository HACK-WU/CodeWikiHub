【接口信息｜Agent 演进接口】
- 子功能：演进治理工作台的读面（dashboard / targets / changes 生命周期投影）与写面（评估、决策、发布、阶段推进、回滚暂停、金丝雀手工测试覆盖）
- 所属模块：Agent 演进专家（前端专题）
- 接口列表：
  - 基址：`API_AGENT_EVOLUTION = API_PREFIX + '/agent-evolution'`（`API_PREFIX = '/api'`，@core/constants/app.constants.ts）；路径 id 一律 `encodeURIComponent(id)`，查询串由 `queryParams()` 生成（跳过 undefined/null/''）
  - 变更源与生命周期（服务端 `lifecycle.controller.ts`）：`GET /changes?pageSize=200`（listLifecycleRecords → lifecycleRecords 源）、`GET /changes/records[?targetId]`（listChanges → 富变更源）、`POST /changes/:id/evaluations`、`POST /changes/:id/decisions`、`POST /changes/:id/publication`
  - 聚合与目标：`GET /dashboard`（17 字段快照）、`GET /targets`、`POST /targets/synchronize`、`GET /baselines/:targetId`（唯一绕门面直取，EvolutionBaselinePanelComponent）、`GET /capability-versions`、`/capability-bundles`、`/active-pointers`
  - 学习/提案/评估/发布：`/learning-events`（GET+PATCH :id/review）、`/diagnoses`、`/clusters`、`/proposals`、`/candidates`（+`POST /candidates/:id/approvals`）、`/datasets`、`/evaluations`、`/releases`、`/release-packages`、`POST /releases/:id/{install,shadow,canary,pause,activate,rollback}`、`GET|POST /releases/:id/canary-test-overrides`、`/deployments`、`/jobs/:jobId`；`POST /examples/conformance-field-mapping/run` 为仅开发/测试夹具
  - 服务端归属：`agent-evolution.controller.ts` 与 `lifecycle.controller.ts`（packages/server-ai/src/agent-evolution），归**后端「Agent 演进专家」——批次 5 未建**，本域只声明调用面
- 前端门面契约：`AgentEvolutionApiService` 是 `API_AGENT_EVOLUTION` 的唯一 HTTP 出口（仅注入 HttpClient，返回 Observable，调用方统一 firstValueFrom）；`AgentEvolutionFacade` 是唯一聚合与写操作入口，由壳组件 `providers: [AgentEvolutionFacade]` 提供（一工作台一实例），组件不得绕过门面直连 API（唯一例外：EvolutionBaselinePanelComponent 按 targetId 直取 getRuleBaseline）
- 关键约束：写操作全部经 `withMutation`（失败收成 `error` 并返回 null，不抛错）；`providerError` 只在 `/changes` + `/changes/records` 失败时置位（静默原文，恢复入口 Retry → `load()`）；`waitForJob` 为 60×1s 等待窗口，超时窗口 ≠ 作业超时
- 逐端点明细：见 .module-experts/前端专题/Agent 演进专家/implementation/01-架构.md 与 C1-能力契约.md
