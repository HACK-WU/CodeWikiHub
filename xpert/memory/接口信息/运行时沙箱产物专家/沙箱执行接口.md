【接口信息｜沙箱执行接口】
- 子功能：会话级沙箱准入与获取、卷文件只读投递（4 条）、文件上传进沙箱、终端执行（SSE）、会话/线程托管服务台账与预览 proxy、WS 交互终端
- 所属模块：运行时·沙箱·产物专家（子专家：沙箱执行）
- 接口列表（真实前缀 `/api/sandbox`，`RouterModule.register([{path:'/sandbox'}])`；类级只有 `@ApiBearerAuth` ＋ `TransformInterceptor`，业务鉴权靠全局 `AuthGuard` ＋ `PluginScopeGuard`）：
  - 卷投递：GET `/volume/project/:projectId/*path`（＋`XpertProjectAccessService.assertCanRead`，`tenant` query 必须等于项目持久化 tenant）、GET `/volume/user/:userId/xpert/:xpertId/*path`（当前用户必须等于 `:userId`）、GET `/volume/xpert/:xpertId/user/:userId/*path`（旧布局兼容）、GET `/volume/*path`（**`@Public()` 匿名**，仅路径黑名单护栏）
  - 上传与执行：POST `/file`（multipart 字段 `file`，经 `UploadFileCommand` 落 `mode:'mounted_workspace'`，返回 `{url,filePath}`）、POST `/terminal`（**`@Post` ＋ `@Sse()` 同挂**，退出码非 0 走流的 error 通道而非 HTTP 错误码）
  - 会话托管服务（7 条）：GET `/conversations/:cid/services`、GET `…/services/:sid`、POST `…/services/start`、GET `…/services/:sid/logs`、POST `…/services/:sid/stop`、POST `…/services/:sid/restart`、POST `…/services/:sid/preview-session`
  - 线程托管服务（7 条）：`threads/:tid/services…` 与会话面一一对应；**线程面无 proxy 路由**
  - 预览 proxy（3 条）：ALL `/conversations/:cid/services/:sid/proxy`、`…/proxy/`、`…/proxy/*path`（`@Public()` ＋ `SandboxPreviewAuthGuard`）
  - WS：`@WebSocketGateway({namespace:'sandbox-terminal', cors:{origin:'*'}})`，4 类客户端消息（`open`/`input`/`resize`/`close`）、5 类服务端事件（`opened`/`output`/`exit`/`error`/`closed`）
- 关键约束：列表端点**绝不创建沙箱**（重启后仍只读既有记录）；预览要求 `transportMode==='http'` 且有 `previewUrl`，cookie path 精确到该 service 的 `/proxy`、TTL 1 小时；WS 每条消息重鉴权（`cs-x-` 前缀走 client-secret，否则 `WsJWTGuard` ＋ `assertWorkbenchPrincipal`），`open` 额外查会话可读，同 `requestId` 重复 open 取消旧请求
- 主要错误码：400 `conversation_not_found`/`provider_unavailable`/`service_start_failed`/`unsupported_provider`/`Invalid sandbox workspace path`；403 `Error.ProjectVolumeCrossTenant`/`Error.UserXpertVolumePrivate`/`Error.ProtectedVolumeAuthenticationRequired`/`Error.ProjectContentGenericWriteForbidden`；404 `service_not_found`；409 `service_name_conflict`；401（预览）`Sandbox preview session is required.`/`is invalid.`；WS 错误码 11 个（`sandbox_disabled`/`unsupported_provider`/`session_not_found`…）
