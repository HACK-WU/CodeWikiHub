【接口信息｜产物与文件访问接口】
- 子功能：产物的登记/版本/分享链接/公开与认证读取/访问审计（管理面 ＋ 公开面）、工作区文件两段式短时授权与内容投递
- 所属模块：运行时·沙箱·产物专家（子专家：产物与文件访问）
- 接口列表（一）artifacts 共 **24 条**（三个控制器各写前缀，**无 UseGuards**，靠全局 `AuthGuard` ＋ 服务层按 `tenantId/organizationId/userId` 作用域查询，越域一律 404 不泄露存在性）：
  - 公开面（`/api/artifacts/share`）：GET `/share/:slug`、GET `/share/:slug/download`、GET `/share/:slug/descriptor`（三条 `@Public()`）；POST `/share-session/:slug`（**非 Public**，写 cookie `xpert_artifact_share_session`，TTL 15 分钟、`path=/artifacts/share`）；DELETE `/share-session`（`@Public()`）
  - 管理面（`/api/artifacts`）：登记与查询 POST `/`、GET `/`、GET `/by-source`；版本 POST `/:artifactId/versions`、GET `/:artifactId/versions`、POST `/:artifactId/versions/ensure`、GET `/:artifactId/versions/:vid/content`、GET `/:idOrSlug`；分享 POST `/:artifactId/links`、POST `/:artifactId/links/signed-preview`、PATCH `links/:idOrSlug/access`、DELETE `links/:idOrSlug`、GET/POST/DELETE `/:artifactId/shares/:shareKey`、GET `/shared-links/:slug/content`；生命周期 PATCH `/:idOrSlug/archive`、DELETE `/:idOrSlug`
- 接口列表（二）workspace-file-access 共 **6 条**（真实前缀 `/api/workspace-files`，`RouterModule.register` ＋ `@Controller()`/`@Controller('content')`）：POST `/view-sessions`、POST `/view-sessions/:sessionId/grants`、GET `/view-sessions/:sessionId/grants/:grantId/content/:fileName`、DELETE `/view-sessions/:sessionId`（四条走全局 `AuthGuard`）；GET `/content/:sessionId/:grantId/:fileName`、HEAD 同路径（**类级 `@Public()` ＋ `WorkspaceFileAccessGuard`**，另做 `assertRequestOrigin`）
- 关键约束：**字节不落表** —— `artifact_version.workspaceFileRef`（json 非空）指向 Workspace Files，读取前重算 `sha256` 复核（不符拒绝并记 `denied`）；响应头固定 `X-Content-Type-Options: nosniff`/`Referrer-Policy: no-referrer`/`Cache-Control: no-store`/`X-Xpert-Artifact-Version`/`X-Xpert-Artifact-SHA256`，`text/html` 额外下发 CSP（`strict`/`interactive` 两档）；工作区文件**客户端不能传路径**，路径由服务端从 grant 的 `reference` 解析（`assertPortableReference` → `resolveWorkspaceVolumeScope` → `volumeClient.resolve`），`fileName` 只参与匹配
- 主要错误码：410 `GoneException`（`Artifact is no longer active`/`…was deleted`/`…link was revoked`/`…link expired`/校验和不一致）；404（作用域不匹配与真不存在共用 `Artifact was not found`/`Artifact version was not found`）；401 `Login is required to access this artifact link`（需要登录时 302 到 `/artifacts/auth/<slug>`）；403 `Download is not allowed for this artifact link`/`Error.WorkspaceFileAccessDenied`；400 `workspaceFileRef is required`/校验和与大小不匹配
