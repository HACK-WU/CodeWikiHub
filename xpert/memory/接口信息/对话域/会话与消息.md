- GET /api/ai/conversations/:id/messages（会话消息，可选 relations）
- GET /api/ai/conversations/:id/messages/search（消息搜索）
- POST /api/chat-conversation/:id/cancel（取消对话）
- /api/chat-message（CRUD 基址；ChatMessageService）
- /api/chat-message-feedback（消息反馈 CRUD；ChatMessageFeedbackService，对话页与 Studio 共用）
