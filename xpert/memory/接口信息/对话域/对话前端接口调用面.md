【接口信息｜对话前端接口调用面】
- 子功能：ClawXpert 对话工作台与会话收发、ChatKit 宿主协议（iframe 双向）、助手绑定/运行时面、公共 ChatKit 页准入、实时通道
- 所属模块：对话前端专家（前端专题）
- 接口列表：
  - 会话（控制面）：GET/POST/PUT/DELETE /api/chat-conversation[/:id] / 列表、详情、新建、软删恢复、/my、/my/sidebar、/:id/sidebar、/by-thread、/entry-by-thread、/:id/state、/:id/cancel、/:id/read-state、/:id/attachments、/:id/files 读写
  - 消息与反馈：GET /api/ai/conversations/:id/messages、POST …/messages/search / 历史与搜索；GET /api/chat-message[/:id/suggested-questions]、GET /api/chat-message-feedback[/my] / 消息基址与反馈
  - 任务与群组：/api/xpert-task 全族（by-ids/total/schedule/capabilities、/:id/{schedule,pause,archive,test,run-as/*}）、GET /api/ai/conversations/:id/task-summary/fileChanges、GET·PATCH /api/ai/groups[/:id[/preferences]]
  - 启动与公共页：GET /api/xpert/:id/frequent-questions、/api/xpert/:slug/app、/api/xpert/:id/enterprise-h5/:platform/bootstrap、GET /api/auth/sso/providers；钉钉/GitHub 整页重定向
  - 跨域引用（服务端契约归「Assistant 定义与运行时专家」）：POST /api/ai/v1/chatkit/sessions、GET /api/ai/threads/:threadId、…/runs/:runId/stream（SSE 续传）、/api/assistant-binding/*（/effective/:code、/:code/preference、/xperts、upsert/delete）
  - 实时通道：socket.io namespace `chat`（双向事件 `message`、ChatGatewayEvent 15 项；握手 auth.token、401 刷新、2s 无 ack 原样重发）；现行主链另有 SSE——ChatService.chat 与 AiThreadService.joinRunStream
  - ChatKit 宿主协议：宿主→iframe client-command 6 类（assistant.chat.send_message、assistant.context.set、assistant.composer.append_references、workbench.browser/file/navigation.open、workspace.connector.connect；当前 commit 实测注册 7 个 key，另有 platform.data-source.create）+ iframe→宿主回调（onReady/onThreadChange/onProjectChange/onResponseStart-End/onEffect/api.getClientSecret/toolOutputAttachments.onRequestPreview）
  - 前端组件与服务调用面：ChatConversationService/ChatMessageService/ChatMessageFeedbackService/ChatGroupService/AiThreadService/AssistantBindingService/XpertTaskService/ChatWebsocketServer；契约 WorkbenchChatFacade + WORKBENCH_CHAT_FACADE、injectHostedAssistantChatkitControl、ASSISTANT_REGISTRY、ViewClientCommandRegistry
- 关键约束：socket 通道在本域无路由级消费者（保留实现）；ChatKit iframe 请求需绝对基址 resolveAbsoluteApiBaseUrl + /api/ai；命令无处理器回 unsupported、上下文不符回 stale_context/forbidden；附件上限 50 MiB、maxCount=5
- 逐端点明细：见 .module-experts/前端专题/对话前端专家/implementation/05-接口.md
