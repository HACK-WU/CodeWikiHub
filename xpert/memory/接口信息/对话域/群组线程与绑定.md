**对话域接口 · 群组/线程/绑定**（前端调用视角，真实路径）

- GET /api/ai/groups（ChatGroupSummary[]）
- GET /api/ai/groups/:id（ChatGroupSnapshot，可带 relations）
- PATCH /api/ai/groups/:id/preferences（群组偏好）
- /api/ai/threads（基址；AiThreadService，API_AI_THREADS = API_PREFIX + '/ai/threads'）
- POST /api/ai/v1/chatkit/sessions（创建 ChatKit 会话；assistant-chatkit.runtime.ts 经 buildAssistantApiUrl = resolveAbsoluteApiBaseUrl + '/api/ai'）
- /api/assistant-binding（基址；API_ASSISTANT_BINDING）：/:code 读取、/effective/:code 生效解析、/:code/preference 用户偏好
- POST /api/assistant-binding/bosi/onboarding/connection/resolve（Bosi 连接）
- 其他：/api/xpert/:id/frequent-questions（常见问题启动屏）、/api/xpert-project/:id/github-installation（项目 GitHub 安装）
