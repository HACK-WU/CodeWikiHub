【接口信息｜运行时助手面与准入】
- 子功能：运行时 Assistant 查询、多受众准入、公共 App 与企业 H5 会话
- 所属模块：Assistant 定义与运行时
- 接口列表（**真实前缀是 /api/ai/...**）：
  - `POST|GET /api/ai/assistants/search|count`・`GET /api/ai/assistants/:id`・`/:id/runtime-capabilities`（?isDraft）・`/:id/models`・`PUT /:id/model-preference`（`@Public()` + `ApiKeyOrClientSecretAuthGuard` + `@AllowClientSecretBindings(ENTERPRISE_XPERT)`）
  - `POST /api/xpert/:identifier/chatkit-session`（`@Public()`；匿名 cookie `anonymous.id` + PUBLIC_XPERT secret，`expires_after` 缺省 600、上限 3600）
  - `GET|POST /api/xpert/:name/chat-app`（公共 App 会话面）
  - `GET|POST /api/xpert/:identifier/enterprise-h5/:platform/{bootstrap,session}`（均 `@Public()`；**bootstrap 在身份校验之前**，只回白名单 12 字段 + platform + clientConfig；session 走 authorization_code 换身份 → ENTERPRISE_XPERT client secret，TTL 固定 600s）
  - 服务入口：PublishedXpertAccessService.getAccessiblePublishedXpert / assertCurrentUserAccess / findAccessiblePublishedXperts / getPublishedXpertInTenant；受众来自 currentApiPrincipal → currentPublicXpertId / currentUserXpertId / currentWorkspaceApiKeyWorkspaceId / currentEnterpriseXpertScope
- 关键约束：准入硬约束 = **publishAt 非空**（各 build*Query 与 getPublishedXpertInTenant 施加；**不在** applyPublishedFilters 内）；`latest` 由调用方决定；受众必须与目标 Assistant 匹配
