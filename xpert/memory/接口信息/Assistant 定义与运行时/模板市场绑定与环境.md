【接口信息｜模板市场绑定与环境】
- 子功能：模板目录与装配安装、市场发现与访问申请审批、系统槽位绑定与 Bosi 引导、环境变量
- 所属模块：Assistant 定义与运行时
- 接口列表：
  - `/api/xpert-template/*`：`GET|POST /`、`catalog`、`mcps`、`pipelines`、`skills-market`、`/:id`、`/:id/install`（**安装 = 建 Assistant（经 XpertImportCommand）+ 在既有工作区补默认 prompt workflow；不创建工作区本体**）
  - `/api/xpert-marketplace`、`/api/xpert-marketplace/:id`、`/api/xpert-marketplace/:id/access-requests`；`/api/xpert-access-requests/{my,reviewable}`、`/:id/{approve,reject}`（**批准即写 UserGroup**，回写 accessGroupId）
  - `/api/assistant-binding/`、`effective/:code`、`:code/preference`、`bosi/*`（setup/bootstrap/welcome/workspace/onboarding[/choice|/connection[/resolve]]）；三层 scope = tenant/organization/user，`getEffectiveBinding` 为 organization 优先回落 tenant
  - `/api/environment/*`（含 `/default/:workspaceId`、`/:id/as-default`；**工作区维度环境变量集，属数据而非进程环境变量**）
  - 服务入口：XpertTemplateService.getCatalog/getTemplateDetail/saveExportedXpertTemplate；XpertMarketplaceService.findMarketplace/requestAccess/approveRequest/rejectRequest/hasRuntimeAccess/ensureAccessGroup；AssistantBindingService.getEffectiveBinding/upsertBinding/getBindingPreference
