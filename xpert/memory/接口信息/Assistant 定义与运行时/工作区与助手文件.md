【接口信息｜工作区与助手文件】
- 子功能：创作容器（工作区）CRUD 与成员、助手数据卷文件（runtime / authoring 双入口）
- 所属模块：Assistant 定义与运行时
- 接口列表：
  - `GET|POST|PUT|DELETE /api/xpert-workspace/*`（`/`、`my`、`my/default`、`count`、`pagination`、`/:workspaceId`、`/:workspaceId/members`、`/:workspaceId/visibility`、`/:workspaceId/soft`、`recover`、`archive`；`?purpose=authoring|runtime`；读 `WorkspaceAuthoringGuard` / 写 `WorkspaceOwnerGuard`）
  - Studio 侧：`/api/xpert/:id/workspace/file(s)`（含 `file/download`、`file/upload`、`file/save-binary`；全部走 `forAuthoring`）
  - 运行侧：`/api/ai/assistants/:assistantId/workspace/{capabilities,files,file,file/download,file/upload,file/save-binary}`（类级 `@AssistantFileAccess('workspace')` + `AssistantFileAccessGuard`；**每个端点重新 `forRuntime(id)`**）
  - 工作台与查看会话：`/api/ai/conversations/:conversationId/workspace/*`、`/api/ai/workspace-files/view-sessions`
  - 服务入口：XpertWorkspaceAccessService.getAccess(workspaceId, options?) / getCapabilities(workspace, options?) / getResourceCapabilities(workspaceIds) / assertCan*(workspaceId, action?)；AssistantFilesService.forRuntime(assistantId) / forAuthoring(assistantId)；ResolveAssistantFileAccessCommand → AssistantFileAccessService.execute
- 关键约束：**文件访问永不授予工作区成员资格或编辑权**；UserGroup 授权只补 `canRun`；每次操作重新授权
