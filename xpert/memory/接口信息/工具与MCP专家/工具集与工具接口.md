【接口信息｜工具集与工具接口】
- 子功能：工具集 CRUD 与工作区视图、内置 provider 目录与实例化、OpenAPI / OData 远端与解析、MCP 工具流式探测、凭据出口、工具详情 / 试跑 / 参数样例、stdio 运行时审计与停机阀
- 所属模块：工具与 MCP 专家（子专家：工具集与工具）
- 接口列表（真实前缀 `/api/xpert-toolset`，走 `RouterModule.register`；其余控制器自带路径段）：
  - 列表与目录：GET `/api/xpert-toolset`、`/tags`、`/providers`、`/by-workspace/:workspaceId`（`by-workspace` 另加 `WorkspaceAuthoringGuard`）、GET `/:toolsetId/tools`、GET `/provider/:name`
  - CRUD：GET/POST/PUT/PATCH/DELETE `/api/xpert-toolset`（登录态；`credentials` 因 `@Exclude` 不出网）；GET `/:id/avatar`、GET `/builtin-provider/:name/icon`（`@Public()`，只跳过全局 JWT 守卫 ≠ 放行）
  - provider 面（登录态）：POST `/provider/openapi/{remote,schema,test}`、POST `/provider/odata/{remote,schema}`、POST `/provider/mcp/tools`（**`@Sse` 流式**：`MessageEvent{type:MESSAGE/EVENT}`，失败走流内 error 事件，不返回 4xx/5xx JSON）、GET `/builtin-provider/:name/tools|/credentials-schema`、POST `/builtin-provider/:name/instance`（其余异常统一包成 **500**）
  - 凭据与运行时：GET `/:id/credentials`（**`ToolsetGuard`**，唯一凭据出口，越权 403 `Access denied`）；GET `/operations/mcp-runtimes`、POST `/:runtimeId/stop`、POST `/kill`（三端点各自手写 `assertSuperAdmin()`，**不是** `@Roles` 元数据）
  - 工具面（前缀 `/api/xpert-tool`，无自定义守卫）：POST `/api/xpert-tool/test`、GET `/:id`、GET `/:id/faker`
- 关键文件：`xpert-toolset/{xpert-toolset.controller.ts,mcp-runtime.controller.ts,mcp-apps.controller.ts}`、`xpert-tool/xpert-tool.controller.ts`
- 关键约束：内置实例先 `validateCredentials` 再落 `category=BUILTIN`/`type=provider`；工具集写前统一 `assertValidTagAssociations(..., TagCategoryEnum.TOOLSET)`；试跑经 `ToolInvokeCommand` 落到统一执行面（非并行实现）；插件托管工具集在 MCP 探测前强制回库校验 `pluginName`/`componentKey`
- 主要错误码：403 `Access denied`（ToolsetGuard）· 403 `Only SUPER_ADMIN users can manage MCP stdio runtimes` · 404 provider/tool 不存在 · 400 `Error.McpToolInvocationScopeRequired` · 500（builtin-provider instance 兜底）
- 逐端点明细：见 .module-experts/后端专题/工具与 MCP 专家/implementation/05-接口.md（本文不复制）
