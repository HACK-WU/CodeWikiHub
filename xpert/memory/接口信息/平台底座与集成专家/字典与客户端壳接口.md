【接口信息｜字典与客户端壳接口】
- 子功能：语言/国家/货币只读字典、联系人继承面（未挂载）、标签字典与用量目录、桌面壳设备注册·授权·命令（HTTP+WS）、移动端 bootstrap、初始化 ClawXpert 恢复、模型 Provider 图标、通用导入（未挂载）
- 所属模块：平台底座与集成专家（子专家：基础字典与客户端壳）
- 鉴权口径：鉴权列只写模块内额外守卫；全站默认 `AuthGuard(['jwt','basic'])` + `PluginScopeGuard`，**仅 `@Public()` 放行**；未列出的基类 CRUD（`contact`/`tags` 继承面）不计入计数
- 接口列表（字典读面）：GET `/api/languages`（方法级 `@Public`，支持 `is_system` 过滤）、GET `/api/languages/getByName/:name`（未命中回 `null`，**软失败不抛错**）、GET `/api/country`、GET `/api/currency`（类级 `@Public`）——**三类字典均无写端点**
- 接口列表（contact 与 tags）：GET `/api/contact`（**未挂载**，类级 `TenantPermissionGuard` 不会实例化；期望行为就是 404）+ 基类 9 条；`tags` 8 条——GET `/api/tags/directory`（逐条附 `targets/editable/usage`）、GET `/categories`、GET|POST `/api/tags`（POST 加 `ORG_TAGS_EDIT` + zod + 租户行锁）、PUT|DELETE `/:id`、DELETE `/:id/soft` 与 PUT `/:id/recover`（**恒 400**，口径改为 `isActive`）
- 接口列表（desktop-shell 9 条 HTTP + WS）：POST `/api/desktop-shell/devices`（回一次性 `token=<id>.<secret>`）、POST `/devices/:id/{refresh,disable}`、POST `/devices/:id/grants`、POST `/devices/:id/prepare`（写 `decision:'pending'`，**只路由不执行**）、POST `/grants/:id/{decision,revoke}`、GET `/operations?deviceId=`（最近 20 条）、POST `/operations/:id/cancel`；WS `ws(s)://<api-host>/desktop-shell` 握手 `version=1` + `token`
- 接口列表（其余模块）：GET `/api/mobile/bootstrap`（无守卫但 service 内 401）、GET `/api/mobile/xperts`（`limit` 默认 25/上限 100、`search` ≤120）、GET|POST `/api/initialization/clawxpert`（`requireCurrentMember` 403）、GET `/api/ai-model/provider/:name/:iconType/:lang`（方法级 `@Public`，缺文件 404 `Icon not found`）、GET|POST `/api/import`（**未挂载**）
- 关键文件：`language/{language.controller.ts,language.seed.ts}`、`tags/{tag.controller.ts,tag-management.service.ts}`、`server-ai/src/desktop-shell/{desktop-shell.controller.ts,desktop-shell.gateway.ts,desktop-shell-auth.service.ts}`、`server-ai/src/mobile/mobile.service.ts`、`server-ai/src/initialization/{bootstrap.processor.ts,clawxpert-recovery.service.ts}`、`server-ai/src/ai-model/ai-model.controller.ts`
- 关键约束（字典与标签）：改字典 = 改常量 + 改初始化（`SeedDataService` 顺序 `Countries → Currencies → Languages → Features`；`LanguageInitCommand` 运行期重灌，唯一冲突被 `try/catch + console.log` 吞掉）；标签写路径在事务内锁 `Tenant` 行 + `LOWER(name)` 域内重名 + `usage()` 全库 M2M 扫描（**未登记 `usageTargets` 的新 junction 会让整个目录接口 400**）
- 关键约束（桌面壳与移动端）：`register` 校验 `installationId` uuid + `platform='darwin'`，明文密钥只回一次（库内 `sha256` + `credentialExpiresAt`）；`argsHash = sha256([command,cwd,timeoutSec])` 双端一致，`prepare` 把 grant 压到 ≤10 分钟；`deployment.viewHostsPath` 固定 `/api/view-hosts`（改动属破坏性变更）
- 主要错误码：400 `INVALID_MESSAGE`/`TagTargetInUse`/`TagUsageUnsupported`/`TagInUse` · 403 `GRANT_REVOKED` / `requireCurrentMember` 403 · 409 `DEVICE_OFFLINE`/`DEVICE_BUSY`/`OPERATION_CONFLICT` · 握手不符 `PROTOCOL_MISMATCH` · `EXECUTION_UNKNOWN`（**不重放**）
