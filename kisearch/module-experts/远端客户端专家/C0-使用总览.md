# C0-使用总览：远端客户端专家

## 能力清单

| 能力 | 说明 | 入口 |
|---|---|---|
| CLI | remote / ping / asset / doc / upload / upload-dir / atlas 命令族 | cli.ts / parseArgs |
| 远端登记 | 多远端配置与环境变量 Token | resolveRemote / readConfig |
| 能力协商 | ping 拿 contractVersion 与 capabilities | pingRemote / assertCapability |
| 上传 | multipart 与 tar.gz 双通道、按上限自动分批 | runUpload / planBatches |
| 文件级增量 | 按 sha256 记状态，失败批不落状态 | lib/state.ts |
| 图集部署 | 整包一次上传，不分片 | runAtlas |
| 打包 | 零依赖自写 ustar | lib/tar.ts |

## 能力边界（本专家不做什么）

- 不实现服务端 /open/v1/*：归开放接口与鉴权专家
- 不读工作区内配置文件
- 不进主包 bin：分发形态是进子目录 npm i -g .
- 不覆盖主仓 test:all：用 node --test 独立跑

## 已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
|---|---|---|
| clone 别人仓库后连到他的源 | 读工作区内配置文件 | 只读 ~/.ki-client/config.yaml 与环境变量 |
| 同名源换机器后整批文件被跳过 | 增量状态 key 没含 url | state key 必须含 url，见 lib/state.ts 注释 |
| multipart 通道附件静默丢失 | 服务端该通道不落附件 | 有子目录或图片就走 tar.gz 通道 |
| ping 字段缺失仍继续调用 | 把 undefined 当有能力 | 缺失视为 contractVersion 0 且能力全 false |
