# C2-使用流程：远端客户端专家

## 上传一个目录到远端

- **业务目标**：从能力协商到文件级增量
- **调用顺序**：parseArgs → readConfig → resolveRemote → pingRemote → planBatches → runUpload → 写 state
- **事务边界**：每批独立 HTTP 请求；失败批不写 state
- **预期结果**：成功批记 sha256，下次重跑只传变更文件
- **真实代码示例**：

```ts
import { readConfig } from './src/config.js';
import { resolveRemote } from './src/remote.js';
import { pingRemote } from './src/http.js';
const cfg = readConfig();
const remote = resolveRemote(cfg, 'prod');
const info = pingRemote(remote);
```
