# C1-能力契约：远端客户端专家

> 本文只写「怎么用」。实现机制、内部状态机与数据结构见 `implementation/`。
> 本次契约基于对模块入口与测试调用点的核对；未采样文件中可能存在未记录的公开方法。

### `parseArgs(argv: string[]): ParsedArgs`

- **用途**：解析 CLI 参数
- **契约来源**：`parseArgs(argv: string[]): ParsedArgs`（ki-client/src/args.ts）
- **参数**：argv 为不含 node/脚本名的参数数组
- **返回**：ParsedArgs
- **异常**：USAGE
- **约束**：命令族见 cli.ts HELP
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { parseArgs } from './src/args.js';
const a = parseArgs(['upload', '--remote', 'prod', './docs']);
```

### `resolveRemote(config: KiClientConfig, requested?: string): ResolvedRemote`

- **用途**：把远端名/环境配置解析成可用地址
- **契约来源**：`resolveRemote(config: KiClientConfig, requested?: string): ResolvedRemote`（ki-client/src/remote.ts）
- **参数**：config 来自 readConfig；requested 可空走默认远端
- **返回**：ResolvedRemote
- **异常**：UNKNOWN_REMOTE / NO_REMOTE_SPECIFIED
- **约束**：KI_REMOTE / KI_URL / KI_TOKEN 可覆盖
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { resolveRemote } from './src/remote.js';
const r = resolveRemote(config, 'prod');
```

### `postMultipart<T>(remote, pathname, form, query?): Promise<T>`

- **用途**：发一个 multipart 请求
- **契约来源**：`postMultipart<T>(remote, pathname, form, query?): Promise<T>`（ki-client/src/http.ts）
- **参数**：FormData 承载文件与字段；query 可带 scope 等
- **返回**：服务端 JSON 响应
- **异常**：REMOTE_UNREACHABLE / SERVER_ERROR / TOKEN_MISSING
- **约束**：只打 /open/v1/*，/api/* 无对外契约
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { postMultipart } from './src/http.js';
const r = await postMultipart(remote, '/open/v1/import/upload', form, { scope: 'kisearch-memory' });
```

### `pingRemote(remote): PingInfo`

- **用途**：能力协商
- **契约来源**：`pingRemote(remote): PingInfo`（ki-client/src/http.ts）
- **参数**：远端配置
- **返回**：contractVersion + capabilities
- **异常**：CONTRACT_TOO_OLD
- **约束**：字段缺失视 0 且能力全 false，绝不按 undefined 继续
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { pingRemote, assertCapability } from './src/http.js';
const info = pingRemote(remote);
assertCapability(info, 'atlas.upload');
```

### `runUpload / planBatches`

- **用途**：上传目录并分批
- **契约来源**：`runUpload / planBatches`（ki-client/src/commands/upload.ts）
- **参数**：含远端、源目录、scope 与上限
- **返回**：上传结果与任务状态
- **异常**：FILE_EXISTS / SERVER_ERROR
- **约束**：按服务端 maxPackageSize 分批；失败批不落状态
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { runUpload, planBatches } from './src/commands/upload.js';
const batches = planBatches(files, info.capabilities.uploadMaxBytes);
await runUpload({ remote, srcDir: './docs', scope: 'kisearch-memory' });
```

### `runAtlas`

- **用途**：一次整包上传图集
- **契约来源**：`runAtlas`（ki-client/src/commands/atlas.ts）
- **参数**：包路径与远端
- **返回**：上传结果
- **异常**：SERVER_ERROR
- **约束**：一次一整包，不分片；上限读 ping 的 maxPackageSize
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { runAtlas } from './src/commands/atlas.js';
await runAtlas({ remote, packagePath: './dist/atlas.zip' });
```
