# C5-关键决策：远端客户端专家

> 只收有明写证据（代码注释 / commit message / 设计文档）的决策；结构暗示的一律前置 `[推测]`。

## 不读工作区内的配置文件

- **分类**：安全
- **决策**：不读工作区内的配置文件
- **背景约束**：否则 clone 别人的仓库就可能连到他的源
- **被否决方案及理由**：读工作区配置；否决理由见 config.ts 文件头
- **重新评估触发条件**：用户明确要求仓库级配置时
- **证据来源**：代码注释：ki-client/src/config.ts 文件头

## ping 字段缺失视为 contractVersion 0 且能力全 false

- **分类**：容错
- **决策**：ping 字段缺失视为 contractVersion 0 且能力全 false
- **背景约束**：绝不能按 undefined 继续尝试
- **被否决方案及理由**：按 undefined 继续；否决理由见 http.ts pingRemote 注释
- **重新评估触发条件**：服务端契约升级为必填时
- **证据来源**：代码注释：ki-client/src/http.ts

## 增量状态 key 必须含 url

- **分类**：增量
- **决策**：增量状态 key 必须含 url
- **背景约束**：同名源被 remote add 改到另一台机器后，旧状态会让客户端误以为文件已传过而整批跳过
- **被否决方案及理由**：只用远端名做 key；否决理由见 lib/state.ts 注释
- **重新评估触发条件**：状态改为按机器而非按源存储时
- **证据来源**：代码注释：ki-client/src/lib/state.ts

## 有子目录或图片即走 tar.gz，图集一次整包不分片

- **分类**：通道
- **决策**：有子目录或图片即走 tar.gz，图集一次整包不分片
- **背景约束**：multipart 通道下服务端不落附件（md 成功但图静默丢失）
- **被否决方案及理由**：一律 multipart；否决理由见 README 与真机验证结论
- **重新评估触发条件**：服务端 multipart 附件缺陷修复后
- **证据来源**：文档：ki-client/README.md；真机验证：2026-11-24
