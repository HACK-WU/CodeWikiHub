# C4-数据流向与消费：远端客户端专家

> 只写数据「用来干嘛」与去向；消费方的处理逻辑见实现层。

| 数据实体 | 来源接口 | 去向 | 消费方（模块级） | 业务用途 |
|---|---|---|---|---|
| ~/.ki-client/config.yaml | readConfig / writeConfig | 用户主目录（目录 0700 / 文件 0600） | 全部命令 | 存远端名、url 与 Token 来源 |
| statePath(key) | lib/state.ts | ~/.ki-client/state/<key>.json | upload / upload-dir | 按 sha256 记文件级增量，key 必须含 url |
| --out 目录 | runAsset / runDoc | 本地输出目录 | 取件命令 | 落附件与 *.md |
