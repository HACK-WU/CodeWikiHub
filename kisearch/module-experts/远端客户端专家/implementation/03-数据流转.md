## 流转步骤

1. 入口：CLI parseArgs
2. 配置：readConfig 读 ~/.ki-client/config.yaml，环境变量可覆盖
3. 远端：resolveRemote 解析 url 与 Token
4. 协商：pingRemote 拿 contractVersion / capabilities
5. 执行：按能力位选择通道与分批，postMultipart 或 tar.gz 上传
6. 状态：成功批按 sha256 写 state，失败批不写

章节来源：[ki-client/src/cli.ts](file://ki-client/src/cli.ts)（关键符号：`parseArgs` / `resolveRemote` / `postMultipart`）
