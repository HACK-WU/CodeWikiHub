# C1-能力契约：开放接口与鉴权专家

> 本文只写「怎么用」。实现机制、内部状态机与数据结构见 `implementation/`。
> 本次契约基于对模块入口与测试调用点的核对；未采样文件中可能存在未记录的公开方法。

### `handleOpenApiRequest(req, res, url, ctx: OpenApiContext): Promise<void>`

- **用途**：/open/v1/* 唯一分发
- **契约来源**：`handleOpenApiRequest(req, res, url, ctx: OpenApiContext): Promise<void>`（src/lib/open-api/index.ts）
- **参数**：req/res/url/ctx；ctx 含开关位 uploadApi / downloadApi 与注入的鉴权依赖
- **返回**：void，直接写响应
- **异常**：OPEN_API_TOKEN_REQUIRED / TOKEN_INVALID / TOKEN_READONLY / SCOPE_FORBIDDEN / DAEMON_DRIFT
- **约束**：三层顺序即语义；与 /api/* 互不调用
- **代码示例**（使用方代码，签名与源码一致）：

```ts
await handleOpenApiRequest(req, res, url, ctx);
```

### `resolveOpenApiPrincipal(req, deps): OpenApiAuthResult`

- **用途**：解析 Bearer Token 成主体
- **契约来源**：`resolveOpenApiPrincipal(req, deps): OpenApiAuthResult`（src/lib/open-api/auth.ts）
- **参数**：deps 提供 resolveTokenAuth(token)
- **返回**：OpenApiAuthResult
- **异常**：TOKEN_INVALID / TOKEN_READONLY
- **约束**：不复用 resolveWebPrincipal，避免回环短路成管理员
- **代码示例**（使用方代码，签名与源码一致）：

```ts
const p = resolveOpenApiPrincipal(req, { resolveTokenAuth });
```

### `createUploadSession(scope: string): UploadSessionDir`

- **用途**：创建上传会话目录
- **契约来源**：`createUploadSession(scope: string): UploadSessionDir`（src/lib/open-api/upload-stream.ts）
- **参数**：scope 为目标库
- **返回**：UploadSessionDir，含 .scope / .upload-session.json / content/ / .upload.tar.gz
- **异常**：目录创建失败由上层转 SERVER_ERROR
- **约束**：落在 ~/.ki/import-uploads/<uploadId>/
- **代码示例**（使用方代码，签名与源码一致）：

```ts
const s = createUploadSession('kisearch-memory');
```

### `ping / capabilities`

- **用途**：能力协商
- **契约来源**：`ping / capabilities`（src/lib/open-api/routes/ping.ts）
- **参数**：GET /open/v1/ping
- **返回**：contractVersion + capabilities（download.asset/doc、atlas.upload/download、maxPackageSize 等）
- **异常**：字段缺失时客户端视为 0
- **约束**：CONTRACT_VERSION=1；downloadApi=false 时相应端点 404
- **代码示例**（使用方代码，签名与源码一致）：

```ts
const info = await fetch('http://127.0.0.1:7423/open/v1/ping', { headers: { Authorization: 'Bearer ...' } }).then(r => r.json());
```
