# C2-使用流程：开放接口与鉴权专家

## 第三方上传一批文档

- **业务目标**：从能力协商到导入完成
- **调用顺序**：GET /open/v1/ping → POST /open/v1/import/upload（分片）→ GET /open/v1/import/status
- **事务边界**：上传会话按 uploadId 落盘，状态与导入 job 解耦
- **预期结果**：服务端 202→200 收口，导入 job 异步完成后状态可查
- **真实代码示例**：

```ts
const ping = await fetch('/open/v1/ping').then(r => r.json());
if (!ping.capabilities.upload) throw new Error('服务端未开放上传');
await fetch('/open/v1/import/upload', { method: 'POST', body: form });
```
