## 流转步骤

1. 入口：mcp-http.ts 把 /open/v1/* 交给 handleOpenApiRequest
2. 开关：uploadApi / downloadApi 决定是否可用
3. 鉴权：resolveOpenApiPrincipal 解析 Bearer 并检查 scope
4. 路由：ROUTES 匹配 ping / doc / asset / events / import / atlas
5. 落盘：上传类写 ~/.ki/import-uploads/<uploadId>/
6. 回传：JSON 结果或 202→200 分片收口

章节来源：[src/lib/open-api/index.ts](file://src/lib/open-api/index.ts)（关键符号：`handleOpenApiRequest` / `resolveOpenApiPrincipal` / `createUploadSession`）
