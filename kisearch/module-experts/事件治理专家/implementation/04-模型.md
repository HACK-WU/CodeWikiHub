## 简介

本篇列出本模块读写的数据模型，供改动前确认字段与约束。

章节来源：[src/lib/governance-http.ts](file://src/lib/governance-http.ts)（关键符号：`handleGovernanceRoutes` / `createEvent` / `transitionEvent`）

## 模型清单

| 模型 / 文件 | 字段或形态 | 约束 |
|---|---|---|
| EventRecord | id / shortId / status / stage / revision / expectedEffect | revision 不匹配拒绝并发写 |
| AnalysisRunStatus | running / ready / partial / failed / cancelled | 超时但有正文落 partial |
| TransitionOutcome | terminalAction: keep 或 trash | trash 会把关联文档移入回收站 |
| GovernanceError | code 语义字符串 + status | 数值不出现在响应体 |

章节来源：[src/lib/governance-http.ts](file://src/lib/governance-http.ts)（关键符号：`handleGovernanceRoutes` / `createEvent` / `transitionEvent`）

## 约束与校验

- EventRecord：revision 不匹配拒绝并发写
- AnalysisRunStatus：超时但有正文落 partial
- TransitionOutcome：trash 会把关联文档移入回收站
- GovernanceError：数值不出现在响应体

章节来源：[src/lib/governance-http.ts](file://src/lib/governance-http.ts)（关键符号：`handleGovernanceRoutes` / `createEvent` / `transitionEvent`）
