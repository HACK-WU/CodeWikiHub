## 流转步骤

1. 入口：HTTP /api/governance/* 或 MCP ki_event_* 到达
2. 分发：handleGovernanceRoutes 或工具实现解析 action / 路径
3. 编排：event-service / analysis-runner 加 withScopeWriteLock
4. 能力：引用、阶段日志、候选查找、结论链各写自己的文件
5. 落盘：.events/{id}.* 与 governance.json，经 readJson / writeJson 原子写
6. 回传：DTO 经 toEventListView / getEventDetail 整形后给 HTTP 与 MCP

章节来源：[src/lib/governance-http.ts](file://src/lib/governance-http.ts)（关键符号：`handleGovernanceRoutes` / `createEvent` / `transitionEvent`）
