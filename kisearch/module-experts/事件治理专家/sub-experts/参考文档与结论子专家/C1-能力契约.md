### `addRefs(scope, eventId, refs)`

- **用途**：批量加参考文档
- **契约来源**：`addRefs(scope, eventId, refs)`（src/lib/events/refs-service.ts）
- **参数**：refs 的键为 sourceScope / group / name
- **返回**：引用清单
- **异常**：REF_LIMIT_EXCEEDED
- **约束**：remove 只解绑不删文档
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { addRefs } from './src/lib/events/refs-service.js';
await addRefs('kisearch-memory', '#38', [{ sourceScope: 'kisearch-memory', group: '决策记录', name: 'JWT 选型' }]);
```
