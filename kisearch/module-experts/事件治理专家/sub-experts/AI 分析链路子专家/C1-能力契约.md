### `startEventAnalysis(opts)`

- **用途**：启动一轮分析
- **契约来源**：`startEventAnalysis(opts)`（src/lib/events/analysis-runner.ts）
- **参数**：内联 opts，含 forceOverwrite / resume / deps / authScopes
- **返回**：启动结果
- **异常**：ANALYSIS_ALREADY_RUNNING
- **约束**：超时有正文落 partial
- **代码示例**（使用方代码，签名与源码一致）：

```ts
await startEventAnalysis({ scope: 'kisearch-memory', eventId: '#38', deps: { runFind: myRunner } });
```
