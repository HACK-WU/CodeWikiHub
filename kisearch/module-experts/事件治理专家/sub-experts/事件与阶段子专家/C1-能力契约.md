# C1-能力契约：事件与阶段子专家

> 本文只写「怎么用」。实现机制、内部状态机与数据结构见 `implementation/`。
> 本次契约基于对模块入口与测试调用点的核对；未采样文件中可能存在未记录的公开方法。

### `createEvent(scope: string, input: CreateEventInput): Promise<EventRecord>`

- **用途**：创建事件
- **契约来源**：`createEvent(scope: string, input: CreateEventInput): Promise<EventRecord>`（src/lib/events/event-service.ts）
- **参数**：scope 与事件字段
- **返回**：EventRecord
- **异常**：超限抛 EVENT_MEMBER_LIMIT_EXCEEDED
- **约束**：需 scope 写锁
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { createEvent } from './src/lib/events/event-service.js';
const ev = await createEvent('kisearch-memory', { title: '锁残留', description: '待查', typeId: 'bug' });
```

### `transitionEvent(scope: string, input: TransitionInput): Promise<TransitionOutcome>`

- **用途**：阶段流转
- **契约来源**：`transitionEvent(scope: string, input: TransitionInput): Promise<TransitionOutcome>`（src/lib/events/event-service.ts）
- **参数**：eventId / stage / revision
- **返回**：TransitionOutcome
- **异常**：EVENT_CLOSED / REVISION_CONFLICT
- **约束**：终态决定文档去向
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { transitionEvent } from './src/lib/events/event-service.js';
await transitionEvent('kisearch-memory', { eventId: '#38', stage: '已修复', revision: 2 });
```
