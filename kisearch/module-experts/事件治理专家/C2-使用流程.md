# C2-使用流程：事件治理专家

## 创建并推进一个事件

- **业务目标**：从零登记一条 bug 并把它推到终态
- **调用顺序**：createEvent → addRefs → startEventAnalysis → transitionEvent
- **事务边界**：每次写操作各自持 withScopeWriteLock，不构成跨调用事务
- **预期结果**：事件进入终态，terminalAction 决定关联文档保留或进回收站
- **真实代码示例**：

```ts
import { createEvent, transitionEvent } from './src/lib/events/event-service.js';
const ev = await createEvent('kisearch-memory', { title: '导入锁残留', description: '锁未释放', typeId: 'bug' });
await transitionEvent('kisearch-memory', { eventId: ev.id, stage: '已修复', revision: ev.revision });
```
