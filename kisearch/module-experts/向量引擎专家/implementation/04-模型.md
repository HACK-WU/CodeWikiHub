## 简介

本文件描述向量引擎的数据模型：集合 schema、文档、检索请求、Filter 与 worker 协议。

## 集合 Schema 模型

**`ZvecEngineConfig`**（`types.ts`）核心字段：

| 字段 | 说明 |
|------|------|
| `dbPath` | 集合目录（绝对路径，create 时须不存在） |
| `collection.name` | 集合名（kisearch 固定 `kisearch`） |
| `collection.denseField` | 稠密向量字段（`dense`） |
| `collection.dimension` | 向量维度（kisearch 固定 4096） |
| `collection.metric` | 距离度量（`COSINE`） |
| `collection.scalarFields` | 标量字段白名单：`[{name, dataType:'STRING', indexed:true}]` |
| `collection.fts` | FTS 配置：`{field, tokenizer:'jieba'}` |
| `embedding` | `EmbeddingProvider` 实例 |

**`ScalarFieldDef`**：`{name: string; dataType: 'STRING'|'INT'|'FLOAT'|'BOOL'; indexed?: boolean}`。

**`PersistedSchema`**：集合持久化的 schema（dense 参数 + scalarFields + fts）。

**Schema 构建**（`schema/builder.ts`）：`ZvecEngineConfig` → `ZVecCollectionSchema`：
- dense → HNSW 向量 schema
- scalarFields → field schema（白名单）
- fts → FTS index params（jieba）

**Schema 校验**（`schema/validator.ts`）：
- create（V-01~V-07）铁律校验
- open（O-02~O-05）校验 + `schemaAssert` 逐项比对
- `mapZvecOpenError`：zvec 原始错误 → 类型化异常

## 文档模型

**`DocInput`**：`{id?, content, ...scalarFields}`。
- `id`：缺省自动生成
- `content`：兼作 FTS 字段（jieba 分词）

**`Doc`**：写入后的文档（含 id + content + scalarFields + dense 向量）。

**`ScalarValue`**：`string | number | boolean`。

## 检索请求模型

| 请求类型 | 字段 | 说明 |
|----------|------|------|
| `SemanticSearchReq` | `queryText` / `limit` / `filters` | 语义检索（需 embed） |
| `VectorSearchReq` | `vector` / `limit` / `filters` | 向量检索（已 embed） |
| `FtsSearchReq` | `query` / `limit` / `filters` | 全文检索 |
| `HybridSearchReq` | `queryText` / `fts` / `limit` / `filters` | 混合检索（RRF） |

**`Hit`**：`{id, content, score, ...scalarFields}`（score 越大越相关，已归一化）。

## Filter 模型

**`Filter`**：结构化过滤条件（字段/操作符/值），经 `compileFilter` 编译为 zvec 类 SQL。

操作符语义：等于 / 不等于 / 包含 / 范围等（按 `filter/compiler.ts` 支持集为准）。

## Worker 协议模型

**`worker-protocol.ts`** 消息 payload：

| Payload | 用途 |
|---------|------|
| `QueryPayload` | 查询请求 |
| `WritePayload` | 写入请求 |
| `WriteDocPayload` | 单文档写入 |
| `MultiQueryPayload` | 多路查询（hybrid） |
| `WriteResultPayload` | 写入结果 |
| `InfoResultPayload` | info 结果 |
| `RawHitPayload` | 原始命中（未归一化） |

错误传输：`serializeError` / `deserializeError`（名称 → 类型化异常）。

## 结论

本专家模型清晰分层：schema 白名单约束集合结构（不可变），文档/检索/Filter/协议模型支撑语义与全文检索；理解 schema 白名单约束是扩展向量字段的关键（无 alter API）。
