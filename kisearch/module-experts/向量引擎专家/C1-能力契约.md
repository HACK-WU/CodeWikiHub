# C1-能力契约：向量引擎专家

> 本契约覆盖本专家的公开能力（经 `index.ts` 导出）。契约来源标注类名/方法签名（非行号）。
> 代码示例为使用方代码，API 签名真实，环境初始化可占位。

## 1. ZvecEngine 静态工厂（`engine.ts`）

### 1.1 `ZvecEngine.create(config): Promise<ZvecEngine>`

- **用途**：创建新向量集合并返回引擎实例。
- **参数**：`config: ZvecEngineConfig` — 含 `dbPath`（需不存在）、`collection`（name/denseField/dimension/metric/scalarFields/fts）、`embedding`（provider）。
- **返回**：`Promise<ZvecEngine>`。
- **异常**：`dbPath` 已存在 → `CollectionAlreadyExistsError`；配置校验失败 → `InvalidSchemaError` 等。
- **约束**：`dbPath` 必须绝对路径且不存在（V-07）。

```ts
// 假设已配置 embedding
import { ZvecEngine } from '../../dist/zvec-engine/index.js';
const engine = await ZvecEngine.create({
  dbPath: '/path/to/vector',
  collection: {
    name: 'kisearch', denseField: 'dense', dimension: 4096, metric: 'COSINE',
    scalarFields: [{ name: 'scope', dataType: 'STRING', indexed: true }],
    fts: { field: 'content', tokenizer: 'jieba' },
  },
  embedding: /* EmbeddingProvider 实例 */,
});
```

### 1.2 `ZvecEngine.open(config): Promise<ZvecEngine>`

- **用途**：打开已存在的集合。
- **参数**：`config: ZvecEngineOpenConfig` — `dbPath` + `collectionName`。
- **异常**：路径不存在 → `CollectionNotFoundError`；schemaAssert 不一致 → `SchemaMismatchError`；被持锁 → `CollectionLockedException`。
- **约束**：open 后执行 schemaAssert 比对（O-02~O-05）。

### 1.3 `ZvecEngine.tryOpen(config): Promise<ZvecEngine | null>`

- **用途**：open 的容错版，任意失败返回 `null` 不抛错。

### 1.4 `ZvecEngine.probe(dbPath, timeoutMs = 3000): Promise<ProbeResult>`

- **用途**：无句柄探测集合状态。
- **返回**：`ProbeResult`（状态含 locked / healthy / corrupted / not_found / error）。
- **行为语义**：`timeoutMs` 默认 3000ms；空目录直接返回 not_found（避免原生挂起）；持锁时超时后判定 locked。

## 2. 检索（`engine.search`）

### 2.1 `engine.search(options: SearchOptions): Promise<Hit[]>`

- **用途**：执行语义 / 全文 / 混合检索。
- **参数**：`SearchOptions` — 支持 `SemanticSearchReq` / `VectorSearchReq` / `FtsSearchReq` / `HybridSearchReq`（按类型路由）。
- **返回**：`Hit[]`（含 `id` / `content` / `score` / 标量字段）。
- **行为语义**：
  - Hybrid：queryText 语义 + fts 关键词 + RRF 融合，score 越大越相关
  - Semantic：纯语义向量
  - Fts：纯全文（jieba 分词）
- **异常**：`InvalidSearchError`（非法参数）。

```ts
const hits = await engine.search({
  type: 'hybrid',
  queryText: '用户登录流程',
  fts: '登录 认证',
  limit: 10,
});
```

## 3. 写入与删除

### 3.1 `engine.write(doc: DocInput): Promise<WriteResult>`

- **用途**：写入单条文档（幂等 upsert）。
- **参数**：`DocInput` — 含 `id`（可选，缺省自动生成）/ `content`（兼作 FTS 字段）/ 标量字段（scope/tag/group 等）。
- **返回**：`WriteResult`。
- **异常**：维度不匹配 → `DimensionMismatchError`；schema 不一致 → `InconsistentUpdateError`。

### 3.2 `engine.writeBatch(docs: DocInput[], batchSize?): Promise<WriteResult>`

- **用途**：批量写入（分批 + `setImmediate` 让出事件循环）。
- **约束**：`batchSize` 默认 100。

### 3.3 `engine.delete(ids: string[]): Promise<WriteResult>`

- **用途**：按 id 删除文档。

## 4. 生命周期与状态

| 方法 | 签名 | 用途 |
|------|------|------|
| `info()` | `Promise<CollectionInfo>` | 集合信息 |
| `close()` | `Promise<void>` | 优雅关闭（drain → worker closeSync → terminate） |
| `destroy()` | `Promise<void>` | 销毁（幂等；send destroy → terminate） |
| `isHealthy()` | `boolean` | proxy 打开且未销毁 |
| `isLocked()` | `boolean` | 是否被锁 |
| `isOpen()` | `boolean` | 是否打开 |

## 5. Embedding（`embedding/*`）

### 5.1 `EmbeddingProvider`（接口）

- **方法**：`embed(texts: string[], options?: EmbedOptions): Promise<number[][]>`
- **约束**：`EmbedOptions` 含 `timeoutMs` / `retries` / `batchSize`。

### 5.2 `SiliconFlowProvider`

- **用途**：OpenAI 兼容 `/embeddings` 参考实现。
- **构造参数**：`SiliconFlowProviderConfig` — `{baseURL, model, dimension, apiKey}`。
- **行为语义**：带重试/退避/超时/维度校验；维度不匹配抛错（`data.actualDim` 可读）。

```ts
import { SiliconFlowProvider } from '../../dist/zvec-engine/index.js';
const provider = new SiliconFlowProvider({
  baseURL: 'https://api.siliconflow.cn/v1',
  model: 'Qwen/Qwen3-Embedding-8B',
  dimension: 4096,
  apiKey: process.env.SILICONFLOW_API_KEY!,
});
const vectors = await provider.embed(['hello'], { timeoutMs: 8000, retries: 1 });
```

## 6. 类型化异常（`errors.ts`）

基类 `ZvecEngineError` + 11 种核心契约异常 + Worker/Embedding 族补充异常（共 18 类，全部导出）：

**核心契约异常（11 种）**：

| 异常 | 触发条件 |
|------|----------|
| `DimensionMismatchError` | 写入/检索向量维度 ≠ 集合维度 |
| `InvalidSchemaError` | create/open 配置校验失败 |
| `InvalidDocInputError` | DocInput 非法 |
| `InvalidSearchError` | SearchOptions 非法 |
| `InvalidFilterError` | Filter 非法 |
| `SchemaMismatchError` | open 时 schemaAssert 不一致 |
| `InconsistentUpdateError` | 写入与 schema 不一致 |
| `CollectionNotFoundError` | 集合不存在 |
| `CollectionLockedException` | 集合被其他进程持锁 |
| `CollectionCorruptedException` | 集合损坏 |
| `CollectionAlreadyExistsError` | create 时集合已存在 |

**Worker/Embedding 族（7 种）**：

| 异常 | 触发条件 |
|------|----------|
| `EmbeddingError` | embedding 调用失败（网络/上游错误） |
| `EmbeddingConfigError` | provider 配置缺失/非法（如 apiKey 未声明） |
| `WorkerSpawnError` | worker 线程启动失败 |
| `WorkerCrashedError` | worker 线程崩溃退出 |
| `WorkerUnavailableError` | worker 已关闭/不可用（如 close 后仍有操作提交；报 "worker not open (state=closed)"） |
| `WorkerProtocolError` | 主线程与 worker 通信协议错误 |
| `CloseTimeoutError` | close 超时未完成 |

> 约束：`WorkerUnavailableError` 的典型场景是「在途操作被 close 打断」（如 embedding 网络等待期被 idle close 关闭）。kisearch 业务层（`vector-client` 的 `withEngine`）已用在途计数 + 捕获自愈重试防护；直接使用引擎的调用方需自行保证 close 前操作已全部完成。

```ts
import { CollectionLockedException, WorkerUnavailableError } from '../../dist/zvec-engine/index.js';
try {
  await ZvecEngine.open(config);
} catch (err) {
  if (err instanceof CollectionLockedException) {
    // 集合被占用，引导关闭其他进程
  }
  if (err instanceof WorkerUnavailableError) {
    // worker 已关闭；业务层 vector-client 会重置引擎后重开重试一次
  }
}
```

## 7. Filter（`filter/compiler.ts`）

### 7.1 `compileFilter(filter: Filter, allowedFields: ReadonlySet<string>): string`

- **用途**：结构化 Filter → zvec 类 SQL 字符串。
- **行为语义**：仅允许 `allowedFields` 白名单内字段；含转义与嵌套深度上限；非法抛 `InvalidFilterError`。

## 已知约束汇总

- 集合 schema 是创建时白名单（scalarFields），**无 alter/drop API**；加字段需删集合重建（影响所有 scope 向量数据）
- embedding 小批大小默认 64（失败粒度 = 小批）
- 同一 dbPath 同进程并发 ZVecOpen 会触发原生竞态（已内部串行化）
- worker 进程 crash 抛 `WorkerCrashedError`
