## 流转步骤

1. 入口：/api/chat/* 或 MCP ki_ask
2. 鉴权与配置：读 chatDir、prompt-config、scope 列表
3. 编排：runAsk 或 runToolLoop 起一轮工具循环
4. 能力：工具注册表按能力位过滤，只读工具调 ki_search / doc 工具
5. 输出：SSE 帧逐条写出，或工具结果对象返回
6. 落盘：会话原子写 {id}.json，日志写 stderr 单行 JSON

章节来源：[src/lib/chat/chat-routes.ts](file://src/lib/chat/chat-routes.ts)（关键符号：`handleChatRoutes` / `writeSseStream` / `runAsk`）
