# C4-数据流向与消费：AI 对话与追问专家

> 只写数据「用来干嘛」与去向；消费方的处理逻辑见实现层。

| 数据实体 | 来源接口 | 去向 | 消费方（模块级） | 业务用途 |
|---|---|---|---|---|
| {id}.json | createConversation | {chatDir}/{scope}/{id}.json | 会话列表与详情 | 存单条会话与消息 |
| prompt-config.json | readPromptConfig | {chatDir}/prompt-config.json | find / recall / chat 三段配置 | 存提示词与运行期预算 |
| ka-*.json | runAsk | {chatDir}/{scope}/ | ki_ask 短会话 | 与 c-*.json 同目录靠前缀隔离 |
| askLog | ask-log.ts | stderr 单行 JSON | 运维排查 | 绝不打印问题与答案正文 |
