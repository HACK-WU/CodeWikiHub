# C2-使用流程：AI 对话与追问专家

## 发起一轮流式对话

- **业务目标**：从建会话到收到 done 帧
- **调用顺序**：POST /api/chat/conversations → POST .../messages（SSE）→ 逐帧写 writeSseStream → 会话原子落盘
- **事务边界**：每次消息写各自落盘，不构成跨消息事务
- **预期结果**：前端收到 reasoning/content/sources/done 帧，会话可刷新接续
- **真实代码示例**：

```ts
const conv = await fetch('/api/chat/conversations', { method: 'POST' }).then(r => r.json());
const stream = await fetch(`/api/chat/conversations/${conv.id}/messages`, { method: 'POST', body: JSON.stringify({ content: '导入锁在哪' }) });
const reader = stream.body.getReader();
```
