# C1-能力契约：会话与追问子专家

> 本文只写「怎么用」。实现机制、内部状态机与数据结构见 `implementation/`。
> 本次契约基于对模块入口与测试调用点的核对；未采样文件中可能存在未记录的公开方法。

### `handleChatRoutes(req, res, url, ctx): Promise<boolean>`

- **用途**：对话路由总分发
- **契约来源**：`handleChatRoutes(req, res, url, ctx): Promise<boolean>`（src/lib/chat/chat-routes.ts）
- **参数**：req/res/url/ctx
- **返回**：boolean
- **异常**：路由错误经 SSE error 帧
- **约束**：新增路由保持 mcp-http-api.ts 单行挂载
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { handleChatRoutes } from './src/lib/chat/chat-routes.js';
await handleChatRoutes(req, res, url, ctx);
```

### `runAsk(input: AskInput): Promise<AskResult>`

- **用途**：一次独立问答
- **契约来源**：`runAsk(input: AskInput): Promise<AskResult>`（src/lib/chat/ask/ask-runner.ts）
- **参数**：AskInput
- **返回**：AskResult
- **异常**：执行器不抛错
- **约束**：scope 单库
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { runAsk } from './src/lib/chat/ask/ask-runner.js';
const r = await runAsk({ scope: 'kisearch-memory', question: '导入锁在哪' });
```
