### `runToolLoop(input): AsyncGenerator<ChatEvent>`

- **用途**：驱动工具循环
- **契约来源**：`runToolLoop(input): AsyncGenerator<ChatEvent>`（src/lib/chat/retrieval/tool-loop.ts）
- **参数**：含会话、工具集与预算
- **返回**：AsyncGenerator<ChatEvent>
- **异常**：工具失败转 error 事件
- **约束**：预算受 find.maxToolCalls 约束
- **代码示例**（使用方代码，签名与源码一致）：

```ts
for await (const ev of runToolLoop(input)) { /* 写 SSE */ }
```
