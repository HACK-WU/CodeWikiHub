# C0-使用总览：工具循环与技能子专家

## 能力清单

| 能力 | 说明 | 入口 |
|---|---|---|
| 工具循环 | AsyncGenerator 驱动多轮调用 | runToolLoop |
| 工具注册 | 按能力位与开关过滤 | getChatTool |
| 内置技能 | refs-locate 等对话内技能 | retrieval/*-skill.ts |
| 响应投影 | 把工具结果投影成 SSE 事件 | tool-response.ts / projection.ts |

## 能力边界（本专家不做什么）

- 不实现 ki_recall 内核（归回想内核专家）
- 不实现 Web 前端聊天界面

## 已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
