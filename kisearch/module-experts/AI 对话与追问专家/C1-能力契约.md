# C1-能力契约：AI 对话与追问专家

> 本文只写「怎么用」。实现机制、内部状态机与数据结构见 `implementation/`。
> 本次契约基于对模块入口与测试调用点的核对；未采样文件中可能存在未记录的公开方法。

### `handleChatRoutes(req: IncomingMessage, res: ServerResponse, url: URL, ctx: ChatRouteContext): Promise<boolean>`

- **用途**：分派 /api/chat/* 全部请求
- **契约来源**：`handleChatRoutes(req: IncomingMessage, res: ServerResponse, url: URL, ctx: ChatRouteContext): Promise<boolean>`（src/lib/chat/chat-routes.ts）
- **参数**：req / res / url / ctx；ctx 含配置与鉴权上下文
- **返回**：Promise<boolean>，true 表示已处理
- **异常**：路由级错误经 SSE error 帧或 HTTP 错误返回
- **约束**：新增路由由 mcp-http-api.ts 单行挂载本函数
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { handleChatRoutes } from './src/lib/chat/chat-routes.js';
const handled = await handleChatRoutes(req, res, url, ctx);
```

### `runAsk(input: AskInput): Promise<AskResult>`

- **用途**：执行一次独立问答
- **契约来源**：`runAsk(input: AskInput): Promise<AskResult>`（src/lib/chat/ask/ask-runner.ts）
- **参数**：AskInput 含 scope / question / 可选 background 与 context_id
- **返回**：AskResult；执行器不抛错，失败进结果
- **异常**：超时/忙碌以 ASK_* 字符串码表达
- **约束**：软预算 25s 强制作答、硬预算 45s 收口
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { runAsk } from './src/lib/chat/ask/ask-runner.js';
const r = await runAsk({ scope: 'kisearch-memory', question: '导入锁在哪里' });
```

### `ki_ask 入参`

- **用途**：MCP 工具入参契约
- **契约来源**：`ki_ask 入参`（src/lib/mcp-tools/ask.ts）
- **参数**：scope: string(min1)；question: string(min1)；background?；context_id?
- **返回**：工具结果对象
- **异常**：ASK_QUESTION_INVALID / ASK_SCOPE_VIEW_UNSUPPORTED / ASK_SCOPE_NOT_FOUND / ASK_DISCLOSURE_REQUIRED / ASK_BUSY / ASK_TIMEOUT / ASK_INTERNAL
- **约束**：READ_ONLY_CAPABILITIES 为 knowledge.read；单库，逗号或视图名直接拒
- **代码示例**（使用方代码，签名与源码一致）：

```ts
const r = await client.callTool({ name: 'ki_ask', arguments: { scope: 'kisearch-memory', question: '导入锁在哪' } });
```

### `writeSseStream(res, events)`

- **用途**：把对话事件写成 SSE 帧
- **契约来源**：`writeSseStream(res, events)`（src/lib/chat/chat-routes.ts）
- **参数**：异步事件序列，帧体 data: {...} 双换行分隔
- **返回**：逐帧写出，type 含 reasoning/content/usage/sources/error/done/aborted
- **异常**：error 帧承载错误，不使用 SSE event: 字段
- **约束**：流式响应一旦 writeHead 就不能再改状态
- **代码示例**（使用方代码，签名与源码一致）：

```ts
for await (const ev of runToolLoop(input)) writeSseStream(res, ev);
```

### `readPromptConfig(config)`

- **用途**：读取 find / recall / chat 三段提示词与预算配置
- **契约来源**：`readPromptConfig(config)`（src/lib/chat/prompt-config.ts）
- **参数**：KiConfig；返回配置对象，缺省走内置默认
- **返回**：提示词配置对象
- **异常**：配置文件损坏时按内置默认并告警
- **约束**：find.maxToolCalls 默认 15（2~30），find.timeoutMs 默认 60s
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { readPromptConfig } from './src/lib/chat/prompt-config.js';
const cfg = readPromptConfig(config);
```

### `runToolLoop(input): AsyncGenerator<ChatEvent>`

- **用途**：驱动一轮模型工具调用
- **契约来源**：`runToolLoop(input): AsyncGenerator<ChatEvent>`（src/lib/chat/retrieval/tool-loop.ts）
- **参数**：输入含会话、工具集与预算
- **返回**：AsyncGenerator<ChatEvent>
- **异常**：工具失败转 error 事件，不中断整条流
- **约束**：工具集由 enabledChatToolEntries 过滤
- **代码示例**（使用方代码，签名与源码一致）：

```ts
for await (const ev of runToolLoop(input)) { /* 写 SSE */ }
```
