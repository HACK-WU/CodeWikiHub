# C1-能力契约：知识资产治理专家

> 本文只写「怎么用」。实现机制、内部状态机与数据结构见 `implementation/`。
> 本次契约基于对模块入口与测试调用点的核对；未采样文件中可能存在未记录的公开方法。

### `moveToTrash(args: MoveToTrashArgs): MoveToTrashOutcome`

- **用途**：把文档或整组移入回收站
- **契约来源**：`moveToTrash(args: MoveToTrashArgs): MoveToTrashOutcome`（src/lib/trash-service.ts）
- **参数**：args 含 scope / groupPath / 文档标识
- **返回**：MoveToTrashOutcome
- **异常**：TRASH_WRITE_FAILED 1301
- **约束**：回收站根在 <kbDir>/<scope>/.trash/，绝不放在用户 wiki 仓库
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { moveToTrash } from './src/lib/trash-service.js';
const r = moveToTrash({ scope: 'kisearch-memory', groupPath: '决策记录', name: '旧决策' });
```

### `installPackage(scope: string, zipBuf: Buffer, opts: InstallOptions = {}): InstallResult`

- **用途**：安装图集包
- **契约来源**：`installPackage(scope: string, zipBuf: Buffer, opts: InstallOptions = {}): InstallResult`（src/lib/atlas/package.ts）
- **参数**：zipBuf 为整包字节；opts 可带 scope 与安装选项
- **返回**：InstallResult
- **异常**：ATLAS_CODES 1401–1407（如 ENTRY_NOT_FOUND 1402 / UNSAFE_ENTRY 1404 / TOO_LARGE）
- **约束**：先全量内存校验再落盘，tmp + rename 原子替换
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { installPackage } from './src/lib/atlas/package.js';
const r = installPackage('kisearch-memory', fs.readFileSync('atlas.zip'));
```

### `handleViewsApi(req, res, url, p, principal, config, _ctx?): Promise<void>`

- **用途**：/api/views* 路由处理
- **契约来源**：`handleViewsApi(req, res, url, p, principal, config, _ctx?): Promise<void>`（src/lib/views-api.ts）
- **参数**：含 WebPrincipal 与 KiConfig；p 为子路径
- **返回**：void，直接写响应
- **异常**：SCOPE_MULTI_UNSUPPORTED 1701 / VIEW_NO_USABLE_MEMBER 1702 / VIEWS_CORRUPT 1704
- **约束**：只读 scope 下拒绝写
- **代码示例**（使用方代码，签名与源码一致）：

```ts
await handleViewsApi(req, res, url, '/api/views', principal, config);
```

### `createView / readViews`

- **用途**：创建与读取知识视图
- **契约来源**：`createView / readViews`（src/lib/scope-view.ts）
- **参数**：视图定义含成员库与 threshold
- **返回**：视图对象或列表
- **异常**：VIEWS_CORRUPT
- **约束**：views.json 为唯一落点，withViewsFile 串行化
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { createView } from './src/lib/scope-view.js';
await createView(config, { name: 'kisearch-docs', members: ['kisearch-memory', 'kisearch-xperts'] });
```
