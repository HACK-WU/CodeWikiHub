# C5-关键决策：知识资产治理专家

> 只收有明写证据（代码注释 / commit message / 设计文档）的决策；结构暗示的一律前置 `[推测]`。

## 图集错误码单独占 14xx 段而不复用 governance-errors

- **分类**：命名空间
- **决策**：图集错误码单独占 14xx 段而不复用 governance-errors
- **背景约束**：图集不属于知识治理域，14xx 空闲且可独占
- **被否决方案及理由**：复用治理错误码表；否决理由见 atlas/errors.ts 文件头
- **重新评估触发条件**：图集被并入治理域时
- **证据来源**：代码注释：src/lib/atlas/errors.ts

## 图集目录用点号前缀 .atlas，与 .relations / .trash 同口径

- **分类**：存储
- **决策**：图集目录用点号前缀 .atlas，与 .relations / .trash 同口径
- **背景约束**：避免被文档扫描当成知识内容
- **被否决方案及理由**：放在普通目录；否决理由见 atlas/paths.ts 注释
- **重新评估触发条件**：文档扫描开始排除点号目录时
- **证据来源**：代码注释：src/lib/atlas/paths.ts

## 回收站绝不放在 {sourceDir}/.ki/trash/

- **分类**：安全
- **决策**：回收站绝不放在 {sourceDir}/.ki/trash/
- **背景约束**：那会在用户 wiki 仓库凭空造目录
- **被否决方案及理由**：放源目录内；否决理由见 trash-store.ts 注释
- **重新评估触发条件**：用户明确要求回收站跟随源仓库时
- **证据来源**：代码注释：src/lib/trash-store.ts

## 图集包先全部在内存里校验完再动磁盘

- **分类**：校验
- **决策**：图集包先全部在内存里校验完再动磁盘
- **背景约束**：坏包不能装进库，且任何时刻磁盘上要么是旧包要么是新包
- **被否决方案及理由**：边校验边写；否决理由见 package.ts 文件头
- **重新评估触发条件**：出现半个包导致页面空白时
- **证据来源**：代码注释：src/lib/atlas/package.ts 文件头
