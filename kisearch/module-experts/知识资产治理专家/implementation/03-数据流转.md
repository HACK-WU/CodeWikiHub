## 流转步骤

1. 入口：HTTP /api/*、CLI ki view/ki atlas 或 /open/v1/atlas/*
2. 鉴权：WebPrincipal / 能力位 views.read / views.write
3. 编排：各自服务层读配置与 scope 路径
4. 校验：图集包做 10 步内存校验；回收站按 hasContent 判可恢复
5. 落盘：tmp + rename 原子替换，视图经 withViewsFile 串行写
6. 回传：状态 JSON 或归档记录

章节来源：[src/lib/trash-service.ts](file://src/lib/trash-service.ts)（关键符号：`moveToTrash` / `restoreFromTrash` / `purgeExpired`）
