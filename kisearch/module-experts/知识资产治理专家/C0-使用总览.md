# C0-使用总览：知识资产治理专家

## 能力清单

| 能力 | 说明 | 入口 |
|---|---|---|
| 回收站 | 删组/删文档统一落回收站，支持整组恢复与过期清理 | moveToTrash / restoreFromTrash / purgeExpired |
| 知识视图 | 多库聚合视图 CRUD 与成员元数据 | createView / handleViewsApi / ki_view_list |
| 图集包 | 整包校验、原子替换、归档与状态查询 | installPackage / atlas/paths.ts |
| CLI | ki view / ki atlas 两族命令 | src/view.ts / src/atlas.ts |
| 只读页 | /atlas iframe 三态 | Web AtlasPage.tsx（归可视化前端专家） |

## 能力边界（本专家不做什么）

- 不实现 Web 页面：AtlasPage / ViewsPage / TrashPage 归「可视化前端专家」
- 不实现文档正文检索：归检索与向量客户端专家
- 不实现 /open/v1 分发：归开放接口与鉴权专家
- 不实现知识地图内容生成：归 project-atlas skill 产物

## 已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
|---|---|---|
| 回收站恢复出空正文文档 | 只看 sizeBytes 判有内容 | 按 content.md 头部判 hasContent，空正文 restore fail-closed（TRASH_CORRUPTED） |
| 图集包上传被拒 | 包内根目录 html 不唯一或含外链 | 包根只放一份 html，且必须 baked:true、无外链 |
| 删组后无法整组恢复 | 删除未落 __group__ 归档目录 | 走 moveToTrash 的组归档分支 |
