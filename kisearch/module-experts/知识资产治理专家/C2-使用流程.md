# C2-使用流程：知识资产治理专家

## 删除并从回收站恢复

- **业务目标**：从误删到完整恢复
- **调用顺序**：moveToTrash → listTrash（读 hasContent）→ restoreFromTrash
- **事务边界**：删除与恢复各自原子落盘，不构成跨调用事务
- **预期结果**：原文与 meta 完整恢复；空正文会 fail-closed 拒绝
- **真实代码示例**：

```ts
import { moveToTrash, restoreFromTrash } from './src/lib/trash-service.js';
moveToTrash({ scope: 'kisearch-memory', groupPath: '决策记录', name: '旧决策' });
const r = restoreFromTrash({ scope: 'kisearch-memory', id: '<trash-id>' });
```
