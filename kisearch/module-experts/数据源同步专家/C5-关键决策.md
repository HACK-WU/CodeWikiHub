# C5-关键决策：数据源同步专家

> 只收有明写证据（代码注释 / commit message / 设计文档）的决策；结构暗示的一律前置 `[推测]`。

## sync 同步只做导入 + 计算待删候选，永不删除

- **分类**：安全
- **决策**：sync 同步只做导入 + 计算待删候选，永不删除
- **背景约束**：误删知识不可逆，删除必须人工确认
- **被否决方案及理由**：同步时直接删除旧条目；否决理由见 datasource.ts 文件头
- **重新评估触发条件**：产品要求全自动裁剪时
- **证据来源**：代码注释：src/lib/datasource.ts 文件头

## 远端 fetch 失败不抛，本地副本可能本来够用，由调用方带 staleWarning 继续校验

- **分类**：容错
- **决策**：远端 fetch 失败不抛，本地副本可能本来够用，由调用方带 staleWarning 继续校验
- **背景约束**：离线/网络抖动不应让同步直接失败
- **被否决方案及理由**：fetch 失败即抛；否决理由见 datasource-git.ts 注释
- **重新评估触发条件**：本地副本过期会造成错误导入时
- **证据来源**：代码注释：src/lib/datasource-git.ts

## 复用托管 clone 前先 fetch

- **分类**：正确性
- **决策**：复用托管 clone 前先 fetch
- **背景约束**：修远端新目录被判「子目录不存在」
- **被否决方案及理由**：直接复用旧 clone；否决理由见 git 历史
- **重新评估触发条件**：远端新增目录仍被误判时
- **证据来源**：commit message（reflog）：fix(datasource): 复用托管 clone 前先 fetch
