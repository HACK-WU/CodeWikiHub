## 流转步骤

1. 入口：CLI / HTTP / 调度器触发
2. 登记：读 datasource.json 拿源与计划
3. 克隆：远端源经 refreshManagedClone 拉到托管目录
4. 同步：复用 importAndPersist 导入变更
5. 裁剪：computePruneToken 算出待删候选
6. 回传：写任务台账与结果，Web 侧确认后才执行删除

章节来源：[src/lib/datasource.ts](file://src/lib/datasource.ts)（关键符号：`addDataSource` / `syncDataSource` / `startDataSourceScheduler`）
