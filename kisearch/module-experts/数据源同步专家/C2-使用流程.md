# C2-使用流程：数据源同步专家

## 配置并同步一个远端源

- **业务目标**：从登记到产出裁剪候选
- **调用顺序**：addDataSource(add-remote) → refreshManagedClone → syncDataSource → 人工确认 prune
- **事务边界**：登记、克隆、导入各阶段独立落盘
- **预期结果**：datasource.json 记录源，KB 得到新导入内容，返回待删候选列表
- **真实代码示例**：

```ts
import { addDataSource, syncDataSource } from './src/lib/datasource.js';
await addDataSource({ type: 'git', url: 'https://example.com/wiki.git', scope: 'kisearch-memory' });
const r = await syncDataSource({ id: 'wiki-git' });
```
