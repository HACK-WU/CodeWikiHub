# C1-能力契约：数据源同步专家

> 本文只写「怎么用」。实现机制、内部状态机与数据结构见 `implementation/`。
> 本次契约基于对模块入口与测试调用点的核对；未采样文件中可能存在未记录的公开方法。

### `addDataSource(input: AddDataSourceInput): Promise<AddDataSourceResult>`

- **用途**：登记或更新数据源
- **契约来源**：`addDataSource(input: AddDataSourceInput): Promise<AddDataSourceResult>`（src/lib/datasource.ts）
- **参数**：input 含类型、路径/远端 URL、scope 与可选映射
- **返回**：AddDataSourceResult
- **异常**：SOURCE_MISSING / SOURCE_NOT_DIR / SOURCE_UNREADABLE / SOURCE_EMPTY / SOURCE_IN_KB_DIR
- **约束**：路径不能落在 KB 目录内
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { addDataSource } from './src/lib/datasource.js';
const r = await addDataSource({ type: 'local', path: './docs', scope: 'kisearch-memory' });
```

### `syncDataSource(input: SyncDataSourceInput): Promise<SyncDataSourceResult>`

- **用途**：导入变更并算出待删候选
- **契约来源**：`syncDataSource(input: SyncDataSourceInput): Promise<SyncDataSourceResult>`（src/lib/datasource.ts）
- **参数**：input 含数据源 id 与同步选项
- **返回**：SyncDataSourceResult，含导入结果与 prune 候选
- **异常**：生命周期锁定时 DATASOURCE_LIFECYCLE_LOCKED 1006
- **约束**：只算候选、永不删除；复用 importAndPersist
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { syncDataSource } from './src/lib/datasource.js';
const r = await syncDataSource({ id: 'docs-local' });
```

### `refreshManagedClone(repoRoot: string, remoteBranch: string`

- **用途**：src/lib/datasource-git.ts
- **契约来源**：`refreshManagedClone(repoRoot: string, remoteBranch: string`（null): Promise<ManagedCloneRefresh>）
- **参数**：复用托管 clone 前先 fetch
- **返回**：repoRoot 为本地克隆根，remoteBranch 可空
- **异常**：ManagedCloneRefresh
- **约束**：fetch 失败不抛，由调用方带 staleWarning 继续校验
- **代码示例**（使用方代码，签名与源码一致）：

```ts
失败时本地副本可能仍够用|import { refreshManagedClone } from './src/lib/datasource-git.js';
const r = await refreshManagedClone('/root/.ki/datasources/repo', 'main');
```

### `startDataSourceScheduler(): void`

- **用途**：daemon 启动时拉起定时同步
- **契约来源**：`startDataSourceScheduler(): void`（src/lib/datasource-scheduler.ts）
- **参数**：无显式入参，读 schedule 配置
- **返回**：void
- **异常**：调度异常由任务台账记录
- **约束**：只在 HTTP/daemon 分支末尾调用
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { startDataSourceScheduler } from './src/lib/datasource-scheduler.js';
startDataSourceScheduler();
```
