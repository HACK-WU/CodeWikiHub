## 简介

本文件描述 MCP 服务专家的对外接口面：CLI 子命令、HTTP 端点、MCP 工具与错误码。

## CLI 接口

`ki mcp` 子命令：

| 子命令 | 说明 |
|--------|------|
| `ki mcp` | stdio 模式（默认），支持多实例并存 |
| `ki mcp --http [--host] [--port] [--token] [--allowed-hosts] [--web\|--no-web] [--daemon\|-d]` | HTTP 共享单例 |
| `ki mcp restart` | 重启 HTTP 单例（强制 `--http --daemon`；检测存活 stdio 实例不静默 kill；非回环做 Token 预检） |
| `ki mcp --status` | 只读状态（探测目标 CLI > lock > 配置 > 默认；lock + 探活 + Token 数量） |
| `ki mcp stop` | 关闭所有实例 + 清理 lock |
| `ki mcp token generate --scope <scope>` | 生成授权 Token（`--scope` 必填：单个/逗号分隔/`all`） |
| `ki mcp token list` | 列出全部 Token（含明文与授权 scope） |
| `ki mcp token update <id> --scope <scope>` | 修改指定 Token 的授权 scope |
| `ki mcp token delete <id>` | 删除指定 Token（立即失效） |

**全局 flag**：`--host` / `--port` / `--token` / `--allowed-hosts` / `--status` / `--web` / `--no-web` / `--daemon`；未知 flag 报 `UNKNOWN_OPTION`。

## HTTP 端点

| 端点 | 方法 | 鉴权 | 说明 |
|------|------|------|------|
| `/healthz` | GET | 免鉴权 | 返回 `{ok, name:'kisearch', pid, version, host?, port?, authFailures?}` |
| `/mcp` | POST | 非回环时 Bearer | MCP JSON-RPC 请求；带 sessionId 复用会话，initialize 新建会话；**scope 越权在此层拦截（403）** |
| `/mcp` | GET/DELETE | 非回环时 Bearer | 会话请求处理（DELETE 关闭） |
| `/api/*` | 各方法 | 同 MCP | Web UI 数据接口（`/api/import/*` 归知识索引导入专家） |
| `GET /*` | GET | 同 MCP | `--web` 时静态页面 + SPA fallback（默认 `web/dist`，`KI_WEB_DIR` 可覆盖） |
| 其他 | - | - | 404 |

**HTTP 响应码**：200（正常）、400（无有效 session ID / 非 JSON）、401（鉴权失败 + WWW-Authenticate）、403（**scope 越权** / Host 不在 `allowedHosts`；越权 scope 名只写服务端 stderr，不回显客户端）、404（路径不存在）、405（方法不允许）、500（内部错误）、503（会话数超限）。

## MCP 工具接口

13 个工具经 `server.tool(name, desc, schema, handler)` 注册（完整入参见 C1-能力契约）：

| 工具 | 类别 | 超时 | 备注 |
|------|------|------|------|
| `ki_search` | 查询 | WRITE（60s） | |
| `ki_store` | 写入 | WRITE | |
| `ki_bulk_store` | 写入 | BULK（300s） | |
| `ki_query_group` | 查询 | READ（30s） | |
| `ki_get_module_info` | 查询 | READ | |
| `ki_sync_relation` | 写入 | WRITE | 支持 `tags?` / `vector?` |
| `ki_bulk_sync_relation` | 写入 | BULK（300s） | 1-50 条，一次 embedding + 一次向量写入 |
| `ki_delete_relation` | 写入 | WRITE | |
| `ki_manage_index_create` | 管理 | WRITE | |
| `ki_manage_index_list` | 管理 | 同步（非 timeout） | 无参 → `SCOPE_LESS_TOOLS` |
| `ki_manage_index_delete` | 管理（仅空节点） | WRITE | |
| `ki_scope_list` | 管理 | 同步 | 无参 → `SCOPE_LESS_TOOLS`，输出按 authScopes 过滤 |
| `ki_tag_list` | 管理 | - | |

**错误返回契约**：handler 失败返回 `{isError: true, content: [{type:'text', text}]}`；成功返回 `{content: [{type:'text', text: JSON.stringify(data)}]}`。

## 错误码

| 错误码 | 场景 |
|--------|------|
| `MCP_HTTP_PORT_INVALID` | 配置/参数端口非法 |
| `MCP_HTTP_TOKEN_REQUIRED` | 非回环绑定未提供任何 Token（CLI/env/存储皆无） |
| `MCP_DAEMON_REQUIRES_HTTP` | `--daemon/-d` 未配合 `--http` |
| `MCP_TOKEN_SCOPE_REQUIRED` | `token generate/update` 未传 `--scope` |
| `MCP_TOKEN_ID_REQUIRED` | `token update/delete` 未传短 ID |
| `MCP_TOKEN_CORRUPT` | `~/.ki/mcp-tokens.json` 损坏或无法解析（写操作与 list 拒绝，防静默丢失） |
| `TOKEN_NOT_FOUND` | 指定的 Token 短 ID 不存在 |
| `MCP_TOKEN_GENERATE_FAILED` / `MCP_TOKEN_LIST_FAILED` / `MCP_TOKEN_UPDATE_FAILED` / `MCP_TOKEN_DELETE_FAILED` | 对应 token 子命令执行失败 |
| `MCP_TOKEN_UNKNOWN_ACTION` | 未知 token 子命令 |
| `TOOL_TIMEOUT` | 工具调用超时 |
| `UNKNOWN_OPTION` | 未知 CLI 参数 |

> 已随单 Token 托管方案移除：`MCP_TOKEN_EXISTS` / `MCP_TOKEN_EMPTY` / `MCP_TOKEN_NOT_FOUND`（旧码，现为 `TOKEN_NOT_FOUND`）/ `MCP_TOKEN_RESET_CONFIRM`。

JSON-RPC 错误码：`-32001`（鉴权失败）、`-32000`（会话相关）、`-32603`（内部错误）。HTTP 层 403 用于 scope 越权与 Host 校验失败（非 JSON-RPC 错误码）。

## 版本策略

- MCP server name 固定 `kisearch`；version 来自 `readKiVersion()`（读 package.json，失败降级 `unknown`）
- `ki mcp --status` / `/healthz` 报告 version，供客户端确认连接目标一致
- 版本变化由 `startVersionGuard` 监听 package.json 告警重启

## 结论

本专家接口面清晰：CLI（4 子命令 + 4 个 token 子命令 + 8 个 flag）+ HTTP（`/healthz` / `/mcp` / `/api/*` / 静态页）+ MCP（13 工具）+ 统一错误码，契约层已覆盖调用方式，本文件补充协议细节供排查。
