# C5-关键决策：回想内核专家

> 只收有明写证据（代码注释 / commit message / 设计文档）的决策；结构暗示的一律前置 `[推测]`。

## 内核错误码与工具错误码分成两段，用单张映射表连接

- **分类**：架构
- **决策**：内核错误码与工具错误码分成两段，用单张映射表连接
- **背景约束**：内核要能在工具层之外被单测，不能关心 MCP 语义
- **被否决方案及理由**：直接抛工具码；否决理由见 codes.ts 文件头
- **重新评估触发条件**：内核开始直接引用 MCP 语义时
- **证据来源**：代码注释：src/lib/recall/codes.ts 文件头

## 删除结果缓存与并发槽，只保留频控 20 次/分钟

- **分类**：护栏
- **决策**：删除结果缓存与并发槽，只保留频控 20 次/分钟
- **背景约束**：低频场景下并发槽只会制造 RECALL_BUSY 噪声
- **被否决方案及理由**：排队与缓存；否决理由见 limits.ts 注释
- **重新评估触发条件**：出现高并发回想需求时
- **证据来源**：代码注释：src/lib/recall/limits.ts

## 范围只有一个来源：调用方显式传入的 scope

- **分类**：可复盘
- **决策**：范围只有一个来源：调用方显式传入的 scope
- **背景约束**：否则查错库时无法区分「传错」与「默认选错」
- **被否决方案及理由**：服务端设默认库；否决理由见 targets.ts 注释（2026-11-18 拍板）
- **重新评估触发条件**：服务端开始补默认库时
- **证据来源**：代码注释：src/lib/recall/targets.ts；设计文档：CodeWikiHub/kisearch/requirements/2026-11-18-AI Agent 任务前上下文预取/design/S01_召回内核_DESIGN.md D-01-5

## ki_recall 的 zod scope 故意不标 required

- **分类**：自愈
- **决策**：ki_recall 的 zod scope 故意不标 required
- **背景约束**：标成必填时 MCP SDK 会在进入处理函数前用 invalid_union 拒绝，设计的「一次自愈」永远走不到
- **被否决方案及理由**：必填 scope；否决理由见 registerRecallTool 注释
- **重新评估触发条件**：MCP SDK 改为允许处理函数先接住缺参时
- **证据来源**：代码注释：src/lib/mcp-tools/recall.ts registerRecallTool
