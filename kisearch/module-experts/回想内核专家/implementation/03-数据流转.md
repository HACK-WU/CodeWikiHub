## 流转步骤

1. 入口：ki_recall 或分析/对话链路调用
2. 范围：resolveRecallTargets 归一 + 逐次鉴权 + 视图展开
3. 预算：resolveRecallConfig / acquireRecallSlot
4. 检索：工具循环调 5 个只读工具，候选必须真读正文
5. 组装：buildWhy / buildNextActions 产出候选与理由
6. 审计：recallLog 写 stderr，结果带 scopesUsed

章节来源：[src/lib/recall/run-recall.ts](file://src/lib/recall/run-recall.ts)（关键符号：`runGroundedRecall` / `runFastRecall` / `resolveRecallTargets`）
