# C1-能力契约：回想内核专家

> 本文只写「怎么用」。实现机制、内部状态机与数据结构见 `implementation/`。
> 本次契约基于对模块入口与测试调用点的核对；未采样文件中可能存在未记录的公开方法。

### `runGroundedRecall(input: GroundedInput): Promise<GroundedResult>`

- **用途**：跑一轮带证据的多轮回想
- **契约来源**：`runGroundedRecall(input: GroundedInput): Promise<GroundedResult>`（src/lib/recall/run-recall.ts）
- **参数**：GroundedInput 含任务画像、目标库与工具运行器
- **返回**：GroundedResult 含候选、why 与 rounds
- **异常**：内核抛 RecallKernelError；工具层映射成 RECALL_* 字符串码
- **约束**：maxRounds=30 仅为安全阀；真预算是 find.maxToolCalls
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { runGroundedRecall } from './src/lib/recall/run-recall.js';
const r = await runGroundedRecall({ task: '排查导入锁', targets, toolRunner, maxToolCalls: 15 });
```

### `runFastRecall(req: RecallRequest, deps: FastRecallDeps): Promise<CoreRecallResult>`

- **用途**：不启模型的确定性种子召回
- **契约来源**：`runFastRecall(req: RecallRequest, deps: FastRecallDeps): Promise<CoreRecallResult>`（src/lib/recall/fast-recall.ts）
- **参数**：RecallRequest 含 task / hints / exclude / limit；deps 提供检索依赖
- **返回**：CoreRecallResult
- **异常**：检索失败由 deps 上报
- **约束**：用于快路径与降级
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { runFastRecall } from './src/lib/recall/fast-recall.js';
const r = await runFastRecall({ task: '导入锁', limit: 8 }, deps);
```

### `resolveRecallTargets(args: ResolveRecallTargetsArgs): ResolveRecallTargetsResult`

- **用途**：把入参 scope 归一成物理库清单
- **契约来源**：`resolveRecallTargets(args: ResolveRecallTargetsArgs): ResolveRecallTargetsResult`（src/lib/recall/targets.ts）
- **参数**：args 含显式 scope（库名/视图/逗号串/数组）与鉴权上下文
- **返回**：targets / physicalTargets / skipped
- **异常**：全部剔除抛 NO_TARGETS；越权抛 SCOPE_FORBIDDEN
- **约束**：schema ≤8 项，解析截到 MAX_TARGETS=6，展开后 MAX_PHYSICAL=12
- **代码示例**（使用方代码，签名与源码一致）：

```ts
import { resolveRecallTargets } from './src/lib/recall/targets.js';
const t = resolveRecallTargets({ scope: 'kisearch-docs', authScopes: ['kisearch-memory'] });
```

### `executeRecall(args: RecallArgs, deps: RecallToolDeps = {})`

- **用途**：MCP 工具编排入口
- **契约来源**：`executeRecall(args: RecallArgs, deps: RecallToolDeps = {})`（src/lib/mcp-tools/recall.ts）
- **参数**：args 含可选 scope / task / hints? / exclude? / limit?
- **返回**：ok 或 fail 结果对象
- **异常**：RECALL_SCOPE_REQUIRED / RECALL_TIMEOUT / RECALL_THROTTLED 等
- **约束**：scope 故意 optional，让「一次自愈」能返回 available
- **代码示例**（使用方代码，签名与源码一致）：

```ts
const r = await client.callTool({ name: 'ki_recall', arguments: { task: '排查导入锁' } });
```

### `resolveRecallConfig / acquireRecallSlot`

- **用途**：读预算并取并发/频控槽
- **契约来源**：`resolveRecallConfig / acquireRecallSlot`（src/lib/recall/limits.ts）
- **参数**：配置来自 find 域与 recall.hardTimeoutMs
- **返回**：配置对象与槽句柄
- **异常**：RECALL_THROTTLED / RECALL_TIMEOUT
- **约束**：保留频控 20 次/分钟；已删除结果缓存与并发槽
- **代码示例**（使用方代码，签名与源码一致）：

```ts
const cfg = resolveRecallConfig(config);
await acquireRecallSlot(cfg);
```

### `buildRecallSystemPrompt / buildWhy`

- **用途**：拼装系统提示词与候选理由
- **契约来源**：`buildRecallSystemPrompt / buildWhy`（src/lib/recall/recall-prompt.ts / assemble.ts）
- **参数**：任务画像、工具清单、候选与读正文证据
- **返回**：提示词字符串与 why/nextActions
- **异常**：无
- **约束**：候选必须真读过正文才能进结论
- **代码示例**（使用方代码，签名与源码一致）：

```ts
const prompt = buildRecallSystemPrompt({ task, tools, scopes });
```
