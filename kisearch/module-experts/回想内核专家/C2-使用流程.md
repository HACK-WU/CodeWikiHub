# C2-使用流程：回想内核专家

## 一次带证据回想

- **业务目标**：从任务画像到可读候选
- **调用顺序**：ki_recall → executeRecall → resolveRecallTargets → runGroundedRecall（工具循环）→ buildWhy → recallLog
- **事务边界**：单次调用内完成，不跨调用保持状态
- **预期结果**：返回候选 + why + nextActions，scopesUsed 可审计
- **真实代码示例**：

```ts
const r = await client.callTool({ name: 'ki_recall', arguments: { scope: 'kisearch-docs', task: '排查导入锁', hints: ['interrupt.ts'] } });
```
