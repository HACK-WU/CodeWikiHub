# C1-能力契约：ki 可视化前端

> 契约来源均为函数签名/组件名（不含行号）。代码示例为使用方代码，API 签名真实，后端服务可用性以注释占位。

## 前置约束（所有能力的公共依赖）

- 前端必须与 `ki mcp --http` **同源**访问（生产：`--web` 静态托管；开发：Vite proxy 转发）。跨源直连后端不可行（未配置 CORS）
- 所有 MCP 工具调用均走 `callTool`：返回值是后端工具 `content[0].text` 的 JSON 解析结果；会话失效自动重连并重试一次
- 所有 `/api/*` 调用走 `req` 封装：非 2xx 或 body 非 JSON 时抛 `Error(error ?? "HTTP <status>")`

## 一、API 封装层（web/src/api/）

### callTool&lt;T&gt;(name, args)

- **用途**：调用后端 MCP 工具并返回解析后的 JSON（通用底层入口，新增工具调用时优先封装业务函数而非直调）
- **参数**：`name`（工具名，如 `'ki_search'`，纯透传）；`args`（工具入参对象，透传给后端）
- **返回**：`Promise<T>`——后端 `content[0].text` JSON.parse 结果；非 JSON 文本时原样返回字符串
- **异常**：重连重试一次后仍失败时抛出传输层错误（如服务未启动）
- **约束**：Client 单例；并发调用共享同一连接；不要在外层再包重试（内部已含一次重连重试）
- **契约来源**：`callTool<T = unknown>(name: string, args: Record<string, unknown>): Promise<T>`（mcpClient.ts）

```ts
// 使用方示例：调用任意 ki MCP 工具（假设 ki mcp --http 已启动）
import { callTool } from '@/api/mcpClient';
const tags = await callTool<{ ok: boolean; tags: { tag: string; count: number }[] }>('ki_tag_list', { scope: 'default' });
```

### reconnect()

- **用途**：主动丢弃当前 MCP 会话并重建（服务重启/空闲回收后恢复）
- **参数/返回**：无参；`Promise<void>`
- **契约来源**：`reconnect(): Promise<void>`（mcpClient.ts）

### kiScopeList()

- **用途**：枚举全部 scope 及其层状态
- **参数**：无
- **返回**：`ScopeListResponse { ok?, scopeMode?, count?, scopes: ScopeInfo[], vectorAvailable?, vectorReason? }`；`ScopeInfo { scope, kb, vector, registered, wikiCount }`
- **行为语义**：`vectorAvailable === false` 表示向量层不可用（如被导入进程持锁），列表已**降级为仅 KB 层枚举**——调用方不应据此报错，应展示 `vectorReason` 提示
- **契约来源**：`kiScopeList(): Promise<ScopeListResponse>`（mcpClient.ts）；后端 `ki_scope_list`

### kiSearch(query, opts?)

- **用途**：语义混合检索（向量 + BM25 + RRF），固定 `include_original: true` 交付原文
- **参数**：`query`（自然语言）；`opts.scope`（不传则后端用 default）；`opts.tags`（string[]，**传空数组 = 不带 tags 参数 = 后端默认 ki-search 过滤；传具体 tag = 精确过滤**）；`opts.threshold`（0–1 相似度阈值，`0/undefined` = 不过滤）；`opts.limit`（条数上限）
- **返回**：`SearchResult { results?: SearchHit[] }`，`SearchHit { group?, relation?, score?, original?, originalRetrieved?, deduplicated?, tag?, memoryId?, ... }`
- **异常**：后端业务失败（如 `ok === false`）**不抛异常**——调用方需自行检查 `res.ok === false` 并读取 `res.error`（SearchPage 即此模式）
- **约束**：空 query 由调用方拦截（组件层已做）
- **契约来源**：`kiSearch(query: string, opts?): Promise<SearchResult>`（mcpClient.ts）；后端 `ki_search`

### kiGetModuleInfo(scope, group, relation)

- **用途**：按 group + relation 精确反查文档原文（原文抽屉的取数入口）
- **返回**：`ModuleInfoResult { ok?, content?, ... }`——`content` 为 Markdown 原文
- **契约来源**：`kiGetModuleInfo(scope, group, relation): Promise<ModuleInfoResult>`（mcpClient.ts）；后端 `ki_get_module_info`

### kiStore(args)

- **用途**：写入一条记忆片段（无 Group 结构）
- **参数**：`{ scope, content, tags? }`——注意映射到后端参数名 `text`
- **契约来源**：`kiStore(args): Promise<StoreResult>`（mcpClient.ts）；后端 `ki_store`。（当前页面未使用，作为封装能力保留）

### kiSyncRelation(args)

- **用途**：写入/覆盖一个关系文档（Group 树 + relations-cache + local KB + 可选向量层）
- **参数**：`{ scope, group, relation, content, vector?, tags? }`——`content` 映射到后端 `module_info`；`vector: false` 时仅写 KB 文本层不向量化；`tags` 逗号拼接下发
- **行为语义**：同 group+relation 重复写入 = **覆盖更新**（幂等）
- **契约来源**：`kiSyncRelation(args): Promise<StoreResult>`（mcpClient.ts）；后端 `ki_sync_relation`

### getHealth()

- **用途**：健康检查。**返回**：`{ ok, report?: { pass?, fail?, warn?, items: HealthItem[] }, error? }`，`HealthItem { name, status: 'pass'|'warn'|'fail', detail?, message? }`
- **行为语义**：`ok === true` 但 `report.fail > 0` 表示服务在线但健康异常（前端徽标区分展示）
- **契约来源**：`getHealth(): Promise<HealthResponse>`（httpApi.ts）；后端 `/api/health`

### getDocList(scope, opts?)

- **用途**：文档列表 + 完整 Group 清单 + 自定义 tag 清单（一接口三用途）
- **参数**：`opts.q`（文件名/路径模糊，后端跨组匹配）；`opts.group`（**传则返回该 group 全量文档，不受 500 条分页截断**）；`opts.tag`（relation.tags 精确匹配）
- **返回**：`{ ok, scope, docs: DocItem[], total, truncated?, groups?: { name, count }[], tags?: string[] }`
- **行为语义**：不传 `group` 时返回当前 scope 全量（`truncated: true` 表示被 500 条分页截断）；`groups`/`tags` 始终是全量统计、不受 docs 截断影响
- **契约来源**：`getDocList(scope, opts?): Promise<DocListResponse>`（httpApi.ts）；后端 `/api/doc/list`

### uploadFiles(scope, files)

- **用途**：上传文件内容换取 `uploadId`（导入第一阶段）
- **参数**：`files: { name, content }[]`——`content` 为 **base64** 字符串；`size` 由封装内部按 base64→字节估算
- **返回**：`{ ok, uploadId?, files?, total?, errors?: { name, error }[], error? }`；`ok === true` 但 `errors` 非空 = 部分文件被拒（调用方需同时处理两者）
- **约束**：单文件 ≤ 1MB（后端限制）；仅 .md/.markdown/.mdx
- **契约来源**：`uploadFiles(scope, files): Promise<UploadResponse>`（httpApi.ts）；后端 `/api/import/upload`

### runImport(args)

- **用途**：触发异步导入任务（导入第二阶段）
- **参数**：`{ scope, uploadId, group?, chunkSize?, chunkOverlap?, vector?, tags? }`——`group` 为目标 Group 路径前缀，**缺省则使用 scope 名作为根**；`tags` 为逗号分隔字符串（注意与 uploadFiles 的数组形态不同）
- **返回**：`{ ok, jobId?, error? }`
- **契约来源**：`runImport(args): Promise<RunImportResponse>`（httpApi.ts）；后端 `/api/import/run`

### getImportStatus(jobId)

- **用途**：轮询导入任务状态（页面层 2s 间隔）
- **返回**：`{ ok, job?: ImportJob, error? }`；`ImportJob.state: 'running'|'done'|'failed'`，running 时含 `phase` 与 `progress { done, total }`；done 时 `result.stats { total, imported, vectorized, errors }`
- **契约来源**：`getImportStatus(jobId): Promise<StatusResponse>`（httpApi.ts）；后端 `/api/import/status`

### fetchTags(scope?)

- **用途**：向量层 tag 列表（**已排除 ki-search/ki-relation/ki-path 内部保留 tag**），供搜索/写入/导入的 tag 选择器
- **返回**：`{ ok, tags: { tag, count }[], scope }`
- **约束**：Browse 页的 tag 过滤**不使用本接口**（用 getDocList 返回的 KB 层 tags，见已知坑）
- **契约来源**：`fetchTags(scope?): Promise<TagsResponse>`（httpApi.ts）；后端 `/api/tags`

## 二、数据 Hooks（web/src/lib/hooks.ts）

> 基于 TanStack Query；queryKey 约定：`['health']`、`['scopeList']`、`['docList', scope(, 'group'|'search', …)]`。刷新 = `queryClient.invalidateQueries()`。

### useHealth() —— `queryKey ['health']`，staleTime 60s，retry false
仅加载时查一次，避免频繁触发后端 zvec 探活。**契约来源**：`useHealth()`。

### useScopeList() —— `queryKey ['scopeList']`，staleTime 30s
**契约来源**：`useScopeList()`。

### useDocList(scope) —— `queryKey ['docList', scope]`，staleTime 30s
一次拉取当前 scope 全量文档；文件名过滤由前端内存完成。**契约来源**：`useDocList(scope: string)`。

### useGroupDocs(scope, group, tag?) —— `queryKey ['docList', scope, 'group', group, tag]`，`enabled: !!group`
指定 group 的完整文档列表（不受 500 条截断），可选 tag 过滤；group 为 null 时不发请求。**契约来源**：`useGroupDocs(scope, group: string | null, tag?: string)`。

```ts
// 使用方示例：在任意组件内消费（已处于 QueryClientProvider + ScopeProvider 下）
import { useDocList, useGroupDocs } from '@/lib/hooks';
const { data, isLoading } = useDocList('default');
const groupQuery = useGroupDocs('default', activeGroup || null, selectedTag || undefined);
```

## 三、全局状态（web/src/lib/scopeContext.tsx）

### &lt;ScopeProvider&gt;
- **用途**：全局 scope 上下文；localStorage 键 `ki-web:scope` 持久化；读写失败静默回退 `'default'`
- **约束**：必须包裹在使用 `useScope`/`useScopeValue` 的组件外层（App.tsx 已置顶）；切换 scope 后，依赖 `useDocList(scope)` 等的页面因 queryKey 变化自动重新拉取
- **契约来源**：`ScopeProvider({ children })`

### useScope() / useScopeValue()
- `useScope(): { scope: string; setScope: (s: string) => void }`；`useScopeValue(): string`（只读便捷版）
- **契约来源**：`useScope()` / `useScopeValue()`

```ts
// 使用方示例
const { scope, setScope } = useScope();
```

## 四、输入校验（web/src/lib/validators.ts）

> 与后端校验对齐：拒路径分隔符 `/` `\` 与穿越 `..`；tag 禁逗号（逗号是 tag 分隔符）。`isXxx` 返回布尔供逻辑分支，`xxxError` 返回中文文案供 UI 展示（空串/空白也判错）。

| 函数 | 用途 | 契约来源 |
|---|---|---|
| `isUnsafeRelationName(value)` | relation 是否含 `/` `\` `..` | validators.ts |
| `isInvalidGroupPath(value)` | group 路径合法性（禁 `\` `..`、`/` 开头、空段） | validators.ts |
| `isInvalidTag(value)` | tag 合法性（禁逗号/分隔符/穿越/空白） | validators.ts |
| `groupError(value): string \| null` | group 校验文案 | validators.ts |
| `relationError(value): string \| null` | relation 校验文案 | validators.ts |
| `tagError(value): string \| null` | tag 校验文案 | validators.ts |

```ts
// 使用方示例（ImportPage 模式：空值不报错、非空才实时校验）
import { groupError } from '@/lib/validators';
const groupErr = group.trim() ? groupError(group) : null;
if (groupErr) { setError(groupErr); return; }
```

## 五、通用组件（web/src/components/）

### &lt;ModuleDrawer scope module group? initialContent? fetcher? onClose /&gt;
- **用途**：原文查看抽屉（Browse/Search 共用）
- **参数行为语义**：`initialContent` 有值则**不发起请求**（搜索结果自带原文的快路径）；否则需同时提供 `group` + `fetcher`（默认注入 `kiGetModuleInfo` 包装）拉取原文；`content !== null` 后不再重复请求
- **交互**：ESC 关闭、scrim 点击关闭、body 滚动锁定、全屏切换、复制（Clipboard API 优先，非安全上下文回退 execCommand；复制失败显示独立提示条不覆盖正文）
- **契约来源**：`ModuleDrawer(props: ModuleDrawerProps)`

```tsx
// 使用方示例（BrowsePage 模式）
<ModuleDrawer scope={scope} module={doc.name} group={doc.group}
  onClose={() => setViewing(null)} fetcher={kiGetModuleInfo} />
```

### &lt;GroupPathSelect scope value onChange placeholder? hint? error? /&gt;
- **用途**：Group 路径 combobox（下拉递归树选已有 + 输入新建），Import/Write/Browse 三处复用
- **参数行为语义**：数据来自 `useDocList(scope).groups`（不受 docs 分页截断，空 Group 也显示）；输入值不在树中时输入框加 `--new` 样式、底部提示「将新建 Group」，**回车或下拉选中才算确认**（`✓` 标记 + `--confirmed` 样式）；`error` 非空时红框并替代 hint
- **契约来源**：`GroupPathSelect(props: GroupPathSelectProps)`

### &lt;MarkdownPreview text /&gt; 与 renderMarkdownHtml(md)
- **用途**：Markdown 渲染（marked GFM + breaks；` ```mermaid ` 代码块异步渲染为图表，动态 import 仅在含 mermaid 时加载 chunk）
- **行为语义/安全约束**：**丢弃文档内嵌原始 HTML**（`renderer.html = () => ''`，防样式注入/XSS）；mermaid 渲染失败保留源码块
- **约束**：内部经 `dangerouslySetInnerHTML` 渲染——正因为 HTML 已被丢弃才是安全的；若放宽 renderer.html 必须同步引入 sanitize
- **契约来源**：`MarkdownPreview({ text })` / `renderMarkdownHtml(md: string): string`

### &lt;ScopeSelect /&gt; 与 &lt;HealthBanner /&gt;
- `ScopeSelect`：顶栏 scope 下拉；scope 列表为空时兜底显示 `default`；向量层降级时 title 悬停提示原因。**契约来源**：`ScopeSelect()`
- `HealthBanner`：`/api/health` 失败时显示启动指引横幅（`ki mcp --http --web`）+ 重试按钮；健康则渲染 null。**契约来源**：`HealthBanner()`

## 六、页面级能力（路由入口，web/src/pages/）

> 页面是路由级组合（`/`、`/browse`、`/search`、`/import`、`/write`，见 routes.tsx），内部契约已由上述 API/hooks/组件覆盖，端到端操作序列见 [C2-使用流程.md](C2-使用流程.md)。特殊交互行为：

- **BrowsePage**：父目录点击仅展开/折叠不选中；叶子 group 选中并请求该组文档；全局搜索词非空时展示跨组搜索结果（limit 2000）；「刷新」按钮在任一请求在途时禁用（useIsFetching）
- **SearchPage**：tag 语义——选中具体 tag = 精确过滤；未选 = 默认 `['ki-search']`；后端 `ok === false` 不抛异常、走 error 展示
- **ImportPage**：上传读取为 base64（`btoa(unescape(encodeURIComponent(text)))`）；目录选择器动态创建原生 input（绕开 macOS webkitdirectory 问题）；导入中 2s 轮询，任务失效即转 failed
- **WritePage**：提交前 group/relation/markdown 非空 + 格式校验；成功后清空表单
- **DashboardPage**：统计派生自 scopeList 与 docList，无独立接口
