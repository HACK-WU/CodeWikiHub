## 简介

本文如实记录 ki-web 的测试现状：**web/ 目录内零单元测试、零 E2E**。自动验证仅有 TypeScript 编译期检查；行为正确性依赖手动浏览器验证与后端测试的契约级间接覆盖。

## 类型检查（唯一的自动验证）

```bash
cd web
npm run typecheck        # tsc --noEmit
npm run build            # 构建前也先跑 tsc --noEmit（脚本内置）
```

- 覆盖：全部 `.ts/.tsx` 的类型正确性（含 API 层返回类型、组件 props、状态机字段）
- 不覆盖：运行时行为（连接自愈、树折叠、轮询、浏览器兼容）
- 注意：`web/tsconfig.json` 独立于根 tsconfig，检查前端必须在 `web/` 目录内执行

章节来源：[package.json](file://web/package.json)（关键符号：`typecheck`、`build` 脚本）

## 后端测试对前端契约的间接覆盖

前端消费的 `/api/*` 契约有后端测试守护，契约破坏会在后端测试先暴露：

| 后端测试 | 守护的契约 | 前端受益点 |
|---|---|---|
| `npx jiti test/mcp-http-api.test.ts` | `/api/health`、`/api/doc/list`、`/api/import/*`、`/api/tags` 行为 | httpApi.ts 六函数的返回结构不被静默破坏 |
| `npx jiti test/mcp-http.test.ts` | `/mcp` 端点、鉴权、SPA fallback/静态托管 | mcpClient.ts 通道与 `--web` 部署形态 |

运行：仓库根目录 `npx jiti test/<name>.test.ts`（无需网络；部分用例依赖向量库锁状态）。

**边界**：后端测试只保证「后端按契约返回」，不保证「前端类型声明与契约一致」——两份类型是手工维护的，仍可能漂移（见 05-接口.md 契约耦合表）。

章节来源：[mcp-http-api.test.ts](file://test/mcp-http-api.test.ts)（关键符号：套件覆盖的端点）；[mcp-http.test.ts](file://test/mcp-http.test.ts)（关键符号：静态托管/鉴权用例）

## 手动验证路径

每次改动后的最小手动回归清单（需 `ki mcp --http` 运行中）：

1. **总览**：徽标绿/黄/红三态正确；scope 表格与统计卡有数
2. **浏览**：树展开/折叠、点叶子组出文档、搜索框跨组命中、tag 过滤、抽屉开/复制/ESC/全屏
3. **搜索**：默认 ki-search 结果带原文；选具体 tag 过滤生效；threshold=0.9 以上基本无结果（合理性）
4. **导入**：传 2 个小 .md → 进度条 → done 统计；Browse「刷新」可见新 Group；重复导入同文件不报错（幂等）
5. **写入**：非法 group（`a/../b`）红框拦截；正常写入成功提示；搜索可召回
6. **全局**：切 scope 数据刷新且刷新页面后保持；暗色主题切换持久；dev 模式（5173）与生产（7423 同源）各跑一遍 1–5

## 测试缺口与建议

| 缺口 | 风险 | 建议优先级 |
|---|---|---|
| validators 零测试 | 校验规则是安全边界（路径穿越拦截），回归靠手测 | 高：纯函数，vitest + 6 函数表驱动用例成本极低 |
| renderMarkdownHtml 零测试 | XSS 防线（HTML 丢弃）无回归保护 | 高：断言 `<script>` 输入输出为空 |
| 树构建函数零测试 | 唯一根上提/空段过滤逻辑易改坏 | 中 |
| 无 E2E | 导入→搜索主链路跨页行为 | 低（成本高，现有手测清单可兜底） |

章节来源：[validators.ts](file://web/src/lib/validators.ts)（关键符号：`isInvalidGroupPath`、`isInvalidTag`）；[MarkdownPreview.tsx](file://web/src/components/MarkdownPreview.tsx)（关键符号：`renderMarkdownHtml`）

## 结论

ki-web 测试现状为「类型检查 + 后端契约测试间接覆盖 + 手动回归清单」。若要补测试，优先级最高的是 `validators.ts` 与 `renderMarkdownHtml` 的纯函数单测（两者都是安全边界且几乎零成本）；行为层测试在页面稳定前不建议投入。
