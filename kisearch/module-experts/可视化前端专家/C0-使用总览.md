# C0-使用总览：ki 可视化前端（ki-web）

> 黑盒使用文档：说明前端能干什么、边界在哪、已知坑。深入实现前先读 [implementation/01-架构.md](implementation/01-架构.md)。

## 能力清单

| 能力 | 入口（路由） | 后端依赖 | 说明 |
|---|---|---|---|
| 服务总览 | `/`（DashboardPage） | `/api/health`、`ki_scope_list`、`/api/doc/list` | 统计卡（scopes/KB 文档/向量层/注册数）+ 当前 scope 概览 + scope 表格 + 健康检查列表 |
| 知识库浏览 | `/browse`（BrowsePage） | `/api/doc/list`、`ki_get_module_info` | 左 Group 递归树 + 右文档列表 + 原文抽屉；支持文件名模糊搜索、tag 过滤、展开/折叠、刷新 |
| 语义搜索 | `/search`（SearchPage） | `ki_search`（include_original=true）、`/api/tags` | 自然语言混合检索；tag 过滤、threshold 滑杆、limit；结果点击查看原文 |
| 上传导入 | `/import`（ImportPage） | `/api/import/upload` → `/api/import/run` → `/api/import/status` | 拖拽/选择 .md 文件或目录；Group 路径、tags、切分参数、向量化开关；2s 轮询进度 |
| 知识写入 | `/write`（WritePage） | `ki_sync_relation`、`/api/tags` | Group + Relation + Markdown 正文 + tags + 向量化开关；实时校验 + Markdown 预览 |
| 全局 scope 切换 | 顶栏（ScopeSelect） | `ki_scope_list` | 全局上下文，localStorage 持久化，切换后各页面数据即时刷新 |
| 服务健康徽标/横幅 | 顶栏 + Dashboard（ServiceBadge/HealthBanner） | `/api/health` | 未就绪时横幅提示 `ki mcp --http --web` 启动指引 |
| 原文抽屉 | ModuleDrawer（Browse/Search 共用） | `ki_get_module_info` 或搜索自带 original | 右侧滑出、ESC 关闭、全屏、复制（Clipboard API + execCommand 回退） |
| Markdown 渲染 | MarkdownPreview | 无（纯前端） | marked GFM + mermaid 图表（动态加载）；**丢弃内嵌原始 HTML 防注入** |
| 主题切换 | 侧边栏底部（useTheme） | 无 | light/dark，`<body data-theme>`，localStorage 持久化 |

## 能力边界（不做什么）

- **不启动/不停止后端服务**：前端只检测健康状态并给出 `ki mcp --http --web` 指引（HealthBanner 明确注释此设计）
- **不做用户系统/鉴权交互**：依赖后端部署形态（本机/可信网络）；token 鉴权由后端承担，前端不管理 token
- **不做文档删除/编辑回写**：只有写入（新增/覆盖）与浏览，无删除 UI
- **拖拽目录导入 V1 简化**：拖拽仅收文件，目录导入走「上传目录」按钮（webkitdirectory）；深层目录递归由浏览器 input 承担
- **搜索不做分页**：limit 5/10/20 截断；文档列表全量拉取 + 前端内存过滤（>500 条时后端分页截断，指定 group 可拿全量）
- **无移动端适配承诺**：CSS 面向桌面浏览器；无单元测试、无 E2E

## 已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
|---|---|---|
| 页面全部接口失败，横幅提示「MCP HTTP 未就绪」 | 后端 `ki mcp --http` 未启动，或 dev 模式下未起 7423 服务 | 先启动 `ki mcp --http --web`（生产）或 `ki mcp --http` + `npm run dev`（开发） |
| 搜索报错「worker not open / 锁」类信息 | 向量库被导入进程持锁或引擎空闲回收期 | 属后端状态，稍后重试；前端已对 MCP 会话失效做自动重连一次 |
| scope 切了但数据没变 | 页面缓存未失效 | react-query staleTime 30s；点 Browse 页「刷新」按钮（invalidateQueries）强制拉取 |
| 导入完成后 Browse 看不到新 Group | docList 缓存 30s 未过期 | 点「刷新」按钮；无需重启服务 |
| Markdown 预览里 HTML 标签消失 | 设计行为：`renderer.html = () => ''` 丢弃原始 HTML（防 XSS） | 知识文档不要依赖内嵌 HTML，用 Markdown 语法 |
| Group 输入被红框拦截 | 前端 validators 与后端对齐：禁 `\` `..`、`/` 开头、连续斜杠、tag 禁逗号 | 按提示修改；规则与后端 resolveGroupPath 一致，绕过前端也会被后端拒 |
| dev 模式下 tag/搜索可用但页面白屏 | 直接访问 5173 而 7423 未起 | dev 代理 `/api` `/mcp` `/healthz` → 127.0.0.1:7423，需后端在跑 |
