# 仓库与需求台账结构

- git 根 `knowledge-indexer`（TS CLI + MCP server + Web 前端），主分支 `master`。
- `CodeWikiHub/` 是**独立 git 仓库**（内嵌）：知识库内容与需求包都在这。
  - 需求包 `CodeWikiHub/kisearch/requirements/<YYYY-MM-DD-需求名>/`（`requirement.md` + `design/` + `review/`）
  - `kisearch-memory` 的 wiki 落点：`CodeWikiHub/kisearch/memory/`（改记忆文件会与 ki 双向可见）
- 根仓库侧台账：`sub-requirements/`（需求包副本）、`.plans/<日期-主题>/`（计划 + 自评审）、`.requirements/acceptance/<需求>/reports/`（验收报告）、`.module-experts/<专家名>/`（模块专家资产）、`.delivery/`（并行交付：ownership / 预合并校验）、`web/`（Vite + React）、`test/`（jiti 直跑）。
- 源码分层：`src/` 顶层是 CLI 命令族（scope / group / doc / search / config …），`src/lib/` 是能力层（store / config / import / search / vector / mcp-http / chat），`src/lib/mcp-tools/` 是 MCP 工具注册。
- 校验口径：`npx jiti test/<x>.test.ts` 直接跑 TS（无需构建），`npx tsc -p tsconfig.src.json --noEmit` 类型检查。
