「AI 查找」底栏主按钮只要出结果就可点：0 勾选时文案为「确认」，语义是"只固定本次结论、不写引用记录"；有勾选时仍为「加入所选 N 篇」，走 addRefs 并带出 summary。原实现 0 选中时禁用且文案「未选择」，用户只剩「取消」，等于否认这次查找发生过。
- 备选: 仅在 0 候选时放开（有候选但全取消时仍禁用）→ 否决，用户要求"无论是否有结果都确认"
- 决定: state=done 且有写权限即可点；0 选中只调 fixSummary（幂等，自动固定已成功的直接收起，不重复写库）
- 边界: loading / error 仍禁用（没有结论可固定）；只读账号仍禁用（固定总结本身是写操作）；固定失败**不关面板**，错误留在原地（fail-loud，不假装存好了）
