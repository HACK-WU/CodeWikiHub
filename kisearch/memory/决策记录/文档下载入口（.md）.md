浏览页阅读器头部新增「下载」按钮（复制之后、删除之前），把当前正文存成 `<文档名>.md`。纯前端实现，无后端接口。
- 三个拍板口径：① 下载内容是 `displayedContent`（与「复制」同源），不重新向服务端取原文——否则会出现「复制到片段、下载到全文」两套事实；② 文件名净化 `[\\/:*?"<>|]` 防 Windows 非法字符，同名冲突交给浏览器加序号；③ 正文加载失败只显示搜索命中片段时，文件名加「-命中片段」后缀（`showingFallback` 判定），避免被当全文存档。
- 门禁：与「复制」同为读动作，只受 `docActionsDisabled`（全库搜索结果态）约束，**不挂** `docWriteDisabled`——只读库也能下载。
- 实现要点：`new Blob([text], {type:'text/markdown;charset=utf-8'})` + objectURL + 挂到 `document.body` 再 click（Firefox 对游离节点不触发 download）；objectURL 必须 `revokeObjectURL` 且**延迟一拍**（click 返回后浏览器可能还在读，Safari 尤甚）。
- 窄屏收起阈值 820 → 880（每加一枚文字动作约 +60~120px，只许单调上调；早收起只多一次点击，晚收起会把动作条折成两行）。
- 下载是查看器自身能力，未上升为页面 prop：检索页/数据源页/任务页/AI 引用预览自动获得（它们本来就渲染「复制」）。
- 验证：web 1154/1154（新增 doc-download-ui 守卫 7 条）、tsc/build ✓；**未做真机点击验证**（Blob 下载行为未实测）。
