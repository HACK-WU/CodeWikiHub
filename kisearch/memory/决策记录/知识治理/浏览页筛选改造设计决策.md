浏览页筛选改造（时间/标签/事件 · 条件构造器）技术设计已定稿（2026-11-20），文档：CodeWikiHub/kisearch/requirements/2026-11-20-browse-filter-change/design/（DESIGN.md + S01_timestamp + S02_doclist-filter + S03_condition-builder）。
- S-01 数据层：Relation 增可选 createdAt/updatedAt（毫秒）。覆盖导入复用 isContentUnchanged（现仅 incremental 模式调用，import.ts 约 1400 行），需下沉到 overwrite 分支按条件判定，内容未变不刷 updatedAt；元数据写（lifecycle/visibility/event 绑定/置顶/回收站恢复）一律不刷。老数据缺省=未知，不命中 since 且不回填。
- S-02 接口：GET /api/doc/list 增 tags(逗号 OR)/since(1h|6h|24h|7d)/event(evt|none)/sort(recent|default)，非法值 400；docs 透出 createdAt/updatedAt/eventId；since 存在时返回 undatedExcluded（视图按桶）。参数解析上移到 handleDocList（视图分支之前），保证非法值只 400 一次。
- S-03 前端：新组件 ConditionBuilder + ConditionChips + lib/browseFilters + lib/useEventOptions；两段式提交（Enter 确认本条写 pending，Ctrl/⌘+Enter 应用全部）；焦点常驻面板搜索框 + is-focused 高亮；有未应用修改时点外部不关闭；筛选本期不进 URL。
- 视图支持：接口层天然逐成员（handleDocList 视图分支用同一 URL 逐成员 buildDocListPayload，参数自动下发），前提是过滤只从 URL query 解析；前端目录树 useGroupDocs 的 queryKey 必须带过滤参数；事件候选在视图下逐成员调 listEvents（治理端点无视图逻辑，传视图名会空），单成员失败只禁该库选项。
- 验收要点：连导两次 updatedAt 不变；视图各桶 total 为过滤后计数；筛选态按 max(createdAt,updatedAt) 倒序 + 新增/更新徽标；老数据显示 undatedExcluded 篇数。
