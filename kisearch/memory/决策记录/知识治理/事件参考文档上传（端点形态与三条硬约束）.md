事件详情「参考文档」卡支持上传本地文件并自动挂为该事件参考文档；服务端顺序固定为「先校验 → 再导入 → 再建引用」，前端只做 UI 与预检。

- 端点: `POST /api/governance/events/:id/refs/upload`（`src/lib/governance-http.ts` 的 `uploadEventRefDocs`），body `{ files:[{name,content(base64)}], group? }`，202 返回 `jobId` + `accepted/rejected`
- 三条硬约束: ① 名额(REF_LIMIT=50)/数量(≤10)/格式/大小/带路径/重名 全部在写暂存目录前拒绝，否则会出现「文档已入库但没进参考文档」的孤儿文档；② `governance-http.ts` **不能静态 import `mcp-http-api.js`**（反向已存在，会成环），导入内核只能 handler 内 `await import()`；③ 事件上传必须 `wikiWriteback:false`，不在用户 wiki 目录凭空生成文件
- 落点缺省 `事件参考/{短号}-{标题}`（body.group 可覆盖）；同名走 `conflictMode:'skip'`，但被 skip 的文档若已在库中仍建立引用
- 结果回执: `Job.refsBinding`（added/skipped/failed/expected），**晚于 `state=done` 写入**，前端需短轮询宽限（否则永远读到 undefined）
- 复用: 暂存目录 `~/.ki/import-uploads/<uuid>` 导入后**不删**（会被登记为 group 的 `source.dir`，后续编辑/同步要读原文）；逐文件校验判据抽到 `src/lib/import-upload-policy.ts`，与 `/api/import/upload` 共用同一份
- 位置: `src/lib/governance-http.ts`、`src/lib/import-upload-policy.ts`、`src/lib/mcp-http-api.ts`（Job.refsBinding + status 透出）、`web/src/components/governance/EventRefUploadModal.tsx`
