事件详情「追问这次分析」的输入框从单行 `<input>` 改为多行 `<textarea>`，交互口径对齐 AI 对话页（`ChatPanel` 的 composer）。

- **Enter 发送 / Shift+Enter 换行**：`e.shiftKey` 的判断必须在 `e.preventDefault()` **之前**，否则换行会被一起拦掉；`e.nativeEvent.isComposing` 一律放行（中文上屏的 Enter 不能当发送）。
- **自动增高**：先 `height='auto'` 再取 `scrollHeight`（删行/清空才收得回去），上下限写 CSS 不写死在 JS —— `.gov-ask__ta` 的 `min-height:30px`（与按钮同高）/ `max-height:134px`（≈6 行，13px × 1.6 + padding）。
- **发送键贴底**：`.gov-ask__input` 由默认 `stretch` 改 `align-items: flex-end`。`stretch` 会把按钮拉成与输入框等高，居中则悬在中间；用户看图后明确要求「在最底下」。
- 发送后 `question` 清空 → `useEffect([question])` 重算高度，输入框回落单行。
- 位置：`web/src/components/governance/event-detail/AskBlock.tsx`、`web/src/styles/governance.css`。
- 测试：`web/test/ask-multiline.test.mjs` 9 例（元素类型 / 回车语义 / 高度跟随 / 贴底）。
- 边界：触屏无 Shift 键，无法输入换行（桌面优先场景，未处理）；字数上限仍 4000，沿用 `maxLength`。
