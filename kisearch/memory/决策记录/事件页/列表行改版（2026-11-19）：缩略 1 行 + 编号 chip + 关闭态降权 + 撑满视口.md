事件页左侧列表 2026-11-19 整体改版：标题缩略 1 行、编号改 chip 并从标题行移入 meta 行、行间实色 1px 分隔、已收口改中性灰 + 字重降权、列表撑满视口（页面不滚 + 双栏内滚），并在搜索行加刷新按钮。
- 位置: `web/src/pages/EventsPage.tsx`（renderEventRow / noscroll effect / loadList）、`web/src/styles/governance.css`（.gov-page--fill / .gov-pane--list / .gov-ev / .gov-ev__id / .gov-ev--closed / .gov-evgroup / .gov-ev__sep）
- 高度（第四版，**推翻前三版**）: 列表视图给 `.ki-content` 挂 `ki-content--noscroll`，高度链 `.gov-page--fill → .gov-split(stretch) → .gov-pane--list(height:100%)` 一路 flex 撑满，左列表与右详情各自内滚。被推翻的旧判断：①固定 560px ②`min(760px, 100vh-220)` ③`100vh-200px` + sticky 吸附 —— 三代都是拿固定值估页头高度，猜少底部跑出视口且永远看不到、猜多滚到底还留半屏空白。**必须摘掉 noscroll 的两处**：`tab !== 'list'`（事件类型是长表格）、`matchMedia('(max-width: 1080px)')`（单列上下堆叠，禁滚会让下半页永远看不到）。实测 1440×900：`paneBottom 884`（距视口底 16px）、页面 scrollHeight === clientHeight、右栏 overflow-y auto 且 scrollHeight 978 > 751。
- 密度: 行高 60~120px（随标题折行跳动）→ 固定 57px；900px 视口可视条目 6 → 11，1200px 8 → 17
- 标题: `-webkit-line-clamp: 1`；完整标题走 `title` 属性与右栏详情
- 编号: 正文裸数字（`#` 只在 title / aria-label），样式抄详情页 `.gov-summary__id`（mono 10.5/600、1px 细框、`--ki-color-surface-muted` 底、radius 4）；已关闭项退成无框裸数字
- 分隔: `.gov-ev + .gov-ev` 用 `--gov-line`(#dcdcdc)，必须比 `--ki-color-border` 深一档，否则灰底行之间看不见
- 关闭态: `--gov-closed-*` 中性灰（bg #fafafa / fg #8c8c8c / weak #9c9c9c）；标题字重 650 → 400 —— 让它「退后」的是字重，不是灰块
- 刷新: 搜索行右侧图标按钮（只读账号可用），同时刷列表与详情（只刷列表会让人以为「刷了还是旧的」）；`loadList` 加请求序号丢弃过期响应
