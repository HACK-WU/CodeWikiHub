对多行文本做「截断 + 追加提示行」的归一函数，**提示行长度必须从字符预算里扣掉**，否则不幂等：3000 字内容 + 13 字提示行 = 3013 字，下次归一又超限 → 再截一次 → 每次读盘都改写一遍（`updatedAt` 抖动、缓存失效）。

- 正确做法：先判 `willTruncate = 行数超 || 字符超`，成立时 `budget = MAX_CHARS - (MARK.length + 1)`，再按 budget 切内容。
- 另：字符截断必须**回退到上一个 `\n`**，否则会留下半行文字（树形看着像坏了）。
- 幂等自检：任何「normalize 会在原值上追加东西」的函数，都要能对自身输出再跑一次而结果不变——`src/lib/events/data-flow.ts` 的单测里有 4 例专测（正常 / 超行 / 超字 / CRLF）。
