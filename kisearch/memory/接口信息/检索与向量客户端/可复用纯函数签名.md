推荐使用面（CLI 与 MCP 共用）：
- executeSearch({scope?,query,limit?,threshold?,tags?,includeOriginal?}) → {ok,scope,results:SearchHit[]} | {ok:false,error,degraded?}
- executeStore({scope?,text,tags?}) → {ok,scope,docId} | {ok:false,error}
- executeBulkStore({scope?,inputFile}) → {ok,scope,total,succeeded,failed,results} | {ok:false,error}
- executeDocList({scope,tags?,limit?,full?}) → {ok,scope,tags,count,docs} | {ok:false,error,degraded?}
- executeDocDelete({scope,ids,yes}) → {ok,scope,requested,deleted,errors} | {ok:false,error,requireConfirm?,willDelete?,notFound?,scopeMismatch?}
- executeTagList({scope,scanLimit?}) → {ok,scope,count,scanned,truncated,tags} | {ok:false,error,degraded?}
向量层原语（被导入/关系管理直接复用）：
- vectorSearch({scope,query,limit?,tags?:string|string[],threshold?}) → VectorSearchResult[]（{memoryId,content,score,tag?,group?}）
- vectorStore({scope,text,tags?,group?}) → {docId}；text 超 MAX_TEXT_LENGTH=50000 抛错
- vectorBulkStore({scope,entries:[{text,tags?,group?}]}) → {total,succeeded,failed,results}；空数组返回 0 计数
- vectorDelete({scope,ids}) → {deleted,errors:[{id,code,reason}]}；**NOT_FOUND 视为已清理由调用方判定**
- vectorListDocs({scope,tags?,limit?}) / vectorFetchDocs(ids) → VectorDocInfo[]（{docId,scope?,tag?,content}）
- vectorListScopes(scanLimit?) → string[]；vectorListTags({scope,scanLimit?}) → {tags,scanned,truncated}
- vectorCountScope({scope,tags?}) → number；vectorDeleteScope({scope,tags?},onProgress?) → {deleted}（分批+无进展保护）
- getRelationMap(scope,ttlMs?) → Map<string,RelationMapEntry>（{group,relation}）；clearRelationMapCache()
- fetchOriginal(scope,group,relation) → {original,hint?} | null
- ensureVectorAvailable(scope?,opts?{fastFail?}) → {available,reason?,code?:'LOCKED'|'CORRUPTED'|'PROBE_ERROR'}
- getEngine()/closeEngine()/enableIdleClose(idleMs)/runWithVectorSource(source,fn)
- generateDocId(text,scope,tag?) → sha256 截 32
