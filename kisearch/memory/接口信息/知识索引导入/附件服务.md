【接口信息｜附件服务】
- 子功能：本地图片附件读取（REQ-20260904-001）
- 所属模块：知识索引导入（内容）/ MCP 服务（路由）
- 接口列表：
  - GET /api/asset?scope=&group=&path= → handleAsset @ src/lib/mcp-http-api.ts：读取 group 级 assets/ 目录下的附件，返回二进制 + 正确 Content-Type（ASSET_MIME 映射，后缀集合与 import.ts 的 ASSET_EXTENSIONS 对应）
- 契约要点：
  - **纯文件读取，不经向量引擎** → 导入后无需重启即生效（与 /api/doc/list 同模式）
  - **双锚点防穿越**（两道都必须校）：group 拒绝对路径与含 `..`/`.`/空段的值（400）——group 原样进 path.join 会搬移前缀校验的锚点，单靠 path 校验会同时失效导致跨 scope 越权甚至读 KB 外宿主机文件（该缺陷已由 code review 实机 HTTP 实证并修复）；解析后的绝对路径必须仍落在 kbRoot 与 assetsDir 内（否则 403）
  - **404 不伪装**：缺失附件与非图片后缀均返回 404 + JSON，不走 SPA fallback（对比：静态页 fallback 对取不到的路径返回 index.html + HTTP 200，会把破图伪装成成功且零可诊断信息）
  - 解码容错：decodeURIComponent 失败时回退原值（与导入侧对称），使文件名含裸 %（如 50%.png）不至永远 404
  - SVG 安全头：X-Content-Type-Options: nosniff + Content-Security-Policy: sandbox（SVG 可含脚本，同源打开会构成 XSS）
  - 鉴权：已加入 handleApiRequest 的 **query scope 越权校验列表**（同 /tags、/doc/list）。注意这是「生效拦截」列表而非「豁免」列表——**新增带 scope 参数的只读接口必须同步加入，否则不受越权拦截**；effective scope = query scope 或 'default'（缺省不绕过授权），越权返回脱敏 403
  - 前端调用形态：URL 由 web/src/components/MarkdownPreview.tsx 直接拼接（**不经 httpApi.ts 封装**，因为作为 <img src> 而非 fetch 消费）
- 相关配置：scopes.<scope>.import.assets（bool，默认 true）、import.maxAssetSize（字节，默认 5242880=5MB），均已纳入 config-schema 字段级校验
