推荐使用面（CLI 与 MCP 共用，绕过进程启动与 engine 开关成本）：
- executeSyncRelation(params:{scope?,group,relation,moduleInfo,vector?,tags?}) → SyncRelationResult
- executeBulkSyncRelation(params:{scope?,items:BulkSyncItem[],vector?}) → BulkSyncRelationResult
- executeQueryGroup(params:{scope,groupsParam?,hotCount,depth,modes,autoFallback?}) → {ok,scope,output}
- executeManageCreate / executeManageDeleteEmpty（{scope,name,parent?}）、executeListScopes()（同步无参）
- executeGetModuleInfo({scope,group,relation}) → {ok,scope,content,hint?}
- executeDeleteRelation({scope?,group,relation}) → {ok,scope,result:DeleteResult}
- executeDeleteGroup({scope?,group}) → {ok,scope,result:DeleteGroupResult}
- executeBatchDelete(scope?, items:[{group,relation}]) → {ok,results,total,failed}（无目录级批量）
- backfillWiki(scope, opts?{force?}) → WikiBackfillResult
- writeBackToWiki(scope,group,relation,moduleInfo) → {synced,file?,reason?}
- resolveGroupPath(userInput,groupIndex,groupsData,scope?) → ResolveResult
- searchPath(query,tag:'ki-path'|'ki-relation',scope,threshold?) → PathSearchResult|null
- scoring: calculateScore(useCount,lastUsedTime,now,halfLifeHours?) / recordUse(relation,now) / partitionByScore<T>(items,accessors,config) / hybridPartition(items,now,config) / boundaryDecay(hot,warm,newScore,decayStep?)
全部不抛异常，失败以 ok:false + error / reason 返回。
