视图名不是物理库，`readAllGroupCaches(视图名)` 恒返回空 Map；按 target 直接统计会让「共 N 篇」显示 0，`total===0` 时还会把空态误判成 empty-scope（2026-11-17 修复）。
- 症状: 配置里加了视图作检索范围，候选能正常出来但库统计为 0；事件库为空时提示「事件与文档不在同一库」
- 根因: 视图展开只在 `search.ts::resolveScopeTargets` 一处做了，缓存读取层不做展开
- 解法: `src/lib/events/find-targets.ts::countDocsByTargets(targets, { viewMembers, cachesOf })` 按成员库求和；`viewMembers` 必填（忘了传就静默算 0）
- 用法: 快速通道（refs-service）与深度通道（find-service）共用同一函数，`viewMembers` 可注入，单测不依赖本机 views.json
- 相关: 保存期范围预检复用 `resolveFindTargets`（能改全局配置的 token 必是 all-scope，授权类判定不可达，实际拦的是 missing / 视图无成员）
