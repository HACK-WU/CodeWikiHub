刷新数据源页时所有开了向量化的行先集体挂上「仅全文」徽标、随即消失，根因是把向量状态 checking 误当成已确诊不可用。

- 现象: 稳定态没有徽标；刷新瞬间每行 scope 名后多一个「仅全文」，探测回来全部消失，顶部横幅同样会闪
- 判据链: 首屏两路 query 都在 pending 时 vectorAvailability.status 是 checking（vectorAvailability.ts 的 isPending 分支），而 UI 用 status === 'available' 取反驱动标记 ⇒ checking 也算不可用
- 根因: 陈述性标记（徽标 / 横幅）用 !available 驱动；checking 与 unknown 都不代表向量真的坏了
- 解法: 新增纯函数 isVectorConfirmedUnavailable() 只认 unavailable，横幅与行徽标改用它；同步按钮禁用仍用 !available（行为约束，checking 期间短暂禁用无副作用）
- 验证方式: vector-availability.test.mjs 的四态真值表 + 数据源页源码守卫；cd web && npm test 1178/1178 全绿；刷新页面肉眼确认
- 位置: web/src/pages/DataSourcePage.tsx、web/src/lib/vectorAvailability.ts
- 排查记录: .debug/datasource-vector-badge-flicker-20261116/
- 同类风险（未改，待确认）: 导入 / 检索 / 写入页若有「非 available 即报不可用」的陈述性文案，同理会闪；这三页目前按状态分档写文
