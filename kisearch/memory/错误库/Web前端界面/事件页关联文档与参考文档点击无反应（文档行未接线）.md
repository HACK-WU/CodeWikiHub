【错误库｜Web前端｜事件页文档行点击无反应】

**现象**：知识治理 → 事件页右栏「关联文档」「参考文档」行点击无任何反应，看不到正文；demo 点同一位置会滑出文档抽屉。

**根因**：`web/src/pages/EventsPage.tsx` 里两处 `.gov-docline` 都是纯 `<div>`，全文件无 `onClick` / 无 Drawer / 未 import `getDocContent` —— 交互根本没实现（设计 S07 §3.3 要求「文档抽屉直接复用 ModuleDrawer」，实现漏接线），不是请求失败或渲染报错。

**解法**：文档名区改为 `<button class="gov-docline__main">` → `setDocTarget({group,name})`，页面末尾渲染 `<ModuleDrawer scope module group fetcher={getDocContent} onClose>`（与任务页 / 数据源页同一用法）；`stale` 引用仍允许点（由阅读器给失败态，比禁用更易查清哪篇没了）。新增 `.gov-docline__main` 样式（hover 底色 + 名称转主色 + focus-visible 描边），负外边距保持分隔线与可见性列位置不变。

**验证**：`web tsc --noEmit` 0 错；`node --test test/*.test.mjs` 1168 例全绿；agent-browser 实测 `.gov-docline__main` = 3 个（1 关联 + 2 参考，改前 0），点开正文 507 / 490 字符。

**有意差异**：抽屉 70vw、无遮罩、带完整阅读器（大纲/文档内查找/全屏），替代 demo 的 560px + 遮罩只读弹窗 —— 跟随全站既有阅读器形态。
