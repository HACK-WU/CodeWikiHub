【专题记忆｜向量引擎专家】
- 资产路径：.module-experts/向量引擎专家/（用 expert-lookup 加载详细资产）
- 一句话职责：kisearch 的向量检索基座——ZvecEngine 门面（worker 多线程隔离），提供语义/全文/混合检索、SiliconFlow embedding、schema 管理、Filter 编译与 18 类类型化异常
- 核心能力：ZvecEngine.create/open/probe/close（生命周期）、engine.search（semantic/fts/hybrid+RRF）、engine.write/writeBatch（自动向量化写入）、SiliconFlowProvider.embed
- 高频坑（≤3）：① 集合被其他进程持锁→CollectionLockedException，关其他实例或 ki restore 重建；② 改 src/zvec-engine 后必须 npm run build:zvec-engine 重建 dist（worker 只能加载编译产物，不构建=假更新）；③ embedding 维度≠集合维度→DimensionMismatchError，须删集合重建（schema 无 alter API）
- 关键代码位置：ZvecEngine @ src/zvec-engine/engine.ts；errors.ts（18 类异常）；proxy.ts/worker.ts（worker 隔离）；filter/compiler.ts（Filter 白名单）；index.ts（唯一导出门面）
- 数据落地：向量集合（dense/content/tag/scope/group 字段）→ config.vectorDir 磁盘持久化
- 检索触发词：向量引擎, ZvecEngine, worker, embedding, SiliconFlow, 异常体系, WorkerUnavailableError, idle close
