向量库为单进程独占锁，生命周期策略全部在 src/lib/vector-client.ts：
- 单例 + 原生操作串行化：probe/create/open/close 全部经 serializeEngineOp 排队（同进程并发 ZVecOpen 同一 dbPath 实测约 62% 概率原生竞态永久阻塞）。
- open 超时自愈：withOpenTimeout 20s（刻意 < 工具护栏 READ 30s）超时后 fire-and-forget 关闭孤儿 engine，保证 _enginePromise 必定 settle。
- closeEngine 必须先置空缓存再 close（close 期间新 getEngine 走 reopen + 撞锁重试，避免 WorkerCrashedError）；close 也经 serializeEngineOp。
- 撞锁重试 probeWithRetry（等 2s × 最多 3 次）+ 空闲释放锁 enableIdleClose（仅常驻 MCP 层调用，CLI 勿用；定时器间隔 max(500, idleMs/2) 且 unref）。
- 在途计数 _inFlightOps：withEngine 进入即 ++，idle timer 见此计数不打断——修复 embedding 网络期被 idle close 打断的「worker not open (state=closed)」竞态。
- 自愈重试：withEngine 捕获 WorkerUnavailableError 后 closeEngine + getEngine 重开重试一次；isWorkerUnavailable 用 duck-typing（err.name 或 /worker not open/i），不用 instanceof——旧 dist 缺新导出时 instanceof undefined 会崩。
- **自定义 engine 使用必须经 withEngine**，直接 await getEngine() 会重演竞态。
- CLI per-call 结束必须 closeEngine()，否则进程不退出。
- runWithVectorSource/getVectorOpSource：AsyncLocalStorage 标注撞锁日志来源（HTTP 端点/MCP 工具名）。
