检索与向量客户端模块是 kisearch 的向量层读写入口（Vector Adapter）。
- 模块根：src/lib/{vector-client,relation-map}.ts + src/{search,store,doc,tag,bulk-store}.ts
- 纯函数层：executeSearch / executeStore / executeBulkStore / executeDocList / executeDocDelete / executeTagList —— CLI 与 MCP 都转调；vector* 系列（vectorSearch/vectorStore/vectorBulkStore/vectorDelete/vectorListDocs/FetchDocs/ListScopes/ListTags/CountScope/DeleteScope）是向量层原语，被知识索引导入与关系索引管理直接复用。
- 适配层：vector-client.ts 封装 ZvecEngine（从 dist/zvec-engine/index.js 导入，非源码——worker_threads 只能加载编译产物，改 src/zvec-engine 必须 npm run build:zvec-engine）。
- MCP 工具层：mcp-tools/{search,store,bulk-store,tag-list}.ts 只做 zod 校验 + TOOL_TIMEOUT 包装 + scope 授权。
- ki doc 无 MCP 暴露（管理面仅 CLI 可达）。
