文档级删除已进回收站（REQ-20261113-004 之后），组级与 scope 级仍为物理删除。三条链路：① MCP `ki_delete_relation` 与 HTTP `POST /api/doc/delete` 都走 `executeDeleteRelation`（src/delete-relation.ts），默认 trashEnabled 为真，删前 `moveToTrash` 落 `{kbDir}/.trash/{group}/`，返回体带 `trash` 回执；② MCP `ki_group_delete_empty` → `executeGroupDelete`（src/lib/group-delete.ts）物理 rmSync，且只允许空组（requireEmpty，GROUP_NOT_EMPTY）；③ CLI `ki scope clear|delete` → `clearKbDir`/`removeKbDir`（src/scope.ts）物理清目录，会把该库 `.trash` 一并清掉。
- 关键约束: `moveToTrash`（src/lib/trash-service.ts）正文空即 `TRASH_CONTENT_MISSING` 中止删除（fail-closed），故空组**不能**直接复用它入站，group 入站需独立的组快照类型
- 不进站的四种情形: `KI_TRASH_DISABLED=1`、`skipDenseDelete`（移动文档）、`wikiDelete=false`（数据源 prune）、group/scope 级删除
- 位置: `src/delete-relation.ts`、`src/lib/group-delete.ts`、`src/scope.ts`、`src/lib/trash-store.ts`
