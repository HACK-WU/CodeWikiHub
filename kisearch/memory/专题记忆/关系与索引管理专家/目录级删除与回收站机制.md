src/delete-relation.ts::executeDeleteGroup——删除整个 Group 子树（含子 Group）。
- 级联范围靠 relations-cache 的**平铺完整路径键**前缀匹配：key===group 或 key.startsWith(group+'/')。只删精确键会漏掉 group/sub 子 Group，留下「树已删但数据仍可查」的幽灵数据。
- **空路径卫兵**：resolvedGroup 为空串直接拒绝（防 rmSync 删到整个 scope 数据目录）。
- 删除顺序：聚合全部 memoryIds 一次 vectorDelete（NOT_FOUND 不算错误，其余错误置 vectorRemoved:false）→ 删 cache 键 → rmSync 递归删 kb/{scope}/{group}/ → moveDirToTrash 移 wiki 目录 → removeGroupNode 删树节点。
- 回收站：{sourceDir}/.ki/trash/{group}/，保留 group 完整相对路径，重名追加 ISO 时间戳。**不物理删除**，需人工清理回收站。
- vectorRemoved:false 是显式反馈，用于暴露「索引已删但仍能搜到」的孤儿向量，避免静默不一致。
- 文档级 executeDeleteRelation 的向量删除三级降级：memoryIds → memoryId → vectorSearch 严格匹配兜底（memMethod 记录实际路径）；deleteBySearch 用自定义中文边界（\b 对中文无效）。
