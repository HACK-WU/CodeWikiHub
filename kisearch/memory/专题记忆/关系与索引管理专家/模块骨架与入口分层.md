关系与索引管理模块采用「纯函数层 + 双入口（CLI + MCP）」骨架。
- 模块根：src/lib/{scoring,group-resolve,wiki-sync,path-search}.ts + src/{sync-relation,query-group,manage-index,get-module-info,delete-relation,wiki-backfill}.ts
- 纯函数层：executeSyncRelation / executeBulkSyncRelation / executeQueryGroup / executeManageCreate / executeManageDeleteEmpty / executeListScopes / executeGetModuleInfo / executeDeleteRelation / executeDeleteGroup / executeBatchDelete / backfillWiki —— CLI 与 MCP 都转调这些函数。
- 入口层：src/lib/mcp-tools/*.ts 只做 zod 参数校验 + 240s 超时包装 + scope 授权过滤。
- 新增能力只需加纯函数，两个入口自动复用。
- 专家资产：.module-experts/关系与索引管理专家/（契约层 C0/C1/C2/C4 + 实现层 01-07）。
