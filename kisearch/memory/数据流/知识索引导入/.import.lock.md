【数据流｜.import.lock】
- 实体类型：导入互斥锁文件（kb/{scope}/.import.lock，内容为 pid）
- 生产方：acquireImportLock @ src/lib/interrupt.ts
- 消费方：acquireImportLock 自身（pid 探活 process.kill(pid,0)，残留锁自愈）、releaseImportLock（清除）
- 业务用途：防止并发导入互踩；进程被 SIGKILL 后残留锁可被下一次导入自动探测并清理
- 详细流向：见 .module-experts/知识索引导入专家/C4-数据流向与消费.md
