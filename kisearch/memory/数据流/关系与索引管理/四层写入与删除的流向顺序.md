写入（executeSyncRelation）：cache 先落盘 → 向量后补写 → wiki 最后。向量失败不影响 KB 层可查，只以 vectorStored/vectorReason 透出；wiki 失败完全不阻断。
批量（executeBulkSyncRelation）：cache 只在阶段 4 落盘**一次**（单条是立即落盘），向量一次 bulkStore，stale 清理在写成功后聚合一次 vectorDelete（先写后删）。
文档级删除（executeDeleteRelation）：cache splice → local KB 删 key → findWikiFile + moveToTrash 移入 .ki/trash → deleteMemMemory（memoryIds 批量 → memoryId → vectorSearch 严格匹配兜底，memMethod 记录实际路径）→ 落盘。即使 cache 中找不到该 relation 仍继续清 wiki/向量（处理已删但残留）。
目录级删除（executeDeleteGroup）：聚合 memoryIds 一次 vectorDelete → 删 cache 键 → rmSync 删 KB 子树 → moveDirToTrash 移 wiki 目录 → removeGroupNode 删树节点（子空则级联清父）→ 落盘 cache + group-index。
评分流转：get-module-info 读取即 recordUse + calculateScore 回写 cache（唯一的「读即写」路径）；query-group 只读不写；分区为读取时计算，不落盘。
