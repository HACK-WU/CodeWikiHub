关系与索引管理产出/消费的数据实体：
1. relations-cache.json（~/.ki/kb/{scope}/）：关系元数据与评分的唯一权威源。groups 是**平铺完整路径键**（wiki 与 wiki/docs 独立），只有 hot_relations 一个数组（warm/cold 查询时由 partitionByScore 现算），partition_config 缺省回退 DEFAULT_PARTITION_CONFIG。消费方：检索客户端（memoryId 反查）、query-group、知识索引导入（共用格式）、export/rebuild/restore。
2. local KB index.json（~/.ki/kb/{scope}/{group}/）：Markdown 原文，向量丢失后据此重建。消费方：get-module-info、rebuild-vector、export、restore。
3. 向量：ki-relation（关系名）、ki-path（Group 路径）、ki-search + 自定义 tags（内容）。消费方：ki search 语义召回（内容向量）、searchPath 语义兜底（路径/关系向量）。
4. group-index.json：Group 树（节点值纯子节点字典，无 rootName），source.dir 决定 wiki 写回目录第一优先级。消费方：query-group、group-resolve、知识导入、export、getSource。
5. 外部 Wiki 文件 {sourceDir}/{group}/{relation}.md（group 即完整相对路径，无前缀剥离）。
6. 回收站 {sourceDir}/.ki/trash/{group}/（保留结构、重名加时间戳，不自动回收）。
7. relation.tags 字段：文档级自定义标签，持久化到 relations-cache 的 hot_relations[].tags，供 rebuild-vector/restore 恢复 tag 向量与 tag 过滤。
Relation 字段：id(rel_NNN) / text / score / useCount / lastUsedTime / isImported / memoryId?(主 doc) / memoryIds?(全部 doc) / sourcePath? / tags?（isFullText 已删除）。
