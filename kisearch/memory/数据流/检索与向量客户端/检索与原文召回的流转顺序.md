检索（executeSearch）：ensureVectorAvailable → [显式 tags ? 单次查询 : 枚举 tag → 单次多 tag OR（topk=limit×N）→ 按 tag 分组 slice limit → TAG_PRIORITY 排序] → getRelationMap 反查附加 group/relation → [includeOriginal ? fetchOriginal 取文件级原文（三处降级出口都保证 original 非空：KB 缺 relation / 读取异常 / 反查未命中 → 向量文档 content 兜底 + originalHint）] → 多 tag 去重（同 group|relation 留最高分）→ 多 chunk 原文去重（后续 deduplicated）→ 交付。
embedding 次数：显式 tags 1 次；默认搜全部也是 1 次（2026-08-28 起取代旧逐 tag 分查 N 次）。
写入（vectorStore/vectorBulkStore）：normalizeTag → generateDocId(text,scope,tag) → engine.upsert（批量一次）→ 返回 docId/逐项结果；本层不写 KB，memoryId 回填 relations-cache 是上层职责。
删除（vectorDelete）：resolveScope 护栏 → engine.delete(ids) → 透出 {deleted, errors:[{id,code,reason}]}；NOT_FOUND 由调用方判定（幂等重删视为已清理）。
清空（vectorDeleteScope）：循环 listIds(≤10000) → delete → onProgress → 本批 ok=0 即退出（无进展保护）→ 本批 < LIMIT 即退出。
doc delete（管理面）：vectorFetchDocs 取回预览 → 分 notFound/inScope/scopeMismatch → 无 --yes 拒绝并回显 willDelete → 有 --yes 只删 inScopeIds。
