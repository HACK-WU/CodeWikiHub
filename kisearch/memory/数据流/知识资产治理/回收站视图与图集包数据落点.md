知识资产治理域的数据实体流向（基线 0f1426b）。
- <kbDir>/<scope>/.trash/{group}/ 与 __group__<stamp>/：生产方 moveToTrash，消费方为回收站页与恢复动作，用途是存被删原文与 meta 并支持整组恢复。
- views.json：生产方 createView（~/.ki/views.json），消费方为 ki_view_list 与检索 scope 展开，用途是存视图成员与阈值。
- <kbDir>/<scope>/.atlas/：生产方 installPackage，含 atlas.html / package.zip / meta.json / archive/ / .upload/，消费方为 /atlas 只读页与 status 接口。
- 详细流向：见 .module-experts/知识资产治理专家/C4-数据流向与消费.md。
