对外 /open/v1 通道与外部模块的强耦合（2026-11-25 核对，基线 0f1426b）。
- 依赖 MCP 服务：TokenAuth 由 mcp-http.ts 注入，resolveTokenAuth 来自 mcp-token.ts；downloadApi / uploadApi 开关位由 HTTP 层给。Token 口径改动会让所有对外调用失效。
- 依赖知识索引导入：上传暂存的 content/ 最终交 handleDirectImport。
- 依赖知识资产治理：/open/v1/atlas/package 调用 installPackage；图集包上限与错误码命名空间要两侧一致。
- HTTP 契约耦合远端客户端：ki-client 无代码 import，只打 /open/v1/*，靠 ping 的 contractVersion / capabilities 协商。契约版本变更必须同步客户端。
- 位置：src/lib/open-api/index.ts、src/lib/open-api/auth.ts、src/lib/mcp-http.ts。
