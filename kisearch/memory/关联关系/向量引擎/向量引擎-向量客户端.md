[强关联] 向量引擎（src/zvec-engine） 与 向量客户端（src/lib/vector-client）
强度：必改——改引擎公开导出面（异常/方法/类型）后，必须 npm run build:zvec-engine 重新构建 dist，vector-client 才能加载到新产物（worker_threads 只能加载编译产物，只改 src 不构建=假更新）；改 vector-client 所依赖的引擎异常语义/方法签名时，引擎端需连带对齐。
原因：vector-client 从 dist/zvec-engine/index.js 导入 ZvecEngine 与全部类型化异常；withEngine 对 WorkerUnavailableError 的自愈重试依赖引擎抛出该异常的语义稳定（58c12ca 起引擎补导出该异常）。

- ZvecEngine @ src/zvec-engine/engine.ts
- errors.ts（18 类类型化异常）
- index.ts（唯一导出门面）

向量客户端端：
- getEngine/withEngine @ src/lib/vector-client.ts
- probeWithRetry / enableIdleClose / serializeEngineOp @ src/lib/vector-client.ts
- runWithVectorSource @ src/lib/vector-client.ts
