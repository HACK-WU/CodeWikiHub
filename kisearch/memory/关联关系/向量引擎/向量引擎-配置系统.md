[强关联] 向量引擎（src/zvec-engine） 与 配置系统（src/lib/config.ts、src/lib/config-schema.ts）
强度：必改——config.embedding 的 baseURL/model/dimension/apiKey 结构或字段校验变更时，SiliconFlowProvider 与 schema/validator 必须连带改；dimension 变更会导致既有集合 DimensionMismatchError/SchemaMismatchError，需删集合重建（schema 无 alter API，影响所有 scope 向量数据）。
原因：引擎的集合 schema 与 embedding 维度直接来自配置，open 时 schemaAssert 强校验一致性。

向量引擎端：
- SiliconFlowProvider @ src/zvec-engine/embedding/siliconflow.ts
- schema/validator.ts @ src/zvec-engine/schema/validator.ts

配置系统端：
- KiConfig.embedding @ src/lib/config.ts
- embedding 节点 schema @ src/lib/config-schema.ts
