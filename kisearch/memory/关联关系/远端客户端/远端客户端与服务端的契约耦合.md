ki-client 与服务端是纯 HTTP 契约耦合（2026-11-25 核对，基线 0f1426b）。
- 不 import 主仓 src/：cli.ts 只 import 自有模块与 node:fs，可独立建专家、独立发布。
- 契约面是 /open/v1/*：ping / import/upload / import/status / asset / doc / atlas/package / atlas/status。服务端改路径或字段，客户端必然失效。
- 能力位协商：pingRemote 读 contractVersion 与 capabilities.download / atlas.upload；字段缺失视为 0 且能力全 false。
- 服务端 multipart 通道附件不落盘是已知不对称：客户端因此改为有子目录或图片就走 tar.gz。
- 位置：ki-client/src/http.ts、src/lib/open-api/index.ts、src/lib/open-api/routes/ping.ts。
