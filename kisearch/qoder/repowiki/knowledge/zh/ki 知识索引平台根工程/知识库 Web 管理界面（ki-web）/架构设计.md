独立 Vite + TypeScript SPA，入口 `src/main.tsx` 通过 `createRoot` 挂载 `<App>`；`App.tsx` 自上而下组合三层 Provider：`QueryClientProvider`（@tanstack/react-query，默认关闭重试与窗口聚焦刷新）、`ScopeProvider`（全局 scope/theme 状态，持久化到 localStorage）、`BrowserRouter`（react-router-dom v7）。路由集中在 `router/routes.tsx`，以 `/` 为根嵌套 `AppShell` 布局组件，子路由映射到 `pages/` 下的五个业务页面（Dashboard/Browse/Search/Import/Write）。`layouts/AppShell.tsx` 提供侧边栏导航、顶部工具栏、主题切换与服务健康徽标（轮询 `/api/health`）。数据层按职责拆分：`api/httpApi.ts` 封装对 `/api/*` 的 fetch 请求并统一错误抛出，`api/mcpClient.ts` 使用 `@modelcontextprotocol/sdk` 的 `StreamableHTTPClientTransport` 直连 `/mcp` 走 MCP 协议调用 `ki_scope_list`、`ki_search`、`ki_get_module_info`、`ki_store`、`ki_sync_relation` 等工具；共享逻辑集中在 `lib/`（hooks、scopeContext、validators），可复用 UI 组件放在 `components/`，样式由 `styles/ki.css` 单文件承载。构建产物输出至 `dist/`，由宿主进程以静态资源方式提供；开发时 `vite.config.ts` 将 `/api`、`/mcp`、`/healthz` 代理到本机 7423 端口。
