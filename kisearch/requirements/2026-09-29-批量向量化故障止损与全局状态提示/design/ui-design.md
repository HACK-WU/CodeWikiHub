# UI 设计方案：全局向量告警与后台任务中心

> 输入：`requirement.md` R4/R5/R7–R10、用户 `/import` 截图、现有 `AppShell` 与 `ki.css`。视觉草案，尚未确认；不包含后端或交互技术设计。

## 1. 页面清单与信息层级

沿用现有五个站内页面（总览、知识库浏览、语义搜索、上传导入、知识写入），新增左侧导航“后台任务”页，并修改共享壳层的顶部任务摘要与维度横幅。后台任务集中呈现 CLI 与 Web 的长时批量向量化任务。

| 区域 | 目的 | 首要信息 | 次要信息 | 辅助信息 |
|---|---|---|---|---|
| 顶栏任务摘要 | 在任一页感知 CLI / Web 任务，尤其是进行中与失败 | 聚合中的任务数及最高严重状态，运行时旋转图标 | 最近活跃任务的 scope、阶段 | 点击进入“后台任务”页 |
| 顶栏下全局维度横幅 | 在任一页面指出当前 scope 的语义能力阻断及恢复路径 | “语义检索不可用”与当前 scope | 配置维度、旧集合维度、全文仍可用 | 重建命令、复制、重新检查 |
| 后台任务页 | 查看任务并发、来源、进度与结果 | 进行中、排队中、最近结束的任务 | 来源、操作、scope、阶段、时间 | 筛选、详情、失败恢复 |

“导入任务的 scope”和“顶栏当前所选 scope”可不同：任务标识保留任务 scope；维度横幅只描述当前所选且有权访问的 scope。正常状态不占用横幅高度。

## 2. 布局与结构

模式：沿用左侧 232px 导航 + 52px 顶栏 + 主内容。桌面横幅在顶栏正下方、主内容滚动区域上方，页面切换时位置不变。长恢复命令不得挤压 scope 选择器与服务状态徽标。

```text
┌─侧栏 232px─┬─顶栏 52px──────────────────────────────────────────────────────────────┐
│ 总览        │ ki 知识库    [◌ 2 个任务进行中]   [kafka ▾] [● 服务已就绪]        │
│ 知识库浏览  ├─全局告警───────────────────────────────────────────────────────────────┤
│ 语义搜索    │ [!] kafka 的语义检索不可用 · 1024 / 4096 维                        │
│ 上传导入    │     全文检索仍可使用   [ki restore kafka --rebuild-vector --yes] [复制] [重新检查] │
│ 知识写入    ├─────────────────────────────────────────────────────────────────────┤
│ 后台任务    │ 当前页面内容（后台任务 / 其他五页）                                  │
└─────────────┴─────────────────────────────────────────────────────────────────────┘
```

任务摘要靠顶栏右侧，紧挨 scope 选择器之前；在 1119px 左右桌面宽度，摘要最长 220px，超出文字省略、完整内容保留在后台任务页。横幅左侧固定 4px 错误色线和 20px 图标；主标题与恢复命令分两行，避免把长命令塞入单行表单错误文字。横幅上下内边距 10px，内容左右与主页面 24px 对齐。

后台任务页的结构是：页标题与更新时间 → 统计条（进行中 / 排队 / 最近失败）→ 任务状态与来源筛选 → 任务列表。每行左侧是带图标的终态、操作名和 scope；中部是阶段与进度；右侧是来源、时间和“查看详情”。点击后在同页展开详情，包含已完成/失败/未处理计数、错误摘要、恢复指引和 jobId，避免跳离当前任务集合。默认进行中排前，最近结束按结束时间倒序；无任务显示引导空态。

## 3. 组件与状态

| 组件/状态 | 视觉与文案 | 动效/反馈 |
|---|---|---|
| 摘要：有进行中 | 实心品牌蓝底、白字；14px 白色环形 spinner；文案如 `2 个任务进行中` | spinner 0.8s 匀速旋转；整块可点击任务页 |
| 摘要：仅有失败 | 浅红色底、深红字、静态 !；文案如 `1 个任务失败` | 无循环动效；点击查看失败任务 |
| 摘要：无活动 | 不占位；后台任务导航保留入口 | 任务页可查最近任务 |
| 任务行：运行中/排队 | 蓝色细状态线和实心状态点，进度条显示已处理/总量；总量未知时用“不确定进度”文案 | 运行中图标旋转，排队静态；不在进度条上持续闪烁 |
| 任务行：完成/失败/取消/状态未知 | 绿/红/灰/琥珀图标与文字；错误摘要仅失败时出现 | 静态；异常任务可展开恢复指引 |
| 任务来源 | 小型 `CLI` 或 `网页` 徽标，和 scope 分开 | 不随页面当前 scope 改变 |
| 维度：确认冲突 | 淡红底、红色左边框；标题、具体维度、恢复命令、全文仍可用说明 | `复制命令` 成功后短暂变为“已复制”；`重新检查` 有局部 loading |
| 维度：暂无法确认 | 淡琥珀底、琥珀边框；文案 `暂无法确认向量维度` | 提供“重新检查”，不显示错误维度及重建命令 |
| 维度：兼容/未创建集合 | 无全局横幅 | 页面保留原有局部上下文提示 |
| 焦点/悬停/禁用 | 任务标识与按钮均有可见 2px 焦点环；悬停底色明度变化；检测中禁用重复触发 | 减少动态效果设置下停用旋转，保留实心蓝与“导入中”文字 |

状态采用文字、图标和色彩三重编码，避免单靠颜色或动画辨认。`role="status"` 用于运行进度摘要，告警出现时用 `role="alert"`；切换页面不重复宣布同一条告警。长命令可换行，且可复制。任务更新只公告状态转移，进度数字变化不逐次播报。任务页仅显示当前用户有权查看的 scope。

## 4. 视觉 token

沿用 `web/src/styles/ki.css` 的品牌蓝、系统字体、间距和圆角；仅为新状态补少量 token。`redesign-existing-projects` 的“先审计再定点升级”准则用于这个局部改造：优先改善层级、反馈和对比，不重做全站字体或导航。

| token | 值 | 用途 |
|---|---|---|
| `--ki-color-primary` | `#0071e3` | 运行中状态底色、链接 |
| `--ki-color-primary-active` | `#005bb5` | 运行中悬停与焦点 |
| `--ki-color-text` | `#1d1d1f` | 主文本 |
| `--ki-color-text-muted` | `#636366` | 次要说明 |
| `--ki-color-surface` | `#ffffff` | 顶栏、按钮表面 |
| `--ki-color-bg` | `#fafafa` | 页面背景 |
| `--ki-color-border-strong` | `#d9d9de` | 控件边界 |
| `--ki-status-active-bg` | `#0071e3` | 任务运行中 |
| `--ki-status-done-bg` | `#e9f8ed` | 任务完成 |
| `--ki-status-done-text` | `#166d31` | 完成文字 |
| `--ki-status-failed-bg` | `#fff0ee` | 任务失败、维度冲突 |
| `--ki-status-failed-text` | `#a52b23` | 失败文字 |
| `--ki-status-failed-line` | `#e44b40` | 维度横幅左边框 |
| `--ki-status-unknown-bg` | `#fff6e7` | 状态未知 |
| `--ki-status-unknown-text` | `#785000` | 未知文字 |
| `--ki-space-1/2/3/4/6` | `4/8/12/16/24px` | 按现有 4px 节奏 |
| `--ki-radius-sm/md` | `8/12px` | 状态标识/横幅 |
| `--ki-header-height` | `52px` | 桌面顶栏 |
| `--ki-sidebar-width` | `232px` | 桌面侧栏 |
| `--ki-shadow-1` | `0 1px 3px rgba(0,0,0,.08)` | 小控件悬浮反馈 |
| `--ki-font-family` | 系统字体栈 | 与项目现状一致 |
| `--ki-font-mono` | SF Mono、Menlo、Monaco | 恢复命令、进度数字 |

字号：顶栏任务 12px/600，横幅标题 14px/600、说明 13px/400、命令 12px/500；任务页标题 22px/650、任务名 14px/600、辅助信息 12px/400；任务数字使用等宽字宽。横幅使用红色强调“阻断”，运行任务使用品牌蓝强调“正在进行”，两者可同时出现而不互相混淆。

## 5. 响应式与暗色

| 宽度 | 规则 |
|---|---|
| `< 720px` | 侧栏折叠；顶栏第一行保留菜单、品牌、服务点，第二行任务摘要与 scope 选择器；横幅文字与操作按钮纵向排布，命令可折行。任务页统计条改两列，列表为单列卡片，来源与时间下沉。 |
| `720–1023px` | 顶栏单行，隐藏非关键服务长文案；任务状态最大 180px，横幅操作区可换行。 |
| `≥ 1024px` | 顶栏标准布局；任务摘要最大 220px；横幅内容左右分组，命令行下沉。任务列表以两栏信息布局，进度占中部。 |

暗色沿用现有 `data-theme="dark"` 体系，运行状态保持品牌蓝；冲突横幅使用 `#3a2526` 深红表面与 `#ffb4ae` 浅红文字，未知使用 `#3a3020` 表面与 `#f1cc75` 文字。任何宽度下不使用持续闪烁；`prefers-reduced-motion: reduce` 停止 spinner 转动。
