# UI 设计方案：工作台其余页面（总览 / 语义搜索 / 上传导入 / 知识写入 / 后台任务）

> 输入来源：REQ-20260930-003 已确认视觉语言（[ui-design.md](ui-design.md) 与 [knowledge-workbench demo](../demo/knowledge-workbench/index.html)）、真实 React 页面 `web/src/pages/{DashboardPage,SearchPage,ImportPage,WritePage,TasksPage}.tsx` 调研 · 状态：独立 demo 方案 · 日期：2026-09-30

## 1. 概述

- **范围**：将知识库浏览 demo 已确认的视觉语言推广到其余 5 个页面的独立 demo。本轮不修改任何正式 React 页面。
- **风格基线**：完全复用 `ui-design.md` §4 的视觉 token（暖中性色、深绿强调 `#2d6755`、mono 数字、1.8px 描边内联图标、克制阴影），不新增任何颜色/字号/圆角/断点。新组件的状态色均由既有 token 组合（失败=`--color-danger`、成功=`--color-success`、选中=`--color-accent-soft`、中性=`--color-sidebar`）。
- **壳层**：5 页共用同一壳——固定侧栏（`<600px` 抽屉、600–959px 窄轨、`≥960px` 224px）、63px 顶栏（面包屑 + Scope pill + 服务徽标）、页面头部（eyebrow + 标题 + 说明）。demo 内通过侧栏导航切换页面视图。
- **示例数据**：静态假数据，页面底部统一标注「示例内容 · 视觉设计 demo」；数量与名称不代表真实知识库。

## 3. 各页布局

壳层 ASCII 同 `ui-design.md` §2（侧栏 + 顶栏 + page 头部），以下仅画 page 区。

### P1 总览 —— 指标行 + 双卡 + 全宽表

```text
┌ 4 统计卡：Scopes │ KB 文档 │ 向量层 │ 注册 ┐   ← ≥1200px 4 列，600–1199px 2 列，<600px 1 列
├───────────────┬────────────────┤
│ 当前知识库     │ 健康状态        │   ← 双栏 1fr/1fr；<960px 纵排
│ 文档数/Groups  │ N 通过·N 警告   │
│ KB 层/向量层   │ ✅⚠️❌ 列表     │
├───────────────┴────────────────┤
│ Scopes 表：Scope │ 层状态 │ 文档数 │   ← 全宽；徽标 KB / RAG / FTS n
└────────────────────────────────┘
```

加载态：统计卡位置显示骨架条；空库态：整幅空状态卡（「暂无知识库」+ 主按钮「上传文档」）。

### P2 语义搜索 —— 单列内容轴

```text
┌ 搜索栏：[⌕ 输入自然语言查询…] [清空] [搜索] ┐  ← 内容轴 max 860px 居中
│ 选项行：Tags chips · Threshold −/＋ · Timeout s · Limit 5/10/20 · 全文开关 │
│ 最近检索：短标签 ×删除 · 清空历史 │
├────────────────────────────────────────┤
│ 搜索结果 · N 条                          │
│ [1] 文档名  [Group]  分数 0.842 ▮▮▮▮▮░  │
│     摘要（含 <mark> 高亮）…              │
└────────────────────────────────────────┘
```

状态：初始引导空态（未搜索）、无结果（建议文案）、错误（维度不匹配红字 + `ki restore --rebuild-vector` 指引 + 「使用全文搜索重试」）、搜索中（按钮 loading + 结果头计数）。全文开关开启后 Threshold/Timeout 禁用。

### P3 上传导入 —— 单列表单大卡

```text
┌ ⇪ 拖拽 Markdown 文件或目录到此处，或点击选择 ┐
│   文档：.md；引用图片一并处理…（限制文案）  │
│ Scope（目标知识库）[选择已有│新建 Scope]    │
│ Group 路径（可选）[combobox]               │
│ 同名文档处理 [下拉 ▾] + 后缀模板 _{n}       │
│ Tags [combobox：pill ✕]                    │
│ [上传目录] [上传文件]                       │
│ 待导入清单：汇总条 + 行（📁/📄 · 移除 ✕）   │
│ ▸ 切分参数（高级）：Chunk Size/Overlap      │
│ 向量化 [开关] + 维度告警（演示态）          │
│ [开始导入]  直导无需 AI · 无第三方依赖      │
└────────────────────────────────────────┘
```

状态：校验错误（未确认 Scope → 错误块「读取失败/输入有误」族）、导入进度（阶段文案 + 「第 i/N 批」+ 进度条）、成功摘要（「导入完成」+ 同名处理结果列表 + 「查看目标 Scope →」「前往搜索验证 →」）、失败（「上传第 i/N 批失败」+ 重试按钮）。

### P4 知识写入 —— 单列表单大卡

```text
┌ Scope（目标知识库）[选择已有│新建] ┐
│ Group（文档分组）[combobox]        │
│ 文档名称 [输入]                    │
│ Module Info [编辑│预览]（320px）   │
│ Tags [combobox：pill ✕]            │
│ 向量化 [开关]                      │
│ [保存] [清空]   ✅ 写入成功（未向量化）│
└────────────────────────────────┘
```

状态：行内校验错误（红字，位于字段下方）、保存中（按钮 loading + 禁用）、成功摘要（绿字 + 链接按钮）+ 表单自动清空。

### P5 后台任务 —— 汇总条 + master-detail 双栏

```text
┌ 运行中 N │ 失败 N │ 部分完成 N │ 可见 N ┐  ← 4 汇总卡
├───────────────────────┬──────────────┤
│ 任务记录  [全部│进行中│失败│最近结束] │ 任务详情       │  ← 1fr / 380px；<960px 详情纵排在下
│ ● 上传导入  default · 网页 · 45%      │ 状态徽标       │
│ ● 向量重建  …                         │ 来源/知识库/   │
│ …                                     │ 阶段/进度/时间 │
│                                       │ 错误 + 恢复建议│
└───────────────────────────────────────┴──────────────┘
```

状态：未选中详情空态（「选择一个任务」）、详情轮询提示、unknown 心跳提示、刷新中、列表错误、空列表。状态徽标色：运行中=accent 系、失败/未知=danger、部分完成=accent-soft、已完成=success、排队中=neutral。
