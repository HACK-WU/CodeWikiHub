# UI 设计方案：知识工作台

> 输入来源：用户提供的知识库浏览截图、现有 `BrowsePage.tsx` 与 `AppShell.tsx` · 状态：独立 demo 方案 · 日期：2026-09-30

## 1. 概述

- **范围**：将独立 demo 中的目录和文档合为左侧导航树，右侧专注阅读；沿用总览、浏览、搜索、导入、写入、任务的导航名称。本轮不修改运行中的 React 页面。
- **目标设备**：桌面优先，兼顾 1280px、平板和 375px 手机。
- **实现约束**：单文件原生 HTML/CSS/JS，内置示例数据，无后端、CDN、字体或图标依赖。
- **风格依据**：`ui-tools/skills/redesign-existing-projects` 的层级与状态审计，以及 `minimalist-ui` 的暖中性色、克制阴影和排版原则。避免大面积亮蓝、重复卡片和混杂图标。

### 现状判断

上一版 demo 将目录、文档列表和原文分成三栏；用户需要先选目录，再在中栏选文档。截图还显示目录面板与全站侧栏之间的留白偏大。新方案将文档作为目录树叶子：展开目录后直接选文档，右侧独占剩余宽度阅读。桌面阅读区常驻，因此 demo 不设置“全屏”按钮。

### 信息优先级

| 级别 | 信息 | 呈现 |
| --- | --- | --- |
| 首要 | 当前文档、原文内容 | 树叶选中态、宽阅读面板 |
| 次要 | 所属目录、标签、目录数量 | 层级缩进、标签、计数 |
| 辅助 | scope、服务状态、搜索、刷新 | 顶栏、阅读工具栏与目录标题栏 |

## 2. 页面结构

### 知识库浏览

布局采用全站侧边栏 + 双栏工作区。页面内容横向铺满可用区域，距离全站侧栏 16px，顶部内边距 16px；目录树按视口在 260–340px 间调整，其余宽度给阅读区。目录与正文各自滚动。正文默认铺满阅读区；当视口至少 1480px 时，可在“居中”和“铺满”间切换，居中时正文最大宽度为 770px。

```text
┌─ 全站导航 ─┬─ 顶栏：位置 / scope / 服务状态 ──────────────────────────┐
│ 品牌      │ 页面标题、说明、文档数量                                 │
│ 总览      ├─────────────────┬───────────────────────────────────────┤
│ 浏览      │ 知识目录        │ 文档内容 / 搜索 / 标签 / 宽度切换     │
│ 搜索      │ 文件夹与文档    │ 路径、标题、标签、正文                │
│ 导入      │ 文件夹          │                                       │
│ 写入      │   └ 文档叶子    │                                       │
│ 任务      │                 │                                       │
└───────────┴─────────────────┴───────────────────────────────────────┘
```

点击文件夹只展开或收起；点击文档叶子更新右侧原文。桌面端将搜索和标签筛选一起放在阅读区标题栏，窄屏时两者一起留在目录页。搜索跨全部目录并按路径、标题、摘要匹配；筛选结果显示在左侧树，右侧已打开的文档保持不变，以免输入每个字符时打断阅读。筛选无结果时在目录树中给出空状态。demo 使用静态示例数据，未接后端；正式页面的正文检索命中、阅读历史、深链接与大纲能力在产品改造时需迁移。

宽屏阅读区标题栏中，搜索与标签属于同一筛选组；筛选组与“居中 / 铺满”宽度控制之间保留 32px 间距，便于区分两类操作。
“清除筛选”始终占据固定宽度：未筛选时显示禁用态，筛选后启用。窄桌面用图标、宽桌面用文字，因此筛选状态变化不会推动搜索和标签控件。

## 3. 组件与状态

| 组件 | 默认 | 悬停 | 聚焦 | 禁用 / 加载 | 错误 / 空 |
| --- | --- | --- | --- | --- | --- |
| 导航项 | 中性文字 | 浅底 | 2px 聚焦环 | 不适用 | 当前页用绿色标记和浅绿底 |
| 文件夹行 | 名称 + 子树数量 | 中性浅底 | 2px 聚焦环 | 刷新时显示骨架 | 展开角标旋转，筛选时显示命中数 / 总数 |
| 全部展开 / 折叠 | 根据可见目录状态切换向下 / 向上双箭头 | 浅底 | 2px 聚焦环 | 加载或无结果时禁用 | 图标、文案与可见目录状态同步 |
| 文档叶子 | 文件图标 + 标题 | 中性浅底 | 2px 聚焦环 | 刷新时显示骨架 | 选中行浅绿底、左边强调线 |
| 搜索框 | 边框与搜索图标 | 边框加深 | 强调色聚焦环 | 加载时仍可编辑 | 无命中时树内显示引导文案 |
| 标签筛选 | 136px 下拉框、自绘箭头 | 强调色边框 | 强调色聚焦环 | 刷新时仍可编辑 | 当前标签完整显示并可清除 |
| 刷新按钮 | 目录标题右侧图标 | 浅底 | 2px 聚焦环 | 加载时禁用并显示骨架 | 错误时目录内显示重试提示 |
| 阅读面板 | 路径、标题、标签、正文 | 无全屏按钮 | 窄屏返回按钮有聚焦环 | 刷新目录时保留已打开内容 | demo 默认打开首篇示例文档 |
| 正文宽度 | 默认铺满可用宽度 | 按钮高亮 | 居中 / 铺满按钮有聚焦环 | 视口较窄时隐藏切换 | 当前模式用按钮按下态表示 |

demo 中通过搜索无命中演示空状态，点击刷新演示加载与禁用状态。移动端点文档后打开阅读覆盖层，用“返回目录”退出；桌面端始终保持双栏。示例内容不模拟真实请求失败。

## 5. 响应式规则

| 宽度 | 布局 |
| --- | --- |
| `>= 1480px` | 全站导航 + 340px 目录树 + 剩余宽度阅读区；搜索与标签在阅读区顶端；显示正文宽度切换 |
| `960–1479px` | 目录树在 260–340px 间自适应；搜索与标签在阅读区顶端另起一行；正文铺满 |
| `600–959px` | 全站导航缩为窄轨，目录树占工作区；阅读从右侧覆盖，提供返回目录 |
| `< 600px` | 顶栏显示菜单按钮，全站导航抽屉；目录树全宽，阅读占满视口并提供返回目录 |

窄屏时搜索与标签都在目录内。搜索结果为空时保留搜索词和标签；“清除筛选”恢复完整目录树。所有动画使用 `transform` 或 `opacity`，尊重 `prefers-reduced-motion`。
