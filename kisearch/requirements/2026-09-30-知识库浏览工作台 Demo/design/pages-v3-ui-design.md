## 1. 概述

- **范围**：把浏览页 demo 已确认的视觉语言推广到其余页面，产出独立 v3 demo；本轮不改任何 React 页面，也不改动 v1/v2 产物。
- **用户授权**（2026-09-30 裁决）：设计**不必完全受限于当前实现**，后续可修改前端与后端代码。因此本方案包含两处「改动授权」项（§10）：独立后台任务页、搜索页桌面常驻原文栏。
- **v3 与 v1/v2 的关系**：并存、互不覆盖。v3 的差异化主张有三点——① shell 规格回归基线实测值（v2 文档写 224px 与基线 248px 漂移，本轮校正）；② 数据口径遵循真实展示约定（无千分位、`score.toFixed(3)`、`formatBytes`、同日 `HH:mm`，§7）；③ 暗色主题为**全 token 成对定义**并在 demo 内可切换实测（修 challenger 意见 3，而非仅 4 个语义色）。
- **风格依据**：`ui-tools/skills/minimalist-ui`（暖单色、无渐变、阴影极低透明度、禁 pill 大容器、禁 emoji、真实上下文数据）+ `redesign-existing-projects`（加载/空/错误状态审计、焦点环、语义标签）。与浏览页已确认方向一致，直接沿用其 token，不重新配色。

- 阶段 → 视觉映射表（照真实状态机，demo 用定时器走 `scanning→uploading→importing→done`，「错误」演示态停 `uploading`）：

| phase / failureStage | 徽标 | 语义色 | 进度条 | 可用操作 |
| --- | --- | --- | --- | --- |
| idle | 等待开始 | 中性 | 隐藏 | 编辑表单 |
| scanning | 读取目录中 | 警告 | 不确定态 | 取消导入 |
| uploading | 上传中 | 强调 | `第 b/B 批 · f/F 个文件 · bytes（p%）` | 取消导入 |
| importing | 导入中 | 强调 | `d/t 个处理单元（p%）`，无 t 时不确定态 | 取消导入 |
| done | 导入完成 | 成功 | 100% | 前往搜索验证、查看任务详情 |
| failed/scan | 读取失败 | 失败 | 冻结+失败色 | 重新选择文件 |
| failed/upload | 上传失败 | 失败 | 同上 +「重试第 2/5 批」（仅快照未变） | 重试批次 |
| failed/import | 导入失败 | 失败 | 冻结+失败色 | 重试导入 |
| cancelled | 导入已取消 | 中性 | 冻结 | 重新开始（仅剩余文件） |
| unknown | 任务状态待确认 | 警告 | 冻结 | 重试 + 查看任务详情（P5） |

- 维度不兼容：向量化开且 `compatible=false` 时开关下方 `role=alert` 段（真实拦截文案三套：未知/不兼容/读取失败）。
