# UI 设计方案：知识工作台 · 其他页面（总览 / 语义搜索 / 上传导入 / 知识写入 / 后台任务）

> 输入来源：已定稿的浏览页 demo（`demo/knowledge-workbench/index.html`）、`design/ui-design.md`、现有 React 页面（`DashboardPage` / `SearchPage` / `ImportPage` / `WritePage` / `TasksPage` / `layouts/AppShell.tsx`）· 状态：独立 demo 方案 · 日期：2026-09-30
> 关联需求：[REQ-20260930-003](../requirement.md) · 可运行 demo：[../demo/workbench-pages/index.html](../demo/workbench-pages/index.html)

## 1. 概述

- **范围**：把浏览页 demo 已确认的视觉语言与外壳（全站侧栏 224px + 63px 顶栏 + 圆角面板 + 暖中性底 + 深绿强调）推广到其余五个页面，每页给出独立视图、四态覆盖与信息层级；本轮仍不改运行中的 React 页面。
- **目标设备**：桌面优先；覆盖 375 / 600 / 960 / 1200 / 1525px。
- **实现约束**：单文件原生 HTML/CSS/JS，内置静态示例数据，无后端、CDN、外部字体或图标依赖。
- **风格依据**：`ui-tools/skills/minimalist-ui`（暖中性单色 + 克制阴影 + 排版对比）、`redesign-existing-projects`（状态审计：加载/空/错误 + 焦点环 + 语义标签）、`design-taste-frontend`（单一强调色锁、一个圆角刻度、标题栏单行、表格数字等宽）。三者与浏览页已确认方向一致，故直接沿用其 token，不重新配色。

### 本轮要解决的三件事

1. **外壳复用**：五个页面与浏览页共用同一套侧栏、顶栏、面板与控件，证明视觉语言可推广（对应 `ui-design.md` 待确认项 3）。
2. **信息层级**：现有 React 页面多为单列长表（导入页 1475 行、搜索页 768 行），主任务与辅助信息混在一条主轴里；本轮改为「主区 + 侧栏轨道」的双栏结构，把进度、摘要、详情这类辅助信息收敛到轨道里。
3. **状态可见**：给每页配一个**演示态切换器**（正常 / 加载 / 空 / 错误），让评审者能直接看到隐藏态，而不是只在代码里存在。

### 信息优先级（五页通用规律）

| 级别 | 信息 | 呈现 |
| --- | --- | --- |
| 首要 | 当前页的主任务对象（文档 / 结果 / 文件清单 / 正文 / 任务） | 主区面板，最宽列，视觉重心 |
| 次要 | 元数据（scope、Group、标签、分数、阶段、进度） | 徽标、等宽数字、辅助行 |
| 辅助 | 服务状态、刷新、清除、跳转 | 顶栏、面板标题栏、页脚操作区 |

```text
│ ai-docs          KB  RAG                             1,866           │
│ wiki             KB  RAG  FTS                          214           │
└──────────────────────────────────────────────────────────────────────┘
```

两栏**等宽等高**（同一基线、同一高度）：卡片纵向撑满，正文区 `flex: 1`，「当前知识库」的四个指标各自带**浅底卡片框**（`--color-surface-soft` 底 + 1px 边 + 10px 圆角），按 `grid-template-rows: repeat(2, 1fr)` 均分正文区高度——既不是裸文字，也不会在卡片中部留下空洞。宽度与高度均取两栏中较高者（当前以健康检查 5 行决定）。

「当前知识库」卡片的文字规格（与右侧健康检查对齐，避免并排时一侧显小）：指标标签 `14px / 600 / --color-muted`（与健康检查条目标题同号），指标数值 `22px( --font-xl ) / 650 / --font-mono`（本卡片最强层级）。四个标签统一用中文（文档 / 分组 / KB 层 / 向量层），避免中英文同字号下的字形大小错觉。

< 960px 时两栏改为上下堆叠（高度回归内容），知识库表仍为整行。

### Scope 字段：选择已有 / 新建（P3 与 P4 共用）

Scope 字段提供两种方式，默认「选择已有」（下拉），切到「新建」后变为文本输入 + 校验：

| 状态 | 呈现 | 动作按钮 |
| --- | --- | --- |
| 选择已有 | 下拉列出已有 Scope（default / ai-docs / wiki…） | 可用 |
| 新建 · 未输入 | 输入框 + 中性提示「请输入新 Scope 名称，例如 wiki/部署运维」，**不出红字** | 禁用 |
| 新建 · 名称非法 | 输入框红边 + 字段下方红字：不能含空格与 `\ : * ? " < > |`、斜杠不能出现在首/尾/连续、不能含 `..` | 禁用 |
| 新建 · 与已有重名 | 红字「该名称已存在，请改用「选择已有」」 | 禁用 |
| 新建 · 合法 | 红字消失；面板标题徽标即时显示目标（如 `wiki/部署运维 / 专题记忆`） | 可用 |

**无抖动约定**：错误提示行 `min-height: 1.6em` 常驻占位（默认 `visibility: hidden`），输入框与下拉同高（38px），提示文案长度变化不改变表单高度；新建模式下未输入时不弹横幅——实测两个页面在「已有 / 新建 / 非法 / 合法」四态间表单高度差值恒为 0。

## 4. 组件与状态

共用组件沿用浏览页规格，新增表格、徽标、进度、横幅、字段、分段控件六类。

| 组件 | 默认 | 悬停 / 聚焦 | 禁用 / 加载 | 空 / 错误 |
| --- | --- | --- | --- | --- |
| 统计卡 | 面板底 + kicker + 大数字 + 副说明 | 无交互 | 加载显示骨架块 | 无数据显示 `—` |
| 数据表（Scopes） | 表头小写等宽 + 行 44px + 数字右对齐 | 行浅底 | 加载 2 行骨架 | 空：引导导入 + 上传文档入口 |
| 徽标 `ki-badge` | 4px 圆角 + 语义底色（success / warn / danger / neutral） | 无 | 加载显示 `读取中` | 未知层显示 `—` 灰 |
| 健康行 | 图标 + 检查名 + detail | 行浅底 | 检测中显示骨架 | 失败行红图标 + detail 换行 |
| 状态横幅 | 左 3px 语义色边 + 浅底 + 图标 | 无 | 无 | 错误横幅带「重试」按钮 |
| 结果卡 | 排名徽标 + 标题 + Group 徽标 + 摘录 + meta + 分数条 | 整卡浅底、可点击 | 搜索中骨架 3 张 | 无结果：保留条件 + 引导词 |
| 分数条 | 4px 高底槽 + 强调色填充 | - | - | 0 分显示空槽 |
| 字段（label 在上） | label 12px + 控件 38px + hint 11px | 控件边框加深 | 未确认 scope 时禁用并提示 | 错误红边框 + 红字（控件下方） |
| 标签 chip（多选） | 4px 圆角 + 计数 | 悬停浅底 | 提交中禁用 | 校验失败红边 + 说明 |
| 分段控件 | 底部浅底轨道 + 选中白底 + 强调字 | 悬停浅底 | 禁用 42% 透明 | - |
| 进度条 | 6px 圆角槽 + 强调色填充 + 右侧百分比 | - | 无总数时不确定态动画 | 失败保留最后百分比并转错误色 |
| 文件行 | 图标 + 名称（可截断）+ 明细 + 移除按钮 | 行浅底 | 上传中行显示进度色 | 跳过行灰化 + 原因 |
| 任务行 | 状态徽标 + 操作名 + `scope · 来源 · 进度` + 时间 | 行浅底 | 读取中骨架 | 选中：浅绿底 + 左强调线 |
| 正文编辑器 | textarea 等宽 1.75 行高 / 预览态排版 | 聚焦 2px 环 | 保存中禁用并显示「保存中…」 | 空正文预览显示「（空）」 |
| 演示态切换器 | 页头右侧分段控件 + `示例` 徽标 | 悬停浅底 | - | - |

**空 / 加载 / 错误 的具体呈现**（每页都实现，可由演示态切换器一键查看）：

- 总览：Scope 表骨架 2 行；空态「暂无知识库 / 导入第一个知识库」+ 上传文档入口；健康卡失败时标题取检查名 + detail 换行。
- 搜索：按钮「搜索中…」+ 3 张结果骨架；空态（未搜索）给 3 个建议检索词；无结果保留条件；错误态区分维度不匹配，给命令与「使用全文搜索重试」。
- 导入：进度条不确定态 + 「读取目录中…」；无文件时「开始导入」禁用；失败按阶段给标题（读取失败 / 上传失败 / 导入失败）并给「重试第 3/5 批」。
- 写入：字段错误红字在控件下方；scope 未确认时 Group/文档名禁用；成功用绿色提示条（无感叹号），失败块给原因并重置 scope 确认。
- 任务：加载「正在读取任务…」；空「暂无任务」；错误「无法读取后台任务。请检查服务连接和数据目录权限。」；未选中详情给引导占位。

## 5. 视觉 token

沿用浏览页全部 token（`--color-canvas #f5f6f3`、`--color-accent #2d6755`、`--space-*` 4px 基准、`--radius-sm/md/lg 6/10/14`、`--radius-tag 4`、`--shadow-panel`、字号阶梯 `11/12/14/17/22/26/32`）。本轮只做**加法**，不新增强调色：

| 类别 | token | 值 | 用途 |
| --- | --- | --- | --- |
| 语义色 | `--color-warn` | `#8a6208` | 告警文字、部分完成 |
| 语义色 | `--color-warn-soft` | `#fbf3db` | 告警底色 |
| 语义色 | `--color-danger-soft` | `#fdebec` | 失败底色 |
| 语义色 | `--color-danger-ink` | `#9d3a36` | 失败底色上的文字 |
| 尺度 | `--radius-track` | `999px` | 仅进度条与分数条底槽 |
| 结构 | `--font-tabular` | `tabular-nums` | 表格数字、分数、时间、字节 |

规则：
- **一个强调色锁**：选中、主按钮、进度填充、分数条一律 `--color-accent`；语义色只用于状态徽标与横幅，不用于按钮底色。
- **圆角刻度固定**：面板 14 / 控件 6 / 标签 4 / 进度槽 999；不出现其他圆角。
- **阴影只用于浮层**：页内卡片只用 1px 边框，不用阴影。
- **标题栏单行**：顶栏 63px、面板头 62px，控件不换行（`min-width: 0` + `text-overflow`）。
- 图标统一 1.8px 描边内联 SVG；不引入图标库（沿用浏览页 symbol 表 + 新增 6 个：inbox、play、pause? 无、warn、check、chart、branch）。
