MCP服务专家

#专题记忆RAG

职责

MCP 服务把知识检索与文档读取能力提供给外部客户端，是 ki 对外的统一入口：scope 级检索、关联查询、文档深链。

调用链

client → mcp-http-api → scope.store → {fts | vector} → rank → data

检索默认走语义 + 全文双轨；向量维度不匹配时降级为 FTS-only，降级口径在结果 meta 与横幅中显式提示。

发布回滚手册

适用场景

步骤

  1. 确认当前批次与健康检查状态
  2. ki rollback --scope ai-docs --to <snapshot>
  3. 校验向量层与 FTS 一致性
回滚不删除数据目录，快照保留 7 天。
