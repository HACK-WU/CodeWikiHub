# 知识库浏览工作台 Demo 需求

> 状态：独立视觉 Demo 已完成，正式产品页尚未纳入本次范围
> 日期：2026-09-30
> 关联设计：[design/ui-design.md](design/ui-design.md)
> 可运行 Demo：[demo/knowledge-workbench/index.html](demo/knowledge-workbench/index.html)

## 1. 背景与目标

现有知识库浏览页在视觉上不够精致，且目录、文档列表和正文分散在多个区域，阅读路径较长。本需求先交付独立 HTML Demo，供评审新的知识浏览方式和视觉语言，再决定是否推广到正式 React 页面。

目标是让用户沿目录树找到文档，并在同一工作区直接阅读正文；同时让搜索、标签筛选和正文宽度控制清晰、稳定，避免工具栏因状态变化而抖动。

## 2. 用户与使用场景

- 用户需要从知识目录中展开分组并定位文档。
- 用户需要搜索文件名、路径或正文，并按标签过滤目录结果。
- 用户需要连续阅读当前文档，并按屏幕宽度选择居中或铺满正文。
- 用户在窄屏设备上浏览目录后进入阅读，再返回目录继续选择。

## 3. 需求范围

### 本次 Demo 必须满足

1. 采用全站侧栏加双栏工作区：左侧为合并了目录和文档叶子的知识树，右侧为当前文档正文。
2. 目录面板靠近全站侧栏，页面内容距侧栏 16px；标题区顶部留白收紧至 16px。
3. 桌面端在阅读区顶部放置搜索框和标签选择器；窄屏端将两者放在目录视图中。
4. 搜索范围为全库，可按路径、标题和摘要匹配；筛选结果更新左侧树，保留当前正在阅读的文档。
5. 标签选择器关闭态宽度固定为 136px，采用与搜索框协调的边框、焦点态和自绘箭头；与“居中 / 铺满”正文宽度控制保持清楚间隔。
6. “清除筛选”始终保留固定位置：无筛选时禁用，有筛选时启用；不同桌面宽度可切换图标或文字，但筛选状态变化不得推动搜索框或标签选择器。
7. 正文默认铺满阅读区；视口宽度不小于 1480px 时提供“居中 / 铺满”切换。
8. 目录批量展开与折叠状态具有不同图标、提示文案和强调样式；加载中或无匹配结果时禁用。
9. 移动端提供目录与阅读视图切换，并能从正文返回目录。
10. Demo 为单文件原生 HTML/CSS/JS，无构建步骤、后端、CDN、外部字体或图标依赖；示例数据须明确不代表实时知识库数据。

### 本次不包含

- 修改正式 React 浏览页或其他产品页面。
- 接入真实知识库 API、真实搜索、用户偏好持久化或服务端分页。
- 决定是否将视觉语言推广到其他页面。

## 4. 交互规则

- 点击目录文件夹只切换展开状态；点击文档叶子更新右侧正文。
- 搜索与标签共同过滤左侧目录树；清除筛选后恢复完整目录。
- 搜索无结果时在目录区域显示空状态，保留当前搜索词和标签条件。
- 正文宽度按钮显示当前模式；较窄视口隐藏该切换。
- 刷新目录时展示加载状态并禁用不适用的批量操作。

## 5. 验收标准

- [x] 可直接打开独立 Demo，桌面端显示知识树和当前正文双栏布局。
- [x] 目录树包含分组和文档叶子；选择文档后正文同步更新。
- [x] 桌面搜索与标签控件位于正文区域上方，窄屏时位于目录视图。
- [x] 标签筛选前后，标签控件水平位置不变；在 375、960、1199、1200、1490、1625px 宽度下验证位移为 0。
- [x] 页面无横向溢出；目录展开/折叠、正文宽度切换、搜索和手机阅读返回可用。
- [x] 页面标题顶部间距为 16px；目录与全站侧栏之间的工作区左间距为 16px。
- [x] 静态示例数据与真实知识库数据有明确区分。
- [ ] 用户评审后决定是否将此方案迁移至正式 React 页面。

## 6. 已确认的设计决策

- 先改独立 Demo，正式 React 页面暂不改动。
- 目录和文档合并为一棵树，右侧专注展示正文，不保留全屏按钮。
- 正文默认铺满；仅宽屏展示居中模式选项。
- 采用暖中性色、深绿色强调色和较克制的边框与阴影。
- 清除筛选控件使用常驻禁用态稳定工具栏布局；960–1199px 显示图标，1200px 起显示文字。
