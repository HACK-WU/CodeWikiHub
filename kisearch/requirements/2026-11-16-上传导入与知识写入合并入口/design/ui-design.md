## 1. 页面清单与信息优先级

| 页面 | 目的 | 首要信息 | 次要信息 |
|---|---|---|---|
| 知识写入（合并页，`/import` + `/write`） | 一个知识库的两种录入方式收在一处：批量导入文件 / 单篇手写 | 目标 Scope 与 Group；当前 tab 的主体表单 | 页头副标题（两种方式的适用差异）、右轨任务进度（仅导入态） |

- 页面身份：顶栏 H1「知识写入」（延续"H1 是页面身份唯一出口"的既有决策：`决策记录/页面头部`）
- 页内层级：H1（页面）→ tab（手段）→ 卡片（表单）
- 导航关系：侧栏 1 项 ↔ 两条 URL（`/import` 上传 tab、`/write` 写入 tab）

## 2. 布局设计

布局模式：**页头 + 页级 tab + 内容栅格**（内容栅格沿用两页各自现状，不做统一）

- 导入 tab：主表单 `minmax(0,1fr)` ｜ 右轨 380px（≥960px 右轨 sticky，终态退出常驻 —— 既有规则不动）
- 写入 tab：元数据卡 380px ｜ 正文编辑器 `minmax(0,1fr)`
- tab 条位置：页头副标题之下、内容栅格之上；**两 tab 共用同一条 tab 条**，切 tab 时 tab 条与页头位置不动（只换下方栅格）

### 2.3 响应式

| 断点 | 页级 tab | 内容栅格 | 右轨 |
|---|---|---|---|
| ≥960px | 左对齐、按内容宽 | 导入 1fr+380 / 写入 380+1fr | sticky（导入态，终态退出） |
| 641–959px | 同左（不折行） | 单列 | 移到表单下方，不 sticky |
| ≤640px | 撑满宽度、`flex:1` 均分两 tab；进度徽标只留圆点不留百分比 | 单列 | 同 641–959 |

## 3. 组件与状态

### 3.1 页级 tab（`page-tabs`，复用 `.ki-segmented`）

| 状态 | 视觉规格 |
|---|---|
| 容器 | `padding 3px`；`border 1px --ki-color-border`；`border-radius --ki-radius-sm (6px)`；`background --ki-color-bg-secondary`；`inline-flex`，`gap 2px` |
| 未选中 | 透明底；`color --ki-color-text-muted`；`font-weight 600`；`min-height 34px`；`padding 0 14px`；`font-size --ki-font-size-md (14px)`；`border-radius 4px` |
| 悬停 | `color --ki-color-text`（无底色变化） |
| 聚焦 | `outline 2px --ki-color-primary`，`outline-offset 1px`（键盘 `←/→` 可切换，`tabIndex` 罗塔） |
| 选中 | `background color-mix(in srgb, --ki-color-primary 10%, transparent)`；`color --ki-color-primary`；`font-weight 650`（与 `res-tabs` 选中态同款） |
| 禁用 | 不适用（两个 tab 都恒可用；无权限时整页入口不出现） |
| 暗色 | 跟随 `--ki-color-primary` 自动映射，无需额外规则 |

> 选中态选择器用 `aria-selected="true"`（tablist 语义），**不是** `aria-pressed`；这与 `ResourcesPage` 的 `res-tabs` 完全同口径（`ki.css:7656-7662`），因此不新增视觉语言。

### 3.2 进度徽标（tab 内微元素）

| 状态 | 视觉规格 |
|---|---|
| 隐藏 | 导入 tab 处于激活态（进度已在右轨展示，不重复） |
| 进行中 | tab 文案右侧：6px 圆点（`--ki-color-primary`，1.6s 脉冲）+ `62%`（`--ki-font-size-xs`，`tabular-nums` 固定位宽，防 tab 宽度抖动） |
| 终态（失败/部分完成） | 不做徽标：走既有顶栏任务徽标（`lib/taskNotice.ts` 口径），避免两处语义 |
| `prefers-reduced-motion` | 脉冲改静态实心点 |

### 3.3 侧栏合并项

| 项 | 规格 |
|---|---|
| 图标 | `edit`（与页名「知识写入」一致；`upload` 保留给导入 tab 的拖拽区，避免侧栏与页内同义重复） |
| 文案 | 知识写入 |
| 位置 | 原「上传导入」槽位（AI 对话之下、数据源之上） |
| 计数/徽标 | 无 |

### 3.4 复用组件（不改视觉）

`ScopePathSelect`、`GroupPathSelect`、Tags combobox、向量化 switch、Notice（只读提示）、`.ki-progress`（进度条）、`.ki-dropzone`、`.ki-md-editor`。

## 4. 视觉 token

**不新增任何 token**，全部取自 `web/src/styles/ki.css`：

| 用途 | token |
|---|---|
| 主色 / 选中底 / 进度 | `--ki-color-primary`、`color-mix(primary 10%)` |
| 文本 | `--ki-color-text`、`--ki-color-text-muted`、`--ki-color-text-subtle` |
| 容器 | `--ki-color-bg-secondary`、`--ki-color-surface`、`--ki-color-border` |
| 圆角 | `--ki-radius-sm`(6)、`--ki-radius-tag`(4)、`--ki-radius-track`(999) |

| 动效 | `--ki-motion-fast` |
