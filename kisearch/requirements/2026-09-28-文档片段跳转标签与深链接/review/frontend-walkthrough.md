# 前端走查报告：Markdown 在线编辑与跳转链接

> **走查对象**：`a582d3b`（`feat: 文档支持在线编辑`，已由 `b9e33a3` 合并进 master）+ 运行中的 Web 界面
> **取证档位**：A（可实操）—— `agent-browser`（真实 Chromium）+ 本机 daemon `ki mcp --http --daemon --host 127.0.0.1 --port 7423 --web`
> **证据声明**：本次最高证据等级 🟢，取证方式为**真实点击 / 真实选中 / 真实键盘操作 + 运行中 DOM 读数**；代码（`file:line`）仅用于穷举入口与判定"分支有无"，不作为体验判据。
> **边界**：只判断不改码；性能只到体检级；未触发任何写库操作（走查后复核文档 `revision` 与内容长度一致，详见附录 B）。

## 0. 直接回答用户提问："可以不选源码、直接选渲染好的文字吗？"

**可以，但当前实现只做了一半。**

现有链路：点击入口按钮的瞬间读取 `window.getSelection()`（`web/src/components/ModuleDrawer.tsx:466-473`）→ 把**选中字符串**传给编辑器 → 编辑器拿这个字符串去源码里做**纯字面 `indexOf`**（`web/src/components/DocumentEditor.tsx:63`）。

因此可用与否，完全取决于"渲染文字是否恰好是源码中一段连续字面文本"：

| 选中渲染文字 | 源码形态 | 实测结果 |
|---|---|---|
| `kisearch 对外 MCP 服务层` | 字面存在 | ✅ 可用：文案自动预填，源码中该段被选中（`taSel=[33,52]`，滚动到第 3 行） |
| `一句话职责：kisearch 对外 MCP 服务层`（跨粗体） | `- **一句话职责**：kisearch…` | ❌ 提示「不唯一或无法直接对应」，**选文与文案一起丢** |
| 跨两行/两个列表项（含 `\n`） | 中间隔着 `\n`、`- ` | ❌ **静默无反应**（`DocumentEditor.tsx:62` 直接 return） |
| 含行内代码 / 链接文字的选段 | `` `code` `` / `[](url)` | ❌ 同第一类，必然失败 |

结论：缺的不是"支持渲染态选文"这个开关，而是**一层"渲染位置 → 源码位置"的映射**。本仓目前无此类工具（全 `web/src` 搜 `data-source` / `sourceStart` / `sourceMap` / `mapRendered` 零命中）。

## 1. 执行摘要

1. 🟢 **入口与心智顺序相反**：必须先点抽屉头部「编辑 / 添加跳转」，选中文字本身不产生任何就地入口（实测选中后 `body > *` 中 position 为 fixed/absolute 的元素数为 0，`[class*=popup|float|bubble|toolbar|selection]` 命中 0）；且选区活不过任何一次其他点击（选中后点 `.ki-drawer__identity` → `getSelection()` 变空，编辑器里零提示）。
2. 🟢 **渲染态选文只有字面命中才可用**：跨格式必失败、跨行静默失败（见 §0）。
3. 🟢 **"没有插入点"时会写坏文档且提示失真**：从未在源码里落过光标时 `selection` 停在 `{0,0}`，插入落在**文首**，提示却写「已在光标位置插入跳转链接」。实测把文档 H1 吞成普通段落（预览 HTML 首行变为 `走查预览链接# MCP 服务专家 · 专题记忆路标`），且 `Ctrl+Z` 无法撤销。
4. 🟢 **预览页签选文完全无效，并会用"上一次源码选区"静默替换别处**：实测在预览里选 `多实例锁管理` 后点插入，被替换的是源码 `[33,52]`，提示「已替换选中内容为跳转链接」。
5. 🟢 **正向链路成立**：深链接冷启动实测打开目标文档并滚动定位（锚点 `p-16a55760a485d90c` → `body.scrollTop=307` + 2.4s `ki-anchor-target` 高亮）；失效锚点降级为「目标段落已变化或不存在。文档已打开，请重新选择位置。」；链接属性 `target="_blank" rel="noopener noreferrer"` 正确。
6. 🟢 **目标位置可选面过窄**：锚点只认 `h1~h6/p`（`web/src/lib/kiLinks.ts:57-64`），而本文档正文几乎全在 `li` 中 →「本文位置」实测仅 2 个候选（标题 + 一行生成信息），跨文档目标同样只有 2 个。需求 R2 想要的"段落/列表项"基本选不到。

## 附录 A：关键复现步骤（可复验）
